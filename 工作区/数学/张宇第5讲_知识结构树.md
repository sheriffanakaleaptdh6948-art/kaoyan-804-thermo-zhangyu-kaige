│  ├─ 整讲框架口诀："三种点、两种性态、一种线"（"三两一"）
│  │  ├─ 三种点：极值点 / 最值点 / 拐点 —— 均必考
│  │  ├─ 两种性态：单调性 / 凹凸性
│  │  └─ 一种线：渐近线（其中**斜渐近线考得最多**）

│  │  └─ 拐点线：凹凸性定义 → 拐点定义 → 二阶可导点是拐点必要条件(f''=0) → 判别拐点三充分条件

│  ├─ 最值存在性：闭区间连续函数**必有最值**；开区间不一定有，无最值时求**取值范围/值域**
│  ├─ 考情：考试不直接考"铅笔画图"，但命题靠**数形结合**——含参不等式、方程根问题须会画图辅助
│  ├─ 曲率/曲率半径：**数学一、二必考，重中之重**；数学三不考
│  ├─ 题型：选择题、填空题、解答题；重难点：极值点判别、拐点判别
│  └─ 目标：①极值概念+导数判单调求极值+最值求法 ②凹凸性+拐点+三类渐近线+描图 ③曲率曲率圆曲率半径（仅数一二）
│
├─【一】极值的定义（视频02；p146-147）
│  ├─ 定义：∃x0 的某邻域，邻域内任意 x 均有 f(x)≤f(x0)(或≥) → x0 为极大(小)值点，f(x0) 为极大(小)值
│  ├─ 注① 局部概念：只与"这一点和它旁边的点"比大小
│  ├─ 注② 双侧邻域前提 → **区间端点不讨论极值**（左端点无左邻域）；同理端点也不讨论间断点
│  │  └─ 这是第6讲证明题要"排除/讨论端点"的前提
│  ├─ 注③ 等号意义：**常函数处处是极大值也处处是极小值**（选择题反例素材）
│  ├─ 注④ 理想极值点（左减右增/左增右减）**不是必要条件**：只要两边点都不比它高即可
│  ├─ 重要：**极值点可以是间断点**（可去/跳跃/无穷/振荡四类均可，因定义只要求点及两边有定义可比较）
│  │  └─ 教材4例(p147)：可去型取1为极大值点 / 跳跃型取-1为极小值点 / 无穷型取-1为极小值点 / 振荡型取2为极大值点
│  └─ 易错：中学"左减右增才叫极值"只对初等函数成立，引入非初等函数后失效
│
├─【二】单调性与极值的判别（视频03；p147-151，本讲主体之一）
│  ├─ 1. 单调性的判别（p147）
│  │  ├─ 定理：f 在[a,b]连续、(a,b)可导；f'≥0 且等号仅在**有限个点**成立 → 严格单增；f'≤0 同理严格单减
│  │  └─ 反向不成立：严格单增不一定 f'>0（例 y=x³ 单增但 f'(0)=0）；"一点导数>0 只决定该点信息，决定不了区间单调性"
│  ├─ 2. 费马定理（一阶可导点是极值点的必要条件，p148，证明在第六讲）
│  │  ├─ 定理：f 在 x0 可导且取极值 → f'(x0)=0
│  │  └─ 注：f'(x0)=0 仅说明 f(x)-f(x0) 是 x-x0 的高阶无穷小，不说明没变化（y=x³）；仅为必要条件
│  │  └─ 找极值两类点：**①驻点(f'=0) ②不可导点**（如 |x| 尖点；可不连续）
│  ├─ 3. 判别极值第一充分条件（p148）：f 在 x0 连续 + 去心邻域可导
│  │  ├─ 左 f'<0 右 f'>0 → 极小值；左 f'>0 右 f'<0 → 极大值；左右不变号 → 非极值
│  │  └─ 注：**不要求 x0 可导**（可出现角点/尖点）
│  ├─ 4. 判别极值第二充分条件（p148-149）：f 在 x0 二阶可导，f'(x0)=0，f''(x0)≠0
│  │  ├─ f''(x0)<0 → 极大值；f''(x0)>0 → 极小值
│  │  └─ 证明用导数定义+局部保号性（**方法考试要求必记**）
│  ├─ 5. 判别极值第三充分条件（p149）：前 n-1 阶导全0、f^(n)(x0)≠0，**n 为偶数** → 极值点（n 偶且 <0 极大，>0 极小）
│  │  └─ 证明用洛必达/泰勒（考纲不要求）；实际计算一般不会到四阶，理论可能考
│  ├─ 方法选择：**一点信息强(二阶可导) → 第二充分条件；一点信息弱(连可导都不讲) → 第一充分条件**
│  └─ 例题索引
│     ├─ 例5.1 (p149-150) f 可导且 f·f'>0 → **选C |f(1)|>|f(-1)|**
│     │  └─ 关键一步"逆运算"：[(f²)]'=2ff'>0 → f² 单调增 → 开方加绝对值 √(f²)=|f|（**平方开根号加绝对值=重要考点**）
│     ├─ 例5.2 (p150) f 二阶可导在 x0 取极大值 → **选B f''(x0)≤0**
│     │  ├─ 反例 f=-x⁴：0 点极大值但 f''(0)=0（**充分条件不可逆，漏掉等号=严重扣分**）
│     │  └─ f''(x0)<0 是"f'(x0)=0 且取极大"的充分不必要条件
│     ├─ 例5.3 (p150) 隐函数 y³+xy²+x²y+6=0 求极值
│     │  ├─ 令 y'=0 → y(y+2x)=0；y=0 舍去（代回 6=0 矛盾）；y=-2x → x=1，y(1)=-2
│     │  └─ 二边再求导代 x=1,y=-2,y'=0：**y''(1)=4/9>0 → 极小值点 x=1，极小值 y(1)=-2（已验证）**
│     └─ 例5.4 (p150-151) f=x·e^x 求 f^(n) 的极值
│        ├─ 承例4.17：f^(n)(x)=(n+x)e^x；f^(n+1)(x)=(n+1+x)e^x
│        ├─ 令 f^(n+1)=0 → 驻点 **x=-(n+1)**；f^(n+2)[-(n+1)]=e^(-n-1)>0 → 极小值点
│        └─ 极小值 f^(n)[-(n+1)]=**-e^(-(n+1))**（已验证）
│
├─【三】凹凸性与拐点的概念（视频04；p151-152）
│  ├─ 凹凸性定义1（弦中点法，**考纲统一规定**，p151）
│  │  ├─ 曲线中点 < 弦中点 → **凹**；> → **凸**（只叫凹/凸，不叫上凸/下凸）
│  │  ├─ ½ 可推广为凸组合：f(λ₁x₁+λ₂x₂) <(>) λ₁f(x₁)+λ₂f(x₂)，λ₁+λ₂=1，λᵢ>0
│  │  └─ 定义1**只要求连续**，不需可导
│  ├─ 凹凸性定义2（切线法，p152，**重要不等式考点**）
│  │  ├─ 切线上值 f(x0)+f'(x0)(x-x0) < f(x) → 凹（切线在曲线下方）；> → 凸
│  │  └─ 定义2**要求可导**（涉及切线）
│  └─ 拐点定义（p152）：连续曲线的**凹弧与凸弧的分界点**
│     ├─ 拐点处**必须连续**，但不要求可导；凹凸不分先后
│     ├─ **拐点写两个坐标 (x0,f(x0))**；极值点只写横坐标 x=x0（选择题陷阱点）
│     └─ 反例纠错：日常"房价拐点"（涨到顶开始降）是极大值点，不是拐点
│
├─【四】凹凸性与拐点的判别（视频05；p152-155）
│  ├─ 1. 凹凸性判别（p152）：f 二阶可导，f''>0 → 凹；f''<0 → 凸
│  │  └─ 记忆：凹=碗口朝上，东西掉进碗里是"加"(正) → f''>0 凹；倒扣碗东西掉出是"减"(负) → f''<0 凸
│  ├─ 2. 二阶可导点是拐点的必要条件：f''(x0)=0（与极值 f'(x0)=0 对比记忆）
│  │  └─ 拐点只两类点：①f''(x0)=0（如 x³ 的(0,0)）②f''(x0)不存在（如 ³√x 的(0,0)，一阶也不存在）
│  ├─ 3. 判别拐点第一充分条件（p153，**最常用的方法**）：x0 连续 + 去心邻域二阶导存在 + 左右 f'' 变号 → 拐点
│  │  └─ 与极值对比：极值点=连续+**一阶导**变号；拐点=连续+**二阶导**变号
│  ├─ 4. 判别拐点第二充分条件（p153-154）：f 在 x0 三阶可导，f''(x0)=0，f'''(x0)≠0 → 拐点（证明用三阶导定义+保号性）
│  ├─ 5. 判别拐点第三充分条件（p154）：前 m=2..n-1 阶全0、f^(n)(x0)≠0，**n 为奇数 → 拐点**
│  │  ├─ 注意：拐点从**二阶导**开始数（不看一阶），**不要求 f'(x0)=0**（与极值错位一个）
│  │  └─ 例：一至三阶全0、四阶≠0(n偶)→极值点；二至四阶全0、五阶≠0(n奇)→拐点
│  └─ 例题：例5.5 (p154-155) f 满足 f''+[f']²=sinx 且 f'(0)=0 → **选C (0,f(0))是拐点**
│     ├─ 令 x=0：f''(0)=0；求导 f'''+2f'f''=cosx，x=0：f'''(0)=1≠0 → 第二充分条件(n=3奇数)
│     └─ 隐含条件（书上批注，重点）：关系式每项可导 → 可推出 f **任意阶可导**（递推）；"拐点在可导点处必不是极值点"由五①知A/B错
│
├─【五】极值点与拐点的重要结论（视频06；p155-157，结论可直接用不必证明，选择题送分）
│  ├─ 结论① 曲线的**可导点**不可同时为极值点和拐点；**不可导点可同时**为极值点和拐点
│  ├─ 结论② 多项式 f(x)=(x-a)^n·g(x)，g(a)≠0：n 为**偶数** → x=a 是极值点；n 为**奇数** → 点(a,0)是拐点
│  │  └─ 辅助：α 是 f(x)=0 的 m 重根 → α 是 f'(x)=0 的 m-1 重根
│  ├─ 结论③ 计数公式（p155，核心）：f=(x-a₁)^n₁···(x-aₖ)^nₖ，aᵢ 两两不等
│  │  ├─ k₁=nᵢ=1 的个数；k₂=nᵢ>1 且为偶数的个数；k₃=nᵢ>1 且为奇数的个数
│  │  ├─ **极值点个数 = k₁ + 2k₂ + k₃ − 1**
│  │  └─ **拐点个数 = k₁ + 2k₂ + 3k₃ − 2**
│  ├─ 考情：此类题**只会命选择题**（无过程要求，记结论省大量时间）；"重要结论"好久没考，2027 考生要重视
│  └─ 例题索引
│     ├─ 例5.6 (p155-156) y=|x·e^(-x)| → **选D**：x=0 极小值点 + (0,0) 拐点（**不可导点同时为极值和拐点**，实证结论①）
│     │  ├─ 绝对值函数=分段函数，先写成分段再分析；y≥0 且仅 x=0 为 0 → 极小值（定义判）
│     │  └─ 承例4.6 得 y'' 分段；x=0 左右 y'' 变号 → 拐点；另 (2, y(2)) 也是拐点（题未问）
│     ├─ 例5.7 (p156) y=(x-1)(x-2)²(x-3)³(x-4)⁴ 的一个拐点 → **选C (3,0)**
│     │  └─ 用结论②：n=3 奇数 → 拐点（常规法需算三重根→单根→变号，慢）
│     └─ 例5.8 (p156-157) f=(x-1)²(x-3)³ 拐点个数 → **选D 3**（k₁=0,k₂=1,k₃=1 → 0+2+3-2=3）
│        └─ 附问 (x-1)²(x-3)² 极值点与拐点个数 → **选A 3,2**（k₁=0,k₂=2,k₃=0 → 极值=4-1=3，拐点=4-2=2）
│
├─【六】渐近线（视频07；p157-160，**几乎一定出题**）
│  ├─ 概念：曲线上的点远离原点时与某直线充分靠近，该直线为渐近线（3 种，均为直线）
│  ├─ 1. 铅直渐近线（p157）：lim(x→x0±)f(x)=∞ → x=x0
│  │  └─ x0 来源：**无定义点、定义区间端点、分段函数分段点**，逐个验极限
│  ├─ 2. 水平渐近线（p157）：lim(x→±∞)f(x)=y₀ → y=y₀；正负方向各自独立，可相同（e^(-|x|)）可不同（arctan x）
│  ├─ 3. 斜渐近线 y=ax+b（p158，**考得最多**）
│  │  ├─ a=lim f(x)/x，要求 **a 为非零常数**（a=0 即退回水平渐近线）
│  │  ├─ b=lim [f(x)-ax]，要求 **b 存在**（是 0 也可，但必须存在）
│  │  ├─ a 存在非零 ⟺ f 与 x 同阶无穷大；比 x 快得多(e^x/x^(3/2))或慢得多(lnx)都无斜渐近线
│  │  └─ 同方向有水平渐近线则必无斜渐近线
│  ├─ 寻找程序（注3+p159流程图）：①无定义/端点/分段点 → 验铅直 ②lim f 为常数 → 水平 ③若为∞ 算 a=lim f/x，a 非零常数再算 b，**a、b 都在才得斜渐近线**（正负方向分别讨论）
│  ├─ 重要细节
│  │  ├─ **曲线与渐近线可以有交点**（不能认为渐近线不相交，例 y=sinx/x）
│  │  └─ 反例警示：y=x+sinx，a=lim(x+sinx)/x=1，但 b=lim sinx **不存在** → 无斜渐近线（真题选项）
│  └─ 例题：例5.9 (p159-160) y=1/x+ln(1+e^x) → 3 条渐近线：**x=0（铅直）、y=0（x→-∞水平）、y=x（x→+∞斜）**
│     ├─ 关键恒等变形：ln(1+e^x)=ln[e^x(1+e^-x)]=x+ln(1+e^-x)（本题难点在极限计算关）
│     └─ b=lim[f(x)-x]=lim[1/x+ln(1+e^-x)]=0
│
├─【七】最值或取值范围（视频08；p160-162）
│  ├─ 定义3（p160）：定义域内任意 x，f(x)≤(≥)f(x0) → f(x0) 为最大(小)值
│  ├─ 极值与最值关系（p160-161）
│  │  ├─ 最值点不一定是极值点（e^x 在 [0,+∞)，x=0 是最小值点但无双侧邻域、**不讨论极值**）
│  │  ├─ 极值不一定是最值（3x-x³ 有极大2极小-2 但无最值）
│  │  └─ **重要结论：最值点若在区间内部(非端点) → 必是极值点**（证明：内部点必有邻域 ⊂ 区间，由极值定义即得）——以后大题常用
│  ├─ 闭区间连续求最值（p161）：找三种"可疑点"——**驻点 + 不可导点 + 端点**，比较全部函数值
│  │  └─ 注：可命制成"求值域 [m,M]"
│  ├─ 开区间求最值或取值范围（p161）：内部找可疑点；**端点取得到就取值，取不到就取极限**（单侧极限，∞ 则对应铅垂渐近线）
│  ├─ 实际问题（注2）：建立目标函数 → 确定定义区间；若有最值且目标函数**唯一极值点** → 该极值即最值
│  └─ 例题：例5.10 (p161-162) 数列最大项 ⁿ√n → **第3项 ³√3**
│     ├─ 连续化 f(x)=x^(1/x)=e^(lnx/x)，f'=x^(1/x)(1-lnx)/x²，唯一驻点 x=e；x<e 增 x>e 减
│     ├─ 端点：x→0⁺→0，x→+∞→1（水平渐近线 y=1）；最大值 f(e)=e^(1/e)≈1.4447
│     ├─ **离散化**：e≈2.7 非整数，就近比较第2与第3项——(√2)⁶=8 < (³√3)⁶=9 → ³√3 更大（**同次方比较避免死记数值**）
│     └─ 方法：数列最值=只看最值点两侧的整数项谁大（已验证）
│
├─【八】作函数图像（视频09；p162-165，张宇称"微分学最重要的应用"）
│  ├─ 一般步骤（p162）
│  │  ├─ ①定义域（最好值域）+ 奇偶性/周期性 + 用好图像变换（对称性减半工作量）
│  │  ├─ ②一阶导定单调/极值（f'=0 及不存在的点，看左右符号）；二阶导定凹凸/拐点（f''=0 及不存在的点）
│  │  ├─ ③渐近线（曲线能否远离原点；有界图必无渐近线）
│  │  └─ ④画图
│  ├─ 图像变换（附录1，**每个都要记**）
│  │  ├─ 平移：f(x+c) 左移 c；f(x)+c 上移

## 附录B：新增结论 / 公式积累

- 极值/拐点计数公式：极值点个数 = k₁+2k₂+k₃−1；拐点个数 = k₁+2k₂+3k₃−2（k₁=nᵢ=1 个数，k₂=偶>1 个数，k₃=奇>1 个数）
- 可导点不可同时为极值点和拐点；不可导点可同时
- (x-a)^n·g(x)，g(a)≠0：n 偶→极值点，n 奇→拐点
- 内部最值点必是极值点（最值=内部点 ⇒ 是极值）
- 端点不讨论极值、也不讨论间断点（双侧邻域前提）
- 极值点可以是间断点（可去/跳跃/无穷/振荡均可）
- 幂指函数 x^x：x→0⁺ → 1；x=1/e 处极小值（即最小值）；恒凹无拐点
- e^x/x：极小值 e 在 x=1；渐近线 y=0、x=0
- 例5.4 结论：f^(n)(x)=(n+x)e^x 的极小值点 x=-(n+1)，极小值 -e^(-(n+1))
- 例5.11 结论：星形线 y²=(1-x²)³ 第一象限拐点 (√2/2, (1/2)^(3/2))
- 曲率公式 k=|y''|/[1+(y')²]^(3/2)，曲率半径 ρ=1/k（仅数一二，必考）
- 习题5.3 结论：约分改变渐近线——(x²+x)/(x²-1)=x/(x-1)，x=-1 非渐近线
