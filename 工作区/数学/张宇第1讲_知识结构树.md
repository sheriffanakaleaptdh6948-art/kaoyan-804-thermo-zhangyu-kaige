├─【一】函数的概念与特性（视频02-03）
│  ├─ 1. 函数概念
│  │  ├─ 定义：对每个 x 有唯一确定的 y 对应（考研默认单值函数）
│  │  ├─ 定义域 = 实际背景 + 对应法则两方面确定
│  │  └─ 单值 vs 多值：铅垂画线法（任意铅垂线与曲线至多一个交点）
│  ├─ 2. 反函数
│  │  ├─ 前提：先过铅垂画线（单值）
│  │  ├─ 判别：水平画线法（任意水平线至多一个交点）
│  │  ├─ 口诀：铅垂画线定单多，水平画线定反值
│  │  ├─ 严格单调必有反函数（充分非必要；反函数不一定单调）
│  │  ├─ 图像关于 y=x 对称的真相 = 交换字母，不是反函数本身的属性
│  │  └─ 逆运算：f(f⁻¹(x))=x，f⁻¹(f(x))=x
│  ├─ 3. 复合函数
│  │  ├─ 概念：f(u), u=g(x) -> f(g(x))（可多层）
│  │  └─ 大纲要求：概念理解即可，重点掌握"复合的方法"
│  ├─ 4. 隐函数
│  │  ├─ 定义：F(x,y)=0 在某区间唯一确定 y（多值则不能确定隐函数）
│  │  ├─ 求 y(x₀)：不用显化，直接代 x₀ 解只含 y 的方程（定初始值，常考）
│  │  └─ 观察法：口诀"解无定法，观察得知"（真题出现过：x=2 代入后 y=1 显然）
│  ├─ 5. 函数四种特性（double star / triple star，太重要）
│  │  ├─ 有界性
│  │  │  ├─ 定义：存在 M>0，|f(x)|≤M；必须指明区间（不谈区间无法谈有界）
│  │  │  ├─ 证明有界：找一个正数 M + 不等式（常用均值不等式）
│  │  │  └─ 例题1.6：证 x/(1+x²) 在 R 上有界（|x|+1/|x|≥2 -> 界 1/2）
│  │  │     └─ 易错：x²=|x|² 但 x³≠|x|³（可正可负）
│  │  ├─ 单调性
│  │  │  ├─ 严格增/减 vs 单调不减/不增（带等号=非严格）
│  │  │  ├─ 等价判别：(x₁−x₂)(f(x₁)−f(x₂))>0 ⇔ 严格单调增
│  │  │  └─ 例题1.7：图像变换四题 -> 答案 D（−f(−x) 保单调）
│  │  │     └─ 串联图像变换：|f(x)|翻下 / f(|x|)内偶则偶 / f(−x)关于y轴对称 / −f(−x)原点对称
│  │  ├─ 奇偶性（四大特性里最重要：题目好出 + 对称美）
│  │  │  ├─ 前提：定义域关于原点对称
│  │  │  ├─ f(x)+f(−x) 必偶；f(x)−f(−x) 必奇（双曲正/余弦，反双曲正切）
│  │  │  ├─ 定理：任何函数 = 偶函数 + 奇函数
│  │  │  ├─ 复合口诀：内偶则偶，内奇同外
│  │  │  ├─ 可导的奇/偶函数求导后奇偶互换（例题3.1 证明）
│  │  │  ├─ 可积奇函数零下限变限积分是偶函数，反之是奇函数（例题9.23）
│  │  │  └─ 例题1.8：函数方程 f(x+y)=f(x)+f(y) -> 证奇函数（先取(0,0)得 f(0)=0）
│  │  └─ 周期性
│  │     ├─ 定义：f(x+T)=f(x)，默认找最小正周期
│  │     ├─ f(ax+b) 以 T/|a| 为周期（b 不影响）
│  │     ├─ g 周期 -> 复合 f(g(x)) 也周期（如 e^sinx 周期 2π；cos²x 周期 π）
│  │     ├─ 可导周期函数求导仍周期且周期不变（第三讲证明）
│  │     ├─ 连续周期函数变限积分：以 T 为周期 ⇔ 一个周期积分值 = 0（第九讲）
│  │     └─ 例题1.9：由关系式证 f 以 2π 为周期（定义法算 f(x+2π)）
│  ├─ 6. 双曲三兄弟（由例题1.3 引出，2023 真题直接考展开式）

├─【二】函数的图像（视频04-05）
│  ├─ 0. 基本初等函数六类：常数 + 反对幂指三（反三角、对数、幂、指数、三角）
│  │  └─ 初等函数 = 六类经有限次四则运算 + 复合、可用一个式子表达
│  ├─ 1. 常数函数 y=a
│  │  └─ 用途：方程实根个数问题 -> 转成水平线 y=a 与曲线交点个数
│  ├─ 2. 幂函数 y=x^μ
│  │  ├─ 定义域依 μ 而定（x>0 处处有定义；√x 要 x≥0；1/x 要 x≠0）
│  │  ├─ 考研核心：单调性 + 最值点（最值技巧四条）
│  │  │  ├─ ① √U 或 U^(1/3) -> 直接研究 U（单调增保持最值点）
│  │  │  ├─ ② 见绝对值 -> 用 U² 研究（最爱考）
│  │  │  ├─ ③ 多项乘除/开方/乘方 -> 先取对数（爱考）
│  │  │  └─ ④ 1/U -> 最值点与 U 相反
│  │  └─ 例题1.10：0<x<1/2 求 x⁶(1−x)²(1−2x)⁴ 最大值点（取对数 -> 驻点 -> (7−√13)/12）
│  │     └─ 伏笔：链式求导、导数应用、压轴大题前身
│  ├─ 3. 指数函数 y=a^x（a=e 最重要）
│  │  ├─ a>1 增 / 0<a<1 减；恒正（放心放根号/分母）
│  │  ├─ 极限唯一性：lim_{x→∞} e^x 不存在（必须分 +∞→+∞ / −∞→0 单侧写）
│  │  ├─ e^x−1 写成 e^x−e⁰（统一美 -> 可接拉格朗日中值定理）
│  │  └─ 指数法则 + 提公因式：e^tanx−e^sinx=e^sinx(e^(tanx−sinx)−1)
│  ├─ 4. 对数函数 y=lnx
│  │  ├─ 真数 x>0；e≈2.7
│  │  ├─ 口诀：积变和、商变差、幂次变倍数
│  │  ├─ ln1 补一（ln(xⁿ)−ln1）-> 统一美 -> 拉格朗日
│  │  └─ 例题1.11：x·[ln(e+1/x)−1] 的极限（ln1 补一 + 等价无穷小 -> 答案 1，不必洛必达）
│  │     └─ 思想：e^x 展开式 -> "用简单逼近复杂" = 泰勒思想（e^x≥1+x）
│  ├─ 5. 三角函数
│  │  ├─ sin/cos：一拱面积=2；0 到 π 四等分中间两块各 √2/2
│  │  ├─ 放缩：x→0 用 sinx≤x，别用 sinx≤1（放得过大会失效）
│  │  ├─ tan/cot：渐近线 x=±π/2（这些无定义点=无穷间断点预告）；见 tanx 写成 sin/cos
│  │  └─ sec/csc：倒数作图法；重点恒等式 1+tan²x=sec²x
│  ├─ 6. 反三角函数
│  │  ├─ 主值区间：arcsin∈[−π/2,π/2]，arccos∈[0,π]；arcsin+arccos=π/2
│  │  ├─ 恒等式4条（含 sin(arccosx)=√(1−x²)，令中间变量 t 证）
│  │  ├─ 例题1.12：0≤x≤2π 求 sinx 各单调区间反函数（规则美：回到主值区间）
│  │  │  ├─ [0,π/2]：x=arcsin y
│  │  │  ├─ [π/2,3π/2]：x=π−arcsin y
│  │  │  └─ [3π/2,2π]：x=2π+arcsin y（伏笔二重积分"后积先定限"）
│  │  └─ arctan 单调性隐蔽考法：arctan b_n − arctan a_n = a_n>0 -> b_n>a_n
│  │     └─ 经验：题目给的关系式做了逆运算 -> "他往东你往西，他往南你往北"
│  ├─ 7. 初等函数定义
│  │  ├─ "六个基本初等函数经有限次四则运算+有限次复合、可用一个式子表达"
│  │  ├─ 定义域可以是区间并/孤立点（√(cosπx−1) 定义域为全体偶数）
│  │  └─ 幂指函数是初等：x^x=e^(x·lnx)，最小值点 x=1/e（预告）
│  └─ 8. 分段函数（考研重要研究对象，形式复杂=>命题丰富）
│     ├─ 绝对值 |x|：既是分段也是初等（|x|=√x²，特例）；= x 到 0 的距离
│     ├─ 符号函数 sgn x：x=0 处跳跃间断点；x=|x|·sgn x
│     ├─ 取整函数 [x]（double/triple star）
│     │  ├─ 定义：不超过 x 的最大整数（[−1.99]=−2，不是 −1）
│     │  ├─ 性质1：[x+n]=[x]+n（整数可进出）
│     │  ├─ 性质2：x−1<[x]≤x
│     │  └─ 性质3：x→0⁺ 时 [x]→0，x→0⁻ 时 [x]→−1
│     └─ 小数部分函数 y=x−[x]：周期 1，{−1.99}=0.01；每块面积 1/2
│
├─【三】函数极限的概念与性质（视频06-11）
│  ├─ 1. 邻域
│  │  ├─ δ 邻域 (x0−δ, x0+δ)；去心邻域（抠掉 x0）；左/右邻域
│  │  └─ 伏笔："附近"到底多近多远 -> 说不清 -> 引出超实数
│  ├─ 2. 函数极限 ε-δ 定义（维尔斯特拉斯）
│  │  ├─ 文字版：去心邻域有定义 + 任给 ε>0 存在 δ>0，0<|x−x0|<δ 时 |f(x)−A|<ε
│  │  ├─ 图解：条带收缩，曲线被夹进无限窄的带内（δ 随之趋零）
│  │  ├─ 意义：解决牛顿/莱布尼兹两百年没搞清的"无穷小到底是什么"
│  │  └─ 例：(x−sinx)/x³ 到零的距离都不知道，但结果 1/6 算得出 = 极限的意义
│  ├─ 3. 超实数系（张宇独门理解工具，贯穿全讲）
│  │  ├─ 数系扩展史：有理数->实数(√2)->复数(√−1)->超实数(无穷小/无穷大)
│  │  ├─ 光环/核模型：每个实数 x0 自带光环（无数个以它为核的超实数）
│  │  │  └─ 超实数 = 标准实数部分 std + 非零无穷小量
│  │  ├─ 非零无穷小量：不在实数系（"此X非彼X"）；其倒数为无穷大量
│  │  └─ 运算两步走铁律（全课最重要的操作法则）
│  │     ├─ 第一步：实数运算（恒等变形，写等号必须是恒等变形）
│  │     ├─ 第二步：趋核运算（取极限，核唯一）
│  │     └─ 反例：sinx/x 是 1 的光晕不是 1，中途先取极限再算 = 错误
│  ├─ 4. 24 个极限定义表（6 趋向 x4 趋核）
│  │  ├─ 趋向方式六种：x→x0⁺/x→x0⁻/x→x0/x→+∞/x→−∞/x→∞
│  │  ├─ 函数趋向四种：→a / →∞ / →+∞ / →−∞
│  │  └─ 记忆法：第一行第一列解决，任意组合可推（要求课后自己填表）
│  ├─ 5. 极限的唯一性 + 充要条件
│  │  ├─ 每个超实数在数轴上有唯一归宿（唯一特例：常数以自己为归宿）
│  │  ├─ 充要条件1：左右极限存在且相等（自变量双向性！）
│  │  │  └─ 四个必分方向函数：e^x、sinx/|x|、arctanx、[x]（+分段函数）
│  │  └─ 充要条件2：脱帽法 f(x)=A+非零无穷小量 α(x)
│  │     └─ 注意：极限值与 f(x0) 天生无关（"不要自己给自己加连续的条件"）
│  ├─ 6. 局部有界性
│  │  ├─ 定理：极限存在 -> 趋向过程有界（充分非必要，反例 sinx）
│  │  ├─ 抽象证明必会：f(x)=(f(x)−A)+A，三角不等式，取 ε=1 -> M=1+|A|
│  │  ├─ 注2：闭区间上连续函数必有界（后面证）
│  │  ├─ 注3：开区间两端极限存在 -> 开区间内有界（例题1.17 核心方法）
│  │  └─ 例题1.17：x·sin(x−3)/[(x−1)(x−3)²] 在哪个开区间有界 -> 选 B(−1,0)
│  │     └─ 口诀："极限存在必然有界"；"纸老虎"
│  ├─ 7. 局部保号性（三大性质里最重要）
│  │  ├─ 定理1（脱帽法，严格）：lim f=A>0 -> 去心邻域内 f(x)>0（取 ε=A/2 证）
│  │  ├─ 定理2（戴帽法，非严格）：f(x)≥0 且极限存在 -> A≥0（必须带等号）
│  │  ├─ 口诀：脱帽法不能带等号；戴帽法抽象问题一定带等号
│  │  │  └─ 真题教训："把等号扔掉，就把分数扔掉了"
│  │  └─ 例题1.18：lim f(x)/(1−cosx)=−1 -> f(x)<0（选 D；由极限负推保号）
│  ├─ 8. 无穷小理论
│  │  ├─ 定义：f(x)→0 为该趋向的无穷小量；唯一例外是 0 本身（最高阶无穷小）
│  │  ├─ 性质1：有限个无穷小之和是无穷小（无限个不成立：1/(n+1)+…+1/(n+n)→ln2）
│  │  │  └─ "人多力量大"
│  │  ├─ 性质2：有界函数 x 无穷小 = 无穷小（|α|≤M，夹逼）
│  │  ├─ 性质3：有限个无穷小之积是无穷小（作业；无限个不成立）
│  │  ├─ 比阶（核心：谁先趋零谁高阶）
│  │  │  ├─ 高阶：lim α/β=0（分子趋零快）
│  │  │  ├─ 低阶：lim α/β=∞
│  │  │  ├─ 同阶：=非零常数 c（阶相同，如田径场百米）
│  │  │  ├─ 等价：=1（同阶中 c=1 的特例；等价≠相等）
│  │  │  ├─ K 阶：α/βᵏ=非零常数
│  │  │  └─ 不可比阶：α=x·sin(1/x) 与 β=x²（孙悟空上天入地回到人间）
│  │  ├─ 常用等价无穷小（x→0，9 条要背 + 广义化）
│  │  │  ├─ sinx~x / tanx~x / arcsinx~x / arctanx~x
│  │  │  ├─ ln(1+x)~x / e^x−1~x
│  │  │  ├─ 1−cosx~(1/2)x²（唯一常记的二次方）
│  │  │  ├─ a^x−1~x·lna / (1+x)^α−1~αx
│  │  │  └─ 广义化（triple star）：G(x)→0 时 e^(G(x))−1~G(x)（"super dog 超级小狗"）
│  │  └─ 无穷大
│  │     ├─ 非零无穷小之倒数是无穷大（反之亦然）
│  │     ├─ 1÷0 叫不存在，不叫无穷大（无穷小必须非零）
│  │     └─ 无界变量 vs 无穷大：无穷大始终天上/地下；无界像孙悟空能回人间
│  │        └─ 结论：无穷大必无界，但无界不一定无穷大（易错）

├─【四】函数极限的计算（视频12-14，重头戏）
│  ├─ 0. 总纲：七种未定式 = 极限计算全部
│  │  ├─ 0/0、∞/∞、0·∞、∞−∞、1^∞、0^0、∞^0
│  │  └─ 四大题型：直接计算 / 反求参数 / 已知一极限求另一 / 无穷小比阶（考最多）
│  ├─ 1. 第一步：化简先行（拿到题先化简，别急着洛必达泰勒）
│  │  ├─ 提极限不为零的因式（只能在乘除位置）
│  │  ├─ 做好等价无穷小代换
│  │  └─ 恒等变形：提公因式 / 拆项 / 分子分母同除最高次（找带头大哥）/ 换元
│  │     └─ 换元要两换（表达式 + 极限号下一起换）
│  ├─ 2. 方法一：极限四则运算
│  │  ├─ 前提：拆开后的两个极限必须是实数（存在）
│  │  ├─ 超实数解释：sinx/x 是 1 的光晕，不能当 1 拆
│  │  ├─ 等价替换真相：不是"换"，是分子分母同乘/除一个极限为 1 的因式
│  │  ├─ 例题1.20：lim f/g=A 且分母→0 -> 分子→0；A≠0 且分子→0 -> 分母→0
│  │  └─ 例题1.21：已知极限反求参数（sinx/[(e^x−a)(cosx−b)]=5 -> a=1, b=−4）
│  ├─ 3. 方法二：洛必达法则
│  │  ├─ 三条件：0/0 或 ∞/∞；去心邻域可导且分母导数≠0；求导后极限存在或∞
│  │  ├─ 后验逻辑：求导结果存在 -> 原式存在（反着不成立）
│  │  │  └─ 反例：x²sin(1/x)/x 求导后震荡不存在，但原极限 =0（不能正用洛必达）
│  │  ├─ 可连续多次使用
│  │  ├─ 例题1.22：新增等价无穷小 ln(x+√(1+x²))~x（反双曲正弦）
│  │  ├─ 例题1.23：(1−cosx)^a~(a/2)x²（推广）
│  │  └─ 无穷大比阶（要背）：
│  │     ├─ 连续版：x→+∞ 时 (lnx)^α << x^β << a^x（x^x 最大）
│  │     └─ 数列版：(lnN)^α ≤ N^β ≤ a^N ≤ N! ≤ N^N
│  ├─ 4. 方法三：泰勒公式（命题老师眼中远优越于洛必达，"一站直达"）
│  │  ├─ 思想：所有可导函数由幂函数组成（泰勒火眼金睛），无限逼近写等号
│  │  ├─ 要背 8 个展开式（每天起床头件事，先背一遍展开式）
│  │  │  ├─ sinx = x − x³/6 + o(x³)
│  │  │  ├─ cosx = 1 − x²/2 + x⁴/24 + o(x⁴)
│  │  │  ├─ e^x = 1 + x + x²/2 + o(x²)
│  │  │  ├─ ln(1+x) = x − x²/2 + x³/3 − … 
│  │  │  ├─ secx = 1 + x²/2 + o(x³)
│  │  │  ├─ 1/(1+x²) = 1 − x² + x⁴ − …
│  │  │  └─ arcsin / arctan / (1+x)^α（要求背全，本讲未展开写）
│  │  ├─ 差函数等价无穷小（重点）
│  │  │  ├─ x−sinx ~ x³/6；arcsinx−x ~ x³/6
│  │  │  ├─ tanx−x ~ x³/3；x−arctanx ~ x³/3
│  │  │  ├─ 口诀：狗减 sin狗 ~ 六分之一狗³；狗减 tan狗 ~ 三分之一狗³
│  │  │  └─ 广义化：g(x)→0 即可套用
│  │  ├─ 高阶无穷小运算 3 条
│  │  │  ├─ 加减：低阶吸收高阶（o(x²)±o(x³)=o(x²)）
│  │  │  ├─ 乘法：阶数累加（o(x²)·o(x³)=o(x⁵)）
│  │  │  └─ 非零常数不改变阶（2·o(x²)=o(x²)）
│  │  │     └─ 易错：o(x²)−o(x²)=o(x²) ≠ 0（真题考过！记号运算不是数量运算）
│  │  └─ 展开原则
│  │     ├─ A/B 型：上下同阶（分母 K 次，分子展到 K 次）
│  │     └─ A−B 型：分别展到系数不相等的 X 的最低次幂
│  │        └─ 例：[cosx−e^(−x²/2)]/(Ax^B) -> A=−1/12, B=4
│  ├─ 5. 两个重要极限（广义化）
│  │  ├─ sinx/x→1（狗→0 时 sin狗/狗→1）
│  │  └─ (1+1/x)^x→e（狗→∞ 时 (1+1/狗)^狗→e）
│  ├─ 6. 七种未定式逐个击破
│  │  ├─ 0/0：例题1.24 [(1+x)^(1/x)−1]/x
│  │  │  └─ 幂指写 e^(vlnu) -> 提公因式 -> 洛必达或泰勒 -> 答案 −e/2（别丢 e）
│  │  │     └─ 新增结论：(1+x)^(1/x)−e ~ −x/2（x→0⁺）
│  │  ├─ ∞/∞：例题1.25 多项式之比（找带头大哥）
│  │  │  ├─ 次数相等：极限=最高次项系数比 a_n/b_n
│  │  │  ├─ 分子次数高：∞；分母次数高：0
│  │  │  └─ 技巧：补带头大哥（0·xⁿ，不能见人）；x→∞找最高次，x→0找最低次
│  │  ├─ 无穷小 x 无穷大：例题1.28 lnx·ln(1−x)（x→1⁻）
│  │  │  ├─ 设置分母：口诀"简单因式才下放"（x^α、e^βx 下放；ln、反三角不放）
│  │  │  ├─ 推广公式：lnx~x−1（x→1）；ln(1−x)~−x 要求 x→0，本题不适用
│  │  │  └─ 重要结论：x^α·lnx→0（x→0⁺，α>0）
│  │  ├─ ∞−∞：口诀"有分母则通分，没分母创造分母再通分"
│  │  │  ├─ 例1：1/ln(1+x)−1/x 通分 -> 1/2（选 D）
│  │  │  └─ 例2：x²(e^(1/x)−1)−x 提 x 再倒代换 t=1/x -> 1/2
│  │  ├─ 幂指函数三类（底和指数都是函数）：见到百分之百写成 e^(v·ln u)
│  │  │  ├─ ∞^0：例题1.32 (x+√(1+x²))^(1/x) -> e^0=1
│  │  │  ├─ 1^∞：例题1.33 [(e^x+e^2x+e^3x)/3]^(1/x)
│  │  │  │  └─ 简化公式：lim u^v = e^(lim v·(u−1))（u→1）；答案 e²；防丢 e
│  │  │  └─ 0^0：同类处理
│  │  ├─ 已知一极限求另一：例题1.27（tan2x+x·f)/sin³x=0 -> [2+f]/x²→−8/3
│  │  │  ├─ 方法一：脱帽法 f=A+α
│  │  │  └─ 方法二（更快）：分子分母同乘 x，两式相减消去 f
│  │  │     └─ 千万不能洛必达（f 可导性未知）
│  │  ├─ 用极限定义对应法则：例题1.26（n→∞ 字母替换，sin(πx)=0 时 f=x² 否则 f=x(1−x)）
│  │  └─ 反求参数：
│  │     ├─ 例题1.34：e^x−(ax²+bx+1) 比 x² 高阶无穷小 -> a=1/2, b=1
│  │     └─ 例题1.35：sinx/(1+x²) 三次泰勒多项式 -> a=1, b=0, c=−7/6
│  └─ 7. 易错点汇总
│     ├─ 加减法不能直接等价替换（先恒等变形）
│     ├─ 幂指函数不能当幂函数求导
│     ├─ 换元必须两换
│     ├─ 1^∞ 公式顺手写 e 的 limit（整体抄，防丢 e）

└─【五】连续与间断（视频15，极限的应用，本讲收尾）
   ├─ 0. 观念转变：连续不是"几何上连着不断"，一切从定义出发
   ├─ 1. 连续的定义
   │  ├─ 三要素：x0 某邻域有定义 + 极限存在 + 极限值 = 函数值
   │  ├─ ε-δ 版：把极限定义右侧的 A 特殊化成 f(x0)
   │  ├─ 核心易错：极限存在 ≠ 连续（A 与 f(x0) 天生无关，相等是"后天加的条件"）
   │  ├─ 连续是点的定义；区间连续 = 每点连续

   ├─ 3. 连续函数的运算
   │  ├─ 四则（除法要求分母该点函数值≠0）/ 复合 / 反函数（单调连续）

   │     └─ 对比极限保号性：极限保号只覆盖去心邻域
   ├─ 4. 间断点分类
   │  ├─ 前提：只讨论"特殊点"（无定义点 + 分段函数分段点）
   │  ├─ 重要约定：必须双侧去心邻域有定义才讨论；区间端点不讨论间断
   │  │  └─ "1 是不是间断点？拒绝回答（右边没有定义）"
   │  ├─ 第一类间断点（左右极限都存在）-- 可去和跳跃"统称"第一类
   │  │  ├─ 可去：左右极限存在相等但 ≠f(x0)（或 f(x0) 无定义）
   │  │  │  └─ 别名可补：修改/补充定义即连续（例 sinx/x 补 f(0)=1）
   │  │  └─ 跳跃：左右极限都存在但不相等（与 f(x0) 无关）
   │  ├─ 第二类间断点（至少一个极限不存在）-- 无穷和振荡"属于"第二类
   │  │  ├─ 无穷：至少一个方向趋向无穷大（是"旁边的状态"，不是点的值）
   │  │  │  └─ 易错：无穷间断点不是这个点无穷大（一点不能谈无穷）
   │  │  └─ 振荡：f(x) 振荡不存在（sin(1/x) 在 ±1 间往复）
   │  │     └─ 悬念揭晓：不是这一点在振，是图形两边的"振荡痕迹"
   │  ├─ 措辞辨析（张宇强调）："可去跳跃统称为第一类"（就这两人）
   │  │  └─ vs "无穷振荡属于第二类"（还有其他人，考研范围内不管）
   │  └─ 分类判定口诀：研究对象就三人 -- 左极限、右极限、f(x0)
   │     ├─ 三者相等 -> 连续
   │     ├─ 左右相等但不等于 f(x0) -> 可去（第一类）
   │     ├─ 左右存在但不相等 -> 跳跃（第一类）
   │     └─ 至少一个不存在（无穷/振荡）-> 第二类
   ├─ 5. 例题

   │  │  └─ 点评："连续概念完全就是一个算极限的过程"

   │  │  └─ 答案：3 个第二类，选 C
   │  └─ 1.38 用极限定义的函数判断间断点（离散点陷阱：X² 只是离散整数点不是抛物线）
