│  ├─ 引例（p105-106）：王子/公主赶高铁（去程加速 / 站内翻包常函数 / 返程匀速）→ 平均 vs 瞬时变化率
│  │  └─ 平均变化率"粗糙"：从家出发又回到家平均变化率=0，"你什么都看不到了"
│  └─ 金句
│     ├─ "极限是研究函数变化趋势的，导数是研究变化快慢趋势的"

│
├─【一】导数的概念（视频02；p106-114，本讲主体）
│  ├─ 1. 导数的定义（比值的极限）
│  │  ├─ 定义：lim(Δx→0) Δy/Δx = lim(Δx→0)[f(x0+Δx)−f(x0)]/Δx 存在，称可导，极限记作 f'(x0)
│  │  ├─ 三种记号：拉格朗日 f' / 莱布尼茨 dy/dx（微商）/ 牛顿 ḟ（考研只用前两种）
│  │  │  └─ 历史：拉格朗日最先使用"导数"；莱布尼茨符号普适性更强
│  │  ├─ 莱布尼茨符号 dA/dB 的普适意义：A 对 B 的变化率
│  │  │  ├─ d兴趣/d时间 <0（喜新厌旧）；对高等数学则 >0
│  │  │  ├─ d利润/d价格 >0 定价低了、<0 定价高了、=0 利润最大（"导数为零的价格应是商品标签上的数字"）
│  │  │  └─ d成绩/d努力 >0 "乘胜追击"继续努力（"宜将剩勇追穷寇"）
│  │  └─ 含义：变化率。"自变量增加一个单位，函数值就增加 f'(x0) 个单位"
│  ├─ 2. 注1 增量式广义化"狗"（超实数）
│  │  ├─ 命题人会把 Δx 换成 −Δx、(Δx)² 等任一趋于0的量，统一叫"狗"
│  │  └─ 关键推论："如果一个量趋向于零，立即推一定不是零"→ 可放心放分母（super dog 超实数，解决牛顿莱布尼茨两百年悬案）
│  ├─ 3. 注2 换元形式（平移变换）
│  │  └─ 令 x0+Δx=x：f'(x0)=lim(x→x0)[f(x)−f(x0)]/(x−x0)（"有对称美"，两种写法各占一半，证抽象函数常用 Δx 式）
│  ├─ 4. 注3 三种等价说法
│  │  └─ "一点可导 = 导数存在 = f'(x0) 存在"，三个说法完全一样
│  ├─ 5. 注4 可导充要条件（考研必考）
│  │  ├─ f'(x0) 存在 ⇔ 左导数 f'₋(x0) 与右导数 f'₊(x0) 均存在且相等（导数的定义本质就是极限问题）
│  │  ├─ 几何：可以有斜的切线或水平切线，但不能有铅垂切线（铅垂切线极限值是无穷大）
│  │  └─ "这一条是考研里面几乎是一定要在这儿出题的了"
│  ├─ 6. 注5 可导的必要条件：可导 ⇒ 连续（反之未必）
│  │  ├─ 证明：Δy = (Δy/Δx)·Δx → f'(x0)·0 = 0（恒等变形：除一个乘一个）
│  │  ├─ 反例：f(x)=|x| 在 x=0 连续不可导；f(x)=x²D(x) 在 x=0 可导（f'(0)=lim x·D(x)=0，无穷小×有界）
│  │  └─ 口诀："数学上凡是等，一定是恒等变形"
│  ├─ 7. 注6 存在/连续/可导的直观解释（图3-2/3-3/3-4）
│  │  ├─ 存在：y 们"无牵无挂"地待着
│  │  ├─ 连续：y 们"相依相偎"，间距只能用超实数无穷小衡量
│  │  ├─ 可导：不仅依偎，靠近 y 的速度不比 X 们靠近 x 慢（一样快或更快）
│  │  └─ 金句："连续曲线不是曲线不断开，恰恰相反，它每一个位置都是断开的"
│  ├─ 8. 注：一点可导推不出区间可导（点信息 vs 区间信息）
│  │  ├─ 例子：x²D(x) 只在 x=0 可导（"连旁边的连续性都保证不了"）
│  │  └─ "连续是点信息，可导也是点信息，不能从一个点去推广到区间；区间上可导是一个点一个点组成的"
│  └─ 9. 例题索引（含打星奇偶性三例）
│     ├─ 例3.1 可导函数奇偶性/周期性命题，错误的是（ ）→ 选D（有界函数求导未必有界）
│     │  ├─ 结论（当结论记住）：可导偶函数→奇导数；可导奇函数→偶导数；可导周期函数→导数同周期（每求导一次奇偶互换）
│     │  ├─ 反例：f(x)=√x 有界，f'(x)=1/(2√x) 在 (0,1] 无界
│     │  ├─ 补充：导函数有界推不出函数有界（y=x）；闭区间导函数有界⇒函数有界（拉格朗日，后谈）
│     │  ├─ 注例1 f(x)=ln(1−x)−ln(1+x)，f''(0)=0（奇函数偶次导在0为0）
│     │  ├─ 注例2 f(x)=1/(2^x+1)，f⁽⁴⁾(0)=0（平移1/2成奇函数，g(x)=f(x)−1/2）
│     │  └─ 注2 f(x)=sin(cos x)+cos(sin x)，f⁽⁵⁾(2π)=0（内偶则偶+周期2π）
│     ├─ 例3.2 二阶可导以2为周期的奇函数，f(1/2)>0，f'(1/2)>0，比大小 → M<K<N 选C
│     │  └─ 方法：f(−1/2)=−f(1/2)<0；f'(x) 偶（例3.1B）且周期2，f'(3/2)=f'(−1/2)=f'(1/2)>0；f'' 奇，f''(0)=0
│     ├─ 例3.3 |f(x)|≤1−cos x，判 f 在 0 处 → 可导且 f'(0)=0 选C（double/triple star，背题）
│     │  └─ 三个层次：夹逼找极限 lim f(x)=0 → 特殊点找函数值 f(0)=0 → 夹逼找导数定义极限 |f(x)−f(0)|/|x|≤(1−cos x)/|x|→0
│     ├─ 例3.4 f(x)=(e^x−1)(e^(2x)−2)⋯(e^(nx)−n)，f'(0) → (−1)^(n−1)(n−1)! 选A（已验证 n=4）
│     │  ├─ 方法：提首项成两项相乘 (e^x−1)·g(x)，代0时含 g' 项消失，f'(0)=g(0)=(−1)(−2)⋯(1−n)
│     │  ├─ 必背公式：(uv)'=u'v+uv'；推广 (u1u2u3)'=u1'u2u3+u1u2'u3+u1u2u3'
│     │  └─ 口诀："前面求导后面不动，加上前面不动后面求导""各打五十大板"
│     ├─ 例3.5 f(x) 在 a 连续，F(x)=f(x)|x−a|，f(a)=0 是 F 在 a 可导的充要条件 → 选A
│     │  ├─ 证：左导数=−f(a)，右导数=f(a)，相等⇔f(a)=0（"什么数等于自己的相反数？只有0"）
│     │  └─ 应用：x−x0 绝对值在 x0 不可导，乘一个在 x0 连续且值为0的 f(x) 就救了它
│     ├─ 例3.6 三个函数不可导点个数 → n2<n1<n3 选A
│     │  └─ 结论（必背）：φ(x) 在 x0 连续，则 |x−x0|φ(x) 在 x0 可导 ⇔ φ(x0)=0（"救人因子"）
│     │     ├─ f1 不可导点 x=−√2,√2（2个）；f2 只有 x=2（1个）；f3 有 x=−√2,√2,−3（3个）
│     ├─ 注：f 与 |f| 连续/可导关系（p113-114，重要结论，"认识函数真实的样子"）
│     │  ├─ 连续：f 在 x0 连续 ⇒ |f| 在 x0 连续（反之不真；加绝对值不破坏"相依相偎"）
│     │  ├─ 可导两条确定性结论：
│     │  │  ├─ f 在 x0 可导且 f(x0)≠0 ⇒ |f| 在 x0 可导（保号性：一点>0则旁边>0）
│     │  │  └─ f 在 x0 可导且 f(x0)=0：f'(x0)≠0 ⇒ |f| 不可导（左右变化率相反，V型）；f'(x0)=0 ⇒ |f| 可导
│     │  └─ 不可导两种机理：①距离拉远（f 趋向 f(x0) 的速度比 x→x0 慢）②尖点改变变化率唯一性（左右相反）
│     │     └─ "它不仅要趋向于 f(x0)，而且我还不能比你慢……一旦你比它慢了，导数就不存在了"
│     └─ 例3.7 g(x)=|f(x−1)|，f(0)=−1，f'(0)=1 → g 在 x=1 必可导 选C
│        └─ 方法：可能不可导点仅有 f(x−1)=0 的点；x=1 时 f(0)=−1≠0 直接可导；x=0 需知 f(−1) 无法判断；f'(0)=1 是多余条件
│
├─【二】导数的几何意义（视频04；p115-116）
│  ├─ 1. 切线斜率：k=f'(x0)（导数值=切线斜率）
│  │  ├─ 切线方程 y−y0=f'(x0)(x−x0)；法线方程 y−y0=−1/f'(x0)·(x−x0)（f'(x0)≠0）
│  │  ├─ Tangent 含义："像一把锋利无比的刀，嗖地切过点"，方向=该点瞬时运动方向（掷铁饼脱手沿切线飞出）
│  │  └─ 核心："切线存在不代表导数存在，但导数存在切线一定存在"
│  ├─ 2. 注例1 y=|x| 在 x=0：角点（左右切线形成角），f'₊(0)=1、f'₋(0)=−1，不可导无切线
│  ├─ 3. 注例2 y=x^(1/3) 在 x=0：无穷导数（f'₊=f'₋=+∞），有铅垂切线 x=0，但高数认为导数不存在
│  │  └─ 结论：曲线有垂直于 x 轴的切线 ⇔ f'(x0)=±∞（无穷导数）；"无穷大是不存在"
│  │  └─ 总结：①f'₊≠f'₋ 角点，无切线；②无穷导数，有切线无导数
│  └─ 4. 例3.8 y=x^n 在(1,1)处切线截 x 轴于 (ξn,0)，lim f(ξn)=1/e（已验证）
│     └─ 方法：f'_n(1)=n，切线 y−1=n(x−1)，ξn=1−1/n，lim(1−1/n)^n=e^(−1)（切线族/函数列思想）
│
├─【三】高阶导数（视频04；p117-118，重点）
│  ├─ 1. 定义：n 阶导数 = n−1 阶导数在该点的变化率（lim 定义式）
│  │  ├─ 物理：位移→速度→加速度→加加速度
│  │  └─ 写法："事不过三"（一撇/两撇/三撇，n≥4 写 f⁽ⁿ⁾(x)，如 f⁽⁴⁾、f⁽⁵⁾）
│  ├─ 2. 注（一点 n 阶可导能推出什么）
│  │  ├─ f''(x0) 存在 ⇒ f'(x) 在 x0 某邻域有定义且在 x0 连续（证：缺什么补什么恒等变形）
│  │  ├─ f⁽ⁿ⁾(x0) 存在 ⇒ f⁽ⁿ⁻¹⁾(x) 在邻域有定义且在 x0 连续（只能谈存在性，其他位置不能谈连续）
│  │  └─ 口诀："缺什么补什么，少什么添什么"
│  └─ 3. 例3.9 一点二阶可导，f'(x0)=0，f''(x0)≠0：f''<0 极大、f''>0 极小
│     └─ 方法：二阶导定义 + 局部保号性（脱帽法：极限<0 推出 f'(x) 与 x−x0 异号）+ 极值第一充分条件（为第5/6讲铺垫）
│
├─【四】微分的概念（视频04；p118-120）
│  ├─ 1. 引例：正方形边长1增 Δx，ΔS=(1+Δx)²−1=2Δx+(Δx)²（2Δx=线性主部，(Δx)²=o(Δx)）
│  │  └─ "Δx 的平方是 Δx 的无穷倍"→ 可忽略；ΔS≈2Δx
│  ├─ 2. 定义：Δy=AΔx+o(Δx)（A 与 Δx 无关）→ 可微；AΔx=线性主部=微分，dy|ₓ₌ₓ₀=AΔx
│  ├─ 3. 可微⇔可导证明：Δy/Δx = A + o(Δx)/Δx → f'(x0)=A；故 dy=f'(x0)Δx=f'(x0)dx（dx=Δx）
│  │  └─ "可微必可导，可导必可微"（一元函数充要，判别可微转化为判别可导）
│  │  └─ 易错："Δy 不是 dy"（差一个误差 o(Δx)）；"dx 等于 Δx"
│  ├─ 4. 注1 可微判别三步：①写真实增量 Δy=f(x0+Δx)−f(x0) ②写线性增量 AΔx=f'(x0)Δx ③作极限 (Δy−AΔx)/Δx→0 则可微
│  ├─ 5. 注2 含义：用简单的线性量 AΔx 代替复杂的增量 Δy，误差 o(Δx) 可忽略不计
│  ├─ 6. 注4/5 几何意义：在 (x0,y0) 附近用切线段近似代替曲线段
│  └─ 7. 例题索引
│     ├─ 例3.10 Δy=[y/(x+√(x²+y²))]·Δx+o(Δx)，f(0)=1 → dy=dx 选B（已验证）
│     │  └─ 方法：概念题转成导数 dy/dx，代值求 f'(0)=1
│     ├─ 例3.11 y=f(x²)，x=−1 处 Δx=−0.1，Δy 线性主部=0.1 → f'(1)=0.5 选C（已验证）
│     │  └─ 方法：dy=f'(x²)·2x·Δx；0.1=2(−1)f'(1)(−0.1)（注意复合求导 y'=f'(x²)·2x）
│     └─ 一题一练 lim(Δx→0)[Δf(1)−df(1)]/Δx → 0 选D
│        └─ "等于零的含义是误差是 Δx 的高阶无穷小，而不是说它俩相等"
│
└─【五】基础习题精练 3.1~3.9（p121-124，带答案与方法）
   ├─ 习题3.1 f={x>0 (1−cos x)/√x；x≤0 x²g(x)}（g 有界）→ 可导 选D（左右导数均0）
   ├─ 习题3.2 |x³−1|φ(x)，φ 在1连续 → φ(1)=0 是 x=1 可导的充要条件 选A（例3.5结论）
   ├─ 习题3.3 切线与 y=2−x 垂直 → dy 与 Δx 等价无穷小 选B（f'(x0)=1）
   ├─ 习题3.4 f'(x0)≠0 → Δy−dy 是 dy 的高阶无穷小 选A
   ├─ 习题3.5 f(x)=(x−a)φ(x)，φ 连续 → f'(a)=φ(a)
   │  └─ 金句："求导数时，当函数不具备导数存在的条件时，往往只能用导数定义求"
   ├─ 习题3.6 f(0)=0，f'(0)存在 → lim f(1−√cos x)/ln(1−x sin x) = −(1/4)f'(0)（已验证 f=sinx）
   ├─ 习题3.7 若 lim(x→x0⁺)F'(x)=A 则 F'₊(x0)=A（洛必达）；逆命题不成立（反例 x²sin(1/x)，F'(0)=0 但 limF'(x) 不存在）
   ├─ 习题3.8 f={x<0 x²sin(π/x)；x=0 A；x>0 ax²+b} → A=b=0，a 任意常数，f'(0)=0（已验证）
   └─ 习题3.9 lim[ln(1−2x)+2xf(x)]/x²=0，f(0)=1 → f(x) 在 x=0 可导且 f'(0)=1（泰勒展开，已验证 f=1+x 成立）
