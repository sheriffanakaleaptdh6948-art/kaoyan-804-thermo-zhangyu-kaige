│  │  ├─ 注2（证明）：设 F 是 f 的原函数，x₀ 为 F'(x) 的间断点，分可去/跳跃/无穷三种，均用洛必达引出矛盾 → **导函数无第一类和无穷间断点**

├─【二】定积分（视频04-05；p210-220）
│  ├─ 1. 定义（p210-212）
│  │  ├─ 张宇先入为主：**定积分 ≠ 不定积分**，记号同形但完全不是一回事
│  │  ├─ 引入：矩形面积 → 曲边梯形面积
│  │  ├─ 四步骤：①分割（方法不唯一）②近似 ③求和 ④取极限（λ=maxΔxₖ→0）
│  │  ├─ 记号：∫ 来自莱布尼茨手稿 "summa"(和) 的 S 拉长；黎曼 (1826-1866) 给出精确定义，故称**黎曼积分**
│  │  ├─ 几何意义：f≥0 为面积；f≤0 为**面积的负值**；有正有负为面积代数和 S_上−S_下
│  │  ├─ 精确定义：可积 = lim[λ→0] Σ f(ξₖ)Δxₖ 存在，且**与分点 xᵢ 及点 ξₖ 的取法无关**（两个"任取"）
│  │  ├─ 特取（两个"特取"）
│  │  │  ├─ 右端点 n 等分：∫ₐᵇ f(x)dx = lim Σ f(a+(b−a)/n·i)·(b−a)/n
│  │  │  └─ 特化公式（0 到 1，**必背**）：**∫₀¹ f(x)dx = lim[n→∞] Σᵢ₌₁ⁿ f(i/n)·(1/n)（已验证）**
│  │  ├─ 注：积分值与字母无关——∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt = ∫ₐᵇ f(u)du，值只与被积函数及区间有关
│  │  └─ 考情：精确定义"经常出题"；和式极限 ↔ 定积分定义互化
│  ├─ 2. 存在定理（p212-213）
│  │  ├─ 常义可积 = 区间有限 + 函数有界（黎曼可积），与反常积分（区间无穷/函数无界）相区别
│  │  ├─ 充分条件
│  │  │  ├─ ① f 在 [a,b] 连续 ⇒ ∫ 存在
│  │  │  ├─ ② f 单调 ⇒ ∫ 存在（f(a)、f(b) 即上下界）
│  │  │  ├─ ③ 有界且只有有限个间断点 ⇒ ∫ 存在（不含无穷间断点，无穷间断点导致无界）
│  │  │  └─ ④ 有有限个第一类间断点 ⇒ ∫ 存在
│  │  ├─ 必要条件：**可积必有界**（无界 → 某小段竖条面积可任意大 → 极限不存在）
│  │  ├─ 注1：**与反常积分区分**——反常积分可能函数无界仍"存在"（广义可积，见【四】注2）
│  │  └─ 注2：不定积分存在定理与定积分存在定理的区别联系见例8.3
│  └─ 3. 性质（p213-220，假设积分均存在）
│     ├─ 两个规定：∫ₐᵃ f(x)dx=0；a>b 时 ∫ₐᵇ = −∫ᵇₐ（交换上下限添负号）
│     ├─ 性质1（区间长度）：∫ₐᵇ dx = b−a
│     ├─ 性质2（线性）：∫[k₁f ± k₂g] = k₁∫f ± k₂∫g
│     ├─ 性质3（区间可加）：无论 a,b,c 大小，∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ
│     ├─ 性质4（保号性）：f≤g ⇒ ∫f ≤ ∫g；特殊 **|∫f| ≤ ∫|f|**
│     │  └─ 注（非负不恒零）：f 非负连续且**不恒等于零** ⇒ **∫ₐᵇ f(x)dx > 0（严格）**，证明见例8.7；极限"戴帽/脱帽"的积分版
│     ├─ 性质5（估值定理）：**最小值 m、最大值 M**，L 为区间长 ⇒ **mL ≤ ∫ₐᵇ f(x)dx ≤ ML**（由 m≤f≤M 及性质1证）
│     ├─ 性质6（积分中值定理，**必背**）：f 在 [a,b] 连续 ⇒ ∃ξ 使 ∫ₐᵇ f(x)dx = f(ξ)(b−a)（"S_曲边梯形=S_矩形"）
│     └─ 例题索引（概念/比大小/存在性，全部已验证）
│        ├─ 例8.3 (p214-215) [−1,2] 四个断言判断正确个数 → **(B) 2 个（③④正确，已验证）**
│        │  ├─ ① f={2(x>0), 1(x=0), −1(x<0)} 断言"有原函数、定积分不存在" → **错**（跳跃间断点：无原函数，但定积分存在）
│        │  ├─ ② f={2x sin(1/x²)−(2/x)cos(1/x²)} 断言"有原函数、定积分也存在" → **错**（有原函数 F=x²sin(1/x²)，但 0 邻域无界 ⇒ 定积分不存在）
│        │  ├─ ③ f={1/x} 断言"没有原函数、定积分也不存在" → **对**（无穷间断点）
│        │  └─ ④ f={2x cos(1/x)+sin(1/x)} 断言"有原函数、定积分也存在" → **对**（|f|≤5 有界 + 一振荡间断点）
│        ├─ 例8.4 (p216) f 单调递增过原点，I=∫₀ᵃ f + ∫₀ᵇ φ(y)dy 与 ab 比大小 → **(A) I>ab（已验证）**
│        │  └─ 大坑：x=φ(y) 与 y=f(x) 是**同一条曲线**（不是关于 y=x 对称！对称的是 y=f⁻¹(x)）
│        ├─ 例8.5 (p216) e⁻ˣsinx 与 x 轴围成面积表达式 → **(C) 正确的有 2 个（①③）**；②是面积差的绝对值，不符题意
│        ├─ 例8.6 (p217) lim Σ (n+i)/(n²+i²) → **(A) ∫₀¹ (1+x)/(1+x²)dx（已验证）**
│        │  └─ 凑定积分定义：①提 1/n ②凑 i/n ③i/n 读作"0 到 1 上的 x"；夹逼凑不出的反例（夹不住 3/4 与 3/2）

├─【三】变限积分（视频06；p220-224）
│  ├─ 1. 概念（p220）
│  │  ├─ 定义：F(x)=∫ₐˣ f(t)dt (a≤x≤b) 称为变上限的定积分；变下限、上下限都变化的统称**变限积分**
│  │  └─ 本质：变限积分就是定积分的推广（如 ∫_{x²}^{eˣ} f(t)dt），是一个由定积分定义的函数
│  ├─ 2. 性质（p220-222）
│  │  ├─ 性质1：f 在 I 可积 ⇒ F(x)=∫ₐˣ f(t)dt 在 I 上连续（**存在必连续**，与普通函数不同）
│  │  │  └─ 证明（看懂即可）：|F(x+Δx)−F(x)| = |∫ₓ^{x+Δx} f(t)dt| ≤ M|Δx|（可积必有界）→ 0
│  │  ├─ 性质2（**太重要**）：f 在 I 连续 ⇒ F 在 I 可导且 **F'(x)=f(x)**（变上限积分求导，考过真题）
│  │  ├─ 性质3（间断点处行为）
│  │  │  ├─ 跳跃间断点：F 连续但**不可导**（尖点），F'₋=lim₋f，F'₊=lim₊f
│  │  │  └─ 可去间断点：F **可导**，F'(x₀)=lim f(x) **≠ f(x₀)** → 仍不是原函数
│  │  └─ 易混点：含跳跃间断点的函数没有原函数，变限积分只是变限积分，**不是**原函数
│  └─ 例题索引（变限积分是考试高频）
│     ├─ 例8.11 (p222) 看 f 的图选 F=∫₀ˣ f(t)dt 的图 → **(D)**（图题，三条逻辑：存在必连续/两跳跃两尖点/过原点）
│     │  ├─ ① 变限积分存在必连续 → 排除 (B)
│     │  ├─ ② 两个跳跃间断点 → F 两个不可导点 → 排除 (A)
│     │  └─ ③ F(0)=0 过原点 → 排除 (C)
│     ├─ 例8.12 (p223) f=cosx(0≤x<π), 1(π≤x≤2π)，x=π 处 → **(C) 连续但不可导（已验证）**
│     │  ├─ 方法一：π 是跳跃间断点 ⇒ F 连续不可导
│     │  └─ 方法二：F 分段写出，F'₋(π)=−1，F'₊(π)=1 不等
│     ├─ 例8.13 (p223) f=e^{x²}+x²(x≠0), a(x=0)，F=∫₋₁ˣ f(t)dt → **(B) ①②正确（已验证）**
│     │  ├─ a=1：连续 ⇒ F 可导，F'(0)=f(0)=1
│     │  └─ a≠1：可去间断点，F'(0)=lim(洛必达)=1 仍存在，但 F 不是 f 的原函数（F'(0)≠f(0)）
│     └─ 例8.14 (p224) a>0，f 在 [0,+∞) 连续有界，证 y=e^{−ax}[∫₀ˣ f(t)e^{at}dt+C] 有界（放缩法，已验证）
│        └─ 证：|f|≤M ⇒ |y| ≤ |C| + M e^{−ax}∫₀ˣ e^{at}dt = |C| + (M/a)(1−e^{−ax}) ≤ |C|+M/a

│  ├─ 1. 概念（p224-225）
│  │  ├─ 引出逻辑：定积分存在有两个必要条件（区间有限、函数有界），各破坏一个：
│  │  │  ├─ 破坏区间有限 → **无穷区间**上的反常积分
│  │  │  └─ 破坏有界 → **无界函数**的反常积分
│  │  ├─ 定义1（无穷区间）：设 F 是 f 的一个原函数
│  │  │  ├─ ① ∫ₐ^{+∞} f(x)dx = lim[x→+∞] F(x) − F(a)：极限存在称**收敛**，否则**发散**
│  │  │  ├─ ② ∫_{−∞}ᵇ = F(b) − lim[x→−∞] F(x)
│  │  │  └─ ③ ∫_{−∞}^{+∞} = ∫_{−∞}^{x₀} + ∫_{x₀}^{+∞}：两个都收敛才收敛，**一个发散整体发散**
│  │  ├─ 瑕点定义：使 f 在 x₀ 的邻域内**无界**的点（不一定是无穷大，无界振荡也是瑕点，如 (1/x)sin(1/x) 在 0）
│  │  ├─ 定义2（无界函数）：x₀ 为瑕点
│  │  │  ├─ ① x=a 是唯一瑕点：∫ₐᵇ = F(b) − lim[x→a⁺] F(x)
│  │  │  ├─ ② x=b 是唯一瑕点：∫ₐᵇ = lim[x→b⁻] F(x) − F(a)
│  │  │  └─ ③ x=c∈(a,b) 是唯一瑕点：∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ
│  │  ├─ 重要警示：**不存在"发散+发散=收敛"**；例 ∫_{−∞}^{+∞} x³dx 因 ∫_{−∞}⁰ 发散而整体发散，**而不是 0**；只有反常积分收敛时 ∫_{−∞}^{+∞} = lim[R→∞]∫₋ᴿᴿ 才成立
│  │  ├─ 注1：∞ 与瑕点统称**奇点**。判别前提：**一个积分只能有一个奇点**，两个及以上先拆分
│  │  └─ 注2（关键辨析）：x=a 为瑕点时 f 无界，∫ₐᵇ 也可能存在——与"可积必有界"不矛盾（定积分=黎曼/常义可积，此处=反常/广义可积，两个概念）
│  ├─ 2. 敛散性判别（p226-231，核心思想=比较）
│  │  ├─ 比较判别法（无穷区间）：f,g 在 [a,+∞) 连续，0≤f≤g
│  │  │  ├─ ① ∫g 收敛 ⇒ ∫f 收敛
│  │  │  └─ ② ∫f 发散 ⇒ ∫g 发散（"大的收敛则小的收敛，小的发散则大的发散"）
│  │  ├─ 比较判别法极限形式（无穷区间，**更重要**）：f≥0，g>0，lim f/g=λ（有限或∞）
│  │  │  ├─ ① λ≠0 且 λ≠∞：f、g 同阶无穷小 ⇒ **同敛散**
│  │  │  ├─ ② λ=0（f 趋 0 比 g 快）：∫g 收敛 ⇒ ∫f 收敛
│  │  │  └─ ③ λ=∞（g 趋 0 比 f 快）：∫g 发散 ⇒ ∫f 发散
│  │  ├─ 比较判别法（无界函数）：f,g 在 (a,b] 连续，瑕点同为 x=a，0≤f≤g，结论同上
│  │  ├─ 比较判别法极限形式（无界函数）：lim[x→a⁺] f/g=λ（无穷大比阶）
│  │  │  ├─ ① λ≠0 非∞：同敛散
│  │  │  ├─ ② λ=0（g 趋 ∞ 比 f 快）：∫g 收敛 ⇒ ∫f 收敛
│  │  │  └─ ③ λ=∞（f 趋 ∞ 比 g 快）：∫g 发散 ⇒ ∫f 发散
│  │  ├─ p-积分两个重要结论（比较对象 g 的选择基准，**必记**）
│  │  │  ├─ ∫₁^{+∞} 1/x^p dx：**收敛(p>1)，发散(p≤1)**（p=1 临界，∫1/x=lnx 发散；p 越大越收敛）
│  │  │  └─ ∫₀¹ 1/x^p dx：**收敛(0<p<1)，发散(p≥1)**（p 越小越收敛）
│  │  │  └─ 记忆：**带无穷大 p 越大越收敛；带零（瑕点）p 越小越收敛；p=1 临界发散**
│  │  ├─ 推广（等价替换定主导项）
│  │  │  ├─ 推广1：x→0⁺ 时 sinx~x ⇒ ∫₀¹ 1/sin^p x dx 收敛(0<p<1)/发散(p≥1)
│  │  │  └─ 推广2：x→+∞ 时 ax+b~x ⇒ ∫₁^{+∞} 1/(ax+b)^p dx 收敛(p>1)/发散(p≤1)
│  │  ├─ 含 ln 四结论（lnx 比任何幂函数慢，"推波助澜 vs 煽风点火"）
│  │  │  ├─ ① ∫₀¹ 1/x^p：收敛(0<p<1)/发散(p≥1)
│  │  │  ├─ ② ∫₀¹ lnx/x^p：**收敛(0≤p<1)/发散(p≥1)**
│  │  │  ├─ ③ ∫₁^{+∞} 1/x^p：收敛(p>1)/发散(p≤1)
│  │  │  └─ ④ ∫₁^{+∞} lnx/x^p：**收敛(p>1)/发散(p≤1)**
│  │  │  └─ 规律：带上 lnx 敛散性不变；数学刻画 **任给 ε>0，x^ε·lnx → 0**
│  │  ├─ 补充速判：lim[x→+∞] x^p·f(x)=λ≥0 且 p>1 ⇒ ∫₁^{+∞} f(x)dx 收敛
│  │  ├─ 对称区间结论：f 偶且 ∫₀^{+∞} 收敛 ⇒ ∫_{−∞}^{+∞}=2∫₀^{+∞}；f 奇且 ∫₀^{+∞} 收敛 ⇒ 全区间=0
│  │  │  └─ 前提：**拆开的一半先证收敛**才可用（偶倍奇零不可想当然）
│  │  ├─ 绝对收敛：|f| 收敛 ⇒ f 收敛（加一项减一项证明，**选择题特别喜欢出**）
│  │  └─ 例题索引（反常积分判敛实战，已验证）
│  │     ├─ 例8.15 (p227) ∫₀^{+∞} 1/(x^a+x^b)dx，a>b>0 收敛条件 → **(B) a>1 且 b<1（已验证）**
│  │     │  ├─ 拆 0→1 与 1→+∞；0 附近 x^a+x^b ~ x^b（次数低是老大）⇒ 需 b<1
│  │     │  └─ +∞ 附近 x^a+x^b ~ x^a（次数高是老大）⇒ 需 a>1
│  │     ├─ 例8.16 (p228) ∫₁^{+∞} [e^{−cos(1/x)}−e^{−1}]·x^k dx 收敛 → **k<1（已验证）**

│  │     ├─ 例8.17 (p228-229) 以下发散的是？→ **(C) ∫₋₁¹ 1/sinx dx（已验证）**

│  │  ├─ 负无穷到正无穷不能直接算，必须拆
