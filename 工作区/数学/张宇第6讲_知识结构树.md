│  │  ├─ ① f(a)=f(b)

│  │  │  ├─ 见到 (f')²+f·f'' → F=f·f'（依据 [ff']'=(f')²+ff''）
│  │  │  └─ 见到 f'+f·φ' → F=f·e^φ（依据 [fe^φ]'=(f'+fφ')e^φ）
│  │  │     ├─ φ=x → 见到 f'+f → F=f·e^x
│  │  │     ├─ φ=−x → 见到 f'−f → F=f·e^(−x)
│  │  │     └─ φ=kx → 见到 f'+kf → F=f·e^(kx)
│  │  ├─ 商求导逆用
│  │  │  ├─ 见到 f'·x−f（x≠0）→ F=f/x
│  │  │  ├─ 见到 f''·f−(f')²（f≠0）→ F=f'/f
│  │  │  └─ 见到 f''·f−(f')²（f>0）→ 亦可 F=ln f（涉及凹凸）

│  │  ├─ [a,b] 罗尔 → f'(ξ₁)=0；[b,c] 罗尔 → f'(ξ₂)=0
│  │  └─ [ξ₁,ξ₂] 对 f' 罗尔 → f''(ξ)=0（三次罗尔）
│  ├─ 方法预判：证 f^(n)(ξ)=0 → 多次罗尔（或费马）；证 f^(n)(ξ)≠0 → 泰勒
│  └─ 例题索引
│     ├─ 例6.6 (p176) 过 A(0,f(0))、B(1,f(1)) 的直线与曲线交于 C(c,f(c)) → 证 f''(ξ)=0

│     │  └─ 关键：F''=f''（弦线二阶导为 0）
│     └─ 例6.7 (p176) f·f''+(f')²=0 在 (0,1) 至少两个不同实根
│        ├─ F=f·f'（对照模式 b，目标方程恰是 F' 的分子）
│        ├─ 例6.2 造 f(b)=0（b∈(0,1)）+ 罗尔造 f'(c)=0 → F 有三等值点
│        └─ 两次罗尔得 ξ≠η 两个根

├─【五】拉格朗日中值定理（视频03-04；p177-178，考察频率最高）
│  ├─ 1. 定理7（p177）
│  │  ├─ 结论：f(b)−f(a)=f'(ξ)(b−a)（两种写法乘 −1 等价）
│  │  ├─ 几何：弦 AB 的斜率 = 区间内某点切线斜率（切线平行弦）
│  │  ├─ 作用：用导函数值控制函数值的增减（复试答这句）
│  │  ├─ 推论：f'(x)≡0 → f 为常数
│  │  └─ 考情：2009 考过证明，之后只考使用；"不会让你随便用"——f(a) 常被藏起来或 =0
│  ├─ 2. 使用信号：见到 f(b)−f(a) 差式或 f 与 f' 的关系 → 创造条件用拉格朗日
│  └─ 例题索引
│     ├─ 例6.8 (p177) f'(x) 有界 → f(x) 在 (a,b) 有界（有限区间）
│     │  ├─ 固定 x₀ + 任意动点 x，在 [x₀,x] 用拉格朗日 + 三角不等式 |a+b|≤|a|+|b|
│     │  └─ 易错：|x−x₀| 是变量要放大成 < b−a；f(x₀) 是数直接用；导函数有界推不出函数有界除非区间有限（反例 f=x）
│     ├─ 例6.9 (p177) f(0)=0 且不恒为 0 → 证存在 ξ 使 f(ξ)f'(ξ)>0
│     │  ├─ F=½f²（ff' 的原函数），F(0)=0，∃a 使 F(a)>0
│     │  └─ 结论是">0"→ 用拉格朗日（=0 才用罗尔），F'(ξ)=(F(a)−F(0))/a>0
│     └─ 例6.10 (p178) f(0)=0, f<0, f'<0, f''>0，0<a<x<b → 选(D) xf(b)>bf(x)
│        ├─ g(x)=xf：g'=f+xf'<0 单减 → (A)(B) 错
│        ├─ h(x)=f/x：h' 分子用拉格朗日 f(x)−f(0)=f'(ξ)x 过渡 → h'=(f'(x)−f'(ξ))/x
│        ├─ 关键链：f''>0 → f' 单调增 → f'(x)>f'(ξ) → h'>0 单增 → (D) 对
│        └─ 口诀落地："0 在加减法里不体现"（f(0)=0 藏起来）

├─【六】柯西中值定理（视频04；p178）
│  ├─ 1. 定理8（p178）
│  │  ├─ 结论：(f(b)−f(a))/(g(b)−g(a)) = f'(ξ)/g'(ξ)（同一个 ξ）
│  │  ├─ 前提：g'(x)≠0（由导数介值定理，g' 保号 → 分母不为 0）
│  │  ├─ 视角：参数方程 x=g(t), y=f(t) 求导
│  │  └─ 易错：不能拿两个拉格朗日相除冒充柯西（两个 ξ 不同）
│  ├─ 2. 使用特点：一个具体函数 + 一个抽象函数（具体做 g，抽象做 f）
│  └─ 例题索引
│     └─ 例6.11 (p178) 0<a<b → 证 f(b)−f(a)=ξ·ln(b/a)·f'(ξ)
│        ├─ 取 g(x)=ln x，g'(x)=1/x≠0（已验证）
│        └─ ln(b/a)=lnb−lna>0；柯西不好出大题，近年数学二仅考过一两问

├─【七】泰勒公式与麦克劳林展开（视频04；p179-181）
│  ├─ 1. 定理9 泰勒公式（p179）
│  │  ├─ 思想：用多项式近似表示 f(x)（知道越多导数值，估计越精确）
│  │  ├─ 带拉格朗日余项（区间宏观，证不等式/中值等式）：要求 x₀ 邻域内 n+1 阶可导（强）
│  │  ├─ 带佩亚诺余项（点附近局部，求极限/判阶/判极值）：只要求 x₀ 处 n 阶可导（弱）
│  │  └─ 递进观：连续→小o(1)；可导→小o(x−x₀)；n阶可导→完整泰勒
│  ├─ 2. 麦克劳林 7 展开（x₀=0，要背；已验证）
│  │  ├─ e^x = 1 + x + x²/2! + … + xⁿ/n! + o(xⁿ)
│  │  ├─ sinx = x − x³/3! + … + (−1)ⁿx^(2n+1)/(2n+1)! + o(x^(2n+1))
│  │  ├─ cosx = 1 − x²/2! + x⁴/4! − … + o(x^(2n))
│  │  ├─ 1/(1−x) = 1 + x + x² + … + xⁿ + o(xⁿ)
│  │  ├─ 1/(1+x) = 1 − x + x² − … + o(xⁿ)
│  │  ├─ ln(1+x) = x − x²/2 + x³/3 − … + o(xⁿ)
│  │  └─ (1+x)^α = 1 + αx + α(α−1)/2!·x² + …（记住前三项，如 √(1+x)=1+x/2−x²/8+o(x²)）
│  ├─ 3. 选点技巧（例6.13 归纳）
│  │  ├─ 展开点 x₀：取已知导数值的点（如 f'(0)=0 → x₀=0 消一次项）
│  │  └─ 被展开点 x：取已知函数值的点 / 端点 / 特殊点
│  └─ 例题索引
│     ├─ 例6.12 (p180) ∫₀¹f(x)dx=0，二阶可导 → 选(D) f''>0 时 f(1/2)<0
│     │  ├─ 在 x₀=1/2 展开带拉格朗日余项 + [0,1] 积分
│     │  ├─ 关键：∫₀¹(x−1/2)dx=0（对称性正负抵消）
│     │  └─ 易错：f''(ξ) 不能提积分号外（ξ=ξ(x) 非常数）；f'(1/2) 是常数可提
│     └─ 例6.13 (p181) f(−1)=0, f(1)=1, f'(0)=0，三阶连续 → 证 f'''(ξ)=3
│        ├─ 展开于 x₀=0（消一次项），被展开点取 ±1
│        ├─ 两式相减：f'''(η₁)+f'''(η₂)=6
│        └─ 最后用平均值/介值定理（f''' 连续）→ f'''(ξ)=3
│
├─【八】微分等式（视频05；p181-184）
│  ├─ 概念：方程的根 = 函数的零点 = 曲线的交点（三种说法等价）
│  ├─ 四方法
│  │  ├─ 1. 零点定理（存在性）：f(a)f(b)<0 → 至少一根
│  │  ├─ 2. 单调性（唯一性）：区间内单调 → 至多一根
│  │  │  └─ 搭配：至少 + 至多 = 恰有一个；可分段研究再相加
│  │  ├─ 3. 罗尔定理及其推论（罗尔原话"以阶数换个数"）
│  │  │  ├─ 一般式：f^(n)(x)=0 至多 k 个根 → f(x)=0 至多 k+n 个根
