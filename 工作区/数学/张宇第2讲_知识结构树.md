├─【一】数列的概念（视频02；p083-084）
│  ├─ 1. 数列定义与整标函数
│  │  ├─ 定义：对每个 n∈N₊ 按法则对应唯一实数 x_n，按下标排成 {x_n}；第 n 项叫一般项（通项）
│  │  ├─ 本质：自变量为正整数 n 的"整标函数" x_n=f(n)
│  │  ├─ 几何：数轴上的动点，一个点一个点地排出来（离散）
│  │  └─ 数列一定有无穷多项（"有限个点"不算本节数列）
│  ├─ 2. 子列
│  │  ├─ 定义：从 {a_n} 取无穷多项按原顺序组成 {a_{n_k}}（须保序且无穷多项）
│  │  ├─ 例：n_k=2k / 2k−1 得偶子列 / 奇子列（两子列交错出现）
│  │  └─ 判定：子列收敛定理见【二】节4
│  ├─ 3. 等差数列
│  │  ├─ 通项 a_n=a_1+(n−1)d
│  │  └─ 前 n 项和 S_n=n/2·[2a_1+(n−1)d]=n/2·(a_1+a_n)（二分之首项加第n项乘n）
│  ├─ 4. 等比数列（公式极为重要，要背）
│  │  ├─ 通项 a_n=a_1·r^(n−1)，公比 r≠0；前 n 项和 r=1 / r≠1 分情况
│  │  ├─ 口诀：一减公比分之首项，乘以一减公比的 n 次方
│  │  └─ 常用 1+r+…+r^(n−1)=(1−r^n)/(1−r)（r≠1）
│  │     └─ 注：等差/等比前 n 项和是有限项和，不会发散；收敛/发散只在无穷项时涉及
│  ├─ 5. 单调数列
│  │  ├─ 单调不减/不增（a_{n+1}≥a_n 带等号）vs 单调递增/递减（严格，不带等号）
│  │  └─ 递增与递减统称单调数列
│  ├─ 6. 有界数列（考试最爱考）
│  │  ├─ 定义：存在 M>0，|a_n|≤M 对一切 n 成立
│  │  ├─ 证有界四方法：①找 M ②放缩 ③找最值 ④基本不等式
│  │  └─ 加绝对值证上界，改 ≥ 证下界
│  ├─ 7. 常见前 n 项和（要背）
│  │  ├─ Σk=n(n+1)/2；Σk²=n(n+1)(2n+1)/6（只需记这两个，其他别多记）
│  │  └─ Σ1/[k(k+1)]=n/(n+1)→1（裂项相消 =1−1/(n+1)）
│  ├─ 8. 重要数列 {(1+1/n)^n}（结论要知）
│  │  ├─ 单调递增有上界，lim (1+1/n)^n = e
│  │  ├─ 首项 n=1 时为 2，值域落在 2 到 2.7 几之间
│  │  └─ 单调性证明不需掌握（超考研计算要求）
│  └─ 9. 例题索引
│     └─ 例题2.1：0<x_1<3，x_{n+1}=√(x_n(3−x_n)) 证有界 -> 0<x_n≤3/2（n>1）
│        ├─ 方法：基本不等式 √(ab)≤(a+b)/2（凑出常数 3/2）+ 数学归纳法
│        └─ 易错：用基本不等式前须确认 x_n 与 3−x_n 均为正
│
├─【二】数列极限的定义（视频02；p085-087）
│  ├─ 1. ε-N 语言定义（维尔斯特拉斯，必须背）
│  │  ├─ 文字版：∀ε>0，∃N>0，n>N 时 |x_n−a|<ε
│  │  ├─ 含义：n 是"离散"地趋于 +∞（n→∞ 专指正无穷，规范写法不加正号）
│  │  ├─ 卷面上不考证明解答题，选择/填空考对定义的理解
│  │  └─ 注：大 N 未必取整数，写"存在 N>0"即可；n>N 与 n≥N 无区别
│  ├─ 2. 与函数极限定义的对比（ε-X 语言）
│  │  └─ 联系靠海涅定理/归结原则（见【五】）
│  ├─ 3. 常用语言
│  │  ├─ lim x_n=∞ ⇔ 任意 X>0，∃N，n>N 时 |x_n|>X（无穷大量）
│  │  └─ a=0 时称 x_n 为无穷小量（离散变量极限为零亦可）
│  ├─ 4. 定理1 子列收敛定理
│  │  ├─ 收敛 ⟹ 任何子列收敛且同极限
│  │  ├─ 推论：lim a_n=a ⇔ lim a_{2k}=a 且 lim a_{2k−1}=a
│  │  └─ 陷阱：lim a_{3k}=lim a_{3k+1}=a 推不出 lim a_n=a（a_{3k+2} 这一支缺失）
│  ├─ 5. 判断发散的方法
│  │  ├─ 找到一个发散子列 -> 原数列发散
│  │  ├─ 找到两个子列收敛到不同极限 -> 原数列发散
│  │  └─ 逆否命题记法：A⇒B∩C，则 B̄∪C̄⇒Ā
│  ├─ 6. 绝对值充要
│  │  ├─ lim a_n=a ⟹ lim|a_n|=|a|（反之不成立，反例 a_n=(−1)^n）
│  │  └─ a=0 时：lim a_n=0 ⟺ lim|a_n|=0（证明极限为零的常用方法）
│  │     └─ 用法：转证 lim|a_n|=0，找 b_n 使 |a_n|≤b_n 且 b_n→0（如 |sin n|/n²≤1/n²）
│  └─ 7. 例题索引
│     ├─ 例题2.2：lim a_n=A ⟹ lim|a_n|=|A| -> 成立
│     │  └─ 方法：三角不等式 ||a|−|b||≤|a−b| + 定义；反过来不成立（a_n=(−1)^n）
│     ├─ 例题2.3：{n^((−1)^n)} 极限不存在
│     │  └─ 方法：取子列 {2n} 无界 -> 发散；易错：有收敛子列 {1/(2n−1)} 决定不了原数列收敛
│     └─ 例题2.4：分段 x_n 无界但不是无穷大量 -> 答案 D
│        └─ 方法：lim x_{2n}=0，lim x_{2n−1}=+∞（抓大头）；找不到大 N 后所有项 |x_n|>X
│
├─【三】收敛数列的性质（视频02；p088）
│  ├─ 1. 定理2 唯一性：lim x_n 存在则唯一（一个数列不能有两个"家"）
│  ├─ 2. 定理3 有界性：极限存在 ⟹ 数列全局有界（逆否：无界 ⟹ 极限不存在，例2.3 用）
│  ├─ 3. 定理4 保号性（也叫保序性）
│  │  ├─ 脱帽法：lim x_n>a（或<b）⟹ 某个大 N 之后 x_n>a（或<b）（严格，不能带等号）
│  │  ├─ 戴帽法：从某项起 x_n≥a 且极限存在 ⟹ lim x_n≥a（非严格，一定带等号）
│  │  └─ b 为任意实数，常考 b=0
│  │     └─ 口诀：脱帽不能带等号；戴帽抽象问题一定带等号
│  │        └─ 真题教训："把等号扔掉，就把分数扔掉了"
│  ├─ 4. 与函数极限性质对照
│  │  ├─ 数列：全局有界 / 有条件保号（某大 N 之后无穷多项）
│  │  └─ 函数：局部有界（邻域）/ 局部保号
│  └─ 5. 例题索引
│     └─ 例题2.5：a_n=1−(−1)^n/n 的最值 -> 答案 A（有最大有最小）
│        ├─ 方法：保号性证大 N 后 a_n 无资格参与最值比较，前有限项必有最大最小
│        ├─ 金句："最值是比较出来的"（莱布尼兹）
│        └─ 注：数学三真题改编（张宇称改简单了些）
│
├─【四】极限四则运算规则（视频03；p088-089）
│  ├─ 1. 三条规则
│  │  ├─ lim(x_n±y_n)=a±b；lim(x_n·y_n)=ab
│  │  └─ lim(x_n/y_n)=a/b，要求分母极限 b≠0（除法要小心，B 不能得零）
│  ├─ 2. 拆开前提：拆出的每一项极限必须是实数（都存在）
│  │  └─ 超实数思想：未确定唯一极限前不能做实数运算（不能拆开算）
│  ├─ 3. 存在性口诀（要背）
│  │  ├─ 存在±存在 = 存在；存在±不存在 = 不存在
│  │  └─ 不存在±不存在 = 不确定
│  ├─ 4. 推广至有限个数列（"有限个"才安全，无限个不成立）
│  ├─ 5. 易错：lim(a_n+b_n) 存在 不代表 a_n、b_n 各自存在
│  │  └─ 反例：sin n + (−sin n)=0，但 sin n 极限不存在
│  └─ 6. 例题索引
│     └─ 例题2.6：a_n+b_n→1，a_n−b_n→3 -> 答案 B（两数列极限均存在；lim a_n=2, lim b_n=−1）
│        └─ 方法：令 u_n=a_n+b_n、v_n=a_n−b_n（确定存在可做实数运算），解出 a_n=½(u_n+v_n)、b_n=½(u_n−v_n)
│
├─【五】海涅定理（归结原则）（视频03；p089-091，triple star）
│  ├─ 1. 定理内容
│  │  ├─ lim_{x→x0} f(x)=A 存在 ⇔ 对任何以 x0 为极限的数列 {x_n}（x_n≠x0，去心邻域内），lim f(x_n)=A
│  │  └─ 桥梁作用：联系数列极限与函数极限（"不知不觉中已在用"），命题老师特别喜欢
│  ├─ 2. 核心用途：数列不能用洛必达（离散不可导）-> 转函数极限后再洛必达/泰勒/等价无穷小
│  │  └─ 例：lim ln n / n = lim_{x→+∞} ln x / x = 0（洛必达）
│  ├─ 3. 三种常考取法
│  │  ├─ x→0 取 x_n=1/n：lim_{n→∞} f(1/n)=A（归结原则互化靠 X=1/N）
│  │  ├─ x→+∞ 取 x_n=n：lim f(n)=A
│  │  └─ 一般：x_n→a 且 x_n≠a，lim f(x_n)=A
│  │     └─ 例：(1−1/(n+1))^n → e^(−1)
│  ├─ 4. 直观：实数轴完备无缝隙；x→x0 如一排同学紧密走过，取离散点列=跳着取人（往回推须"任给"，缺一不可）
│  ├─ 5. 否定极限：找两条路径极限不相等 -> 原极限不存在
│  │  └─ 例：f(x)=x²D(x)（狄利克雷型）在 x=0 连续（无穷小×有界 / 夹逼），一切 x≠0 不连续（有理/无理两条路径极限不同）——"一点连续推不出附近连续"
│  ├─ 6. 新增结论（要背）
│  │  └─ (1+1/n)^n − e ~ −e/(2n)（n→∞；由第1讲例1.24 (1+x)^(1/x)−e ~ −(e/2)x 令 x=1/n）
│  │     └─ 若 (1+1/n)^n−e 与 a/n 等价，则 a=−e/2（真题常考）
│  └─ 7. 例题索引
│     ├─ 例题2.7：(1/x)sin(1/x) 在 x→0 是 -> 答案 B（无界量但不是无穷大量）
│     │  ├─ 方法：取 x_n=1/(nπ) 得 0；取 x'_n=1/((2n+½)π) 得 +∞，两条路径极限不等
│     │  └─ 易错：无界≠无穷大；否定极限必须取两条矛盾路径
│     └─ 例题2.8：lim ⁿ√[(cos(1/√n))^(n²)] -> 答案 e^(−1/2)（已验证：≈0.6065）
│        └─ 方法：1^∞ 型 u^v~e^(v(u−1))，归结原则转函数极限 + ln(1+t)~t、cos狗−1~−½狗²
│
├─【六】夹逼准则（视频04；p091-094，triple star，本讲最难的"不等思想"）
│  ├─ 1. 准则内容
│  │  ├─ 条件①从某项起 y_n≤x_n≤z_n（不需验证等号）
│  │  ├─ 条件②lim y_n = lim z_n = a（a 可为常数或同号无穷大 +∞/−∞）
│  │  └─ 结论：lim x_n = a
│  │     └─ 名称：夹逼（"夹"在中间 + "逼"近，缺一不可；不叫"两边夹/三明治"）
│  ├─ 2. 不等思想（double/triple star）：集中体现考研数学的重要思想，真正有区分度
│  │  └─ 口诀："大喊一声哪里跑——被逼近到 a/正无穷/负无穷，回答完毕"（考场上心里喊，别喊出声提醒别人）
│  ├─ 3. 放缩两大来源（要背）
│  │  ├─ 已知方法（命题不提示，须自己掌握）：简单放大缩小 / 重要不等式①-⑫ / 闭区间连续函数最值 / 压缩映射
│  │  └─ 非经典方法（命题必给提示，往往是解答题第 1 问，例2.11 型）
│  ├─ 4. 放缩方法细分
│  │  ├─ 简单放大缩小：分母统一，分母越大分数越小
│  │  │  ├─ 无穷项相加：n·u_min ≤ u_1+…+u_n ≤ n·u_max（先放缩后取极限）
│  │  │  └─ 有限项相加（u_i≥0）：1·u_max ≤ Σ ≤ n·u_max（缩小端只留最大项）
│  │  ├─ 重要不等式①-⑫（一到十二都要背，背下来放缩能力立即上去）
│  │  │  ├─ ① |a±b|≤|a|+|b| 及 n 个推广；② ||a|−|b||≤|a−b|
│  │  │  ├─ ③ √(ab)≤(a+b)/2≤√((a²+b²)/2)；④ |ab|≤(a²+b²)/2
│  │  │  ├─ ⑤ a≥b≥0 时 m>0 则 a^m≥b^m，m<0 则 a^m≤b^m
│  │  │  ├─ ⑥ 分式放缩：0<a<x<b, 0<c<y<d 则 c/b<y/x<d/a
│  │  │  ├─ ⑦ sinx<x<tanx(0<x<π/2)；sinx<x(x>0)
│  │  │  ├─ ⑧ x<tanx<4x/π(0<x<π/4)；⑨ sinx>2x/π(0<x<π/2)
│  │  │  ├─ ⑩ arctanx≤x≤arcsinx(0≤x≤1)（递推 x_{n+1}=arctan x_n<x_n 单调减）
│  │  │  ├─ ⑪ e^x≥x+1（x_{n+1}=e^x_n−1≥x_n 单调不减）；⑫ x−1≥lnx（x_{n+1}=ln x_n+1≤x_n 单调不增）
│  │  │  └─ 补充：1/(1+x)<ln(1+1/x)<1/x(x>0)（中值定理可证）
│  │  ├─ 闭区间上连续函数必有最大值最小值（放缩来源③，归入中值定理章再讲）
│  │  ├─ 压缩映射原理（见【七】节4）
│  │  └─ 题设条件推证（例2.11 型）
│  ├─ 5. 放缩精度原则（视频强调）：放大的要小、缩小的要大（放缩别过头，如 sinx 放大到 1 就失效）
│  ├─ 6. 例题索引
│  │  ├─ 例题2.9：Σ_{i=1}^n i/(n²+n+i) -> 答案 1/2（已验证）
│  │  │  ├─ 方法：分母统一放缩（全取最大/最小分母）夹逼；"找带头大哥"看最高次项系数比
│  │  │  └─ 考情：N 项和的极限数学二几乎年年考（本质是级数问题）
│  │  ├─ 例题2.10：lim ⁿ√(a_1^n+…+a_m^n) = max{a_i}（结论要背）
