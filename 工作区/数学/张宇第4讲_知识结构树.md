│  ├─ 整讲结构 = 十个标题（2个基本要素 + 8种题型）
│  │  └─ "考试不可能再出这8种题型之外的类型，8种都是复习重点"

│  │  ├─ 基本求导公式（"熟稔于心，倒背如流"——倒着背就是后面的积分公式）
│  │  └─ 四则运算（加减乘除求导法则）
│  ├─ 八种题型（张宇：不需要区分哪个更重要，哪个都重要、都容易考）

│  ├─ 题型定位：选择题
│  ├─ 目标：①四则+复合+基本导数公式；微分四则+一阶微分形式不变性 ②了解高阶导数，会求简单函数高阶导 ③会求分段/隐函数/参数方程（仅数一二）/反函数的导数
│  ├─ 重难点：复合函数求导，分段函数求导，隐函数求导
│  └─ 范围标记：参数方程所确定函数的导数"仅数学一、数学二"（数二需掌握，p125）
│     └─ 本讲 4 个视频张宇未专门区分数二与数一/数三（微分计算为三套卷共同重点）
│
├─【一】基本求导公式（视频02；p126）
│  ├─ 公式块A 幂/指/对
│  │  ├─ (x^α)'=α·x^(α−1)（"拿下来，指数里头减个一"）
│  │  ├─ (a^x)'=a^x·ln a；(e^x)'=e^x
│  │  ├─ (log_a x)'=1/(x·ln a)；(ln x)'=1/x
│  ├─ 公式块B 绝对值对数（考研真题常考，命题老师要求不分情况讨论）
│  │  ├─ (ln|x|)'=1/x（x≠0）；[ln|u(x)|]'=u'(x)/u(x)
│  │  └─ 口诀："ln 求导是绝对值而不见"（视绝对值而不见）
│  ├─ 公式块C 三角/反三角
│  │  ├─ sin→cos；cos→−sin（负号别忘了）
│  │  ├─ tan→sec²；cot→−csc²；sec→sec·tan；csc→−csc·cot（sec/tan 常出错提醒注意）
│  │  ├─ arcsin→1/√(1−x²)；arccos→−1/√(1−x²)
│  │  └─ arctan→1/(1+x²)；arccot→−1/(1+x²)
│  ├─ 公式块D 反双曲
│  │  ├─ [ln(x+√(x²+1))]'=1/√(x²+1)
│  │  └─ [ln(x+√(x²−1))]'=1/√(x²−1)
│  └─ 高阶铺垫（为【十】埋伏笔）
│     ├─ (a^x)⁽ⁿ⁾=a^x·(ln a)^n；(e^x)⁽ⁿ⁾=e^x
│     └─ 金句："e^x 不论怎么求导永远是他自己，始终如一，不忘初心"
│
├─【二】四则运算（视频02；p126-127）
│  ├─ 和差：(u±v)'=u'±v'；d(u±v)=du±dv
│  ├─ 积：(uv)'=u'v+uv'（口诀"前导后不动+前不动后导"）
│  │  ├─ 三乘积：(uvw)'=u'vw+uv'w+uvw'（"不患寡患不均""三人排一排每人一巴掌"）
│  │  └─ 重要结论：因式超过三个一般不要直接求导，要另谋他法
│  ├─ 商：(u/v)'=(u'v−uv')/v²（看成 u·(1/v)，用乘法+复合求导再通分）
│  ├─ 注：乘积公式证明（2015年考研真题考过）
│  │  └─ 导数定义 + 分子加减 u(x)·v(x+Δx) 恒等变形，特指点/泛指点两式
│  └─ 例4.1 f(x)=∏[tan(πx^n/4)−n]（n=1..100），f'(1) → −π·99!/2（已验证通式）
│     └─ 方法：100项→两项 [tan(πx/4)−1]·G(x)，代 x=1 含 G' 项消失，剩 sec²(π/4)·(π/4)·G(1)
│
├─【三】复合函数与微分形式不变性（视频02；p128-129）
│  ├─ 链式法则：{f[g(x)]}'=f'[g(x)]·g'(x)
│  │  ├─ 符号辨析：撇在最外=对 x（整体）求导；f' 在中间=对中间变量 g(x) 求导（"看清求导符号的位置"）
│  │  ├─ 三层：f'x = f'u·u'v·v'x（"考试最多3层"）
│  │  └─ 助记：歌词"如果你愿意一层一层一层地剥开它的心……"
│  ├─ 一阶微分形式不变性：df(u)=f'(u)·du，无论 u 是自变量还是中间变量都成立（"微分学中最重要的计算方法"）
│  │  ├─ 例：d[e^(x²)]=e^(x²)·d(x²)；d[(ln x)²]=2(ln x)·d(ln x)
│  └─ 例题索引
│     ├─ 例4.2 y=ln(x+√(x²+a²))，y'(0) → 1/|a|（已验证）
│     │  └─ a=1 即反双曲正弦（回顾第1讲）
│     ├─ 例4.3 f={x≥1 ln√x；x<1 2x−1}，y=f(f(x))，dy/dx|_{x=e} → 1/e（已验证）
│     │  └─ 方法：先代点不展开，f'(e)=1/(2e)、f'(1/2)=2，乘积 1/e；注意 x=e 不是分段点
│     └─ 例4.4 y=e^(sin(ln x))，求 dy → e^(sin ln x)·cos(ln x)·(1/x)·dx（已验证）
│
├─【四】分段函数的导数（视频03；p130-131）
│  ├─ 核心规则
│  │  ├─ 分段点：用导数定义求（右导用右侧表达式、左导用左侧表达式，比较是否相等）
│  │  ├─ 非分段点：用导数公式求（x>x0 对 f1'，x<x0 对 f2'）
│  │  └─ 分段点无定义 ⇒ 连连续都没有，直接不谈可导
│  ├─ 例4.5 y=ln|x| → y'=1/x（x≠0），两段结果相同（视绝对值而不见）
│  └─ 例4.6 y=|x·e^(−x)|，求 y'' → x=0 一阶不可导（左−1≠右+1），y'' 分段给出
│     ├─ 答案：x<0 时 y''=e^(−x)(2−x)；x>0 时 y''=e^(−x)(x−2)
│     └─ 易错：e^(−x)>0 恒正，去绝对值只看 x 的正负
│
├─【五】反函数的导数（视频03；p131-132）
│  ├─ 一阶：y=f(x) 单调可导且 f'(x)≠0，反函数 x=φ(y)，则 φ'(y)=1/f'(x)（dx/dy=1/(dy/dx)）
│  │  └─ arcsin 推导：(arcsin x)'=1/cos y=1/√(1−sin²y)=1/√(1−x²)（回到基本公式表）
│  ├─ 二阶（重要，建议背）
│  │  ├─ y''xx = −x''yy/(x'y)³；对称 x''yy = −y''xx/(y'x)³
│  │  └─ 关键：dy/dx 是 y 的函数，d/dx = d/dy·dy/dx（恒等变形）
│  └─ 例4.7 x>0 时 y=3x²+e^x 有反函数 φ，φ''(3+e) → −1/(6+e)²（已验证）
│     └─ 方法：直接套公式 φ''(y)=−f''/(f')³，由 3+e=3x²+e^x 得 x=1（"送分题，关键看多快拿到"）
│
├─【六】隐函数求导法（视频03；p132）
│  ├─ 方法两步
│  │  ├─ ① F(x,y)=0 两边对 x 求导，注意 y=y(x) 是中间变量（凡含 y 的项都可能是复合）
│  │  └─ ② 解出 y'（得含 y' 的方程）
│  └─ 例4.8 y³+xy²+x²y+6=0，y'(1)=0，求 y''(1) → 4/9（已验证数值）
│     ├─ 注意：y² 求导=2yy'、三项乘积求导；代 y'(1)=0 解出 y(1)=−2（y=0 代回不成立舍去）
│     └─ 金句："考研特别爱考""一定要仔细，一定要小心"；做完"打个井号代表结束"
│
├─【七】参数方程所确定的函数的导数（视频03；p132-134，仅数学一、数学二）
│  ├─ 一阶：dy/dx = ψ'(t)/φ'(t)（"分子分母同时除以 dt"；t 是中间人传话，两口子吵架找第三者）
│  ├─ 二阶：记 dy/dx=Ω(t)，d²y/dx²=Ω'(t)/φ'(t)（记成一个新表达式，不必背两个展开式）
│  └─ 例题索引
│     ├─ 例4.9 x=sin t，y=t·sin t+cos t，d²y/dx²|_{t=π/4} → √2（已验证）
│     │  └─ 方法：dy/dx=(dy/dt)/(dx/dt)=t，d²y/dx²=(dt/dx)=1/cos t
│     ├─ 例4.10 x=arctan t，e^t+2y−ty²=0（打星，小综合）→ dy/dx=(1+t²)(y²−e^t)/[2(1−ty)]
│     │  └─ 方法：参数式+隐函数综合，dy/dt 对隐式方程两端对 t 求导解出，dx/dt=1/(1+t²)
│     └─ 考情："这种题以前在真题里也考过"
│
├─【八】对数求导法（视频04；p134）
│  ├─ 适用：多项相乘/相除/开方/乘方的式子（"一般先取对数再求导"）
│  ├─ 步骤：①取对数 ln y=ln f(x) ②对数性质化简（乘变加、除变减、幂变倍数）③两边求导 y'/y=(ln f(x))' ④y'=y·(ln f(x))'
│  └─ 例4.11 x·e^(f(y))=e^y·ln2（f 二阶可导，f'(y)≠1），求 d²y/dx²
│     ├─ 答案：y'' = −{[1−f'(y)]²−f''(y)}/{x²·[1−f'(y)]³}（sympy 已验证）
│     └─ 条件检验：凡"谁不等于谁/不得零"往往因在分母，可检验结果；x>0 满足取对数条件
│
├─【九】幂指函数求导法（视频04；p134-135）
│  ├─ 核心：u(x)^v(x)=e^(v·ln u)（底>0 且≠1），转复合函数求导；"公式不要记，直接求导"
│  ├─ 例4.12 y=x^x（x>0）→ y'=x^x·(1+ln x)（已验证）
│  └─ 例4.13 y=x^(1/x)（x>0）→ y'=x^(1/x−2)·(1−ln x)（已验证；y'=0 得 x=e，为第5讲驻点埋伏笔）
│     └─ 金句："不叫简单，它叫经典，考研就喜欢考这种经典的东西""四两拨千斤"
│
└─【十】高阶导数（视频04；p135-141，三颗星，必考，区分度最高）
   ├─ 定位："一阶二阶导谁都会，没有区分度；高阶导数是区分度最高的热门考点"
   │  └─ 常考：f 的十阶导数在零点的值之类，"用普通方法根本没法解决"
   ├─ 方法一：归纳法（search and research，逐次求导探索规律得通式）
   │  ├─ 例4.14 (sin x)⁽ⁿ⁾=sin(x+n·π/2)（诱导公式"奇变偶不变，符号看象限"）
   │  ├─ 常用高阶导公式5条（要背，记不住要会快速推导）
   │  │  ├─ (e^(ax+b))⁽ⁿ⁾=aⁿ·e^(ax+b)
   │  │  ├─ [sin(ax+b)]⁽ⁿ⁾=aⁿ·sin(ax+b+nπ/2)
   │  │  ├─ [cos(ax+b)]⁽ⁿ⁾=aⁿ·cos(ax+b+nπ/2)
   │  │  ├─ [ln(ax+b)]⁽ⁿ⁾=(−1)^(n−1)·aⁿ·(n−1)!/(ax+b)ⁿ
   │  │  └─ (1/(ax+b))⁽ⁿ⁾=(−1)ⁿ·aⁿ·n!/(ax+b)^(n+1)
   │  ├─ 例4.15 y=(1−x)/(1+x)，y⁽ⁿ⁾(0) → (−1)ⁿ·2·n! 选A（已验证 n=3）
   │  │  └─ 恒等变形 y=−1+2/(1+x) 套 (1/(ax+b))⁽ⁿ⁾ 公式
   │  └─ 例4.16 f'(x)=f(x)² → f⁽ⁿ⁾(x)=n!·[f(x)]^(n+1)（归纳 + 数学归纳法证明）
   ├─ 方法二：莱布尼茨公式（主要考乘积形式）
   │  ├─ (uv)⁽ⁿ⁾=Σ C(n,k)·u⁽ⁿ⁻ᵏ⁾·v⁽ᵏ⁾（k=0..n，共 n+1 项）
   │  │  └─ 关键词："此消彼长，阶数相加等于 n"（u、v 求导次数互补）
   │  ├─ 关键技巧：u 或 v 取低次幂函数（如 x²），求几阶导变 0，后面项全部消失
   │  ├─ 系数记忆：杨辉三角（1；1 1；1 2 1；1 3 3 1；1 4 6 4 1）
   │  └─ 例4.17 f(x)=x·e^x → f⁽ⁿ⁾=(n+x)·e^x（已验证 n=3）
   │     └─ 莱布尼茨只有2项（x 二阶导为0），"求 n 阶导就加个 n"
   ├─ 方法三：泰勒展开式（无穷阶可导，用展开式求高阶导）
   │  ├─ 抽象展开：f(x)=Σ f⁽ⁿ⁾(x0)/n!·(x−x0)ⁿ；零点展开 f(x)=Σ f⁽ⁿ⁾(0)/n!·xⁿ
   │  ├─ 具体展开（x0=0，常用展开式要熟记，"每天起床头件事先背一遍展开式"）
   │  │  ├─ e^x=Σ xⁿ/n!（全实数）；1/(1+x)=Σ(−1)ⁿxⁿ（−1<x<1）；1/(1−x)=Σxⁿ（−1<x<1）
   │  │  ├─ ln(1+x)=Σ(−1)^(n−1)xⁿ/n（−1<x≤1）
   │  │  ├─ sin x、cos x（全实数）；(1+x)^α（收敛域按 α 分四段）；tan、arcsin、arctan 前三项
   │  ├─ 唯一性：无论何种方法展开，泰勒展开式唯一 → 比较系数求 f⁽ⁿ⁾(x0)（"由唯一性，比较系数"）
   │  └─ 例题索引
   │     ├─ 例4.18 f=x²·ln(1−x)，f⁽ⁿ⁾(0) → −n!/(n−2)（n≥3）选A（已验证 n=4）
   │     │  └─ 方法：ln(1−x)=−Σx^m/m，乘 x² 具体展开，令 n=m+3 比较系数
   │     └─ 例4.19 f=x²·2^x，f⁽ⁿ⁾(0) → n(n−1)·(ln2)^(n−2)（已验证 n=4）
   │        └─ 两法：莱布尼茨3项（C(n,2)=n(n−1)/2）/ 泰勒（2^x=e^(x·ln2)，回顾第1讲例1.11）
   ├─ 基础习题精练 4.1~4.8（p141-144，带答案与方法）
   │  ├─ 4.1 h=e^(1+g(x))，h'(1)=1，g'(1)=2 → g(1)=−ln2−1 选C
   │  ├─ 4.2 f(x)=x·lim(1−2t)^(−x/t)=x·e^(2x)，f'(x)=(1+2x)·e^(2x)（已验证）
   │  ├─ 4.3 f'(x)=A·e^x，反函数二阶导 → −1/(A²·e^(2x))（已验证）
   │  ├─ 4.4 参数方程 x=ln(1+t²)+1，y=2arctan t−(t+1)² → d²y/dx²=−(1+2t)(1+t²)/(2t)（已验证）
   │  ├─ 4.5 f'=e^f，f(2)=1 → f⁽ⁿ⁾(2)=(n−1)!·eⁿ（数值验证 n=3）
   │  ├─ 4.6 sin(xy)=ln((x+e)/y)+1，y'(0) → e−e⁴（数值验证 y(0)=e²）
   │  ├─ 4.7 g 二阶可导，g(0)=g'(0)=0，f={g(x)/x；x=0 为0}，证 f' 在 x=0 连续（导数定义+洛必达）
   │  └─ 4.8 f=x²·ln(1+x)，f⁽ⁿ⁾(0) → (−1)^(n−1)·n!/(n−2)（n≥3；莱布尼茨/泰勒两法一致）
   │
   └─ 考情提示
      ├─ 高阶导数常考具体某点的值（如零点的十阶导）而非通式
      └─ "要考就得考这种题，看起来非常简洁，简洁美、对称美"
