2027考研数学基础通关600题（线代分册）

A. $\lambda_1 \neq 0$.
B. $\lambda_2 \neq 0$.
C. $\lambda_1 = 0$.
D. $\lambda_2 = 0$.

【答案】B

【解析】令 $k_1\alpha_1 + k_2 A(\alpha_1 + \alpha_2) = 0$，则 $k_1\alpha_1 + k_2\lambda_1\alpha_1 + k_2\lambda_2\alpha_2 = 0$，$(k_1 + k_2\lambda_1)\alpha_1 + k_2\lambda_2\alpha_2 = 0$，由于 $\alpha_1, \alpha_2$ 线性无关，所以有 $\begin{cases} k_1 + k_2\lambda_1 = 0, \\ k_2\lambda_2 = 0. \end{cases}$

当 $\lambda_2 \neq 0$ 时，$k_1 = k_2 = 0$，此时 $\alpha_1, A(\alpha_1 + \alpha_2)$ 线性无关；反过来，若 $\alpha_1, A(\alpha_1 + \alpha_2)$ 线性无关，则必有 $\lambda_2 \neq 0$，否则 $\alpha_1$ 与 $A(\alpha_1 + \alpha_2) = A\alpha_1 + A\alpha_2 = A\alpha_1 = \lambda_1\alpha_1$ 线性相关，故B正确.

6. 设 $A$ 为三阶矩阵，满足 $\mathrm{r}(A-2E) < \mathrm{r}(A-E) < \mathrm{r}(A)$，则 $|A| = $ \_\_\_\_\_\_\_\_.

【答案】4

【解析】由 $A$ 为三阶矩阵可知 $\mathrm{r}(A) \leqslant 3$，故不等式 $\mathrm{r}(A-2E) < \mathrm{r}(A-E) < \mathrm{r}(A)$ 只可能为 $0 < 1 < 2$ 或 $1 < 2 < 3$.
若为 $0 < 1 < 2$，此时 $\mathrm{r}(A-2E) = 0$，$\mathrm{r}(A) = 2$，而由 $\mathrm{r}(A-2E) = 0$ 得 $A = 2E$，这与 $\mathrm{r}(A) = 2$ 相矛盾，故 $\mathrm{r}(A-2E) < \mathrm{r}(A-E) < \mathrm{r}(A)$ 只可能是 $1 < 2 < 3$.
此时 $\mathrm{r}(A-2E) = 1$，$\mathrm{r}(A-E) = 2$，均非满秩，说明 $A$ 有特征值 $2, 1$，且 $3 - \mathrm{r}(A-2E) = 2$，说明 $2$ 应为 $A$ 的二重特征值，故 $A$ 的特征值为 $2, 2, 1$，可得 $|A| = 2 \times 2 \times 1 = 4$.

7. 设 $A$ 为三阶不可逆矩阵，若三维线性无关列向量 $\alpha, \beta$ 满足 $A\alpha = \beta$，$A\beta = \alpha$，则 $\mathrm{tr}(A) = $ \_\_\_\_\_\_\_\_.

【答案】0

【解析】由 $A$ 不可逆可知 $A$ 有特征值 $0$，由 $A\alpha = \beta$，$A\beta = \alpha$ 两式相加得 $A(\alpha + \beta) = \alpha + \beta$，两式相减得 $A(\alpha - \beta) = -(\alpha - \beta)$，故 $A$ 有特征值 $1, -1$.
综上，$A$ 有三个特征值 $0, 1, -1$，故 $\mathrm{tr}(A) = 0 + 1 + (-1) = 0$.

8. 设矩阵 $A = \begin{pmatrix} 2 & -1 & 0 \\ -2 & 3 & 0 \\ 0 & 0 & 4 \end{pmatrix}$，向量 $\xi = (-2, 7, 1)^{\mathrm{T}}$.

(I) 将 $\xi$ 由 $A$ 的线性无关的特征向量线性表示；

(II) 求 $A^n \xi$.

【答案】(I) $\xi = \xi_1 + 3\xi_2 + \xi_3$，其中 $\xi_1 = (1, 1, 0)^{\mathrm{T}}$，$\xi_2 = (-1, 2, 0)^{\mathrm{T}}$，$\xi_3 = (0, 0, 1)^{\mathrm{T}}$；
(II) $(1 - 3 \cdot 4^n, 1 + 6 \cdot 4^n, 4^n)^{\mathrm{T}}$.
