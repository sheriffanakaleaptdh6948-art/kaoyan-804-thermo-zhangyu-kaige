### 4.4 套皮二次型

**【例 1】** 设 $A$ 是 3 阶实对称矩阵，且 $|A|=2, A^* = A - E$，其中 $A^*$ 是 $A$ 的伴随矩阵，则二次型 $x^{\mathrm{T}} A x$ 的规范形为（ ）.

(A) $-y_1^2 - y_2^2 + y_3^2$
(B) $-y_1^2 - y_2^2 - y_3^2$
(C) $y_1^2 + y_2^2 - y_3^2$
(D) $y_1^2 + y_2^2 + y_3^2$

**【例 2】** 设二次型 $f(x_1, x_2, x_3)$ 在正交变换 $x=Qy$ 下的标准形为 $2y_1^2 + y_2^2 - y_3^2$，其中 $Q=[\eta_1, \eta_2, \eta_3]$. 若正交矩阵 $Q_1 = [-\eta_3, \eta_1, -\eta_2]$，则 $f(x_1, x_2, x_3)$ 在正交变换 $x=Q_1 y$ 下的标准形为（ ）.

(A) $2y_1^2 + y_2^2 - y_3^2$
(B) $-y_1^2 + 2y_2^2 - y_3^2$
(C) $-y_1^2 + 2y_2^2 + y_3^2$
(D) $y_1^2 + 2y_2^2 - y_3^2$

**【例 3】** 设 $\alpha, \beta$ 是 3 维单位正交列向量，则二次型 $f(x_1, x_2, x_3) = x^{\mathrm{T}} (2\alpha\alpha^{\mathrm{T}} + \beta\beta^{\mathrm{T}}) x$ 的规范形为（ ）.

(A) $y_1^2 + y_2^2$
(B) $y_1^2 - y_2^2$
(C) $y_1^2 + y_2^2 - y_3^2$
(D) $y_1^2 - y_2^2 - y_3^2$
