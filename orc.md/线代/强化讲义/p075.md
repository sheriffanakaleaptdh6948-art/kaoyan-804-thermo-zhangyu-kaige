**【例 3】** 设二次型 $f(x_1, x_2, x_3) = \boldsymbol{x}^{\mathrm{T}} \boldsymbol{A} \boldsymbol{x} = x_1^2 + x_2^2 + 2x_3^2 + 2x_2 x_3$， $g(y_1, y_2, y_3) = \boldsymbol{y}^{\mathrm{T}} \boldsymbol{B} \boldsymbol{y} = \sum_{i=1}^3 \sum_{j=1}^3 A_{ij} y_i y_j$ 其中 $A_{ij}$ 是 $\boldsymbol{A}$ 中 $a_{ij} (i, j=1, 2, 3)$ 的代数余子式，$\boldsymbol{A}, \boldsymbol{B}$ 均是实对称矩阵.
(1) 是否存在正交矩阵 $\boldsymbol{Q}$，使得 $\boldsymbol{Q}^{\mathrm{T}} \boldsymbol{A} \boldsymbol{Q} = \boldsymbol{B}$.
(2) 是否存在可逆矩阵 $\boldsymbol{P}$，使得 $\boldsymbol{P}^{\mathrm{T}} \boldsymbol{A} \boldsymbol{P} = \boldsymbol{B}$. 若不存在请说明理由；若存在，试求出一个可逆矩阵 $\boldsymbol{P}$.

**【例 4】** 设二次型 $f(x_1, x_2) = \boldsymbol{x}^{\mathrm{T}} \boldsymbol{A} \boldsymbol{x} = x_1^2 + 2x_2^2 + 2x_1 x_2$，二次型 $g(x_1, x_2) = \boldsymbol{x}^{\mathrm{T}} \boldsymbol{B} \boldsymbol{x} = -x_1^2 + 2x_2^2 + 2x_1 x_2$.
(1) 求可逆线性变换 $\boldsymbol{x} = \boldsymbol{C} \boldsymbol{y}$ 将二次型 $f$ 化为规范形.
(2) 求一个可逆矩阵 $\boldsymbol{P}$ 及对角矩阵 $\boldsymbol{\Lambda}$，使得 $\boldsymbol{P}^{\mathrm{T}} \boldsymbol{A} \boldsymbol{P} = \boldsymbol{E}$ 且 $\boldsymbol{P}^{\mathrm{T}} \boldsymbol{B} \boldsymbol{P} = \boldsymbol{\Lambda}$.
