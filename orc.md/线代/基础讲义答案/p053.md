由（1），$\alpha_1$ 可由 $\alpha_2, \alpha_3$ 表出（设 $\alpha_1 = l_2 \alpha_2 + l_3 \alpha_3$），代入得 $\alpha_4$ 可由 $\alpha_2, \alpha_3$ 表出，与 $\alpha_2, \alpha_3, \alpha_4$ 线性无关矛盾，故 $\alpha_4$ 不能表出.

【例 15】设向量（I）$\beta_1, \beta_2, \cdots, \beta_t$，（II）$\alpha_1, \alpha_2, \cdots, \alpha_s$，则下列命题正确的是（ ）.

①若向量组（I）可由（II）线性表示，且 $s < t$，则必有（I）线性相关，

②若向量组（II）可由（I）线性表示，且 $s < t$，则必有（I）线性相关，

③若向量组（I）可由（II）线性表示，且（I）线性无关，则必有 $s \ge t$，

④若向量组（II）可由（I）线性表示，且（I）线性无关，则必有 $s \ge t$，

(A) ①④ (B) ③ (C) ②③ (D) ②④

[解] ①：（I）可由（II）表出，则 $r(\beta_1, \cdots, \beta_t) \le r(\alpha_1, \cdots, \alpha_s) \le s$，因 $s < t$，故 $r(\beta_1, \cdots, \beta_t) < t$，（I）线性相关，正确.

②：（II）可由（I）表出，则 $r(\alpha_1, \cdots, \alpha_s) \le r(\beta_1, \cdots, \beta_t) \le t$. $s < t$ 无法推出 $r(\beta_1, \cdots, \beta_t) < t$，（I）不一定相关，错误.

③：（I）可由（II）表出且（I）无关，则 $r(\beta_1, \cdots, \beta_t) = t$，又 $t \le r(\alpha_1, \cdots, \alpha_s) \le s$，故 $s \ge t$，正确.

④：（II）可由（I）表出且（I）无关，则 $r(\alpha_1, \cdots, \alpha_s) \le t$，无法推出 $s \ge t$，错误.

答案：B
