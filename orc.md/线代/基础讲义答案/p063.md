**【例 9】** 设 $A$ 为 $4 \times 3$ 矩阵，$\eta_1, \eta_2, \eta_3$ 是非齐次线性方程组 $Ax=\beta$ 的 3 个线性无关的解，$k_1, k_2$ 为任意常数，则 $Ax=\beta$ 的通解为（ ）.

(A) $\frac{\eta_2+\eta_3}{2} + k_1(\eta_1-\eta_2)$
(B) $\frac{\eta_2-\eta_3}{2} + k_1(\eta_2-\eta_1)$
(C) $\frac{\eta_2+\eta_3}{2} + k_1(\eta_3-\eta_1) + k_2(\eta_2-\eta_1)$
(D) $\frac{\eta_1-2\eta_2+\eta_3}{2} + k_1(\eta_1+\eta_2-2\eta_3) + k_2(\eta_1-\eta_2)$

**[解]** 首先从特解角度出发：因为 $\eta_1, \eta_2, \eta_3$ 是 $Ax=\beta$ 的解，对于选项中的特解部分：

由 $A\eta_i = \beta (i=1,2,3)$，则 $A\left(\frac{\eta_2+\eta_3}{2}\right) = \frac{1}{2}(A\eta_2 + A\eta_3) = \beta$；
$A\left(\frac{\eta_1-2\eta_2+\eta_3}{2}\right) = \frac{1}{2}(A\eta_1 - 2A\eta_2 + A\eta_3) = 0$， $A\left(\frac{\eta_2-\eta_3}{2}\right) = \frac{1}{2}(A\eta_2 - A\eta_3) = 0$（不是特解，排除 B、D）. 所以 $\frac{\eta_2+\eta_3}{2}$ 是 $Ax=\beta$ 的特解.

从齐次解与基础解系出发：齐次方程 $Ax=0$ 的解：由 $A(\eta_i - \eta_j) = A\eta_i - A\eta_j = 0 (i \neq j)$，可知 $\eta_1-\eta_2, \eta_3-\eta_1, \eta_2-\eta_3$ 等是 $Ax=0$ 的解.

基础解系秩：因 $\eta_1, \eta_2, \eta_3$ 线性无关所以，$(\eta_2-\eta_1), (\eta_3-\eta_1)$ 线性无关，可知 $r(A) \le 1$，又因为 $A$ 为非零矩阵（否则不可能为非齐次方程组），故 $r(A)=1$，齐次基础解系无关个数为 2，A 选项只有 1 个齐次解，无法构成基础解系排除 A.

C 选项中 $\frac{\eta_2+\eta_3}{2}$ 是特解，$\eta_3-\eta_1, \eta_2-\eta_1$ 是 $Ax=0$ 的线性无关解，可构成基础解系.

答案：C

**【例 10】** 设 $A=(\alpha_1, \alpha_2, \alpha_3, \alpha_4)$ 是 4 阶矩阵，非齐次线性方程组 $Ax=\beta$ 的通解为 $k(1, 0, -3, 2)^{\mathrm{T}} + (1, -1, 0, 1)^{\mathrm{T}}$，$k$ 为任意常数，记 $B=(\alpha_2+\beta, \alpha_4, \alpha_3, \alpha_2, \alpha_1)$. 求方程组 $Bx=\beta$ 的通解.

**[解]** 由 $Ax=\beta$ 通解 $k(1, 0, -3, 2)^{\mathrm{T}} + (1, -1, 0, 1)^{\mathrm{T}}$，可知齐次解 $\xi=(1, 0, -3, 2)^{\mathrm{T}}$（对应 $\alpha_1 - 3\alpha_3 + 2\alpha_4 = 0$），特解 $\eta=(1, -1, 0, 1)^{\mathrm{T}}$（对应 $\alpha_1 - \alpha_2 + \alpha_4 = \beta$），且 $r(A)=3$.
