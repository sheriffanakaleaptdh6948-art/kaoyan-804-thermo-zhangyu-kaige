**【8】**（李艳芳 900 题）设向量组 I：$\alpha_1, \alpha_2, \alpha_3$ 可由向量组 II：$\alpha_1, \alpha_2, \beta$ 线性表示，则（ ）.

（A）若 $\alpha_3$ 与 $\beta$ 线性无关，则 $\alpha_3$ 可由 $\alpha_1, \alpha_2$ 线性表示

（B）若 $\alpha_3$ 与 $\beta$ 线性无关，则向量组 I 与向量组 II 等价

（C）若向量组 I 与向量组 II 等价，则 $\alpha_3$ 与 $\beta$ 线性相关

（D）若 $\alpha_3$ 与 $\beta$ 线性相关但与 $\alpha_1$ 线性无关，则向量组 I 与向量组 II 等价

**[解]** 答案 D.

对选项 A 和 C，设 $\alpha_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \alpha_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \alpha_3 = \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix}, \beta = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}$，则向量组I与II等价，$\alpha_3$ 与 $\beta$ 线性无关，且 $\alpha_3$ 不可以由 $\alpha_1, \alpha_2$ 线性表示。选项 A 和 C 不正确。

对选项 B，设 $\alpha_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \alpha_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \alpha_3 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \beta = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}$，则 $\alpha_3$ 与 $\beta$ 线性无关，但是向量组II不可以由向量组I线性表示。选项 B 不正确。

对选项 D，由于 $\alpha_1, \alpha_3$ 线性无关，故 $\alpha_3 \neq 0$. 又 $\alpha_3$ 与 $\beta$ 线性相关，故 $\beta$ 可由 $\alpha_3$ 线性表示。从而向量组II可由向量组I线性表示。于是向量组I与II等价。选项 D 正确。

因此，应选 D.
