**【5】**（李林 880 题）设 $\boldsymbol{a}$ 为 $n$ 维单位列向量，$E$ 为 $n$ 阶单位阵，则（ ）.

(A) $E-\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 不可逆
(B) $E+\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 不可逆
(C) $E+2\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 不可逆
(D) $E-2\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 不可逆

[解]由已知，可设 $\boldsymbol{a}=(1,0,\cdots,0)^{\mathrm{T}}$，则 $r(\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}})=1$，$\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 的特征值为 $1, 0, \dots, 0$，故 $E-\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 的特征值为 $0, 1, 1, \dots, 1$，从而 $\left|E-\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}\right|=0$，于是 $E-\boldsymbol{a}\boldsymbol{a}^{\mathrm{T}}$ 不可逆，A 正确。

**【6】**（李林 880 题）设 $A, B$ 均是 $n$ 阶矩阵，则 $A \sim B$ 的充分条件是（ ）.

(A) $A^2$ 与 $B^2$ 相似
(B) $A$ 与 $B$ 有相同的特征值
(C) $A$ 与 $B$ 有相同的特征向量
(D) $A$ 与 $B$ 均与对角矩阵 $\Lambda$ 相似

[解]对于 A，若 $A \sim B$，则存在可逆矩阵 $P$，使得 $P^{-1}AP=B$，故 $P^{-1}A^2P=\left(P^{-1}AP\right)\left(P^{-1}AP\right)=B^2$，从而 $A^2 \sim B^2$. 但由 $A^2 \sim B^2$ 不能得到 $A \sim B$. 例如：取 $A=\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, B=\begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$，则由 $r(A) \neq r(B)$，知 $A$ 与 $B$ 不相似，但 $A^2=B^2$，即有 $E^{-1}A^2E=B^2$，故 $A^2 \sim B^2$，从而 A 是必要条件，不是充分条件。

对于 B，B 也是 $A \sim B$ 的必要条件，而非充分条件。由 $P^{-1}AP=B$，有
$$
|\lambda E-B|=\left|\lambda E-P^{-1}AP\right|=\left|P^{-1}(\lambda E-A)P\right|=|\lambda E-A|,
$$
即 $A, B$ 有相同的特征值，但 A 的例子告诉我们，虽然 $A, B$ 有相同的特征值 $\lambda_1=\lambda_2=0$，但 $A, B$ 不相似，故 B 不是 $A \sim B$ 的充分条件。

对于 C，若 $\boldsymbol{a}$ 是 $A$ 的属于特征值 $\lambda$ 的特征向量，$\boldsymbol{a}$ 是 $B$ 的属于特征值 $\mu$ 的特征向量，显然 $A, B$ 有相同的特征向量，但当 $\lambda \neq \mu$ 时，$A$ 与 $B$ 不相似，故 C 不是 $A \sim B$ 的充分条件。

对于 D，若 $A \sim \Lambda, B \sim \Lambda$，则 $A \sim B$，D 正确。
