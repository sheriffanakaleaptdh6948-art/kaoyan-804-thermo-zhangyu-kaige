$\text { 例: ...they both just pop into my mind... (2013, Translation) }$

译: ……它们 (指这两件事) 在我脑海里突然出现……

介词 into 表示 “进入……里面”，此句中介词短语 into my mind 表示 “进入我的脑海里”。

例: And so he reads—everything from encyclopedias to science fiction novels. (2018, Translation)

译: 于是, 他就这样读书——从百科全书到科幻小说, 什么都看。

介词 from…to…表示 “从……到……”，此句中介词短语 from encyclopedias to science fiction novels 表示 “从百科全书到科幻小说”。

3. 其他用法的介词

| 介词 | 表达含义 |
| --- | --- |
| of | $\begin{aligned} & \text { ……的…… (表示属性) } \\ & (\text { "A of B" 通常翻译为 "B的A" }) \end{aligned}$ |
| about | 关于…… |
| with/without | 伴随着有…… / 没有…… |
| for | 为了…… (表示目的) |
|  | 因为…… (表示原因) |
|  | 对于…… (表示对象) |
| by | 通过……方式或方法 |
|  | 被……做 (被动语态 + by + 动作的发出者) |
|  | 相差了…… (表示变化的差额) |
| as | 作为…… |
|  | 像……一样, 如同…… |
| like | 像……一样 |
|  | 例如, 比如 |
| despite, in spite of | 尽管…… |

例: The users of their services are not their customers. (2018, Reading Comprehension, Part A Text 3)

译: 它们 (指数字巨头) 服务的用户并不是它们的顾客。

介词 of 表示属性, 翻译成 “……的……”, 考研中最常出现的结构是 “A of B”, 翻译成 “B 的 A”。此句中介词短语 (The users) of their services 表示 “它们服务的 (用户)”。
