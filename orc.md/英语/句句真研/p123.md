通常是名词或代词来充当，但为了详细说明这个对象，随着表达信息的增多，就从“词—词组一句话”逐渐扩展，最后变成一个句子作主语，就出现了主语从句。其他名词性从句亦然。因此，在考研写作中，想详细说明某一个对象、概念或事情时，一定会使用到名词性从句，在稍后的考场攻略中会给大家讲解几种重要的名词性从句的写作模板。在阅读、翻译等题型中也必然会考查到名词性从句，尤其是在长难句中，因此找到并看懂名词性从句至关重要。

内容要点

(1) 名词性从句分为四类：宾语从句、表语从句、主语从句、同位语从句。

(2) 名词性从句的写法基本相同：连接词 + 陈述句。

(后面的陈述句缺什么，连接词加什么；如果不缺成分，则加 that)

|  |  |
|  |  |

(3) 名词性从句的位置不同。

名词性从句

| 宾语从句 | 三种位置 | 介宾 |
| --- | --- | --- |
|  |  | 形容词 + 宾语从句 |
| 表语从句 | 一种位置 | 系动词后（最常用的是 be 动词后） |
| 主语从句 | 两种位置 | 句首 |
|  |  | 句尾（句首用形式主语 it） |
| 同位语从句 | 一种位置 | 抽象名词后 |
