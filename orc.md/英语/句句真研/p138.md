2. 特殊的非限定性定语从句，补充说明整句话

一般的非限定性定语从句都是补充说明前面一个名词，即补充说明先行词；但还有一种特殊的非限定性定语从句，可以补充说明前面整句话，此时关系词只能用 which 或 as，且它们在从句中都作成分。which 和 as 引导这种特殊的非限定性定语从句时，用法上没有区别，区别主要在从句的位置上。which 引导的特殊非限定性定语从句只能位于主句后；而 as 引导的特殊非限定性定语从句可以位于主句前、中、后。换句话说，这种特殊的非限定性定语从句位于主句后，可以用 which 或 as 来引导，都可以；但位于主句前或主句中时，只能用 as 来引导，不能用 which。

例：…so the centres need to be well air-conditioned, which uses even more energy. (2011, Translation)

译：…因此数据中心还需要良好的空调环境，而这又会消耗更多的能量。

例：…it takes several days before a check is cashed and funds are withdrawn from the issuer’s account, which means that the writer of the check can earn interest on the funds in the meantime. (2013, Use of English)

译：…支票被兑现、资金从出票人账户中被取出之前会花费几天的时间，这就意味着出票人在此期间可以从这笔资金中赚取利息。

以上两句中，定语从句的关系词 which 都不是指前面的名词，而是指前面整句话。注意 which 从句位于句尾（主句后），还可以换成 as 来引导。

例：As Koziatek knows, there is learning in just about everything. (2018, Reading Comprehension, Part A Text 1)

译：正如科齐亚特克所认识到的，几乎一切事物都有学问。

非限定性定语从句 As Koziatek knows，其中 knows 是及物动词，所以后面缺宾语，而关系词 As 正好作这个成分，指后面整句话。
