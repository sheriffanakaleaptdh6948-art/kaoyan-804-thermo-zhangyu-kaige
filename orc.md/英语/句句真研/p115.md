(二) 宾语从句的位置

宾语从句的位置共有三种，分别是及物动词后（动宾）、介词后（介宾）、形容词后。

| 位置 | 真题例句 |
| --- | --- |
|  |  |
| 动单宾： |  |
| 及物动词+从句 | 例：Some worry that this is having a destructive effect on society... (2023, Reading Comprehension, Part A Text 3) |
|  | 译：有人担心这会对社会产生破坏性影响…… |
| 动双宾： |  |
| 及物动词+ | 例：HGTV has seriously changed how people view real estate. (2019, Reading Comprehension, Part B) |
| 人+从句 | 译：HGTV（美国家园频道）极大地改变了人们对房地产的看法。 |
|  |  |
| 介宾：介词+宾语从句 | 例：He reminds himself that not every lecture can be a Nobel winner; some will be less effective than others. (2014, Translation) |
|  | 译：他提醒自己，不是每堂课都有获诺贝尔奖的水准；总会有一些课的效果不如别的课好。 |
| 形容词+宾语从句 | 例：The survey... asks people if they worked less than 35 hours in the reference week. (2015, Reading Comprehension, Part A Text 4) |
|  | 译：这项调查……询问了人们在参照周的工作时长是否少于35小时。 |
|  | 例：...being human, you'll sometimes change your mind about what you fancy. (2013, Reading Comprehension, Part B) |
|  | 译：……作为人类，难免有时你会改变主意，想换换口味。 |
|  | 例：A Google search can leak between 0.2 and 7.0 grams of CO2, depending on how many attempts are needed to get the “right” answer. (2011, Translation) |
|  | 译：每用谷歌搜索一次就会释放出0.2克至7.0克的二氧化碳，释放量的多少取决于使用者需要搜索多少次才能得到“正确”答案。 |
|  | 例：I'm pretty confident we're at the bottom. (2010, Reading Comprehension, Part A Text 1) |
|  | 译：我相当确信我们现在处于谷底。 |
