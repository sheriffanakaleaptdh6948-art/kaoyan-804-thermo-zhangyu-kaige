$\text { 第一章 并列句 }$

What is 并列句?

所谓 “并列”，指的就是同样重要，例如：奥运会比赛的两个选手 “并列” 第一，指的就是两个选手的成绩一样，因此重要性也是一样的。同理，并列句指的就是多件事（两件或两件以上）同等重要。多件事由多个一件事（多个简单句）构成，而想要表示同等重要，连成并列句，就需要在多个简单句之间加上并列连词，即并列句的构成为 “多个简单句 + 并列连词”。简单句在本书的第一部分已经讲过，因此想学会并列句，接下来要做的就是掌握并列连词。根据多件事之间逻辑关系的不同，可以加入不同的并列连词，连成并列句。

How to use 并列句?

(一) 并列句的构成

1. 表示顺接的并列连词

| 并列连词 | 含义 |
| --- | --- |
| ... and... | ...和... |
| both... and... |  |
| not only... but... as well | 不但……而且…… |
| not only... but also... | (……和……) |
| not only... but... |  |
| not just... but (also)... |  |
| not merely... but (also)... |  |

例: That boy was Bill Gates, and he hasn’t stopped reading yet... (2018, Translation)

译: 那个男孩就是比尔·盖茨，而且，他至今依然没有停止阅读……

例: A few wealthy people will own all the capital, and the masses will struggle in an impoverished wasteland. (2017, Use of English)

译: 少数富人将拥有所有的财富，而大众将挣扎在贫困的荒芜之地。

capital /ˈkæpɪtl/ n. 资本

wasteland /ˈwɔːstlænd/ n. 荒地，荒漠

impoverished /ɪmˈpɒvərɪʃ/ adj. 穷困的，贫穷的
