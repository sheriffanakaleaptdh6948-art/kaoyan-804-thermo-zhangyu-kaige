5. 主系表 = 主语 + 系动词 + 表语

有些句子的句意中，没有实在的动作含义出现（即没有实义动词），但是没有动词又不能构成句子（简单句中必须要具备一个谓语动词），因此需要加入一类特殊的动词——虽然无实义，但是可以把句子前后“连系”起来——这类动词简称“系动词”。

Yet this understanding _ outdated.

然而，这种理解是过时的。

其中谓语动词部分“是”，很明显无实义，但是必须要加入动词才能前后“连系”起来，构成完整的句子，因此就加入了最常用的一种系动词——be 动词，来表示“是”这一含义，如下。

例：Yet this understanding is outdated. (2019, Reading Comprehension, Part A Text 1)

译：然而，这种理解是过时的。

考研真题中常出现的系动词，总结如下。

| 系动词 | 含义 | 真题例句 |
| --- | --- | --- |
| be | 是 | 例：More education is the new principle. (2018, Reading Comprehension, Part A Text 1) |
|  | (单独出现，无其他实义的动词) | 译：(接受)更多的教育是新的观念。 |
| get become turn go grow | 变得，成为 | 例：Teenagers are paradoxical. (2023, Reading Comprehension, Part A Text 4) |
|  | 译：青少年是矛盾的。 | 例：These purchases often become more valuable with time... (2014, Reading Comprehension, Part A Text 1) |
| look sound smell taste feel | 看/听/闻/尝/感觉起来 | 例：...the man looked puzzled and hurt. (2010, Reading Comprehension, Part A Text 2) |
|  | ... | 译：……这位男士看起来既迷茫又受伤。 |
|  | (感官动词) | 例：...the zone's future looks uncertain at best. (2020, Reading Comprehension, Part A Text 3) |
|  |  | 译：……往好了说，该区域的未来看起来并不明朗。 |

outdated /'aut'dertid/ adj. 过时的，陈旧的

look puzzled 看起来很困惑、茫然

paradoxical /'pæro'daksikl/ adj. 自相矛盾的，看似荒谬的

at best 充其量，至多
