3. 原因状语从句

| 从属连词 | 含义 | 真题例句 |
| --- | --- | --- |
| because | 因为…… | 例：I've also experienced greater success in achieving my specific fitness goals, because I'm training according to those goals, not the numbers on a scale. (2019, Use of English) |
| 译：在实现具体的健身目标方面，我也获得了更大的成功，因为我是根据这些目标来训练的，而不是体重秤上的数字。 |  |  |
| since | 因为…… | 例：Since weight loss is not my goal, it is less important for me to track my weight each week. (2019, Use of English) |
| 译：因为减肥不是我的目标，所以对我来说，每周跟踪我的体重（变化）就不那么重要了。 |  |  |
| as | 因为…… | 例：They also need better public relations skills than their predecessors, as the costs of even a minor slipup can be significant. (2020, Reading Comprehension, Part A Text 2) |
| 译：与前辈们相比，他们还需要更厉害的公关技巧，因为即使是一个小失误，代价也可能是巨大的。 |  |  |

because，since，as 三个从属连词都可以表示原因，这三个词表达的语气逐渐减弱，但是同学们不需要明确分辨，只要知道它们都表示“因为”即可。还有一个从属连词的词组 now that，表示“既然，由于……”，后接的原因常常是显而易见的事实，考研中不常见。
