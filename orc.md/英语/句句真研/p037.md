③情态动词没有人称的变化，即无论主语是谁，情态动词永远用原形，没有第三人称单数。

④情态动词变否定，直接后加 not；变疑问，直接提到主语前。

1. 情态动词表示 “情态”

| 情态动词 | 含义 | 真题例句 |
| --- | --- | --- |
| must | 必须 | 例：To some extent the housing sector must shoulder the blame. (2014, Reading Comprehension, Part A Text 4) |
| 译：从某种程度上说，房地产行业必须承担责任。 |  |  |
| can could | 能够 / 可以 | 例：They can also learn geometry by assembling a bicycle. (2018, Reading Comprehension, Part A Text 1) |
| 译：通过组装自行车，他们也可以学习几何。 |  |  |
| will would | 愿意 / 将要（表示“将要”常用于将来时态） | 例：In the past, workers with average skills... could earn an average lifestyle. (2013, Reading Comprehension, Part A Text 1) |
| 译：在过去，拥有一般技能的工人……就能过上普通的生活。 |  |  |
| may might | 可以 / 可能 | 例：Will you marry me? |
| 译：你愿意嫁给我吗？（求婚时常用，表示意愿，而非将来） |  |  |
|  |  | 例：...some will be less effective than others. (2014, Translation) |
|  |  | 译：...有一些（课）的效果将会不如别的好。 |
|  |  | 例：In effect, the approach would create a “walled garden” in cyberspace... (2011, Use of English) |
|  |  | 译：实际上，这种方式将在网络空间创建一种“围墙花园”…… |
| should | 应该 | 例：May I help you? |
|  |  | 译：我可以帮你吗？ |
|  |  | 例：...guilt may compensate for an emotional deficiency. (2019, Reading Comprehension, Part A Text 1) |
|  |  | 译：……内疚感或能弥补某种情感缺失。 |
|  |  | 例：We might then begin to solve our immigration challenges. (2013, Reading Comprehension, Part A Text 2) |
|  |  | 译：然后，我们才有可能开始解决我们（面临）的移民挑战。 |
|  |  | 例：Should they become charitable corporations? (2011, Reading Comprehension, Part A Text 2) |
|  |  | 译：它们（指报社）应该转变为慈善机构吗？ |
|  |  | 例：...I should have deep work scheduled for roughly the next month. (2018, Reading Comprehension, Part A Text 4) |
|  |  | 译：……我应该计划好接下来大约一个月的深入工作。 |

to some extent 在某种程度上，在一定程度上

shoulder /'faʊldə(r)/ v. 承担，肩负 n. 肩膀

housing sector 房地产行业

assemble /ə'sembrl/ v. 组装，装配；集合，聚集

shoulder the blame 承担责任，承担过失

average /'ævərdɪ/ adj. 普通的，中等的；平均的
