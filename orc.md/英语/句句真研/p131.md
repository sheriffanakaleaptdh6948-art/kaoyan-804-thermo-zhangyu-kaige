【补充】定语从句中的关系词有两个作用：一是“引导”，引导定语从句，连接先行词和从句；二是“替代”，关系词在定语从句中充当成分，它替代了从句中跟先行词一样的成分，如下图。

| 先行词 = 关系词 |  |
| --- | --- |
| This is a skill | that will help them all throughout life. |
| 主句 | 定语从句 |
| This is a skill. | A skill will help them all throughout life. |

原本是两个句子，有相同的成分 a skill，两个句子合并时，为了避免重复，把相同的成分替换掉，即把 a skill 替换成了 that（因为指代事物）。通过上图可以得出结论：定语从句的关系词在从句中作成分，且所作成分与先行词相同（即关系词 = 先行词）。

How to use 定语从句？

(一) 定语从句的写法

和名词性从句相似，定语从句的写法是“关系词 + 陈述句”，关键在于关系词的选择。通过名词性从句可以推测出：关系词的选择就看后面的陈述句中缺什么成分。定语从句中后面的陈述句所缺少的成分，是由关系词来充当的；而关系词替代的成分又跟先行词相同，所以定语从句的关系词的选择，就是四个字——看先行词。如果先行词是事或物，选择对应的关系词 which 或 that；如果先行词是人，选择对应的关系词 who、whom 或 that，以此类推，如下。

| 先行词 | 关系词 |
| --- | --- |
| 事 / 物 | which/that |
| 人 | who/whom/that |
| 人 / 物（表示人或物的所有关系，即“某人的/某物的”） | whose |
| 时间 | when |
| 地点 | where |
| 原因 | why |
