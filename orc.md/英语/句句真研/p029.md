(四) “完成进行” 时态

顾名思义就是 “完成” 和 “进行” 两种时态的结合，即在 “完成” 时态的基础上又更进一步，强调了 “进行” 的过程。所以 “完成进行” 时态的用法为: XX 时间的之前, 强调一件事进行的过程。

【补充】“进行”的过程又分为三种: 还在进行 (事情没有全部做完)；持续进行 (不间断地进行)；重复进行 (一次又一次，断断续续地进行)。但是，在考研应试时，同学们不需要掌握这三种不同的 “进行”，只要记住 “完成进行” 时态是强调过程的即可。

1. 过去完成进行时: 谓语动词 = had been + doing

同学们不必纠结于语法书上写的各种用法，可以从应用的角度更加简单地理解，把相同时间段的 “完成时” 和 “完成进行时” 放在一起来看。以 “过去完成时” 和 “过去完成进行时” 为例，两者看事情的角度相同（都是站在过去回头看之前的事），但强调的方面不同。比较如下。

| 角度相同 | 都表示 “过去的之前” |
| --- | --- |
| 两种时态 | 过去完成时 had + done | 过去完成进行时 had been + doing |
| 强调不同 | 强调结果（做完与否都可以） | 强调过程 |
|  | We had not won the match. | We had been working hard for several months. |

如上两个例句, “我们没有赢得比赛” 和 “我们努力了好几个月” 都是过去的之前发生的事, 差别只在于 “努力” 是强调过程 (用过去完成进行时), 而 “没赢得比赛” 是强调结果 (用过去完成时)。

由此得知: 想表达 “过去的之前” 发生的事情, 有两种选择——过去完成时和过去完成进行时, 到底用哪一个取决于想强调什么。强调结果, 用过去完成时; 强调过程, 用过去完成进行时。

例: The world art market had already been losing momentum for a while after rising bewilderingly since 2003. (2010, Reading Comprehension, Part A Text 1)

译: 世界艺术品市场失去其发展势头已经有一段时间了, 自 2003 年 (经历了) 令人困惑的上涨后。

谓语动词是 had been losing, 过去完成进行时, 表示 “过去的之前已经失去发展势头了”, 且强调这个失去的过程持续了一段时间 (for a while)。

2. 现在完成进行时: 谓语动词 = have/has been + doing

想表达 “现在的之前” 发生的事情, 且强调过程, 用现在完成进行时。

例: Yes, new technology has been eating jobs forever, and always will. (2013, Reading Comprehension, Part A Text 1)

lose momentum 失去发展势头

momentum /mə'mentəm/ n. 势头; 动力

for a while（持续）一段时间

bewilderingly /'brˈwɪldərnli/ adv. 令人困惑地, 令人费解地
