(例) : Last month, Howard Schmidt… offered the federal government a proposal…

$\begin{aligned} & \text { vt. + } \\ & \text { 人 } \\ & + \text { 物 } \\ & = \text { Last month, Howard Schmidt… offered a proposal to the federal government… } \\ & \text { vt. + 物 } \\ & + \text { 介词 + 人 } \end{aligned}$

注意在 “物 + 人” 的情况下, 中间要加人介词, 通常为 to 或 for, to 强调动作的方向, for 强调动作的目的。例如: I bought you a present. = I bought a present for you. “我给你买了一个礼物。” 其中 “给你” 表示的是买礼物的目的, 因此用介词 for。

【补充】主谓双宾结构中, 无论两个宾语 “人 + 物” 哪个位于前面, “物” 永远是直接宾语, “人” 永远是间接宾语, 因为动作一定是直接作用在 “物” 上面, 间接传递给 “人”。但是这个不重要, 在考研英语中不需要掌握。

4. 主谓宾补 = 主语 + 及物动词 (vt.) + 宾语 + 宾语的补足语 (简称宾补)

有时 “主谓宾” 虽然结构完整, 但是意思还有所欠缺, 就需要加入补充的成分。

(例) : Furthermore, these losses make us mature… (2015, Reading Comprehension, Part B)

译: 此外, 这些失去让我们变得成熟 ……

“these losses make us”, 表示 “这些失去让我们”, 如果只写到这, 给人感觉话还没有说完, 没有说清楚 “让我们怎么样”, 因此要加上补充说明的内容——“mature” (成熟的), 把句意补充完整, 就构成了主谓宾补结构的简单句。

(例) : Pete Schneider considers the climb tougher today. (2016, Reading Comprehension, Part A Text 4)

译: 皮特・施耐德认为如今的攀行更艰难。

“Pete Schneider considers the climb”, 表示 “皮特・施耐德认为攀行”, 但没有说清楚 “认为攀行怎么样”, 因此要加上补充说明的内容——“tougher” (更加艰难), 补全句意, 就构成了主谓宾补结构的简单句。

【补充】宾补是用来补充说明宾语的, 因此它与宾语有逻辑上的主谓关系, 简单来说就是在宾语和宾补的内容中间加上中文 “是”, 可以构成完整的句意。如上面的例子, “these losses make us mature”, 其中宾语 us 和宾补 mature 的关系是 “us 是 mature”, 即 “我们是成熟的”。

可以作宾补的词有形容词、名词 (或词组)、介词短语、doing 或 to do 等。但在考研英语中, 宾补不重要, 只要大家能看懂它是补充说明宾语的即可。
