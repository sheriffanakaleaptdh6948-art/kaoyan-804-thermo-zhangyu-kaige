## 第二节 定语从句

What is 定语从句?

定语从句就是一个句子作定语，去修饰限定名词（名词词组或代词），位置放在所修饰的名词后。

This is a skill that will help them all throughout life.

主句

定语从句

例: This is a skill that will help them all throughout life. (2020, Use of English)

译：这（指耐心）是一项对他们终身有益的技能。

此句中 that will help them all throughout life 是定语从句，修饰限定名词 a skill，表示“将帮助他们一生的一项技能”。注意：翻译时通常按照中文的语言习惯，把定语从句放在所修饰的名词前，翻译成“……的名词”。

其中，定语从句所修饰的名词是“先行词”，因为定语从句要放在所修饰的名词后，因此该名词一定比定语从句“先走一步”，所以叫作“先行词”，此句中是 a skill。引出定语从句的连接词叫作“关系词”，因为是通过它来把先行词和定语从句“关系”起来的，此句中是 that。
