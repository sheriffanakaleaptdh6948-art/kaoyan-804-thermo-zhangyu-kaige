**例题 14** $\int \frac{\cos x}{\sin x + \cos x} \mathrm{d}x$

**解：** $I = \int \frac{\frac{1}{2}(\sin x + \cos x) + \frac{1}{2}(\cos x - \sin x)}{\sin x + \cos x} \mathrm{d}x = \frac{x}{2} + \frac{1}{2} \ln|\sin x + \cos x| + C$

**例题 15** $\int \frac{1}{\sin x \cdot \sin 2x} \mathrm{d}x$

**解：** $I = \frac{1}{2} \int \frac{1}{\sin^2 x \cos x} \mathrm{d}x = -\frac{1}{2} \int \sec x \mathrm{d}(\cot x) = -\frac{1}{2} \sec x \cot x + \frac{1}{2} \int \cot x \cdot \sec x \tan x \mathrm{d}x$
$$
= -\frac{1}{2} \sec x \cot x + \frac{1}{2} \ln|\sec x + \tan x| + C
$$

**例题 16** $\int \frac{\cos 2x - \sin 2x}{\sin x + \cos x} \mathrm{d}x$

**解：** $I = \int \frac{\cos^2 x - \sin^2 x - 2\sin x \cos x}{\sin x + \cos x} \mathrm{d}x = \int (\cos x - \sin x + \frac{1 - (\sin x + \cos x)^2}{\sin x + \cos x}) \mathrm{d}x$
$$
= 2\cos x + \int \frac{1}{\sin x + \cos x} \mathrm{d}x = 2\cos x + \frac{1}{\sqrt{2}} \int \frac{1}{\sin(x + \frac{\pi}{4})} \mathrm{d}x
$$
$$
= 2\cos x + \frac{1}{\sqrt{2}} \ln|\csc(x + \frac{\pi}{4}) - \cot(x + \frac{\pi}{4})| + C
$$

**例题 17** $\int \sin 2x \cdot \sin 3x \mathrm{d}x$

**解：** $I = \frac{1}{2} \int (\cos x - \cos 5x) \mathrm{d}x = \frac{1}{2} \sin x - \frac{1}{10} \sin 5x + C$

**例题 18** $\int \frac{1}{1 + \cos x} \mathrm{d}x$

**解：** $I = \int \frac{1}{2\cos^2 \frac{x}{2}} \mathrm{d}x = \tan \frac{x}{2} + C$

**类题 1** $\int \frac{1}{\sin x \cdot \sin 2x} \mathrm{d}x$

**解：** $I = \int \frac{\sin^2 x + \cos^2 x}{2\sin^2 x \cos x} \mathrm{d}x = \frac{1}{2} \int \frac{1}{\cos x} \mathrm{d}x + \frac{1}{2} \int \frac{\mathrm{d}\sin x}{\sin^2 x} = \frac{1}{2} \ln|\sec x + \tan x| - \frac{1}{2\sin x} + C$

**类题 2** $\int \frac{1}{1 + \sin x + \cos x} \mathrm{d}x$

**解：** 使用万能公式
$$
I = \int \frac{1}{1 + \frac{2u}{1+u^2} + \frac{1-u^2}{1+u^2}} \cdot \frac{2}{1+u^2} \mathrm{d}u = \int \frac{1}{u+1} \mathrm{d}u = \ln|u+1| + C = \ln|\tan \frac{x}{2} + 1| + C
$$
