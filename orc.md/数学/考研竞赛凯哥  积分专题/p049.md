（二） 三角有理函数积分的特殊解法

**例题 3** $\int \frac{1}{1+\cos x} \mathrm{d}x$

解：$I = \int \frac{1}{2\cos^2 \frac{x}{2}} \mathrm{d}x = \tan \frac{x}{2} + C$

**类题 1** $\int \frac{\sin x}{1+\sin x} \mathrm{d}x$

解：$I = \int \frac{\frac{2u}{1+u^2}}{1+\frac{2u}{1+u^2}} \cdot \frac{2}{1+u^2} \mathrm{d}u = \int \frac{4u}{(1+u^2)(u+1)^2} \mathrm{d}u = 2\int \frac{(u+1)^2 - (1+u^2)}{(1+u^2)(u+1)^2} \mathrm{d}u$
$= 2\int \frac{1}{1+u^2} \mathrm{d}u - 2\int \frac{1}{(u-1)^2} \mathrm{d}u = 2\arctan u + \frac{2}{u-1} + C = 2\arctan(\tan \frac{x}{2}) + \frac{2}{\tan \frac{x}{2} - 1} + C$

**类题 2** $\int \frac{1}{\sin x + \cos x} \mathrm{d}x$

解：$I = \int \frac{1}{\sqrt{2}\sin(x+\frac{\pi}{4})} \mathrm{d}x = \frac{1}{\sqrt{2}} \ln |\csc(x+\frac{\pi}{4}) - \cot(x+\frac{\pi}{4})| + C$

**类题 3** $\int \frac{\cos x}{\sin x + \cos x} \mathrm{d}x$

解：$I = \int \frac{\cos(x+\frac{\pi}{4}-\frac{\pi}{4})}{\sqrt{2}\sin(x+\frac{\pi}{4})} \mathrm{d}x = \frac{1}{\sqrt{2}} \int \frac{\frac{\sqrt{2}}{2}\cos(x+\frac{\pi}{4}) + \frac{\sqrt{2}}{2}\sin(x+\frac{\pi}{4})}{\sin(x+\frac{\pi}{4})} \mathrm{d}x = \frac{1}{2} \ln |\sin(x+\frac{\pi}{4})| + \frac{1}{2}x + C$

**例题 4** $\int \frac{1}{\sin^2 x \cdot \cos x} \mathrm{d}x$

解：$I = \int \frac{\sin^2 x + \cos^2 x}{\sin^2 x \cos x} \mathrm{d}x = \ln |\sec x + \tan x| - \frac{1}{\sin x} + C$

**例题 5** $\int \frac{\cos^3 x - 2\cos x}{1+\sin^2 x + \sin^4 x} \mathrm{d}x$

解：$I = \int \frac{\cos^2 x - 2}{1+\sin^2 x + \sin^4 x} \mathrm{d}(\sin x) = - \int \frac{1+\sin^2 x}{1+\sin^2 x + \sin^4 x} \mathrm{d}(\sin x) = - \int \frac{1+\frac{1}{u^2}}{u^2+1+\frac{1}{u^2}} \mathrm{d}u$
$= - \int \frac{1}{(u-\frac{1}{u})^2+3} \mathrm{d}(u-\frac{1}{u}) = - \frac{1}{\sqrt{3}} \arctan(\frac{u-\frac{1}{u}}{\sqrt{3}}) + C = - \frac{1}{\sqrt{3}} \arctan\left(\frac{\sin x - \frac{1}{\sin x}}{\sqrt{3}}\right) + C$

**例题 6** $\int \sec^3 x \mathrm{d}x$

解：$I = \int \sec x \mathrm{d}\tan x = \sec x \tan x - \int \sec x \tan^2 x \mathrm{d}x = \sec x \tan x - \int \sec x (\sec^2 x - 1) \mathrm{d}x$
$= \sec x \tan x + \int \sec x \mathrm{d}x - I$
