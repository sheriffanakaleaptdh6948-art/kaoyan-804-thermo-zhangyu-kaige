类题 4 $\int \frac{1}{\sqrt[3]{(x+1)^2(x-1)^4}} \mathrm{d}x$

解：令 $\sqrt[3]{\frac{x+1}{x-1}}=t$

$$
\text{原式} = -\int \frac{(t^3-1)^2 6t^2}{(t^3-1)^2 4t^2} \mathrm{d}t = -\int \frac{3}{2} \mathrm{d}t = -\frac{3}{2}t + C = -\frac{3}{2}\sqrt[3]{\frac{x+1}{x-1}} + C
$$

**例题 2** $\int \frac{1}{(1+\sqrt[3]{x})\sqrt{x}} \mathrm{d}x$

解：令 $x=t^6$

$$
\text{原式} = \int \frac{6t^5}{(1+t^2)t^3} \mathrm{d}t = 6\int \frac{t^2+1-1}{1+t^2} \mathrm{d}t = 6t - 6\arctan t + C = 6x^{\frac{1}{6}} - 6\arctan x^{\frac{1}{6}} + C
$$

类题 $\int \frac{1}{1+\mathrm{e}^{\frac{x}{2}}+\mathrm{e}^{\frac{x}{3}}+\mathrm{e}^{\frac{x}{6}}} \mathrm{d}x$

解：令 $t=\mathrm{e}^{\frac{x}{6}}$

$$
\text{原式} = \int \frac{1}{1+t^3+t^2+t} \frac{6}{t} \mathrm{d}t = 6\int \frac{1}{t(1+t)(1+t^2)} \mathrm{d}t = \int \left( \frac{6}{t} - \frac{3}{1+t} - \frac{3t+3}{1+t^2} \right) \mathrm{d}t
$$

$$
= 6\ln t - 3\ln(1+t) - \frac{3}{2}\ln(1+t^2) - 3\arctan t + C = x - 3\ln\left(1+\mathrm{e}^{\frac{x}{6}}\right) - \frac{3}{2}\ln\left(1+\mathrm{e}^{\frac{x}{3}}\right) - 3\arctan \mathrm{e}^{\frac{x}{6}} + C
$$

**例题 3** $\int \frac{1}{x^4}\sqrt{4-x^2} \mathrm{d}x$

解：令 $x=2\sin t$

$$
\text{原式} = \int \frac{2\cos t}{16\sin^4 t} \cdot 2\cos t \mathrm{d}t = \frac{1}{4}\int \frac{\cos^2 t}{\sin^4 t} \mathrm{d}t = \frac{1}{4}\int \frac{\sec^2 t}{\tan^4 t} \mathrm{d}t = \frac{1}{4}\int \frac{1}{\tan^4 t} \mathrm{d}\tan t = -\frac{1}{12}\tan^{-3} t + C
$$

$$
= -\frac{1}{12}\tan\left(\arcsin\frac{x}{2}\right)^{-3} + C
$$

**例题 4** $\int \frac{1}{\sqrt{(x^2+1)^3}} \mathrm{d}x$

解：令 $x=\tan t$

$$
\text{原式} = \int \frac{1}{\sec^3 t} \sec^2 t \mathrm{d}t = \int \cos t \mathrm{d}t = \sin t + C = \frac{x}{\sqrt{1+x^2}} + C
$$

**例题 5** $\int \frac{1}{\sqrt{x(4-x)}} \mathrm{d}x$

解：令 $x-2=2\sin t$

$$
\text{原式} = \int \frac{1}{\sqrt{4-(x-2)^2}} \mathrm{d}x = \int 1 \mathrm{d}t = t + C = \arcsin\frac{x-2}{2} + C
$$
