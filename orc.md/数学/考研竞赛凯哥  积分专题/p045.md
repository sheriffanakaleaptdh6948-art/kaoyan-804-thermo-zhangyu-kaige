NO.4-1 不定积分解题方法（上）

**套路一 有理函数的积分**

**（一） 有理函数积分的通用方法**

**例题 1** $\displaystyle \int \frac{x+3}{x^2+2x+4} \mathrm{d}x$

**解：** $\displaystyle I = \int \frac{\frac{1}{2}(2x+2)+2}{x^2+2x+4} \mathrm{d}x = \frac{1}{2}\ln|x^2+2x+4| + 2\int \frac{1}{(x+1)^2+(\sqrt{3})^2} \mathrm{d}x$
$\displaystyle = \frac{1}{2}\ln|x^2+2x+4| + \frac{2}{\sqrt{3}}\arctan\frac{x+1}{\sqrt{3}} + C$

**例题 2** $\displaystyle \int \frac{x^2}{(a^2+x^2)^2} \mathrm{d}x$

**解：** $\displaystyle I = -\frac{1}{2}\int x\mathrm{d}(\frac{1}{x^2+a^2}) = -\frac{x}{2(x^2+a^2)} + \frac{1}{2}\int \frac{1}{x^2+a^2} \mathrm{d}x = -\frac{x}{2(x^2+a^2)} + \frac{1}{2a}\arctan\frac{x}{a} + C$

**类题** $\displaystyle \int \frac{1}{(a^2+x^2)^2} \mathrm{d}x$

**解：** 使用三角换元，令 $x=a\tan t$，则 $\mathrm{d}x = a\sec^2 t \mathrm{d}t$
$\displaystyle I = \int \frac{1}{a^4\sec^4 t} \cdot a\sec^2 t \mathrm{d}t = \frac{1}{a^3}\int \cos^2 t \mathrm{d}t = \frac{1}{2a^3}\int (\cos 2t + 1)\mathrm{d}t = \frac{1}{4a^3}\sin 2t + \frac{t}{2a^3} + C$
$\displaystyle = \frac{x}{2a^2(x^2+a^2)} + \frac{1}{2a^3}\arctan\frac{x}{a} + C$

**注：** 换元后一定要回代，回代！！！

**例题 3** $\displaystyle \int \frac{3x+6}{(x-1)^2(x^2+x+1)} \mathrm{d}x$ （此为 2019 年的一道 10 分大题，居然只有一个考点，出题人真是极其无聊）

**解：** $\displaystyle \frac{3x+6}{(x-1)^2(x^2+x+1)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{Cx+D}{x^2+x+1}$
$\displaystyle = \frac{A(x-1)(x^2+x+1) + B(x^2+x+1) + (Cx+D)(x-1)^2}{(x-1)^2(x^2+x+1)}$

可得 $\begin{cases} A+C=0 \\ 3B=9 (x=1 \text{代入}) \\ B-2C+D=0 \\ -A+B+D=6 (x=0 \text{代入}) \end{cases}$ 解得 $A=-2, B=3, C=2, D=1$

$\displaystyle I = -2\ln|x-1| - \frac{1}{3(x-1)} + \ln|x^2+x+1| + C$

**例题 4** $\displaystyle \int \frac{1}{1+x^3} \mathrm{d}x$

**解：** $\displaystyle \frac{1}{x^3+1} = \frac{A}{x+1} + \frac{Bx+C}{x^2+1-x}$
