故 $I = \frac{1}{2}(\sec x \tan x + \ln|\sec x + \tan x|) + C$

**类题 1** $\int \sqrt{1+x^2} \mathrm{d}x$

**解：** $I = x\sqrt{1+x^2} - \int \frac{x^2}{\sqrt{1+x^2}} \mathrm{d}x = x\sqrt{1+x^2} - \int \frac{x^2+1-1}{\sqrt{1+x^2}} \mathrm{d}x = x\sqrt{1+x^2} - \int (\sqrt{1+x^2} - \frac{1}{\sqrt{1+x^2}})\mathrm{d}x$
$= x\sqrt{1+x^2} - I + \ln|x + \sqrt{1+x^2}|$
故 $I = \frac{1}{2}(x\sqrt{1+x^2} + \ln|x + \sqrt{1+x^2}|) + C$

**类题 2** 请思考如何计算积分 $I_n = \int \sec^n x \mathrm{d}x \ (n \ge 3)$

**解：** $I_n = \int \sec^{n-2} x \mathrm{d}(\tan x) = \tan x \cdot \sec^{n-2} x - (n-2) \int \tan^2 x \cdot \sec^{n-2} x \mathrm{d}x$
$= \tan x \cdot \sec^{n-2} x - (n-2) \int (\sec^2 x - 1)\sec^{n-2} x \mathrm{d}x = \tan x \cdot \sec^{n-2} x - (n-2)(I_n - I_{n-2})$
故 $I_n = \frac{1}{n-1} \tan x \cdot \sec^{n-2} x + \frac{n-2}{n-1} I_{n-2}$
其中 $I_1 = \ln|\sec x + \tan x| + C, \quad I_2 = \tan x + C$

**类题 3** 请推导出积分 $I_n = \int \tan^n x \mathrm{d}x \ (n \ge 2)$ 的递推公式

**解：** $I_n = \int \tan^{n-2} x (\tan^2 x + 1)\mathrm{d}x - I_{n-2} = \int \tan^{n-2} x \cdot \sec^2 x \mathrm{d}x - I_{n-2} = \int \tan^{n-2} x \mathrm{d}(\tan x) - I_{n-2}$
$= \frac{1}{n-1} \tan^{n-1} x - I_{n-2}$
其中 $I_0 = x + C, \quad I_1 = -\ln|\cos x| + C$

**类题 4** 请推导出积分 $I_n = \int \sin^n x \mathrm{d}x \ (n \ge 2)$ 的递推公式

**解：** $I_n - I_{n+2} = \int \sin^n x (1 - \sin^2 x)\mathrm{d}x = \int \sin^n x \cdot \cos^2 x \mathrm{d}x = \frac{1}{n+1} \int \cos x \mathrm{d}(\sin^{n+1} x)$
$= \frac{1}{n+1} \sin^{n+1} x \cos x + \frac{1}{n+1} I_{n+2}$
故 $I_{n+2} = \frac{n+1}{n+2} I_n - \frac{1}{n+2} \sin^{n+1} x \cos x$ 即 $I_n = \frac{n-1}{n} I_{n-2} - \frac{1}{n} \sin^{n-1} x \cos x$
其中 $I_1 = -\cos x + C, \quad I_0 = x + C$

**类题 5** 根据类题 4 的结论，可推导出定积分中大名鼎鼎的“点火公式”——
$$ I_n = \int_0^{\frac{\pi}{2}} \sin^n x \mathrm{d}x = \int_0^{\frac{\pi}{2}} \cos^n x \mathrm{d}x = \begin{cases} \frac{n-1}{n} \cdot \frac{n-3}{n-2} \cdot \dots \cdot \frac{2}{3}, & n \text{为奇数} \\ \frac{n-1}{n} \cdot \frac{n-3}{n-2} \cdot \dots \cdot \frac{1}{2} \cdot \frac{\pi}{2}, & n \text{为偶数} \end{cases} $$
*(注：原文第二个积分写作 $\int_0^{\frac{\pi}{2}} \sin^2 x \mathrm{d}x$ 疑似笔误，根据点火公式性质应为 $\cos^n x$ 或重复 $\sin^n x$，此处按标准公式 $\cos^n x$ 或仅保留左侧理解)*
