**例题 5** 已知 $f''(x)$ 连续，$f'(x) \neq 0$，求 $\int \left[ \frac{f(x)}{f'(x)} - \frac{f^2(x)f''(x)}{(f'(x))^3} \right] \mathrm{d}x$

**解：** 原式 $= \int \frac{-f''f^2 + ff'^2}{f'^3} \mathrm{d}x = \int \frac{f}{f'} \mathrm{d}\frac{f}{f'} = \frac{1}{2} \left( \frac{f}{f'} \right)^2 + C$

**例题 6** $\int \frac{1-\ln x}{(x-\ln x)^2} \mathrm{d}x$

**解：** 原式 $= \int \frac{x-\ln x + 1-x}{(x-\ln x)^2} = \int \frac{1}{x-\ln x} \mathrm{d}x + \int \frac{1-x}{(x-\ln x)^2} \mathrm{d}x = \frac{x}{x-\ln x} + C$

**套路八** 对复杂因子求导，期待出现奇迹

**例题 1** $\int \frac{\ln x}{\sqrt{1+[x(\ln x - 1)]^2}} \mathrm{d}x$

**解：** 原式 $= \int \frac{1}{\sqrt{1+[x(\ln x - 1)]^2}} \mathrm{d}(x(\ln x - 1)) = \ln \left( x(\ln x - 1) + \sqrt{1+[x(\ln x - 1)]^2} \right) + C$

**例题 2** $\int \frac{x+1}{x(1+xe^x)} \mathrm{d}x$

**解：** 原式 $= \int \frac{1}{e^x x(1+xe^x)} \mathrm{d}xe^x = \ln \left| \frac{xe^x}{1+xe^x} \right| + C$

**类题** $\int \frac{1+x\cos x}{x(1+xe^{\sin x})} \mathrm{d}x$

**解：** 原式 $= \int \frac{e^{\sin x}(x\cos x + 1)}{xe^{\sin x}(1+xe^{\sin x})} \mathrm{d}x = \ln \left| \frac{xe^{\sin x}}{1+xe^{\sin x}} \right| + C$

**例题 3** $\int \frac{1-\ln x}{(x-\ln x)^2} \mathrm{d}x$

**解：** 原式 $= \int \frac{x-\ln x + 1-x}{(x-\ln x)^2} = \int \frac{1}{x-\ln x} \mathrm{d}x + \int \frac{1-x}{(x-\ln x)^2} \mathrm{d}x = \frac{x}{x-\ln x} + C$

**类题 1** $\int \frac{e^x(x-1)}{(x-e^x)^2} \mathrm{d}x$

**解：** 原式 $= \int \frac{e^x(x-1)}{x^2\left(1-\frac{e^x}{x}\right)^2} \mathrm{d}x = \frac{1}{1-\frac{e^x}{x}} + C = \frac{x}{x-e^x} + C$

**类题 2** $\int \frac{x+\sin x \cdot \cos x}{(\cos x - x \cdot \sin x)^2} \mathrm{d}x$

**解：** 原式 $= \int \frac{x+\sin x \cos x}{(1-x\tan x)^2 \cos^2 x} \mathrm{d}x = \int \frac{1}{(x\tan x - 1)^2} \mathrm{d}x \tan x = \frac{1}{1-x\tan x} + C$
