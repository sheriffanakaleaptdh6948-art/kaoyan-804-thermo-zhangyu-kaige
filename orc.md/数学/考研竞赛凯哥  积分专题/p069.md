**例题 7** 计算积分 $\int_0^1 (1-x)^{100} x \, \mathrm{d}x$

**解：** $\int_0^1 (1-x)^{100} x \, \mathrm{d}x \xrightarrow{t=1-x} \int_0^1 t^{100}(1-t) \mathrm{d}t = \int_0^1 t^{100}(1-t) \mathrm{d}t = \left( \frac{t^{101}}{101} - \frac{t^{102}}{102} \right) \Bigg|_0^1$
$$= \frac{1}{101} - \frac{1}{102} = \frac{1}{101 \times 102} = \frac{1}{10302} \text{；}$$

**例题 8** 计算积分 $\int_0^2 x(x-1)(x-2) \, \mathrm{d}x$

**解：** $\int_0^2 x(x-1)(x-2) \mathrm{d}x \xrightarrow{t=x-1} \int_{-1}^1 (t+1)t(t-1) \mathrm{d}t$
令 $f(t) = (t+1)t(t-1)$，
$f(-t) = (-t+1)(-t)(-t-1) = -(t+1)t(t-1) = -f(t)$
所以 $f(t)$ 是关于 $t$ 的奇函数， $\int_{-1}^1 (t+1)t(t-1) \mathrm{d}t = 0$；

**类题** 计算积分 $\int_0^{2n} x(x-1)(x-2)\cdots(x-n)\cdots[x-(2n-1)](x-2n) \, \mathrm{d}x$

**解：** $\int_0^{2n} x(x-1)(x-2)\dots(x-n)\dots[x-(2n-1)](x-2n) \mathrm{d}x$
$$\xrightarrow{t=x-n} \int_{-n}^n (t+n)(t+(n-1))\dots t \dots (t-(n-1))(t-n) \mathrm{d}t$$
$$= \int_{-n}^n t(t^2-n^2)(t^2-(n-1)^2)\dots(t^2-1) \mathrm{d}t = 0 \text{；}$$

**例题 9** $\int_0^1 \left| x - \frac{1}{2} \right|^5 x^n (1-x)^n \mathrm{d}x$

**解：** $\xrightarrow{t=x-\frac{1}{2}} \int_{-\frac{1}{2}}^{\frac{1}{2}} |t|^5 \left(t+\frac{1}{2}\right)^n \left(\frac{1}{2}-t\right)^n \mathrm{d}t = \int_{-\frac{1}{2}}^{\frac{1}{2}} |t|^5 \left(\frac{1}{4}-t^2\right)^n \mathrm{d}t$
$$= 2 \int_0^{\frac{1}{2}} t^5 \left(\frac{1}{4}-t^2\right)^n \mathrm{d}t = \int_0^{\frac{1}{2}} t^4 \left(\frac{1}{4}-t^2\right)^n \mathrm{d}t^2 \xrightarrow{u=\frac{1}{4}-t^2} \int_0^{\frac{1}{4}} \left(\frac{1}{4}-u\right)^2 u^n \mathrm{d}u$$
$$= \int_0^{\frac{1}{4}} \left( \frac{1}{16} - \frac{u}{2} + u^2 \right) u^n \mathrm{d}u = \left( \frac{u^{n+1}}{16(n+1)} - \frac{u^{n+2}}{2(n+2)} + \frac{u^{n+3}}{n+3} \right) \Bigg|_0^{\frac{1}{4}}$$
$$= \frac{1}{4^{n+3}} \left( \frac{1}{(n+1)} - \frac{2}{(n+2)} + \frac{1}{(n+3)} \right) \text{；}$$
