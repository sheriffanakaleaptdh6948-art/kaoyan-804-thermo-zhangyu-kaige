**例题 5** 若不定积分 $\int \frac{x^2+ax+2}{(x+1)(x^2+1)} \mathrm{d}x$ 的结果中不含反正切函数，求 $a$

**解：** $\frac{x^2+ax+2}{(x+1)(x^2+1)} = \frac{A}{x+1} + \frac{Bx+D}{x^2+1}$

原积分 $I = A\ln|x+1| + \frac{B}{2}\ln|x^2+1| + D\arctan x + C$

可得 $A(x^2+1)+(Bx+D)(x+1)=x^2+ax+2$

$$
\begin{cases}
A+B=1 \\
B+D=a \\
A+D=2
\end{cases}
\text{解得} A=\frac{3-a}{2}, B=\frac{a-1}{2}, D=\frac{a+1}{2}
$$

若使得原积分不含反正切函数，则 $D=0$ 即 $a=-1$

**（二） 有理函数积分的特殊解法**

**例题 6** $\int \frac{1}{1-x^4} \mathrm{d}x$

**解：** $I = \frac{1}{2}\int \frac{1+x^2+1-x^2}{(1+x^2)(1-x^2)} \mathrm{d}x = \frac{1}{2}\int \left( \frac{1}{2} \cdot \frac{1-x+1+x}{1-x^2} + \frac{1}{1+x^2} \right) \mathrm{d}x = \frac{1}{4}\ln\left| \frac{x+1}{x-1} \right| + \frac{1}{2}\arctan x + C$

**类题 1** $\int \frac{1}{x^8(1+x^2)} \mathrm{d}x$

**解：** $I = -\int \frac{x^8-1-x^8}{x^8(1+x^2)} \mathrm{d}x = -\int \frac{(x^4+1)(x^2+1)(x^2-1)}{x^8(1+x^2)} \mathrm{d}x + \arctan x + C$
$$
= -\int \frac{x^6+x^2-x^4-1}{x^8} \mathrm{d}x + \arctan x + C = \frac{1}{x} + \frac{1}{5x^5} - \frac{1}{3x^3} - \frac{1}{7x^7} + \arctan x + C
$$

**注：** 本题使用倒代换也可，具体操作如下：

令 $x=\frac{1}{t}$，则 $\mathrm{d}t = -\frac{1}{x^2}\mathrm{d}x$
