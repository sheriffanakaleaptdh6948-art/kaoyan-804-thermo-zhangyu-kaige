**例题 2** $\int \mathrm{e}^x \sin x \, \mathrm{d}x$

**解：** 原式 $= \int \sin x \, \mathrm{d}\mathrm{e}^x = \sin x \mathrm{e}^x - \int \mathrm{e}^x \cos x \, \mathrm{d}x = \sin x \mathrm{e}^x - \int \cos x \, \mathrm{d}\mathrm{e}^x$
$$
= \sin x \mathrm{e}^x - \mathrm{e}^x \cos x - \int \mathrm{e}^x \sin x \, \mathrm{d}x = \frac{1}{2} \mathrm{e}^x \sin x - \frac{1}{2} \mathrm{e}^x \cos x + C
$$

**类题** $\int x \cdot \mathrm{e}^x \cdot \sin x \, \mathrm{d}x$

**解：** 原式 $= \frac{1}{2} \int x \, \mathrm{d}\mathrm{e}^x (\sin x - \cos x) = \frac{x}{2} \mathrm{e}^x (\sin x - \cos x) - \frac{1}{2} \int \mathrm{e}^x (\sin x - \cos x) \, \mathrm{d}x$
$$
= \frac{x}{2} \mathrm{e}^x (\sin x - \cos x) + \frac{1}{2} \mathrm{e}^x \cos x + C
$$

**例题 3** $\int \ln^2 \left( x + \sqrt{1+x^2} \right) \, \mathrm{d}x$

**解：** 原式 $= x \ln \left( x + \sqrt{1+x^2} \right)^2 - \int \frac{2x \ln \left( \left( x + \sqrt{1+x^2} \right) \right)}{\sqrt{1+x^2}} \, \mathrm{d}x$
$$
= x \ln \left( x + \sqrt{1+x^2} \right)^2 - \int 2 \ln \left( x + \sqrt{1+x^2} \right) \mathrm{d}\sqrt{1+x^2}
$$
$$
= x \ln \left( x + \sqrt{1+x^2} \right)^2 - 2\sqrt{1+x^2} \ln \left( x + \sqrt{1+x^2} \right) + 2 \int \frac{\sqrt{1+x^2}}{\sqrt{1+x^2}} \, \mathrm{d}x
$$
$$
= x \ln \left( x + \sqrt{1+x^2} \right)^2 - 2\sqrt{1+x^2} \ln \left( x + \sqrt{1+x^2} \right) + 2x + C
$$

**例题 1** $\int \mathrm{e}^{2x} \arctan \sqrt{\mathrm{e}^x - 1} \, \mathrm{d}x$

**解：** 令 $\sqrt{\mathrm{e}^x - 1} = t$
$$
\text{原式} = \int \arctan t \cdot \frac{2t}{1+t^2} (1+t^2)^2 \, \mathrm{d}t = \frac{1}{2} \int \arctan t \, \mathrm{d}(1+t^2)^2 = \frac{(1+t^2)^2}{2} \arctan t - \frac{1}{2} \int 1+t^2 \, \mathrm{d}t
$$
$$
= \frac{(1+t^2)^2}{2} \arctan t - \frac{t^3}{6} - \frac{t}{2} + C = \frac{\mathrm{e}^{2x}}{2} \arctan \sqrt{\mathrm{e}^x - 1} - \frac{(\mathrm{e}^x - 1)^{\frac{3}{2}}}{6} - \frac{\sqrt{\mathrm{e}^x - 1}}{2} + C
$$
