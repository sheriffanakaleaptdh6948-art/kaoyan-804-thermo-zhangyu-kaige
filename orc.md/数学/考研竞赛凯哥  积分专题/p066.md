NO.5-2 定积分计算（上）

**套路一 定积分的常规计算技巧**

**例题1** 利用N-L公式，直接计算下列定积分

(1) $\int_0^1 \frac{x^2 \arcsin x}{\sqrt{1-x^2}} \mathrm{d}x$

(2) $\int_0^3 \arcsin \sqrt{\frac{x}{1+x}} \mathrm{d}x$

(3) $\int_1^{16} \arctan \sqrt{\sqrt{x}-1} \mathrm{d}x$

(4) $\int_0^{\frac{\pi}{2}} \sin x \cdot \ln \sin x \mathrm{d}x$

**解：** (1) $\int_0^1 \frac{x^2 \arcsin x}{\sqrt{1-x^2}} \mathrm{d}x = \int_0^1 x^2 \arcsin x \mathrm{d}(\arcsin x)$

令 $\arcsin x = t$

原式 $= \int_0^{\frac{\pi}{2}} t \sin^2 t \mathrm{d}t = \int_0^{\frac{\pi}{2}} t \sin^2 t \mathrm{d}t = \frac{1}{2} \int_0^{\frac{\pi}{2}} t(1-\cos 2t) \mathrm{d}t = \frac{t^2}{4} \bigg|_0^{\frac{\pi}{2}} - \frac{1}{2} \int_0^{\frac{\pi}{2}} t \cos 2t \mathrm{d}t$

$= \frac{\pi^2}{16} - \frac{1}{2} \left( \frac{t \sin 2t}{2} \bigg|_0^{\frac{\pi}{2}} - \frac{1}{2} \int_0^{\frac{\pi}{2}} \sin 2t \mathrm{d}t \right) = \frac{\pi^2}{16} - \frac{1}{8} \cos 2t \bigg|_0^{\frac{\pi}{2}} = \frac{\pi^2}{16} + \frac{1}{4}$；

(2) 令 $t = \arcsin \sqrt{\frac{x}{1+x}}$， $x = \tan^2 t$

$\int_0^{\frac{\pi}{3}} t \mathrm{d}(\tan^2 t) = t \tan^2 t \bigg|_0^{\frac{\pi}{3}} - \int_0^{\frac{\pi}{3}} \tan^2 t \mathrm{d}t = \pi - (\tan t - t) \bigg|_0^{\frac{\pi}{3}} = \pi - \left( \sqrt{3} - \frac{\pi}{3} \right)$

$= \frac{4\pi}{3} - \sqrt{3}$；

(3) 令 $t = \arctan \sqrt{\sqrt{x}-1}$

则 $\tan t = \sqrt{\sqrt{x}-1} \Rightarrow \tan^2 t + 1 = \sqrt{x} \Rightarrow x = \sec^4 t$

$\int_0^{\frac{\pi}{3}} t \mathrm{d}(\sec^4 t) = t \sec^4 t \bigg|_0^{\frac{\pi}{3}} - \int_0^{\frac{\pi}{3}} \sec^4 t \mathrm{d}t = \frac{16\pi}{3} - \int_0^{\frac{\pi}{3}} \sec^2 t \mathrm{d}(\tan t)$

$= \frac{16\pi}{3} - \int_0^{\frac{\pi}{3}} (\tan^2 t + 1) \mathrm{d}(\tan t) = \frac{16\pi}{3} - \left( \frac{\tan^3 t}{3} + \tan t \right) \bigg|_0^{\frac{\pi}{3}} = \frac{16\pi}{3} - 2\sqrt{3}$；

(4) $\int \sin x \cdot \ln \sin x \mathrm{d}x = -\cos x \cdot \ln \sin x + \int \frac{\cos^2 x}{\sin x} \mathrm{d}x = -\cos x \cdot \ln \sin x + \int \frac{1-\sin^2 x}{\sin x} \mathrm{d}x$

$= -\cos x \cdot \ln \sin x + \cos x - \ln(\csc x - \cot x)$
