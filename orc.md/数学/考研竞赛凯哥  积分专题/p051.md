**例题 7** $\int \frac{1}{\sin x \cdot \cos^2 x} \mathrm{d}x$

**解：** $I = \int \csc x \mathrm{d}(\tan x) = \csc x \tan x + \int \tan x \cdot \csc x \cot x \mathrm{d}x = \csc x \tan x + \ln|\csc x - \cot x| + C$

**例题 8** $\int \frac{5+4\cos x}{(2+\cos x)^2 \cdot \sin x} \mathrm{d}x$

**解：** $I = \int \frac{(5+4\cos x)\sin x}{(2+\cos x)^2 \sin^2 x} \mathrm{d}x = -\int \frac{5+4\cos x}{(2+\cos x)^2 (1-\cos^2 x)} \mathrm{d}(\cos x)$
$$= -\int \frac{(2+\cos x)^2 + (1-\cos^2 x)}{(2+\cos x)^2 (1-\cos^2 x)} \mathrm{d}(\cos x) = -\int \frac{1}{1-\cos^2 x} \mathrm{d}(\cos x) - \int \frac{1}{(2+\cos x)^2} \mathrm{d}(\cos x + 2)$$
$$= \frac{1}{2} \ln \left| \frac{\cos x - 1}{\cos x + 1} \right| + \frac{1}{2+\cos x} + C$$

**例题 9** $\int \frac{1}{1+\cos^2 x} \mathrm{d}x$

**解：** $I = \int \frac{1}{\sin^2 x + 2\cos^2 x} \mathrm{d}x = \int \frac{1}{\tan^2 x + 2} \mathrm{d}(\tan x) = \frac{1}{\sqrt{2}} \arctan \frac{\tan x}{\sqrt{2}} + C$

**例题 10** $\int \frac{1}{(3\sin x + 2\cos x)^2} \mathrm{d}x$

**解：** $I = \int \frac{\sec^2 x}{(3\tan x + 2)^2} \mathrm{d}x = \frac{1}{3} \int \frac{1}{(3\tan x + 2)^2} \mathrm{d}(3\tan x + 2) = -\frac{1}{3(3\tan x + 2)} + C$

**例题 11** $\int \frac{1}{a^2\sin^2 x + b^2\cos^2 x} \mathrm{d}x$

**解：** 当 $a \neq 0, b=0$ 时 $I = \frac{1}{a^2} \int \frac{1}{\sin^2 x} \mathrm{d}x = -\frac{1}{a^2} \cot x + C$

当 $a=0, b \neq 0$ 时 $I = \frac{1}{b^2} \int \frac{1}{\cos^2 x} \mathrm{d}x = \frac{1}{b^2} \tan x + C$

当 $a \neq 0, b \neq 0$ 时 $I = \int \frac{1}{a^2\tan^2 x + b^2} \mathrm{d}(\tan x) = \frac{1}{ab} \arctan(\frac{a}{b}\tan x) + C$

**例题 12** $\int \frac{1}{\sin^4 x \cdot \cos^2 x} \mathrm{d}x$

**解：** $I = \int \frac{\sin^2 x + \cos^2 x}{\sin^4 x \cos^2 x} \mathrm{d}x = \int \frac{\sin^2 x + \cos^2 x}{\sin^2 x \cos^2 x} \mathrm{d}x + \int \frac{1}{\sin^4 x} \mathrm{d}x = \int (\frac{1}{\sin^2 x} + \frac{1}{\cos^2 x}) \mathrm{d}x + \int \frac{1}{\sin^4 x} \mathrm{d}x$
$$= -\cot x + \tan x - \int \csc^2 x \mathrm{d}(\cot x) = -\cot x + \tan x - \int (\cot^2 x + 1) \mathrm{d}(\cot x)$$
$$= -2\cot x + \tan x - \frac{1}{3}\cot^3 x + C$$

**例题 13** $\int \frac{1+\sin x + \cos x}{1+\sin^2 x} \mathrm{d}x$

**解：** $I = \int \frac{1}{2\sin^2 x + \cos^2 x} \mathrm{d}x + \int \frac{\sin x}{1+\sin^2 x} \mathrm{d}x + \arctan(\sin x)$
$$= \frac{1}{\sqrt{2}} \arctan(\sqrt{2}\tan x) + \int \frac{\sec x \tan x}{\tan^2 x + \sec^2 x} \mathrm{d}x + \arctan(\sin x)$$
