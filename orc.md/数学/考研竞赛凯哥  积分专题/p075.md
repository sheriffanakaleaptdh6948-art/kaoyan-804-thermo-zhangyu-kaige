**例题 5** 证明：$J_n = \int_0^{\frac{\pi}{2}} \cos x \cdot \sin nx \, \mathrm{d}x = \frac{1}{2^{n+1}} \left( 2 + \frac{2^2}{2} + \frac{2^3}{3} + \cdots + \frac{2^n}{n} \right)$，其中 $n$ 为自然数

**解：** 考虑到 $\cos^n x = \left( \frac{e^{ix} + e^{-ix}}{2} \right)^n = \frac{1}{2^n} \sum_{k=0}^n C_n^k e^{i(n-2k)x} \xrightarrow{\text{区间再现}} \frac{1}{2^{n+1}} \left[ \sum_{k=0}^n C_n^k e^{i(n-2k)x} + \sum_{k=0}^n C_n^k e^{-i(n-2k)x} \right]$
$$= \frac{1}{2^n} \sum_{k=0}^n C_n^k \cos(n-2k)x, \text{ 于是}$$
$$J_n = \int_0^{\frac{\pi}{2}} \cos^n x \sin nx \, \mathrm{d}x = \frac{1}{2^n} \int_0^{\frac{\pi}{2}} \sin nx \sum_{k=0}^n C_n^k \cos(n-2k)x \, \mathrm{d}x = \frac{1}{2^n} \sum_{k=0}^n C_n^k \int_0^{\frac{\pi}{2}} \sin nx \cos(n-2k)x \, \mathrm{d}x$$
$$\xrightarrow{\text{积化和差}} \frac{1}{2^{n+1}} \sum_{k=0}^n C_n^k \int_0^{\frac{\pi}{2}} [\sin(2n-2k)x + \sin 2kx] \mathrm{d}x$$
$$= \frac{1}{2^{n+1}} \left\{ \frac{1+(-1)^{n-1}}{n} + \frac{1}{2} \sum_{k=1}^{n-1} C_n^k \left[ \frac{1}{n-k} - \frac{(-1)^{n-k}}{n-k} + \frac{1}{k} - \frac{(-1)^k}{k} \right] \right\}$$
$$\xrightarrow{\text{区间再现}} \frac{1}{2^{n+1}} \sum_{k=1}^n [1 - (-1)^k] \frac{C_n^k}{k} = \frac{1}{2^{n+1}} \sum_{k=1}^n \frac{2^k}{k} \cdots$$

**综合题型六 分段函数的定积分**

**例题 1** 设 $f(x) = \int_0^1 |t^2 - x^2| \mathrm{d}t (x>0)$，求 $f'(x)$ 并求 $f(x)$ 的最小值

**解：** $f(x) = \int_0^1 |t^2 - x^2| \mathrm{d}t = \begin{cases} \int_0^x (x^2 - t^2) \mathrm{d}t + \int_x^1 (t^2 - x^2) \mathrm{d}t = \frac{4}{3}x^3 - x^2 + \frac{1}{3}, & (0 < x < 1) \\ \int_0^1 (x^2 - t^2) \mathrm{d}t = x^2 - \frac{1}{3}, & (x \geqslant 1) \end{cases}$

$\lim_{x \to 1^-} f(x) = f(1)$，故 $f(x)$ 连续。$\lim_{x \to 1^-} f'(x) = \lim_{x \to 1^+} f'(x)$，故 $f(x)$ 可导。$f'(x) = \begin{cases} 4x^2 - 2x, & (0 < x < 1) \\ 2x, & (x \geqslant 1) \end{cases}$

令 $f'(x) = 0$，得到 $x = \frac{1}{2}$，于是 $f(x)$ 在 $\left( 0, \frac{1}{2} \right)$ 内单调递减，在 $\left( \frac{1}{2}, +\infty \right)$ 内单调递增，最小值为 $f\left( \frac{1}{2} \right) = \frac{1}{4}$.

**例题 2** 设 $f(x) = \begin{cases} 2x + \frac{3}{2}x^2, & 0 \leqslant x < 1 \\ \frac{1+x}{x(1+xe^x)}, & 1 \leqslant x \leqslant 2 \end{cases}$，求函数 $F(x) = \int_0^x f(t) \mathrm{d}t$ 的表达式

**解：** $0 \leqslant x < 1$ 时，$F(x) = \int_0^x \left( 2t + \frac{3}{2}t^2 \right) \mathrm{d}t = x^2 + \frac{1}{2}x^3$;

$1 \leqslant x \leqslant 2$ 时，$F(x) = \frac{3}{2} + \int_1^x \frac{1+t}{t(1+te^t)} \mathrm{d}t = \frac{3}{2} + \int_1^x \frac{\mathrm{d}(te^t)}{te^t(1+te^t)} = \frac{1}{2} + \ln(1+e) + \ln\left( \frac{xe^x}{1+xe^x} \right)$.
