**例题 19** $\int \frac{\sin x \cdot \cos x}{\sin x + \cos x} \mathrm{d}x$

**解：**
$$
\begin{aligned}
I &= \frac{1}{2} \int \frac{(\sin x + \cos x)^2 - 1}{\sin x + \cos x} \mathrm{d}x = \frac{1}{2} \int (\sin x + \cos x) \mathrm{d}x - \frac{1}{2} \int \frac{1}{\sin x + \cos x} \mathrm{d}x \\
&= \frac{1}{2} \int (\sin x + \cos x) \mathrm{d}x - \frac{1}{2\sqrt{2}} \int \frac{1}{\sin(x + \frac{\pi}{4})} \mathrm{d}x \\
&= \frac{1}{2} (\sin x - \cos x) - \frac{1}{2\sqrt{2}} \ln \left| \csc(x + \frac{\pi}{4}) - \cot(x + \frac{\pi}{4}) \right| + C
\end{aligned}
$$

**注：** $(\sin x + \cos x)^2 = 1 + 2\sin x \cos x = 1 + \sin 2x$
$(\sin x - \cos x)^2 = 1 - 2\sin x \cos x = 1 - \sin 2x$

**例题 20** $\int \frac{\sin x \cdot \cos x}{\sin^4 x + \cos^4 x} \mathrm{d}x$

**解：**
$$
I = \int \frac{\tan x \sec^2 x}{\tan^4 x + 1} \mathrm{d}x = \frac{1}{2} \int \frac{1}{\tan^4 x + 1} \mathrm{d}(\tan^2 x) = \frac{1}{2} \arctan(\tan^2 x) + C
$$

**例题 21** $\int \frac{1}{\sin^6 x + \cos^6 x} \mathrm{d}x$

**解：**
$$
\begin{aligned}
I &= \int \frac{\sec^6 x}{\tan^6 x + 1} \mathrm{d}x = \int \frac{\sec^4 x}{\tan^6 x + 1} \mathrm{d}(\tan x) = \int \frac{(\tan^2 x + 1)^2}{\tan^6 x + 1} \mathrm{d}(\tan x) \\
&= \int \frac{\tan^4 x + 1 + 2\tan^2 x}{\tan^6 x + 1} \mathrm{d}(\tan x) = \int \frac{\tan^4 x + 1 - \tan^2 x + 3\tan^2 x}{\tan^6 x + 1} \mathrm{d}(\tan x) \\
&= \int \frac{1}{\tan^2 x + 1} \mathrm{d}(\tan x) + \int \frac{1}{(\tan^3 x)^2 + 1} \mathrm{d}(\tan^3 x) = x + \arctan(\tan^3 x) + C
\end{aligned}
$$

**注：** 熟记公式 $\sec^2 x = \tan^2 x + 1$ 和立方和立方差公式

**例题 22** $\int \frac{1}{\sin^3 x + \cos^3 x} \mathrm{d}x$

**解：**
$$
\begin{aligned}
I &= \int \frac{1}{(\sin x + \cos x)(\sin^2 x + \cos^2 x - \sin x \cos x)} \mathrm{d}x = \int \frac{1}{(\sin x + \cos x)(1 - \sin x \cos x)} \mathrm{d}x \\
&= \frac{1}{3} \int \frac{(\sin x + \cos x)^2 + 2(1 - \sin x \cos x)}{(\sin x + \cos x)(1 - \sin x \cos x)} \mathrm{d}x = \frac{1}{3} \int \frac{\sin x + \cos x}{1 - \sin x \cos x} \mathrm{d}x + \frac{2}{3} \int \frac{1}{\sin x + \cos x} \mathrm{d}x \\
&= \frac{2}{3} \int \frac{1}{1 + (\sin x - \cos x)^2} \mathrm{d}(\sin x - \cos x) + \frac{\sqrt{2}}{3} \int \frac{1}{\sin(x + \frac{\pi}{4})} \mathrm{d}x \\
&= \frac{2}{3} \arctan(\sin x - \cos x) + \frac{\sqrt{2}}{3} \ln \left| \csc(x + \frac{\pi}{4}) - \cot(x + \frac{\pi}{4}) \right| + C
\end{aligned}
$$

**例题 23** $\int \frac{1}{\sin(x+a)\sin(x+b)} \mathrm{d}x$ （其中 $\sin(a-b) \neq 0$）

**解：**
$$
\begin{aligned}
I &= \frac{\int \frac{\sin[(x+a)-(x+b)]}{\sin(x+a)\sin(x+b)} \mathrm{d}x}{\sin(a-b)} = \frac{\int \frac{\sin(x+a)\cos(x+b) - \cos(x+a)\sin(x+b)}{\sin(x+a)\sin(x+b)} \mathrm{d}x}{\sin(a-b)} \\
&= \frac{1}{\sin(a-b)} \ln \left| \frac{\sin(x+b)}{\sin(x+a)} \right| + C
\end{aligned}
$$
