## 解答

**15.1** (B) **解** 原微分方程所对应齐次方程的特征方程为 $r^2 - 4r + 4 = 0$，特征根 $r_{1,2} = 2$．而 $f_1(x) = x^2$，$\lambda_1 = 0$ 非特征根，故 $y_1^* = ax^2 + bx + c$．又 $f_2(x) = 8\mathrm{e}^{2x}$，$\lambda_2 = 2$ 是二重特征根，所以 $y_2^* = dx^2 \mathrm{e}^{2x}$．$y_1^* + y_2^*$ 就是特解的形式，选 (B)．

**15.2** $y = \mathrm{e}^{3x} - \mathrm{e}^x - x\mathrm{e}^{2x}$ **解** 记 $\bar{y}_1 = y_1 - y_3 = \mathrm{e}^{3x}$，$\bar{y}_2 = y_2 - y_3 = \mathrm{e}^x$，则 $\bar{y}_1, \bar{y}_2$ 是题设二阶常系数非齐次线性微分方程对应的齐次方程的两个解，且 $\bar{y}_1$ 和 $\bar{y}_2$ 线性无关．由此可得题设微分方程的通解是
$$y = C_1 \bar{y}_1 + C_2 \bar{y}_2 + y_3,$$
即
$$y = C_1 \mathrm{e}^{3x} + C_2 \mathrm{e}^x - x\mathrm{e}^{2x},$$
代入初始条件 $y|_{x=0} = 0$，$y'|_{x=0} = 1$，得
$$
\begin{cases}
C_1 + C_2 = 0, \\
3C_1 + C_2 - 1 = 1,
\end{cases}
$$
解得 $C_1 = 1, C_2 = -1$，故所求特解为 $y = \mathrm{e}^{3x} - \mathrm{e}^x - x\mathrm{e}^{2x}$．
