故原关系式化为 $\frac{\mathrm{d}^2 y}{\mathrm{d} t^2} + y = t$，解得 $y = C_1 \cos t + C_2 \sin t + t$，又由 $y\left(\ln \frac{2}{\pi}\right) = \frac{\pi}{2}$，知当 $t = \frac{\pi}{2}$ 时，$y = \frac{\pi}{2}$，
代入得 $C_2 = 0$。又由 $x = -\ln t$，得 $t = \mathrm{e}^{-x}$，故 $y(x) = C \cos \mathrm{e}^{-x} + \mathrm{e}^{-x}$，其中 $C$ 为任意常数。

**32. 【解析】** (1) 由于 $f'(x) = f\left(\frac{2}{x}\right)$，因此
$$f''(x) = f'\left(\frac{2}{x}\right) \cdot \left(-\frac{2}{x^2}\right),$$
从而有 $x^2 f''(x) + 2f'\left(\frac{2}{x}\right) = 0$，由题设可知 $f'\left(\frac{2}{x}\right) = f(x)$，故
$$x^2 f''(x) + 2f(x) = 0.$$
证毕.

(2) 令 $y = f(x)$，则
$$f'(x) = \frac{\frac{\mathrm{d}y}{\mathrm{d}t}}{\frac{\mathrm{d}x}{\mathrm{d}t}} = \mathrm{e}^{-t} \frac{\mathrm{d}y}{\mathrm{d}t},$$
$$f''(x) = \frac{\frac{\mathrm{d}}{\mathrm{d}t}\left(\mathrm{e}^{-t} \frac{\mathrm{d}y}{\mathrm{d}t}\right)}{\frac{\mathrm{d}x}{\mathrm{d}t}} = \mathrm{e}^{-2t} \frac{\mathrm{d}^2 y}{\mathrm{d} t^2} - \mathrm{e}^{-2t} \frac{\mathrm{d}y}{\mathrm{d}t}.$$
将 $y=f(x)$ 及上式代入方程 $x^2 f''(x) + 2f(x) = 0$，化简得 $\frac{\mathrm{d}^2 y}{\mathrm{d} t^2} - \frac{\mathrm{d}y}{\mathrm{d}t} + 2y = 0$，解得
$$y = f(x) = \mathrm{e}^{\frac{1}{2}t} \left( C_1 \cos \frac{\sqrt{7}}{2} t + C_2 \sin \frac{\sqrt{7}}{2} t \right)$$
$$= \sqrt{x} \left[ C_1 \cos \left( \frac{\sqrt{7}}{2} \ln x \right) + C_2 \sin \left( \frac{\sqrt{7}}{2} \ln x \right) \right] (x > 0).$$

**33. 【解析】**
$$\frac{\partial u}{\partial x} = f'(x), \frac{\partial^2 u}{\partial x^2} = f''(x), \frac{\partial u}{\partial y} = g'(y), \frac{\partial^2 u}{\partial y^2} = g''(y), \frac{\partial^2 u}{\partial x \partial y} = 0,$$

$$\{1 + [g'(y)]^2\} f''(x) + \{1 + [f'(x)]^2\} g''(y) = 0,$$
