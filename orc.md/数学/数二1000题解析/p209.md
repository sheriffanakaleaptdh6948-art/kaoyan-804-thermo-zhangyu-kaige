第6章 一元函数微分学的应用（二）——中值定理、微分等式与微分不等式

$$f(0^+) = \lim_{x \to 0^+} \left( \frac{1}{x^2} - \frac{\arctan x}{x^3} \right) = \lim_{x \to 0^+} \frac{x - \arctan x}{x^3} = \lim_{x \to 0^+} \frac{1 - \frac{1}{1+x^2}}{3x^2} = \frac{1}{3},$$

故当 $0 < x \leqslant 1$ 时， $1 - \frac{\pi}{4} \leqslant f(x) < \frac{1}{3}$。由此可见，当且仅当 $1 - \frac{\pi}{4} \leqslant k < \frac{1}{3}$ 时，方程 $\frac{1}{x^2} - \frac{\arctan x}{x^3} = k$ 在 $(0, 1]$ 内有实根。由于在 $(0, 1]$ 内方程 $x - \arctan x = kx^3$ 有实根，即方程 $\frac{1}{x^2} - \frac{\arctan x}{x^3} = k$ 有实根，故所求常数 $k$ 的取值范围为 $1 - \frac{\pi}{4} \leqslant k < \frac{1}{3}$。

**17. 【答案】(C)**

**【解析】** 令 $f(x) = \frac{\tan x}{x}$，则

$$f'(x) = \frac{x \sec^2 x - \tan x}{x^2} = \frac{x - \sin x \cos x}{x^2 \cos^2 x} = \frac{2x - \sin 2x}{2x^2 \cos^2 x} > 0 \left( 0 < x < \frac{\pi}{4} \right).$$

故函数 $f(x)$ 在 $\left( 0, \frac{\pi}{4} \right]$ 上单调增加，从而当 $0 < x < \frac{\pi}{4}$ 时， $f(0^+) < f(x) < f\left( \frac{\pi}{4} \right)$，即 $1 < f(x) < \frac{4}{\pi}$。

于是，当且仅当 $1 < k < \frac{4}{\pi}$ 时，方程 $\frac{\tan x}{x} = k$ 在 $\left( 0, \frac{\pi}{4} \right)$ 内有实根。

**18. 【答案】(A)**

**【解析】** 令 $f(x) = \frac{\int_0^x t e^t dt}{\int_0^x e^t dt} (x \neq 0)$，其中 $\int_0^x e^t dt = e^x - 1$，则

$$f'(x) = \frac{x e^x \cdot \int_0^x e^t dt - \int_0^x t e^t dt \cdot e^x}{(e^x - 1)^2} = \frac{e^x \left( \int_0^x x e^t dt - \int_0^x t e^t dt \right)}{(e^x - 1)^2} = \frac{e^x \cdot \int_0^x (x-t) e^t dt}{(e^x - 1)^2} > 0.$$

故 $f(x)$ 在 $(-\infty, 0), (0, +\infty)$ 上分别单调递增，又 $\lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{x e^x}{e^x} = 0$，所以当 $b > 0 > a$ 时， $f(b) > \lim_{x \to 0^+} f(x) = \lim_{x \to 0^-} f(x) > f(a)$，即 $\frac{\int_0^b t e^t dt}{\int_0^b e^t dt} > \frac{\int_0^a t e^t dt}{\int_0^a e^t dt}$，整理得 $a e^a (e^b - 1) > b e^b (e^a - 1)$，故(A)正确，(B)错误。

对于选项(C),(D)，构造函数 $g(x) = \frac{x(e^x - 1)}{e^x}$，求导得 $g'(x) = \frac{e^x - 1 + x}{e^x} \begin{cases} > 0, & x > 0, \\ < 0, & x < 0, \end{cases}$ 得 $g(x)$ 在 $(0, +\infty)$ 上单调递增，在 $(-\infty, 0)$ 上单调递减，无法判断 $g(a), g(b)$ 的大小。
