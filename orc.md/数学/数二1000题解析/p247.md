强化篇
第13章 多元函数微分学

方法二 令 $\sin x = t$，则 $F(a,b) = \int_0^1 (at - t^2 + b)^2 dt$。令
$$
\begin{cases}
\frac{\partial F}{\partial a} = \int_0^1 2(at - t^2 + b) \cdot t dt = 0, \\
\frac{\partial F}{\partial b} = \int_0^1 2(at - t^2 + b) dt = 0,
\end{cases}
$$
即 $\begin{cases} \frac{a}{3} + \frac{b}{2} - \frac{1}{4} = 0, \\ \frac{a}{2} + b - \frac{1}{3} = 0, \end{cases}$ 解得 $\begin{cases} a = 1, \\ b = -\frac{1}{6}, \end{cases}$ 又在 $\left(1, -\frac{1}{6}\right)$ 处，
$$
A = \frac{\partial^2 F}{\partial a^2} = \int_0^1 2t^2 dt = \frac{2}{3}, \quad B = \frac{\partial^2 F}{\partial a \partial b} = \int_0^1 2t dt = 1, \quad C = \frac{\partial^2 F}{\partial b^2} = \int_0^1 2 dt = 2,
$$
则 $\Delta = AC - B^2 > 0, A > 0$，故 $\left(1, -\frac{1}{6}\right)$ 为 $F(a,b)$ 的极小值点，又因为驻点唯一，故 $\left(1, -\frac{1}{6}\right)$ 为 $F(a,b)$ 的最小值点。

【注】方法二中积分号内可求导应用了如下定理：
设函数 $f(t,x)$ 在 $\{(t,x) | \alpha \leqslant t \leqslant \beta, a \leqslant x \leqslant b\}$ 上连续可微，则函数 $I(t) = \int_a^b f(t,x) dx$ 在区间 $[\alpha, \beta]$ 上连续可微，且
$$ I'(t) = \int_a^b \frac{\partial [f(t,x)]}{\partial t} dx. $$
在考试中，若是客观题，此定理可直接使用；若是解答题，只需把定理叙述一遍后使用即可。

**4.【解析】** (1) 由已知得 $\frac{f(x,y) - \sqrt{x^2 + y^2}}{\sqrt{x^2 + y^2}} = a + o(1)$，即
$$ f(x,y) = (a+1)\sqrt{x^2 + y^2} + o(\sqrt{x^2 + y^2}), $$
则 $\lim_{(x,y) \to (0,0)} f(x,y) = 0 = f(0,0)$，故函数 $f(x,y)$ 在点 $(0,0)$ 处连续。
(2) 由可微的定义，为使上式具有微分的形式，只需取 $a = -1$，此时函数 $f(x,y)$ 在点 $(0,0)$ 处的微分 $df|_{(0,0)} = 0$。

**5.【解析】** $\frac{\partial u}{\partial x} = [e^x + f'(x)]y, \frac{\partial u}{\partial y} = f'(x), \frac{\partial^2 u}{\partial x \partial y} = e^x + f'(x), \frac{\partial^2 u}{\partial y \partial x} = f''(x)$，
由于 $f(x)$ 具有二阶连续的导数，则 $u(x,y)$ 的二阶偏导数连续。从而 $\frac{\partial^2 u}{\partial x \partial y} = \frac{\partial^2 u}{\partial y \partial x}$，即 $f''(x) - f'(x) = e^x$，即 $f(x) = C_1 + C_2 e^x + x e^x$，又 $f(0) = 4, f'(0) = 3$，得 $C_1 = 2, C_2 = 2$，即
$$ f(x) = 2 + (2+x)e^x. $$
