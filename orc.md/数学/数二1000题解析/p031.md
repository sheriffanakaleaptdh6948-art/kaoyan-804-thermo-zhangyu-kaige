# 第5章 一元函数微分学的应用（一）
——几何应用

**1.【答案】** $\sqrt{2}$

**【解析】** 方法一 $\mathrm{e}^x + \frac{\mathrm{e}^{-x}}{2} \geqslant 2\sqrt{\mathrm{e}^x \cdot \frac{\mathrm{e}^{-x}}{2}} = \sqrt{2}$，当且仅当 $x=\frac{1}{2}\ln\frac{1}{2}$ 时，等号成立，故 $y$ 的最小值为 $\sqrt{2}$。

方法二
$$y' = \mathrm{e}^x - \frac{1}{2}\mathrm{e}^{-x} = \frac{2\mathrm{e}^{2x}-1}{2\mathrm{e}^x}, \quad y'' = \mathrm{e}^x + \frac{1}{2\mathrm{e}^x} > 0.$$
令 $y'=0$，解得 $x=\frac{1}{2}\ln\frac{1}{2}$，且 $y'$ 为增函数，故当 $x=\frac{1}{2}\ln\frac{1}{2}$ 时，$y$ 取到最小值，最小值为
$$y\bigg|_{x=\frac{1}{2}\ln\frac{1}{2}} = \mathrm{e}^{\frac{1}{2}\ln\frac{1}{2}} + \frac{\mathrm{e}^{-\frac{1}{2}\ln\frac{1}{2}}}{2} = \sqrt{\frac{1}{2}} + \frac{1}{2} \times \frac{1}{\sqrt{\frac{1}{2}}} = \sqrt{2}.$$

**2.【答案】** $(-\infty, -\mathrm{e})$

**【解析】** $f'(x) = (-a) \cdot \mathrm{e}^{-ax} - \mathrm{e} \stackrel{\text{令}}{=} 0$，得驻点 $x=x_0$ 满足 $-a\mathrm{e}^{-ax_0} - \mathrm{e} = 0$，即 $a = -\mathrm{e}^{1+ax_0} < 0$，又 $x_0 < 0$，于是 $1+ax_0 > 1$，又因为 $-\mathrm{e}^u$ 为单调减函数，所以 $a < -\mathrm{e}$。综上，$a \in (-\infty, -\mathrm{e})$。

> **【注】** 若命制为极值点大于零，则 $a \in (-\mathrm{e}, 0)$。

**3.【答案】** (B)

**【解析】** 当 $x<0$ 时，$f(x) = \cos(-x)-1 = \cos x - 1$，所以有
$$\lim_{x \to 0^-} \frac{f(x)-f(0)}{x} = \lim_{x \to 0^-} \frac{\cos x - 1}{x} = \lim_{x \to 0^-} \frac{-\frac{1}{2}x^2}{x} = 0,$$
$$\lim_{x \to 0^+} \frac{f(x)-f(0)}{x} = \lim_{x \to 0^+} \frac{x\ln x}{x} = -\infty,$$
故 $f(x)$ 在 $x=0$ 处的右导数不存在，从而 $f(x)$ 在 $x=0$ 处不可导。

当 $-\frac{\pi}{2} < x < 0$ 时，$f'(x) = -\sin x > 0$，当 $0 < x < \mathrm{e}^{-1}$ 时，$f'(x) = \ln x + 1 < 0$，且 $f(x)$ 在 $x=0$ 处连续，所以 $x=0$ 是 $f(x)$ 的极大值点。
