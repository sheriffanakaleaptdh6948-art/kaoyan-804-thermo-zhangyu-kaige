### 四 平面区域 $D$ 大观

要想正确计算二重积分，准确画出平面区域 $D$ 是必不可少的基本功，本讲最后，总结出常见的平面区域 $D$ 的图形及表达，考生应多画、多练，这些图不是背的，而是训练画区域能力的素材.

**1 直角坐标系下直线边界型**

考生应能熟练画出平面区域 $D$.

(1) $D=\{(x,y)|0 \leqslant x \leqslant 1, 0 \leqslant y \leqslant 1\}$.

(2) $D=\{(x,y)|x+y \leqslant 1, x \geqslant 0, y \geqslant 0\}$.
> 图注：$x+y=1$

(3) $D=\{(x,y)|0 \leqslant x \leqslant 1, 0 \leqslant y \leqslant x\}$.
> 图注：$y=x$

(4) $D=\{(x,y)|0 \leqslant x \leqslant 2, x \leqslant y \leqslant \sqrt{3}x\}$.
> 图注：$y=\sqrt{3}x$, $y=x$

(5) $D=\{(x,y)|0 \leqslant x \leqslant \pi, 0 \leqslant y \leqslant 1\}$.

(6) $D=\{(x,y)|1 \leqslant x+y \leqslant 2, x \geqslant 0, y \geqslant 0\}$.
> 图注：$x+y=2$, $x+y=1$

(7) $D=\left\{(x,y) \middle| 0 \leqslant x \leqslant 3, 0 \leqslant y \leqslant 3, \frac{\sqrt{3}}{3}x \leqslant y \leqslant \sqrt{3}x\right\}$.

(8) $D=\{(x,y)|1 \leqslant x+y \leqslant 2, 0 \leqslant y \leqslant x\}$.
