# 第14章 二重积分

**1.** $\lim_{n \to \infty} \sum_{i=1}^n \sum_{j=1}^n \frac{1}{(n+i)\sqrt{n^2+j^2}} = \_\_\_\_\_\_.$

**2.** 设 $D=\{(x,y) \mid |x|+|y| \leqslant 3\}$，$D_k(k=1,2,3,4)$ 是 $D$ 的第 $k$ 象限部分，$I_k = \iint_{D_k} \sin(x-y)\mathrm{d}x\mathrm{d}y$，则( ).
(A) $I_1 > 0$
(B) $I_2 > 0$
(C) $I_3 > 0$
(D) $I_4 > 0$

**3.** 设 $M = \iint_D \ln(x^2+y^2)\mathrm{d}x\mathrm{d}y$，$N = \iint_D [\ln(x^2+y^2)]^2\mathrm{d}x\mathrm{d}y$，$P = \iint_D (x^2+y^2-1)\mathrm{d}x\mathrm{d}y$，其中 $D=\{(x,y) \mid 1 \leqslant x^2+y^2 \leqslant 2\}$，则必有( ).
(A) $M < N < P$
(B) $N < M < P$
(C) $M < P < N$
(D) $N < P < M$

**4.** 设 $f(x)$ 是 $[0,1]$ 上的连续函数且其在 $[0,1]$ 上的平均值 $\bar{f} = \frac{1}{2}$，满足 $f(x) + a \int_1^x f(y)f(y-x)\mathrm{d}y = 1$，求常数 $a$ 的值.

**5.** 设 $I_1 = \iint_{\substack{0 \leqslant x \leqslant 1 \\ 0 \leqslant y \leqslant 1}} (\sin x^2 + \cos y^2)\mathrm{d}\sigma$，$I_2 = \iint_{|x|+|y| \leqslant \frac{1}{2}} \left[ 2 + \ln\left(\sqrt{x^2+y^2} + \frac{1}{2}\right) \right]\mathrm{d}\sigma$，则( ).
(A) $1 \leqslant I_1 \leqslant I_2$
(B) $I_1 \leqslant I_2 \leqslant 1$
(C) $I_2 \leqslant I_1 \leqslant 1$
(D) $I_2 \leqslant 1 \leqslant I_1$

**6.** $\int_{-1}^0 \mathrm{d}x \int_{(1-x^2)^{\frac{3}{2}}}^{(1-x^2)^{\frac{1}{2}}} (1-\sin x \cos y)\mathrm{d}y + \int_0^1 \mathrm{d}x \int_{(1-x^3)^{\frac{2}{3}}}^{(1-x^2)^{\frac{1}{2}}} (1-\sin x \cos y)\mathrm{d}y = \_\_\_\_\_\_.$

**7.** 设有界区域 $D$ 是由圆 $x^2+y^2=1$ 和直线 $y=x$ 以及 $x$ 轴所围成的在第一象限的图形，计算二重积分 $\iint_D e^{(x+y)^2}(x^2-y^2)\mathrm{d}x\mathrm{d}y$.

**8.** 设 $D=\{(x,y) \mid 4x^2+y^2 < 1, x \geqslant 0, y \geqslant 0\}$，则积分 $I = \iint_D (1-12x^2-y^2)\mathrm{d}x\mathrm{d}y = \_\_\_\_\_\_.$

**9.** 设平面区域 $D=\left\{(x,y) \left| \frac{1}{\sqrt{3}}x \leqslant y \leqslant \sqrt{3}x, 1 \leqslant x \leqslant 2 \right.\right\}$，求二重积分 $I = \iint_D y e^{\frac{y}{x}}\mathrm{d}x\mathrm{d}y$.
