# 第9章 一元函数积分学的计算

**1.** $\int_0^1 \ln \frac{1}{1-x} \mathrm{d}x = \underline{\hspace{2cm}}.$

**2.** 求 $\int \frac{x+2}{(2x+1)(x^2+x+1)} \mathrm{d}x$.

**3.** $\int_1^{\mathrm{e}} \cos(\ln x) \mathrm{d}x = \underline{\hspace{2cm}}.$

**4.** 设函数 $f(x)$ 满足方程 $xf(x)+f(1-x)=x^2$，求 $\int f(x) \mathrm{d}x$.

**5.** $\sum_{n=1}^{\infty} \int_n^{n+1} 2^{-\sqrt{x}} \mathrm{d}x = \underline{\hspace{2cm}}.$

**6.** 已知 $f(x)$ 是连续的偶函数，且 $\int_0^1 f(x) \mathrm{d}x = 2$，则 $\int_0^2 xf(1-x) \mathrm{d}x = \underline{\hspace{2cm}}.$

**7.** 已知 $f(x)$ 连续，$f(x^2+1)-f(x^2)=x(x>0)$，$\int_0^1 f(x) \mathrm{d}x = 1$，则 $\int_1^2 f(x) \mathrm{d}x = \underline{\hspace{2cm}}$

**8.** 设 $f(t) = \int_0^1 t|t-x| \mathrm{d}x$，求 $\int_{-1}^2 f(t) \mathrm{d}t$.

**9.** 设 $f(x)$ 是以2为周期的连续函数，$\int_0^2 f(x) \mathrm{d}x = 1$，$g(x)$ 是过点 $\left(-\frac{1}{2}, 0\right)$ 和 $(0, 1)$ 的直线，则 $\int_0^2 f[g(x)] \mathrm{d}x = (\quad)$.

**10.** 已知 $f''(x) = \arctan(x-1)^2, f(0)=0$，则 $\int_0^1 f(x) \mathrm{d}x = \underline{\hspace{2cm}}.$

**11.** 设 $g(x)=x^2$，$g[f(x)]=-x^2+2x+3$，且 $f(x)>0$，则 $\int_0^1 \frac{1}{f(x)} \mathrm{d}x = \underline{\hspace{2cm}}.$

**12.** 求 $\int_{-1}^1 x \ln(1+\mathrm{e}^x) \mathrm{d}x$.

**13.** 求 $\int_0^1 \frac{\mathrm{d}x}{(x+1)(x^2+1)}$.
