**张宇**考研数学题源探析经典1000题（数学二）

$ax_1 + bx_2 + cx_3 + dx_4 = 0$，得(II) $\begin{cases} x_1 + 3x_3 + 5x_4 = 0, \\ x_1 - x_2 - 2x_3 + 2x_4 = 0, \\ 2x_1 - x_2 + x_3 + 3x_4 = 0, \\ ax_1 + bx_2 + cx_3 + dx_4 = 0. \end{cases}$ 问 $a, b, c, d$ 满足什么条件时，方程组 (I), (II) 是同解方程组？并求出此时方程组(II)的通解。
