若 $F(D)\big|_{D=\alpha}=0$，而 $F'(D)\big|_{D=\alpha} \neq 0$，有 $y^* = x \frac{1}{F'(D)\big|_{D=\alpha}} \mathrm{e}^{\alpha x} \longrightarrow$ 注例2

若 $F(D)\big|_{D=\alpha}=0, F'(D)\big|_{D=\alpha}=0$，而 $F''(D)\big|_{D=\alpha} \neq 0$，有
$$y^* = x^2 \frac{1}{F''(D)\big|_{D=\alpha}} \mathrm{e}^{\alpha x} \longrightarrow \text{注例3}$$

**注例 1** 已知 $y''+y'-2y=2$，求 $y^*$。

**解** $y^* = \frac{1}{\mathrm{D}^2+\mathrm{D}-2} 2\mathrm{e}^{0x}$，由 $(\mathrm{D}^2+\mathrm{D}-2)\big|_{\mathrm{D}=0} \neq 0$，得 $F(\mathrm{D})\big|_{\mathrm{D}=\alpha} \neq 0$
$$y^* = \frac{1}{(\mathrm{D}^2+\mathrm{D}-2)\big|_{\mathrm{D}=0}} 2\mathrm{e}^{0x} = \frac{1}{-2} \cdot 2 = -1 \text{ .}$$

**注例 2** 已知 $y''+y'-2y=\mathrm{e}^x$，求 $y^*$。

**解** $y^* = \frac{1}{\mathrm{D}^2+\mathrm{D}-2} \mathrm{e}^x$，由 $(\mathrm{D}^2+\mathrm{D}-2)\big|_{\mathrm{D}=1}=0, (\mathrm{D}^2+\mathrm{D}-2)'\big|_{\mathrm{D}=1} \neq 0$，得 $\begin{cases} F(\mathrm{D})\big|_{\mathrm{D}=\alpha}=0, \\ \text{而 } F'(\mathrm{D})\big|_{\mathrm{D}=\alpha} \neq 0 \end{cases}$
$$y^* = x \frac{1}{(\mathrm{D}^2+\mathrm{D}-2)'\big|_{\mathrm{D}=1}} \mathrm{e}^x = x \cdot \frac{1}{3} \mathrm{e}^x = \frac{1}{3} x \mathrm{e}^x \text{ .}$$

**注例 3** 已知 $y''-2y'+y=\mathrm{e}^x$，求 $y^*$。

**解** $y^* = \frac{1}{\mathrm{D}^2-2\mathrm{D}+1} \mathrm{e}^x$，由 $\begin{cases} F(\mathrm{D})\big|_{\mathrm{D}=\alpha}=0, \\ F'(\mathrm{D})\big|_{\mathrm{D}=\alpha}=0, \\ \text{而 } F''(\mathrm{D})\big|_{\mathrm{D}=\alpha} \neq 0 \end{cases}$
$$(\mathrm{D}^2-2\mathrm{D}+1)\big|_{\mathrm{D}=1}=0, (\mathrm{D}^2-2\mathrm{D}+1)'\big|_{\mathrm{D}=1}=0, (\mathrm{D}^2-2\mathrm{D}+1)''\big|_{\mathrm{D}=1} \neq 0 \text{ ,}$$
得
$$y^* = x^2 \frac{1}{(\mathrm{D}^2-2\mathrm{D}+1)''\big|_{\mathrm{D}=1}} \mathrm{e}^x = x^2 \cdot \frac{1}{2} \mathrm{e}^x = \frac{1}{2} x^2 \mathrm{e}^x \text{ .}$$

② a. $\frac{1}{\mathrm{D}^2+q} \cos \beta x$ 或 $\frac{1}{\mathrm{D}^2+q} \sin \beta x$ 型。

若 $(\mathrm{D}^2+q)\big|_{\mathrm{D}=\beta \mathrm{i}} \neq 0$，有 $y^* = \frac{1}{(\mathrm{D}^2+q)\big|_{\mathrm{D}=\beta \mathrm{i}}} \cos \beta x$ 或 $y^* = \frac{1}{(\mathrm{D}^2+q)\big|_{\mathrm{D}=\beta \mathrm{i}}} \sin \beta x \longrightarrow$ 注例4

若 $(\mathrm{D}^2+q)\big|_{\mathrm{D}=\beta \mathrm{i}} = 0$，有 $y^* = x \frac{1}{(\mathrm{D}^2+q)'} \cos \beta x$ 或 $y^* = x \frac{1}{(\mathrm{D}^2+q)'} \sin \beta x \longrightarrow$ 注例5

b. $\frac{1}{F(\mathrm{D})} \cos \beta x$ 或 $\frac{1}{F(\mathrm{D})} \sin \beta x$ 型。

若 $F(\mathrm{D}) = \mathrm{D}^2+p\mathrm{D}+q$，则取
$$F(\mathrm{D})\big|_{\mathrm{D}^2=(\beta \mathrm{i})^2} = p\mathrm{D}+q-\beta^2 \longrightarrow \text{注例6}$$
$$y^* = \frac{1}{F(\mathrm{D})} \bigg|_{\mathrm{D}^2=(\beta \mathrm{i})^2} \cos \beta x = \frac{p\mathrm{D}-(q-\beta^2)}{p^2 \mathrm{D}^2 - (q-\beta^2)^2} \bigg|_{\mathrm{D}^2=(\beta \mathrm{i})^2} \cos \beta x = \frac{p\mathrm{D}-(q-\beta^2)}{-p^2 \beta^2 - (q-\beta^2)^2} \cos \beta x \text{ .}$$
