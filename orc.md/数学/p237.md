第9讲 一元函数积分学的计算

## 基础内容精讲

### 一 基本积分公式

以下10组公式，要牢记.

① $\int x^k \mathrm{d}x = \frac{1}{k+1}x^{k+1} + C, k \neq -1$; $\begin{cases} \int \frac{1}{x^2} \mathrm{d}x = -\frac{1}{x} + C, \\ \int \frac{1}{\sqrt{x}} \mathrm{d}x = 2\sqrt{x} + C. \end{cases}$

② $\int \frac{1}{x} \mathrm{d}x = \ln|x| + C$. $\longrightarrow (\ln x)' = \frac{1}{x}$

③ $\int \mathrm{e}^x \mathrm{d}x = \mathrm{e}^x + C$; $\int a^x \mathrm{d}x = \frac{a^x}{\ln a} + C, a>0$ 且 $a \neq 1$. $\longrightarrow (a^x)' = a^x \ln a$

④ $\int \sin x \mathrm{d}x = -\cos x + C$; $\int \cos x \mathrm{d}x = \sin x + C$;
$\int \tan x \mathrm{d}x = -\ln|\cos x| + C$; $\int \cot x \mathrm{d}x = \ln|\sin x| + C$;

角度一：$(-\ln|\cos x|)' = \tan x \Rightarrow \int \tan x \mathrm{d}x = -\ln|\cos x| + C$.
角度二：$\int \tan x \mathrm{d}x = \int \frac{\sin x}{\cos x} \mathrm{d}x = -\int \frac{1}{\cos x} (\cos x)' \mathrm{d}x$ (凑微分)
$\underset{u=\cos x}{=\!\!=\!\!=\!\!=\!\!=} -\int \frac{1}{u} \mathrm{d}u = -\ln|u| + C = -\ln|\cos x| + C$.

$\int \frac{\mathrm{d}x}{\cos x} = \int \sec x \mathrm{d}x = \ln|\sec x + \tan x| + C$; $\star$
$\int \frac{\mathrm{d}x}{\sin x} = \int \csc x \mathrm{d}x = \ln|\csc x - \cot x| + C$;
$\int \sec^2 x \mathrm{d}x = \tan x + C$; $\int \csc^2 x \mathrm{d}x = -\cot x + C$;
$\int \sec x \tan x \mathrm{d}x = \sec x + C$; $\int \csc x \cot x \mathrm{d}x = -\csc x + C$.

⑤ $\begin{cases} \int \frac{1}{1+x^2} \mathrm{d}x = \arctan x + C, \\ \int \frac{1}{a^2+x^2} \mathrm{d}x = \frac{1}{a} \arctan \frac{x}{a} + C (a>0). \end{cases}$
$\longrightarrow \int \frac{1}{x^2+a^2} \mathrm{d}x = \frac{1}{a} \int \frac{1}{1+\left(\frac{x}{a}\right)^2} \left(\frac{x}{a}\right)' \mathrm{d}x$
$\underset{\frac{x}{a}=u}{=\!\!=\!\!=\!\!=\!\!=} \frac{1}{a} \int \frac{1}{1+u^2} \mathrm{d}u = \frac{1}{a} \arctan u + C$
$= \frac{1}{a} \arctan \frac{x}{a} + C$

 $\begin{cases} \int \frac{1}{\sqrt{1-x^2}} \mathrm{d}x = \arcsin x + C, \\ \int \frac{1}{\sqrt{a^2-x^2}} \mathrm{d}x = \arcsin \frac{x}{a} + C (a>0). \end{cases}$
