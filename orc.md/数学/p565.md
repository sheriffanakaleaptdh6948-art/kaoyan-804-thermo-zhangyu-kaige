附录5 从指数函数到双曲函数

为自然对数.
自然对数与普通以10为底的对数的联系是
$$ \ln x = \ln 10 \cdot \lg x (\ln 10 \approx 2.302585), $$
$$ \lg x = \lg e \cdot \ln x (\lg e \approx 0.434294). $$

**2 双曲函数**

双曲函数是由指数函数 $e^x$ 与 $e^{-x}$ 构成的初等函数.

**(1) 定义.**

双曲正弦函数
$$ \text{sh } x = \frac{e^x - e^{-x}}{2}. $$

双曲余弦函数
$$ \text{ch } x = \frac{e^x + e^{-x}}{2}. $$

双曲正切函数
$$ \text{th } x = \frac{\text{sh } x}{\text{ch } x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}. $$

$$ \text{sh}(-x) = \frac{e^{-x} - e^x}{2} = -\frac{e^x - e^{-x}}{2} = -\text{sh } x, $$
$$ \text{ch}(-x) = \frac{e^{-x} + e^x}{2} = \frac{e^x + e^{-x}}{2} = \text{ch } x, $$
$$ \text{th}(-x) = \frac{\text{sh}(-x)}{\text{ch}(-x)} = \frac{-\text{sh } x}{\text{ch } x} = -\text{th } x, $$

故 $\text{sh } x, \text{th } x$ 都是奇函数，$\text{ch } x$ 是偶函数.

想要画出这三种函数的图形，只要先画出右半平面的曲线部分 ($x \geqslant 0$)，再根据对称性就能画出整个曲线（见图2）. 注意到
$$ \text{sh } x = \frac{1}{2}e^x - \frac{1}{2}e^{-x}, $$
$$ \text{ch } x = \frac{1}{2}e^x + \frac{1}{2}e^{-x}, $$
先作出 $y=\frac{1}{2}e^x$ 与 $y=\frac{1}{2}e^{-x}$ 的图形，$\text{sh } x$ 的值正是这两条曲线在点 $x$ 处的纵坐标之差，$\text{ch } x$ 的值正是这两条曲线在点 $x$ 处的纵坐标之和. 容易看出，当 $x$ 很大时，$\text{ch } x$ 总是大于 $\frac{1}{2}e^x$，但很接近它，$\text{sh } x$ 总是小于 $\frac{1}{2}e^x$，也很接近它.
