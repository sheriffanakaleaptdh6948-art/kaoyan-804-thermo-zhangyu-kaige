类题 2 设 $x_n > 0$，$x_n + \frac{4}{x_{n+1}^2} < 3$，证明 $\{x_n\}$ 收敛并求极限

**（二） 不单调数列的处理方法**

对于不单调的数列，处理起来更为复杂，上面我们已经提到过一个定理——
“若 $f(x)$ 递减，则 $\{x_n\}$ 必不单调，但 $\{x_n\}$ 的奇偶子列必定分别单调，且具有相反的单调性.”
除此之外，还有一个较为常用的定理，叫作“压缩映像原理”——

**必背结论 1** 对任一数列 $\{x_n\}$，若存在 $0 \leqslant k < 1$，使得 $|x_{n+1} - x_n| \leqslant k|x_n - x_{n-1}|$ 成立，则 $\{x_n\}$ 一定收敛。

证：由比值判别法可得，级数 $\sum_{n=1}^{\infty} (x_{n+1} - x_n)$ 绝对收敛，又由 $x_n = x_1 + \sum_{k=1}^{n-1} (x_{k+1} - x_k)$ 得 $\{x_n\}$ 也收敛.

**必背结论 2** 设 $x_{n+1} = f(x_n)$，若存在 $0 \leqslant k < 1$，使得 $|f'(x)| \leqslant k < 1$ 成立，则 $\{x_n\}$ 一定收敛。

法1：$|x_{n+1} - x_n| = |f(x_n) - f(x_{n-1})| = |f'(\xi_n)| |x_n - x_{n-1}| \leqslant k|x_n - x_{n-1}|$，问题转化为结论1，证毕.
法2：先求出 $x = f(x)$ 的根（设为 $A$），则 $|x_{n+1} - A| = |f(x_n) - f(A)| = |f'(\xi_n)| |x_n - A| \leqslant k|x_n - x_{n-1}|$
$\leqslant k^2|x_{n-1} - x_{n-2}| \leqslant \cdots \leqslant k^n|x_1 - x_0|$. 又 $0 < k < 1$，故 $\lim_{n \to \infty} k^n|x_1 - x_0| = 0$，夹逼可得 $\lim_{n \to \infty} x_n = A$.

**注：** 在利用压缩映像原理解题时，最常见的错误就是忽略了 $k < 1$ 的条件。从压缩映像原理的证明过程中可以发现，$k < 1$ 是非常重要的——正是因为 $k < 1$，才能保证数列 $\{x_n\}$ 收敛。这里的 $k$ 相当于是一个“压缩比例”或“压缩因子”。所以，**如果只是证明出来了 $|f'(x)| < 1$，是证明不出数列 $\{x_n\}$ 收敛的；只有证明出 $|f'(x)| \leqslant k < 1$，才能说明数列 $\{x_n\}$ 收敛，也就是说，这个 $k$ 是不可缺少的，在解题时一定要找到这个具体的 $k$，切记！**
