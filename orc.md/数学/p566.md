**(2) 关系式.**
双曲函数之间具有一些重要恒等式.
根据双曲正弦与双曲余弦的定义立即可知
$$ \text{e}^x = \text{ch } x + \text{sh } x, \text{e}^{-x} = \text{ch } x - \text{sh } x, $$
利用这两个恒等式，就能通过指数函数的性质来证明一些关于双曲函数的恒等式. 如
$$ \begin{aligned} \text{sh}(u+v) &= \frac{1}{2}[\text{e}^{(u+v)} - \text{e}^{-(u+v)}] = \frac{1}{2}(\text{e}^u \cdot \text{e}^v - \text{e}^{-u} \cdot \text{e}^{-v}) \\ &= \frac{1}{2}[(\text{ch } u + \text{sh } u)(\text{ch } v + \text{sh } v) - (\text{ch } u - \text{sh } u)(\text{ch } v - \text{sh } v)], \end{aligned} $$
也就是
$$ \text{sh}(u+v) = \text{sh } u \text{ ch } v + \text{ch } u \text{ sh } v. $$
在这个恒等式中，将两端所包含的 $v$ 换作 $-v$，并利用双曲函数的奇偶性，立即可得
$$ \text{sh}(u-v) = \text{sh } u \text{ ch}(-v) + \text{ch } u \text{ sh}(-v) $$
