第6讲 一元函数微分学的应用（二）——中值定理、微分等式与微分不等式

### 三 微分不等式

#### 1 用函数性态（包括单调性、凹凸性和最值等）证明不等式

一般地，使用如下依据.

(1) 若有 $f'(x) \geqslant 0, a < x < b$，则有 $f(a) \leqslant f(x) \leqslant f(b)$.

$\star$ (2) 若有 $f''(x) \geqslant 0, a < x < b$，则有 $f'(a) \leqslant f'(x) \leqslant f'(b)$.
① 当 $f'(a) > 0$ 时，$f'(x) > 0$，则 $f(x)$ 单调增加；
② 当 $f'(b) < 0$ 时，$f'(x) < 0$，则 $f(x)$ 单调减少.

$\star$ (3) 设 $f(x)$ 在 $I$ 内连续，且有唯一的极值点 $x_0$，则
$$
\begin{cases}
\text{当 } x_0 \text{ 为极大值点时，即为 } I \text{ 内的最大值点，有 } f(x_0) \geqslant f(x), & f(x) \leqslant M \\
\text{当 } x_0 \text{ 为极小值点时，即为 } I \text{ 内的最小值点，有 } f(x_0) \leqslant f(x), & f(x) \geqslant m
\end{cases}
$$
其中 $x \in I$.

$\star$ (4) 若有 $f''(x) > 0$（注：凹凸性），$a < x < b, f(a) = f(b) = 0$，则有 $f(x) < 0$.
（右侧图示：坐标系中 $f(x)$ 轴，$x$ 轴，$O, a, b$，曲线在 $a, b$ 之间位于 $x$ 轴下方）

**例 6.19** 证明当 $0 < x < \frac{\pi}{2}$ 时，有 $\sin x > \frac{2x}{\pi}$. （注：$\frac{2x}{\pi} < \sin x < x$）

**证 方法一**（注：主流方法：单调性） 若证 $\sin x > \frac{2x}{\pi}$，即需证 $\frac{\sin x}{x} > \frac{2}{\pi}$，令 $f(x) = \frac{\sin x}{x}, x \in \left(0, \frac{\pi}{2}\right)$，则
$$ f'(x) = \frac{x \cos x - \sin x}{x^2} $$
（注：定不出正负，继续求导）

（注：分母大于0，只需研究分子）
令 $g(x) = x \cos x - \sin x, x \in \left(0, \frac{\pi}{2}\right)$，得 $g'(x) = -x \sin x < 0$，则 $g(x)$ 单调递减，$g(x) < g(0) = 0$，所以在 $\left(0, \frac{\pi}{2}\right)$ 上 $f'(x) < 0, f(x)$ 单调递减，$f(x) > f\left(\frac{\pi}{2}\right) = \frac{2}{\pi}$，即
$$ \sin x > \frac{2x}{\pi}, x \in \left(0, \frac{\pi}{2}\right). $$
