**例题 6** 设$f(x)$在$[0,1]$二阶可导，且$|f(x)| \leqslant a$，$|f''(x)| \leqslant b$，证：$|f'(x)| \leqslant 2a + \frac{b}{2}$恒成立

**证明：** $\forall x \in [0,1]$，将$f(x)$在$c$点处展开成泰勒公式，

得$f(x) = f(c) + f'(c)(x-c) + \frac{f''(\xi)}{2}(x-c)^2$，

其中$\xi$在$c$与$x$之间.当$x=0, 1$时，分别有$f(0) = f(c) + f'(c)(-c) + \frac{f''(\xi_0)}{2}(-c)^2 (0 < \xi_0 < c)$

$f(1) = f(c) + f'(c)(1-c) + \frac{f''(\xi_1)}{2}(1-c)^2 (c < \xi_1 < 1)$

两式相减，得$f(1) - f(0) = f'(c) + \frac{f''(\xi_1)}{2}(1-c)^2 - \frac{f''(\xi_0)}{2}c^2$，

即$f'(c) = f(1) - f(0) + \frac{f''(\xi_0)}{2}c^2 - \frac{f''(\xi_1)}{2}(1-c)^2$.

两边取绝对值，由绝对值不等式及$|f(1)| \leqslant a, |f(0)| \leqslant a, |f''(\xi_0)| \leqslant b, |f''(\xi_1)| \leqslant b$，

得$|f'(c)| \leqslant 2a + \frac{b}{2}[(1-c)^2 + c^2] \leqslant 2a + \frac{b}{2}[(1-c) + c] = 2a + \frac{b}{2}$，

其中$0 < 1-c < 1, 0 < c < 1$，所以$(1-c)^2 < 1-c, c^2 < c$.

**类题 1** 设$f(x)$在$(-\infty, +\infty)$二阶可导，记$M_i = \max |f^{(i)}(x)|$ $(i=0,1,2)$，证明：$M_1^2 \leqslant 2M_0 M_2$

**证明：** 由泰勒展开得$f(x+h) = f(x) + hf'(x) + \frac{f''(\xi)}{2}h^2$，

$\xi \in (x, x+h), f(x-h) = f(x) - hf'(x) + \frac{f''(\eta)}{2}h^2, \eta \in (x-h, x)$

相减得$f(x+h) - f(x-h) = 2f'(x)h + \frac{h^2}{2}[f''(\xi) - f''(\eta)]$

$2f'(x)h = f(x+h) - f(x-h) - \frac{h^2}{2}[f''(\xi) - f''(\eta)]$

下有两种处理方法：

法一：$2|f'(x)|h \leqslant |f(x+h)| + |f(x-h)| + \frac{1}{2}h^2(|f''(\xi)| + |f''(\eta)|) \leqslant 2M_0 + h^2 M_2$

即 $M_2 h^2 - 2|f'(x)|h + 2M_0 \geqslant 0$ 对一切$h$成立.

故判别式 $|f'(x)|^2 - 2M_0 M_2 \leqslant 0$，

即 $M_1 = \sup_{-\infty < x < +\infty} |f'(x)|^2 \leqslant 2M_0 M_2$ 对一切$x$成立.

法二：$|f'(x)| \leqslant \frac{M_0}{h} + \frac{h M_2}{2}, \forall h > 0$ 而 $\frac{M_0}{h} \cdot \frac{h M_2}{2} = \frac{1}{2} M_0 M_2$ 为常数

.所以将右端看成关于$h$的函数，当$\frac{M_0}{h} = \frac{h M_2}{2}$取最小.令$h = \sqrt{2M_0/M_2}$，

代入得$|f'(x)| \leqslant \sqrt{2M_0 M_2}, \quad \forall x \in (-\infty, +\infty)$ 所以 $M_1^2 \leqslant 2M_0 M_2$.
