3-24 解 题过程 取容器中 R134a 为闭口系，据题意，查 R134a 热力性质表，300 kPa、100 °C 时，

$$h_{1}=490.13 \mathrm{~kJ} / \mathrm{kg}, v_{1}=0.09875 \mathrm{~m}^{3} / \mathrm{kg}$$

$$u_{1}=h_{1}-p_{1} v_{1}=490.13 \mathrm{~kJ} / \mathrm{kg}-300 \mathrm{kPa} \times 0.09875 \mathrm{~m}^{3} / \mathrm{kg}=460.55 \mathrm{~kJ} / \mathrm{kg}$$

$p_{2}=p_{1}=300 \mathrm{kPa}$

查 R134a 饱和性质表，$v^{\prime}=0.00077492 \mathrm{~m}^{3} / \mathrm{kg}, v^{\prime \prime}=0.066694 \mathrm{~m}^{3} / \mathrm{kg}$、

$h^{\prime \prime}=398.36 \mathrm{~kJ} / \mathrm{kg}, h^{\prime}=200.85 \mathrm{~kJ} / \mathrm{kg}$

$$h_{2}=h^{\prime}+x_{2}\left(h^{\prime \prime}-h^{\prime}\right)$$

$$=200.85 \mathrm{~kJ} / \mathrm{kg}+0.75 \times(398.36 \mathrm{~kJ} / \mathrm{kg}-200.85 \mathrm{~kJ} / \mathrm{kg})$$

$$=348.98 \mathrm{~kJ} / \mathrm{kg}$$

$v_{2}=v^{\prime}+x_{2}\left(v^{\prime \prime}-v^{\prime}\right)$

$$=0.00077492 \mathrm{~m}^{3} / \mathrm{kg}+0.75 \times(0.066694-0.77492) \mathrm{m}^{3} / \mathrm{kg}$$

$$=0.050214 \mathrm{~m}^{3} / \mathrm{kg}$$

$$u_{2}=h_{2}-p_{2} v_{2}=348.98 \mathrm{~kJ} / \mathrm{kg}-300 \mathrm{kPa} \times 0.050214 \mathrm{~m}^{3} / \mathrm{kg}$$

$$=333.92 \mathrm{~kJ} / \mathrm{kg}$$

$\Delta U=m \Delta u=1 \mathrm{~kg} \times(333.92-348.98) \mathrm{kJ} / \mathrm{kg}=-15.06 \mathrm{~kJ}$

3-25 解 题过程 取容器内 $\mathrm{NH}_{3}$ 为系统，$0^{\circ} \mathrm{C}$ 时，$p=429.6 \mathrm{kPa}, h=957.3 \mathrm{~kJ} / \mathrm{kg}$、

$v=0.1741 \mathrm{~m}^{3} / \mathrm{kg}$

$$\begin{aligned} & v=\frac{V}{v}=\frac{0.2 \mathrm{~m}^{3}}{0.1741 \mathrm{~m}^{3} / \mathrm{kg}}=1.149 \mathrm{~kg} \\ & u_{1}=h_{1}-p_{1} v_{1}=957.3 \mathrm{~kJ} / \mathrm{kg}-429.6 \mathrm{kPa} \times 0.1741 \mathrm{~m}^{3} / \mathrm{kg}=882.5 \mathrm{~kJ} / \mathrm{kg} \end{aligned}$$

因容器是刚性的，所以在过程中氨的比体积不变 $p_{2}=1 \mathrm{MPa}$ 时，$v^{\prime \prime}=0.1285$ $\mathrm{m}^{3} / \mathrm{kg}<v_{2}$，所以终态为过热蒸汽。查 $\mathrm{NH}_{3}$ 热力性质表，$h=1684.4 \mathrm{~kJ} / \mathrm{kg}$

$$u_{2}=h_{2}-p_{2} v_{2}=1684.4 \mathrm{~kJ} / \mathrm{kg}-1000 \mathrm{kPa} \times 0.1741 \mathrm{~m}^{3} / \mathrm{kg}=1510.3 \mathrm{~kJ} / \mathrm{kg}$$

$Q=\Delta U+W=m\left(u_{2}-u_{1}\right)=1.149 \mathrm{~kg} \times(1510.3-882.5) \mathrm{kJ} / \mathrm{kg}=721.3 \mathrm{~kJ}$
