1. 压气机理论耗功: 压缩气体的生产过程包括气体的流入、压缩和输出, 所以压气机耗功应以技术功计. 通常用符号 $W_{\mathrm{C}}$ 表示压气机的耗功, 且有 $W_{\mathrm{C}}=-W_{\mathrm{t}}$.

| 可逆绝热压缩 | $W_{\mathrm{C}, s}=W_{\mathrm{t}, s}=\frac{\kappa}{\kappa-1}\left(p_{2} v_{2}-p_{1} v_{1}\right)=\frac{\kappa R_{\mathrm{g}}}{K-1}\left(T_{2}-T_{1}\right)$ |
| --- | --- |
|  | $=\frac{\kappa}{\kappa-1} R_{\mathrm{g}} T_{1}\left[\left(\frac{p_{2}}{p_{1}}\right)^{\kappa-1 / \kappa}-1\right]$ |

| 可逆多变过程 | $W_{\mathrm{C}, n}=-W_{\mathrm{t}, n}=\frac{n}{n-1}\left(p_{2} v_{2}-p_{1} v_{1}\right)=\frac{n}{n-1} R_{\mathrm{g}} T_{1}\left[\left(\frac{p_{2}}{p_{1}}\right)^{n-1 / n}-1\right]$ |
| --- | --- |
|  | $W_{\mathrm{C}, \mathrm{T}}=-W_{\mathrm{t}, \mathrm{T}}=-R_{\mathrm{g}} T_{1} \ln \frac{v_{2}}{v_{1}}=R_{\mathrm{g}} T_{1} \ln \frac{p_{2}}{p_{1}}$ |

2. 容积效率: 即有效吸气容积 $V$ 与气缸排量 $V_{\mathrm{h}}$ 的比值, 用 $\eta_{V}$ 表示.

3. 余隙容积百分比: 即余隙容积 $V_{\mathrm{c}}$ 与气缸排量 $V_{\mathrm{h}}$ 的比值, 用 $\sigma$ 表示.

4. 容积效率的计算公式: $\eta_{V}=1-\sigma\left[\pi^{\frac{1}{n}}-1\right]$. 当余隙容积百分比 $\sigma$ 和多变指数 $n$ 一定时, 增压比 $\pi$ 越大, 则容积效率越低, 当 $\pi$ 增加到某一值时容积效率为零; 当增压比 $\pi$ 一定时, 余隙容积百分比越大, 容积效率越低.

5. 多级压缩中间压力的选择原则:

每级压气机所需的功相等, 有利于压气机曲轴平衡;

每个气缸中气体压缩后达到的最高温度相同, 每个气缸的温度条件相同;
