$\begin{aligned}\Delta u &= \Delta h - \Delta(pv) = \Delta h - R_g \Delta T \\&= 598.52 - 282.22 - 0.287 \times (590 - 280) = 227.33 \, \text{kJ/kg}\end{aligned}$

根据闭口系能量方程得

$q = \Delta u + w = 227.3 + w$

闭口系熵方程

$\begin{aligned}s_g &= s_2 - s_1 - s_f \\s_2 - s_1 &= s_2^o - s_1^o - R_g \ln \frac{p_2}{p_1} \\&= 7.3964 - 6.638 - 0.287 \times \ln 2.107 \\&= 0.5445 \, \text{kJ/(kg·K)} \\s_f &= \frac{q}{T_r} = \frac{227.33 + w}{556}\end{aligned}$

所以有 $s_g = s_2 - s_1 - s_f = 0.5445 - \frac{227.33 + w}{556}$

(2) 据题意, $T_2 = 590 \, \text{K}, T_r = 556 \, \text{K}, T_2 > T_r$, 所以靠热源加热至多可加热到 $T_a$ $= T_r = 556 \, \text{K}, T_a \to T_2$ 这一段温升只是由于叶轮搅拌而产生. 故将过程分成两个阶段: 由 $T_1$ 到 $T_2$ 靠热源加热, 由 $T_a$ 到 $T_2$ 靠搅拌.

查附表得 $h_a = 563 \, \text{kJ/kg}, s_a^o = 7.3343 \, \text{kJ/(kg·K)}$

$\Delta h_{1-a} = h_a - h_1 = 563 - 282.22 = 280.78 \, \text{kJ/kg}$

$\Delta u_{1-a} = \Delta h_{1-a} - R_g \Delta T_{1-a}$

$\text { 号楼 }$

因此 $q_{1-a} = \Delta u_{1-a} = 201.57 \, \text{kJ/kg}$

$w_{\min} = -\Delta u_{a-2} = -\left(\Delta u_{1-2} - \Delta u_{1-a}\right) = -(227.33 - 201.57)$

$= -25.76 \, \text{kJ/kg}$

$s_{\mathrm{g}, \min } = s_2 - s_1 - s_f$

$= 0.5445 - \frac{227.33 - 25.76}{556} = 0.18196 \, \text{kJ/(kg·K)}$

(3) 最大熵产发生不靠加热, 全部由于搅拌而升温, 这时 $q = 0, s_f = 0$

$s_{\mathrm{g}, \max } = s_2 - s_1 = 0.5445 \, \text{kJ/(kg·K)}$

此时, 搅拌功最大, $w_{\max } = -\Delta u_{1-2} = -227.33 \, \text{kJ/kg}$
