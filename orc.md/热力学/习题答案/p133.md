(1) 据题意, $p_{1} = 110 \mathrm{kPa}, T_{1} = 273.15 + 50 = 323.15 \mathrm{~K}, \epsilon = v_{1} / v_{2} = 8, T_{3} =$ $273.15 + 900 = 1173.15 \mathrm{~K}$

$v_{1} = \frac{R_{g} T_{1}}{p_{1}} = \frac{287 \times 323.15}{110 \times 10^{3}} = 0.8431 \mathrm{~m}^{3} / \mathrm{kg}$

$v_{2} = v_{1} / \epsilon = 0.8431 / 8 = 0.1054 \mathrm{~m}^{3} / \mathrm{kg}$

$p_{2} = p_{1} \epsilon^{k} = 110 \times 8^{1.4} = 2021.71 \mathrm{kPa}$

$T_{2} = \frac{p_{2} v_{2}}{R_{g}} = \frac{2021.71 \times 0.1054}{287} = 724.47 \mathrm{~K}$

$v_{3} = v_{2} = 0.1054 \mathrm{~m}^{3} / \mathrm{kg}$

$p_{3} = p_{2} \cdot \frac{T_{3}}{T_{2}} = 2021.71 \times \frac{1173.15}{742.47} = 3194.44 \mathrm{kPa}$

$v_{4} = v_{1} = 0.8431 \mathrm{~m}^{3} / \mathrm{kg}$

$p_{4} = p_{3}\left(\frac{v_{3}}{v_{4}}\right)^{k} = p_{3}\left(\frac{v_{2}}{v_{1}}\right)^{k} = 3194.44 \times \frac{1}{8^{1.4}} = 173.81 \mathrm{kPa}$

$T_{4} = \frac{p_{4} v_{4}}{R_{g}} = \frac{173.81 \times 10^{3} \times 0.8431}{287} = 510.59 \mathrm{~K}$
