据题意，查表：$h_{1}=1515.0 \mathrm{~kJ} / \mathrm{kg}, h_{2}=1287.8 \mathrm{~kJ} / \mathrm{kg} ; h_{3}=950.7 \mathrm{~kJ} / \mathrm{kg}$, $p=6.53 \mathrm{MPa}$ 时；$h^{\prime}=1242.0 \mathrm{~kJ} / \mathrm{kg}, h^{\prime \prime}=2777.8 \mathrm{~kJ} / \mathrm{kg}$，新蒸汽干度 $x=0.9956$，所以

$\begin{aligned} & h_{4}=h^{\prime}+x\left(h^{\prime \prime}-h^{\prime}\right) \\ & =1242.0 \mathrm{~kJ} / \mathrm{kg}+0.9956 \times(2777.8-1242.0) \mathrm{kJ} / \mathrm{kg}=2771.0 \mathrm{~kJ} / \mathrm{kg} \end{aligned}$

取蒸汽发生器为控制体积，忽略向环境大气散热量，不计工质的动能差和位能差，由能量方程 $q_{\mathrm{ml}}\left(h_{1}-h_{2}\right)=q_{\mathrm{m} 3}\left(h_{4}-h_{3}\right)$ 解得蒸汽流量

$\begin{aligned} q_{\mathrm{m} 3} & =\frac{q_{\mathrm{ml}}\left(h_{1}-h_{2}\right)}{\left(h_{4}-h_{3}\right)} \\ & =\frac{4875 \mathrm{~kg} / \mathrm{s} \times\left(1515.0 \mathrm{~kJ} / \mathrm{kg}-1287.8 \mathrm{~kJ} / \mathrm{kg}\right)}{2771.0 \mathrm{~kJ} / \mathrm{kg}-950.7 \mathrm{~kJ} / \mathrm{kg}}=608.47 \mathrm{~kg} / \mathrm{s} \end{aligned}$

(2) 蒸汽发生器输出蒸汽压力 $6.53 \mathrm{MPa}$ 时，$h^{\prime \prime}=2777.8 \mathrm{~kJ} / \mathrm{kg}$，

$v^{\prime \prime}=296 \mathrm{~m}^{3} / \mathrm{kg}, h^{\prime}=1242 \mathrm{~kJ} / \mathrm{kg}, v^{\prime}=0.00013 \mathrm{~m}^{3} / \mathrm{kg}$.

$h=h^{\prime}+x\left(h^{\prime \prime}-h^{\prime}\right)$

$=1242 \mathrm{~kJ} / \mathrm{kg}+0.9956 \times(2777.8-1242) \mathrm{kJ} / \mathrm{kg}$

$=2771 \mathrm{~kJ} / \mathrm{kg}$

$v=v^{\prime}+x\left(v^{\prime \prime}-v^{\prime}\right)$

$=0.0013 \mathrm{~m}^{3} / \mathrm{kg}+0.9956 \times(0.0296-0.0013) \mathrm{m}^{3} / \mathrm{kg}$

$=0.02948 \mathrm{~m}^{3} / \mathrm{kg}$

$q_{\mathrm{m}}=\frac{A_{\mathrm{cl}}}{v}=\frac{\pi d_{1}^{2} c_{1}}{4 v}=\frac{A_{\mathrm{cl}}}{4 v} \times 2777.8 \mathrm{~kJ} / \mathrm{kg} / \mathrm{s}$

$d_{\mathrm{i}}=\sqrt{\frac{4 u q_{\mathrm{m}}}{\pi c_{\mathrm{i}}}}=\sqrt{\frac{4 \times 0.02948 \mathrm{~m}^{3} / \mathrm{kg} \times 608.47 \mathrm{~kg} / \mathrm{s}}{\pi \times 20 \mathrm{~m} / \mathrm{s}}}=$

$=1.07 \mathrm{~m}$
