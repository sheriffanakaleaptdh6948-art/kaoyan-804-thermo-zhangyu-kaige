1-4 解: 过程

(1) 由题意可知 $p = p_{\mathrm{b}} - p_{\mathrm{v}} = 0.101 \times 10^{6} - 752.5 \times 133.3 = 691.75 \mathrm{~Pa}$

(2) $F = A \Delta p = A\left(p_{\mathrm{b}} - p\right) = A p_{\mathrm{v}} = 4 \pi\left(\frac{d}{2}\right)^{2} \cdot p_{\mathrm{v}}$

$= 4 \times 3.1416 \times \frac{1}{4} \times 752.5 \times 133.3 = 3.151 \times 10^{5} \mathrm{~N}$

1-5 解: 过程

由图可知，$p = p_{\text {空 }} + p_{\text {水柱 }} + p_{\text {水银柱 }}$

$$= \left(755 \times 133.3\right) + \left(1020 \times 9.81\right) + \left(900 \times 133.3\right)$$

$= 2.306 \times 10^{5} \mathrm{~Pa} = 0.231 \mathrm{MPa}$

1-6 解: 过程

由题意可得绝对压力

$$p = p_{\mathrm{b}} - p_{\mathrm{v}} = (755-600) \times 133.3 = 0.0207 \mathrm{MPa} = 155 \mathrm{mmHg}$$

若容器中绝对压力保持不变，而大气压力变为 $p_{\mathrm{b}}^{\prime} = 770 \mathrm{~mmHg}$

则此时真空表上的读数为 $p_{\mathrm{v}}^{\prime} = p_{\mathrm{b}}^{\prime} - p = (770-155) \mathrm{mmHg} = 615 \mathrm{~mmHg}$

1-7 解: 过程

由题意可知，倾斜压力计上读数即为烟气的真空度

$$p_{\mathrm{v}} = \frac{F}{A} = \frac{\mathrm{mg} \sin \alpha}{A} = \frac{\rho A \lg \sin \alpha}{A} = \rho \lg \sin \alpha$$

得 $p_{\mathrm{v}} = \rho \lg \sin \alpha = 0.8 \times 10^{3} \times 200 \times 10^{-3} \times 9.81 \times 0.5 \mathrm{~Pa} = 80 \times 9.81 \mathrm{~Pa}$

又因为 $1 \mathrm{~mmHg} = 9.81 \mathrm{~Pa}$，所以 $p_{\mathrm{v}} = 80 \times 9.81 \mathrm{~Pa} = 80 \mathrm{~mmHg}$

绝对压力 $p = p_{\mathrm{b}} - p_{\mathrm{v}} = (745 \times 133.3) - (80 \times 9.81) = 9.85 \times 10^{4} \mathrm{~Pa}$

1-8 解: 过程

由题意可知，蒸汽逸出时压力锅内压力即为柱塞的压力，即有

$$p_{\text {内 }} = p_{\text {柱 }} = p_{\mathrm{b}} + \mathrm{mg} / \mathrm{A}$$

所以 $m = \frac{\left(p_{\text {内 }} - p_{\mathrm{b}}\right) A}{g} = \frac{(201-101) \times 10^{3} \times 4 \times 10^{-6}}{9.81} = 0.0408 \mathrm{~kg} = 40.8 \mathrm{~g}$

1-9 解: 过程

由题意可知 $p_{\mathrm{A}} = p_{\mathrm{b}} + p_{\mathrm{el}}$

$$p_{\mathrm{B}} = p_{\mathrm{b}} + p_{\mathrm{e} 3}$$

$p_{\mathrm{e} 2} = \left| p_{\mathrm{A}} - p_{\mathrm{B}} \right| = \left| p_{\mathrm{el}} - p_{\mathrm{e} 3} \right|$

所以 $p_{\mathrm{e} 3} = p_{\mathrm{e} 1} \pm p_{\mathrm{e} 2}$
