2. 理想气体比定压热容、比定容热容和迈耶公式

(1) 比热容一般表达式

$\begin{aligned}c &= \frac{\partial u}{\mathrm{~d}T} = \frac{\mathrm{du} + \partial u}{\mathrm{~d}T} = \frac{\mathrm{du}}{\mathrm{dT}} + \frac{p \mathrm{~d} u}{\mathrm{~d}T} \\u &= u(T, v), \mathrm{d}u = \left( \frac{\partial u}{\partial T} \right)_v \mathrm{~dT} + \left( \frac{\partial u}{\partial v} \right)_T \mathrm{~dv}\end{aligned}$

将其代入 (1) 式中, 得比热容一般表达式如下:

$c = \left( \frac{\partial u}{\partial T} \right)_v + \left[ \left( \frac{\partial u}{\partial v} \right)_T + p \right] \frac{\mathrm{dv}}{\mathrm{dT}}$

(2) 定容热容 \(c_v\)

定容过程: \(\mathrm{d}v = 0\)

代入一般表达式得 \(c_v = \left( \frac{\partial u}{\partial T} \right)_v\)

若气体为理想气体, 有 \(u = u(T)\)

因此, 得 \(c_v = \left( \frac{\partial u}{\partial T} \right)_v = \frac{\mathrm{du}}{\mathrm{dT}}\) 或 \(\mathrm{d}u = c_v \mathrm{dT}\)

结论: (1) \(c_v\) 只与温度有关; (2) 理想气体热力学能 \(u\) 是状态参数, 与过程无关, 且仅是温度的函数。

(3) 定压热容 \(c_p\)

定压过程: \(\mathrm{dp} = 0\)

据一般表达式可得

$c_p = \left( \frac{\partial u}{\partial T} \right)_v + \left[ \left( \frac{\partial u}{\partial v} \right)_T + p \right] \frac{\mathrm{dv}}{\mathrm{dT}} = c_v + \left[ \left( \frac{\partial u}{\partial v} \right)_T + p \right] \frac{\mathrm{dv}}{\mathrm{dT}}$

若气体为理想气体, 有 \(u = u(T)\), 即 \(\left( \frac{\partial u}{\partial v} \right)_T = 0\)

因此, 得

$c_p = c_v + p \frac{\mathrm{dv}}{\mathrm{dT}} = \frac{\mathrm{du}}{\mathrm{dT}} + p \frac{\mathrm{dv}}{\mathrm{dT}} = \frac{\mathrm{d}(h - pv) + p \mathrm{~dv}}{\mathrm{dT}}$

简化后得

$c_p = \frac{\mathrm{dh} - v \mathrm{dp}}{\mathrm{dT}} = \frac{\mathrm{dh}}{\mathrm{dT}}$

结论: (1) \(c_p\) 只与温度有关; (2) 理想气体焓 \(h\) 是状态参数, 与过程无关, 且仅是温度的函数。
