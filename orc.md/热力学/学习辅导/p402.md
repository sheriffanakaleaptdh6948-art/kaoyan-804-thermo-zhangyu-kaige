6. 某理想气体在气缸内作可逆绝热膨胀，当容积变为原来的 1.79 倍时，温度由 197.6 °C 下降到 100 °C，同时气体对外作功 60 kJ/kg，设比热容为定值，试求气体的比定压热容和比定容热容。（10 分）

提示及答案 因可逆绝热膨胀，有 Δu + w = 0，Δs₁₋₂ = cᵥ ln (T₂ / T₁) + R_g ln (v₂ / v₁) = 0。所以过程功 w = -Δu = u₁ - u₂ = cᵥ (T₁ - T₂)，求得 cᵥ = w / (T₁ - T₂) = 0.615 kJ/(kg·K)；Δs₁₋₂ = 0，得 R_g = 0.246 kJ/(kg·K)，cₚ = R_g + cᵥ = 0.861 kJ/(kg·K)。

本题主要错误及简析 （1）“cₚ = 1.4 cᵥ = ”“cₚ = ncᵥ”——理想气体 cₚ = κcᵥ，双原子理想气体比热容为定值时绝热指数取 1.4，但题目未明指气体类型且多变指数 n ≠ cₚ / cᵥ；（2）“n = ln (p₂ / p₁) / ln (v₂ / v₁) = ⋯”⇒ n = ln (p₂ / p₁) / ln (v₁ / v₂) 是多变指数的计算式，仅适用于可逆过程，不可逆绝热过程无多变指数概念。

2008 年工程热力学Ⅱ试题及要点提示

（考试时间 120 分）

一、简答题（20 分）

1. 有人提出理想气体混合气体中第 i 种组元气体的分压力 pᵢ 与分体积 Vᵢ 之间满足 pᵢV = ViP，其中 p、V 为混合气体总压力和总容积。这种说法是否正确并说明理由。（12 分）

答题要点 正确。分压力 pᵢ = xiP，xi = pi/P = φi = Vi/V，故 pᵢV = ViP。

本题主要错误及简析 （1）“错。若 pᵢV = ViP 成立，则因 pᵢ/P = ni/n，而 pᵢ/P = Vi/V = ni/vn，显然 vi ≠ v，因此命题不成立。”$$\frac{V_{i}}{V}=\frac{n_{i}V_{m,i}}{nV_{m}}\neq\frac{n_{i}v_{i}}{nv}$$，同温同压Vm,i =Vm,m，Vi/V =ni/n = xi/P，所以 pᵢV = ViP 成立；（2）“$\frac{p_{i}}{p}=\frac{n_{i}RT/V_{i}}{nRT/V}=\frac{n_{i}}{n}\frac{1}{V_{i}/V}=x_{i}\frac{1}{\varphi_{i}}=1$”——分压力是组分气体与混合气体相同温度，相同体积单独施加的压力，分体积是组分气体与混合气体相同温度，并保持相同的压力占据的体积，所以 pᵢ = niRT/V、RT ≠ ViPni。
