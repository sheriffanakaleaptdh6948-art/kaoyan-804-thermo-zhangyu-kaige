点评 通常水和水蒸气的热力性质图表上并不列出热力学能的值, 水蒸气的热力学能可通过 $u=h-p v$ 计算得到。

理想气体可逆等温过程的膨胀功等于技术功等于热量, 但水蒸气可逆等温过程的膨胀功不等于热量, 因为水蒸气的热力学能是温度和比体积的函数, 虽温度不变,热力学能仍可能改变。

【例 3-9】图 3-10 所示的汽缸活塞系统, 最大容积为 $0.5 \mathrm{~m}^{3}$ 。初始时汽缸内含有 $50 \mathrm{~kg}$ 压力为 $200 \mathrm{kPa}$ 的水 $0.1 \mathrm{~m}^{3}$, 若加热水至 $200{ }^{\circ} \mathrm{C}$, 试确定缸内工质的终态。

解 令水吸热膨胀过程中体积达汽缸最大容积时状态为 $\mathrm{a}$, 终态温度为 $t_{2}$ 。

状态 $1: v_{1}=\frac{V_{1}}{m}=\frac{0.1 \mathrm{~m}^{3}}{50 \mathrm{~kg}}=0.002 \mathrm{~m}^{3} / \mathrm{kg}$;

状态 $\mathrm{a}: v_{\mathrm{a}}=\frac{V_{\mathrm{a}}}{m}=\frac{V_{\max }}{m}=\frac{0.5 \mathrm{~m}}{50 \mathrm{~kg}}=0.01 \mathrm{~m}^{3} / \mathrm{kg}$

状态 $2: v_{2}=v_{\mathrm{a}}=0.01 \mathrm{~m}^{3}$;

由 $t_{2}=200{ }^{\circ} \mathrm{C}$, 查水和水蒸气热力性质表, $v^{\prime}=$ $0.0012 \mathrm{~m}^{3} / \mathrm{kg}, v^{\prime \prime}=0.1274 \mathrm{~m}^{3} / \mathrm{kg}, v^{\prime}<v_{2}<v^{\prime \prime}$, 所以终态为湿饱和蒸汽, $p_{2}=p_{s 2}=1553.6 \mathrm{kPa}$, 干度为

$x_{2}=\frac{v_{2}-v^{\prime}}{v^{\prime \prime}-v^{\prime}}=\frac{0.01 \mathrm{~m}^{3} / \mathrm{kg}-0.0012 \mathrm{~m}^{3} / \mathrm{kg}}{0.1274 \mathrm{~m}^{3} / \mathrm{kg}-0.0012 \mathrm{~m}^{3} / \mathrm{kg}}=0.07$
