$\begin{aligned}& T_{2}=350 \mathrm{~K}+\frac{2.610 \quad 3-2.420 \quad 4}{2.672 \quad 0-2.420 \quad 4} \times(360 \mathrm{~K}-350 \mathrm{~K})=357.60 \mathrm{~K} \\& h_{2}=352.54 \mathrm{~kJ} / \mathrm{kg}+\frac{357.60 \mathrm{~K}-350 \mathrm{~K}}{360 \mathrm{~K}-350 \mathrm{~K}} \times(362.61-352.54) \mathrm{kJ} / \mathrm{kg} \\& =360.19 \mathrm{~kJ} / \mathrm{kg} \\& T_{4}=200 \mathrm{~K}+\frac{0.403 \quad 1-0.341 \quad 4}{0.405 \quad 1-0.341 \quad 4} \times(210 \mathrm{~K}-200 \mathrm{~K})=209.69 \mathrm{~K} \\& h_{4}=201.87 \mathrm{~kJ} / \mathrm{kg}+\frac{209.67 \mathrm{~K}-200 \mathrm{~K}}{210 \mathrm{~K}-200 \mathrm{~K}} \times(211.94-201.87) \mathrm{kJ} / \mathrm{kg} \\& =211.61 \mathrm{~kJ} / \mathrm{kg}\end{aligned}$

压缩机耗功为

$w_{\mathrm{c}}=h_{2}-h_{1}=360.19 \mathrm{~kJ} / \mathrm{kg}-252.12 \mathrm{~kJ} / \mathrm{kg}=108.07 \mathrm{~kJ} / \mathrm{kg}$

膨胀机作出的功为

$w_{\mathrm{T}}=h_{3}-h_{4}=302.29 \mathrm{~kJ} / \mathrm{kg}-211.61 \mathrm{~kJ} / \mathrm{kg}=90.68 \mathrm{~kJ} / \mathrm{kg}$

空气在冷却器中放热量为

$q_{0}=h_{2}-h_{3}=360.19 \mathrm{~kJ} / \mathrm{kg}-302.29 \mathrm{~kJ} / \mathrm{kg}=57.90 \mathrm{~kJ} / \mathrm{kg}$

1 kg 空气在冷库中的吸热量即为 1 kg 空气的制冷量为

$q_{\mathrm{C}}=h_{1}-h_{4}=252.12 \mathrm{~kJ} / \mathrm{kg}-211.61 \mathrm{~kJ} / \mathrm{kg}=40.51 \mathrm{~kJ} / \mathrm{kg}$

循环输入的净功为

$w_{\text {net }}=w_{\mathrm{C}}-w_{\mathrm{T}}=108.07 \mathrm{~kJ} / \mathrm{kg}-90.68 \mathrm{~kJ} / \mathrm{kg}=17.39 \mathrm{~kJ} / \mathrm{kg}$

循环的净热量为

$q_{\text {net }}=q_{0}-q_{\mathrm{C}}=57.90 \mathrm{~kJ} / \mathrm{kg}-40.51 \mathrm{~kJ} / \mathrm{kg}=17.39 \mathrm{~kJ} / \mathrm{kg}$

循环的制冷系数为

$\varepsilon=\frac{q_{\mathrm{C}}}{w_{\text {net }}}=\frac{40.51 \mathrm{~kJ} / \mathrm{kg}}{17.39 \mathrm{~kJ} / \mathrm{kg}}=2.33$
