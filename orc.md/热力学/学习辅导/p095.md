代入式 (a)，得

$Q=\left(m_{2} h_{2}-m_{1} h_{1}\right)-m_{1} h_{1}$

据题意，初态为饱和蒸汽状态，终态仍为相同温度、相同压力的湿饱和蒸汽状态。由于过程中原在容器内的水的焓值无变化；未冷凝的蒸汽焓值也不变，控制体积内焓值的变化由加入的水和饱和蒸汽冷凝成饱和液体的焓变构成，所以

$Q=m_{1}\left(h^{\prime}-h_{1}\right)-\Delta m_{v}\left(h^{\prime \prime}-h^{\prime}\right)$

式中，$\Delta m_{v}$ 是冷凝的蒸汽质量。又，控制体积内总容积不变，所以泵入水终态的体积满足下式

$m_{1} v^{\prime}-\Delta m_{v}\left(v^{\prime \prime}-v^{\prime}\right)=0$

查饱和水和饱和水蒸气表，230 °C 时 $v^{\prime}=0.00120882 \mathrm{~m}^{3} / \mathrm{kg}$、$v^{\prime \prime}=0.071553 \mathrm{~m}^{3} / \mathrm{kg}$、$h^{\prime}=898.95 \mathrm{~kJ} / \mathrm{kg}$、$h^{\prime \prime}=2803.00 \mathrm{~kJ} / \mathrm{kg}$；查未饱和水和饱和过热水蒸气表，65 °C、2.795 05 MPa 的未饱和水焓 $h=274.4 \mathrm{~kJ} / \mathrm{kg}$，所以

$\Delta m_{v}=\frac{m_{1} v^{\prime}}{v^{\prime \prime}-v^{\prime}}=\frac{900 \mathrm{~kg} \times 0.00120882 \mathrm{~m}^{3} / \mathrm{kg}}{(0.071553-0.00120882) \mathrm{m}^{3} / \mathrm{kg}}=15.466 \mathrm{~kg}$

代入式 (b)，得

$\begin{aligned} Q=900 \mathrm{~kg} \times(989.95-274.4) \mathrm{kJ} / \mathrm{kg}-15.466 \mathrm{~kg} \times(2803.00-989.95) \mathrm{kJ} / \mathrm{kg} \\ =615954.4 \mathrm{~kJ} \end{aligned}$

点评 理想气体和水蒸气的热力过程都遵循热力学第一定律，但是对于水蒸气这样的实际气体还应注意平衡相变时的规律。

2. 对于理想气体的任何一种过程，下列两组公式是否都适用？

$\Delta u=c_{v}\left(t_{2}-t_{1}\right), \Delta h=c_{p}\left(t_{2}-t_{1}\right) ; q=\Delta u=c_{v}\left(t_{2}-t_{1}\right), q=\Delta h=c_{p}\left(t_{2}-t_{1}\right)$

提示：据理想气体热力学能和焓的特性，结合气体比热容性质和热力学第一定律解析式分析。如，式 $q=\Delta u=c_{v}\left(t_{2}-t_{1}\right)$ 而言，热力学第一定律第一解析式 $q=\Delta u+w$ 适用于任意工质、任何过程，当然可用于理想气体的任意过程。进一步简化为 $q=\Delta u$ 则适用于定比体积过程。$\Delta u=c_{v}\left(t_{2}-t_{1}\right)$ 要求定容比热容 $c_{v}$ 为常数，由于理想气体的热力学能只是温度的函数，所以相同温度区间内其热力学能的变化量相同。$q=\Delta u=c_{v}\left(t_{2}-t_{1}\right)$ 表示定比热容理想气体定容过程的热量。
