答题要点 利用废气加热，如供热水：$q_{m,w} = \frac{q_{m,g} c_{p,g} (T_{g1} - T_{g2})}{c_{p,w} (T_{w2} - T_{w1})}$；利用废气热能转变为功，如发电：$P_{net} = q_{m,g} \left[ c_{p,g} (T_{g1} - T_{g2}) - T_0 (s_{g1} - s_{g2}) \right] = \cdots = 14.59\,\mathrm{kW}$。

本题主要错误及简析 （1）“设计斯特林循环如附录 II 图 30，其循环等效于在废气热源恒温吸热，向环境恒温放热，热效率为 $\eta_i = 1 - \frac{(20 + 273)\,\mathrm{K}}{(600 + 273)\,\mathrm{K}} = 0.664,\cdots$”——斯特林循环是两个多变过程与两个等温过程组成的概括性卡诺循环，但作为提供热量的热源，受制于废气的性质，难以实现等温放热，因此无法达成 $0.664$ 的热效率；（2）“柴油机废气最大可利用能量为 $q_Q = q_m c_p (T - T_0) = \cdots$，其焱值 $\dot{E}_x = q_Q \left( 1 - \frac{T_2}{T_1} \right) = q_Q \times \left( 1 - \frac{293\,\mathrm{K}}{873\,\mathrm{K}} \right) = \cdots$”——柴油机废气放热，温度从 $600\,\mathrm{℃}$ 下降到 $20\,\mathrm{℃}$，其放出热量的焱值 $\dot{E}_x = q_Q \left( 1 - \frac{T_0}{T_1} \right) = \cdots$；

（3）“因压力不足，故考虑直接利用热能加热生活用热水等。”——热量传递的条件是温差，压力不高但温度较高的工质通过间壁式换热器同样可以加热高压工质，如蒸汽动力装置锅炉内的烟气压力通常仅稍稍高于（或低于）环境压力，但可加热产生高压蒸汽；（4）“废气定压放热到环境温度，焱损 $i = T_0 \Delta s = 293\,\mathrm{K} \times 1.01\,\mathrm{kJ/(kg·K)} \times \ln \frac{293\,\mathrm{K}}{873\,\mathrm{K}} = \cdots$”——不可逆过程中单位质量工质的焱损 $i = T_0 s_g$，只有在绝热过程中因熵流等于零，$i = T_0 s_g = T_0 \Delta s$；（5）“利用废气为热源，热机从中吸热，向冷源放热，每小时可向热机提供热量 $q_Q = q_m T \Delta s = q_m T \left( c_p \ln \frac{T_2}{T_1} - R_g \ln \frac{p_2}{p_1} \right) = \cdots$”——可逆过程的热量可用 $q = \int_1^2 T\,ds$ 计算，可逆等温过程才有 $q = T \Delta s$，其中 $T$ 为热源温度，而废气随着放热温度下降，所以 $q = \overline{T} \Delta s$；（6）“在柴油机排气口设置喷管装置，增加废气的可用能，然后利用喷出的高速气流推动叶轮作功”——气流在喷管流速增大的必要条件是压降，气流在喷管内绝热膨胀，气流的焓焨转化为宏观动能，在题给条件下，设想几无可能实现。同时，任何实际过程都有不可逆损失，所以不改变废气参数而“增加废气的可用能”违反热力学基本定律。
