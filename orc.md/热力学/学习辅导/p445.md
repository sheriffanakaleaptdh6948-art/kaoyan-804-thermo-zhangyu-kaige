2. 某太阳能供暖的房屋用 $5 \, \text{m} \times 8 \, \text{m} \times 0.3 \, \text{m}$ 的大块混凝土板作为蓄热材料，该混凝土的密度为 $2300 \, \text{kg/m}^3$，比热容 $0.65 \, \text{kJ/(kg·K)}$。若在 $18^\circ \text{C}$ 的房子内的混凝土板在晚上从 $23^\circ \text{C}$ 冷却到 $18^\circ \text{C}$，求此过程混凝土板的散热量、熵流和熵产。（15分）

提示及答案 混凝土板的质量 $m = \rho V = 27600 \, \text{kg}$，释热量 $Q = mc\Delta T = 89700 \, \text{kJ}$，混凝土板的熵变 \(\Delta S_1 = m \int_1^2 \frac{\delta q}{T} = mc \ln \frac{T_2}{T_1} = -305.63 \, \text{kJ/K}\)，熵流 $S_1 = \frac{Q}{T_0} = -308.25 \, \text{kJ/K}$，熵产 $S_2 = \Delta S - S_1 = 2.62 \, \text{kJ/K}$。

本题主要错误及简析 （1）“取混凝土板与室内空气为孤立系，\(\Delta S_{\text{iso}} = S_1 + S_2 = 0\)，因熵流 $S_1 = \frac{Q}{T_0} = \cdots = -308.9 \, \text{kJ/K}\)，所以 $S_2 = -S_1 = 308.9 \, \text{kJ/K}$”——若取混凝土板与室内空气为孤立系，那么孤立系与外界没有任何形式的质、能交换，也就没有热量交换，就不存在热熵流，孤立系统熵增原理指出孤立系统内进行的不可逆过程必定使孤立系统熵增大，孤立系统内进行可逆过程，熵不变。不能既有 \(\Delta S_{\text{iso}} = 0\)，又有 $S_2 = 308.9 \, \text{kJ/K} > 0$；（2）“取室内空气为系统，其熵方程为 $S_2 - S_1 = S_1 + S_2$，$S_1 = \frac{Q}{\Delta T} = \cdots$，因空气状态不变所以 $S_2 = -S_1 = \cdots$”——$S_1 = \int_1^2 \frac{\delta Q}{T_r}$，其中 $T_r$ 为热源温度，在热源为恒温热源时 $S_1 = \frac{Q}{T_r}$。取室内空气为系统，混凝土板即为热源，混凝土板是变温的，熵流应积分求解，即 $S_1 = \int_1^2 \frac{\delta Q}{T_r}$，其中热量符号由系统确定，空气吸热，故热量为正，与混凝土板放热量等值反号。题目仅给出温度不变，所以不能就此得出空气状态不变，但空气吸热熵增加，\(\Delta S_{\text{1-2}} = \frac{Q}{T_0} = 308.25 \, \text{kJ/K}\)，故 $S_2 = \Delta S_{\text{1-2}} - S_{\text{1,o}}$ （3）“\(\Delta S_{\text{iso}} = S_2 = \frac{-Q}{T_m} + \frac{Q}{T_a} = \frac{-8.97 \times 10^4}{(291 + 296)/2} + \frac{8.97 \times 10^4}{291} = \cdots\)”——混凝土平均放放热温度应是积分平均值，而非算术平均值；（4）“$S_2 = S_1 T_0$”——等式两侧量纲不一致；且熵产与环境温度的乘积表示过程不可逆的作功能力损失，熵流与环境温度的乘积物理意义？
