2. 现有两个容积相等且材质也相同的容器，它们的容积为 \(1 \, \mathrm{m}^3\)，其中一个装有压力为 \(1 \, \mathrm{MPa}\) 的干饱和蒸汽，另一个盛有 \(1 \, \mathrm{MPa}\) 的饱和水，如果由于意外的原因发生爆炸，问哪一个容器爆炸引起的危害性大些？为什么？水蒸气参数见附表。

答题要点 爆炸危害由爆炸物质的内热能释放引起，判别两容器内工质的热力学能即可确定爆炸危害的大小。爆炸物质的内热能 \(U = mu\)，\(m' = \frac{V}{v'} =\) 887.2 kg, \(m'' = \frac{V}{v''} = 5.14\) kg, \(u' = h' - p_s v' = 761.4\) kJ/kg, \(u'' = h'' - p_s v'' = 2583.29\) kJ/kg，\(U'' = m'' u'' = 13278.1\) kJ, \(U' = m' u' = 675514.1\) kJ，所以盛有饱和水的容器爆炸引起的危害性大。

3. 一个门窗打开的房间，若房内空气温度上升而压力不变，则房内空气的总热力学能如何变化？为什么（空气比热容按定值计）？

答题要点 门窗开启的房间，房内空气温度上升压力不变，故房内空气质量变化，房内空气的总热力学能变化 \(\Delta U = m_2 c_V T_2 - m_1 c_V T_1 = \frac{pV}{R_g T_2} c_V T_2 - \frac{pV}{R_g T_1} c_V T_1 =\) \(\frac{pV}{R_g} c_V - \frac{pV}{R_g} c_V\)，房内压力和体积均不变，所以 \(\Delta U = 0\)

4. 在内燃机混合加热理想循环、定容加热理想循环及定压加热理想循环中，提高压缩比 \(\varepsilon\) 都可使循环热效率提高，试从热力学基本原理分析其原因。

答题要点 在内燃机混合加热理想循环、定容加热理想循环及定压加热理想循环中，提高压缩比 \(\varepsilon\) 使燃气平均吸热温度提高，由于平均放热温度不变，据卡诺定理及多热源内可逆循环热效率的表达式 \(\eta_t = 1 - \frac{\overline{T_2}}{\overline{T_1}}\)，循环热效率提高。
