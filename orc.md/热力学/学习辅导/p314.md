算混合后空气的温度及相对湿度 (图 12-6)。( $p_{b}=1 \times 10^{5} \mathrm{~Pa}$ )

解 据 $t_{1}=10{ }^{\circ} \mathrm{C} 、 \varphi_{1}=100 \%$ 和 $t_{2}=$ $38{ }^{\circ} \mathrm{C} 、 \varphi_{2}=30 \%$ 分别从 $h-d$ 图, 查得

$d_{1}=7.7 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right),$

$h_{1}=29.5 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })$

$d_{2}=12.4 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right),$

$h_{2}=70.7 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })$

两股气流绝热混合, 据质量守恒和能量守恒可导得

$\frac{q_{m a 1}}{q_{m a 2}}=\frac{d_{3}-d_{2}}{d_{1}-d_{3}}=\frac{h_{3}-h_{2}}{h_{1}-h_{3}}$

而据题意, $\frac{q_{m a 1}}{q_{m a 2}}=5$, 所以,

$\begin{aligned} & 5=\frac{d_{3}-12.4 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right)}{7.7 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right)-d_{3}} \\ & 5=\frac{h_{3}-70.0 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })}{29.5 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })-h_{3}} \end{aligned}$

解得

$\begin{aligned} & d_{3}=8.5 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right) \\ & h_{3}=36.25 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 }) \end{aligned}$

由 $h_{3}$ 和 $d_{3}$, 根据 $h_{3}=1.005 t_{3}+1 d_{3}(2501+1.86 t_{3})$ 解得 $t_{3}=14.7{ }^{\circ} \mathrm{C}$ 。进而由 $t_{3}$ 查得 $p_{s 3}=16.72 \times 10^{2} \mathrm{~Pa}$ 。

因

$d_{3}=0.622 \frac{\varphi_{3} p_{s 3}}{p-\varphi_{3} p_{s 3}}$

所以

$\begin{aligned} \varphi_{3}= & \frac{\frac{d_{3}}{0.622^{p}}}{\left(1+\frac{d_{3}}{0.622}\right) p_{s 3}}=\frac{\frac{8.5 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right)}{0.622}}{\left[1+\frac{8.5 \times 10^{-3} \mathrm{~kg} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right)}{0.622}\right]} \times 16.72 \times 10^{2} \mathrm{~Pa} \\ = & 0.81 \end{aligned}$

点评 只要对绝热混合过程列出水的质量守恒和能量守恒方程联立求解,就可导出本题使用的式 (a)。本例的求解也可利用 $h-d$ 图进行, 在 $h-d$ 图上连接 1 和 2 , 以 $m_{\mathrm{a} 1}$ 和 $m_{\mathrm{a} 2}$ 分割连线如图 12-4 所示, 据式 (a), 分割点即混合后湿空气的状态。从交点读出 $t=14.5{ }^{\circ} \mathrm{C} 、 d_{3}=8.5 \mathrm{~g} /\left(\text { 水蒸气 } / \mathrm{kg}\right) /\left(\text { 干空气 }\right) 、 \varphi=82 \%$ 。
