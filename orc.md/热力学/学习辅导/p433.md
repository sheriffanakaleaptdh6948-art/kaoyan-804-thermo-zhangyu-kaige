提示及答案 (1) h = 1.005t + d(2501 + 1.86t) = 156.1 kJ/kg(DA), d = 0.622 \frac{p_v}{p - p_v}, p_v = \frac{pd}{0.622 + d} = 6.75 kPa, p_s(40 ℃) = 7.375 kPa, φ = \frac{p_v}{p_s} = 91.5%。由水蒸气分压力插值 t_d = 38.34 ℃；(2) 由于储气筒内平衡温度为 37 ℃，水蒸气最大分压力为 6.274 kPa，甚至小于压缩前的 6.75 kPa，故空气相对湿度 100%，水蒸气分压力为 6.274 kPa。 x_v = \frac{p_v}{p} = 0.009。

本题主要错误及简析 (1) “0.7 MPa 时 t_s = 151.867 ℃ ≥ t = 37 ℃，说明湿空气处于为饱和状态，……” —— 湿空气被压缩到 0.7 MPa，但水蒸气的分压力 p_v = x_v p，小于 0.7 MPa，所以湿空气中水蒸气对应的饱和温度应小于 151.867 ℃。湿空气中的水蒸气处于过热或饱和状态，湿空气的温度（即是空气中水蒸气的温度）高于（或等于）水蒸气分压力对应的饱和温度。就湿空气而言，当自身温度低于饱和温度时，必定有部分水蒸气凝结析出；(2) “压缩过程 d 不变，p = 0.7 MPa 时 t_s < 37 ℃，则此时为未饱和水，p_v = 0, x = 0, φ = 0, ……” —— 压缩过程（尤其在压缩过程的前期）可能含湿量不变，但由于压缩过程中水蒸气的分压力对应的饱和温度与空气的温度的关系可能发生变化，当水蒸气的分压力对应的饱和温度等于空气的温度时仍能保持 d 不变，但若要发生 t_s > t 的状况时部分水蒸气将凝结以保持 t_s = t，即空气保持饱和的状态，水蒸气的分压力与空气温度对应饱和压力相等，即 p_v = p_s(t)，相对湿度等于 1。(3) “干度 x = \frac{1}{1 + d} = ……，0.1 MPa 时 h' = 417.52 kJ/kg、h'' = 2 675.1 kJ/kg，所以 x = \frac{h - h'}{h'' - h'} = ……” —— 干度是饱和液和干饱和蒸气混合物中气态物质的质量分数，是指同种物质，湿空气是干空气和水蒸气的混合物，不存在干度的概念；饱和空气中的水蒸气处于饱和的状态，并非湿饱和蒸汽。
