实际上蒸汽在动力装置中的全部过程都是不可逆的，尤其是蒸汽高速流经汽轮机时绝热膨胀与理想可逆过程的差别较为显著。考虑汽轮机中的不可逆损失，则蒸汽经过汽轮机时实际所作的技术功为

$$w_{1, \text { act }}=h_{1}-h_{2, \text { act }}=\left(h_{1}-h_{2}\right)-\left(h_{2, \text { act }}-h_{2}\right)$$

少作的功等于在冷凝器中多排出的热量 $\left(h_{2, \text { act }}-h_{2}\right)$ 。值得指出的是，由于 $2_{\text {act }}$ 与 2 状态不同，故少作的功并不就是不可逆膨胀过程的作功能力损失。作功能力损失仍应由 $T_{0} s_{\mathrm{g}}$ 计算。

汽轮机内蒸汽实际作功 $w_{\mathrm{t}, \text { act }}$ 与理论功 $w_{1}$ 的比值称为汽轮机的相对内效率，简称汽轮机效率，以 $\eta_{\mathrm{T}}$ 表示，则

$\begin{gathered} \eta_{\mathrm{T}}=\frac{w_{1, \text { act }}}{w_{1}}=\frac{h_{1}-h_{2, \text { act }}}{h_{1}-h_{2}} \\ h_{2, \text { act }}=h_{2}+\left(1-\eta_{\mathrm{T}}\right)\left(h_{1}-h_{2}\right)=h_{2}+\left(1-\eta_{\mathrm{T}}\right) h_{0} \end{gathered}$

式中，$h_{0}=h_{1}-h_{2}$，为理想绝热熵降。

1 kg 蒸汽在实际工作循环中作出的循环净功称为实际循环内部功，用 $w_{\text {net, act }}$ 表示

$w_{\text {net, act }}=w_{1, \text { act }}-w_{\mathrm{P}, \text { act }}$

如忽略水泵功，

$w_{\text {net, act }} \approx w_{\mathrm{t}, \text { act }}=h_{1}-h_{2, \text { act }}$

循环内部热效率 $\eta_{\mathrm{i}}$ 为蒸汽在实际循环中所作的循环净功与循环中热源所供给的热量的比值

$\eta_{\mathrm{i}}=\frac{w_{\text {net, act }}}{q_{1}}=\frac{h_{1}-h_{2, \text { act }}}{h_{1}-h_{2}^{\prime}}=\frac{\eta_{\mathrm{T}}\left(h_{1}-h_{2}\right)}{h_{1}-h_{2}^{\prime}}=\eta_{\mathrm{T}} \eta_{\mathrm{i}}$

若再考虑轴承等处的机械损失，则汽轮机输出的有效功，即轴功为

$w_{\mathrm{s}}=\eta_{\mathrm{m}} w_{\mathrm{t}, \text { act }}$

式中，$\eta_{\mathrm{m}}$ 为机械效率。

$w_{\mathrm{s}}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} w_{\mathrm{i}}$

或用轴功率表示

$P_{\mathrm{s}}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} P_{0}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} \frac{D\left(h_{1}-h_{2}\right)}{3600}$

上式是忽略水泵功时循环输出净功率表达式。
