(3) 由 0.45 MPa、310 K 变化到 0.11 MPa、310 K 的可逆定温膨胀是吸热过程，并对外作出膨胀功。由热力学第一定律能量方程可知，吸热量等于过程功：

$\begin{aligned}q_{T} & = w_{T} = w_{\text {t,T }} = -R_{\text {g }} T \ln \frac{p_{2}}{p_{1}} \\& = -310 \text { K } \times 0.297 \text { kJ/(kg } \cdot \text { K) } \times \ln \frac{0.11 \text { MPa }}{0.45 \text { MPa }} = 129.71 \text { kJ/kg }\end{aligned}$

点评 既然是可逆的定温过程，必然有温度为 \(T\) (\(T \neq T_{0}\)) 的热源供给系统热量，而不是从环境吸热。

$\begin{aligned}w_{1-2,\text { max }} & = e_{x, 1} - e_{x, 2} + e_{x, q} = e_{x, H_{1}} - e_{x, H_{2}} + \int_{1}^{2} \left( 1 - \frac{T_{0}}{T} \right) \delta q = e_{x, H_{1}} - e_{x, H_{2}} + \left( 1 - \frac{T_{0}}{T} \right) q \\& = 121.34 \text { kJ/kg } + \left( 1 - \frac{290 \text { K }}{310 \text { K }} \right) \times 129.71 \text { kJ/kg } \\& = 129.71 \text { kJ/kg }\end{aligned}$

这里，\(\int_{1}^{2} \left( 1 - \frac{T_{0}}{T} \right) \delta q = 8.37 \text { kJ/kg }\) 是可逆等温过程中系统自热源吸热 129.71 kJ/kg 得到的热量焱。
