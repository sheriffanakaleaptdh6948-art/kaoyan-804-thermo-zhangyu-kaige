开排气, 初始时瓶内有 -20 °C 、干度 20% 的氨蒸气, 由于意外加热, 钢瓶压力升高, 直至安全阀启动, 求安全阀刚打开时的温度和换热量。

解 取容器内工质为闭口系。在安全阀打开前的过程中, 钢瓶内氨质量不变, 体积不变, W = 0。

状态 1: 查 NH₃ 的热力性质图表, -20 °C 时: p_s = 200.7 kPa, v′ = 0.001 5 m³/kg、 v″ = 0.623 7 m³/kg、 h′ = 108.6 kJ/kg、 h″ = 1437.7 kJ/kg。

$v_{1}=v^{\prime}+x_{1}\left(v^{\prime \prime}-v^{\prime}\right)$

$=0.0015 \mathrm{~m}^{3} / \mathrm{kg}+0.2 \times\left(0.6237 \mathrm{~m}^{3} / \mathrm{kg}-0.0015 \mathrm{~m}^{3} / \mathrm{kg}\right)=0.12594 \mathrm{~m}^{3} / \mathrm{kg}$

$m=\frac{V}{v_{1}}=\frac{0.05 \mathrm{~m}^{3}}{0.12594 \mathrm{~m}^{3} / \mathrm{kg}}=0.397 \mathrm{~kg}$

$h_{1}=h^{\prime}+x_{1}\left(h^{\prime \prime}-h^{\prime}\right)=108.6 \mathrm{~kJ} / \mathrm{kg}+0.2 \times\left(1437.7 \mathrm{~kJ} / \mathrm{kg}-108.6 \mathrm{~kJ} / \mathrm{kg}\right)=374.4 \mathrm{~kJ} / \mathrm{kg}$

$u_{1}=h_{1}-p_{1} v_{1}=374.4 \mathrm{~kJ} / \mathrm{kg}-190.1 \mathrm{kPa} \times 0.12594 \mathrm{~m}^{3} / \mathrm{kg}=350.5 \mathrm{~kJ} / \mathrm{kg}$

安全阀刚打开时 $p_{2}=1.4 \mathrm{MPa} 、 v_{2}=v_{1}=0.12594 \mathrm{~m}^{3} / \mathrm{kg}$, 查 NH₃ 的热力性质图表, NH₃ 处在过热状态时, $t_{2}=110.3{ }^{\circ} \mathrm{C} 、 h=1696.9 \mathrm{~kJ} / \mathrm{kg}$ 。

$u_{2}=h_{2}-p_{2} v_{2}=1696.9 \mathrm{~kJ} / \mathrm{kg}-1400 \mathrm{kPa} \times 0.12594 \mathrm{~m}^{3} / \mathrm{kg}=1520.6 \mathrm{~kJ} / \mathrm{kg}$

$Q=\Delta U+W=m\left(u_{2}-u_{1}\right)=0.397 \mathrm{~kg} \times(1520.6 \mathrm{~kJ} / \mathrm{kg}-350.5 \mathrm{~kJ} / \mathrm{kg})=464.5 \mathrm{~kJ}$

4-18 活塞上压力维持恒定的汽缸内有 0.2 kg 压力为 400 kPa 的干饱和蒸汽。使其冷却到体积为原有体积的一半, 试确定过程中水蒸气的放热量。

提示和答案: 终态是湿蒸汽状态, $x_{2}=0.4989, Q=m\left(h_{2}-h_{1}\right)=-213.84 \mathrm{~kJ}$ 。

4-19 一个 $10 \mathrm{~L}$ 的刚性容器内有 -10 °C 、干度为 0.8 的 R134a, 容器内设有电阻丝连接在 $6 \mathrm{~V}$ 的电池上。电阻丝通以 $10 \mathrm{~A}$ 的电流 10 分钟后容器内 R134a 的温度升高到 $40{ }^{\circ} \mathrm{C}$, 求过程中热量。

提示和答案: 取容器内工质为系统。过程中系统与电阻丝交换热量, 体积不变, $W=0$ 。查 R134a 的热力性质图表并辅以计算确定热力学能等参数, 列能量方程

$Q=\Delta U+W-Q^{\prime}=m\left(u_{2}-u_{1}\right)-I V \Delta \tau$

解得通过筒体放热 $26.7 \mathrm{~kJ}$ 。
