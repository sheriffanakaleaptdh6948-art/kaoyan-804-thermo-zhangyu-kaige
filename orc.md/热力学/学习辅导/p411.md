6. 一所房子利用供暖系数为 3.6 的热泵供暖维持室内 20 °C，据估算室外大气温度每低于房内温度 1 °C，房子向外散热增加 0.8 kW，若室外温度为 -5 °C，(1) 求驱动热泵所需的功率；(2) 若以平均温度为 95 °C 的热源供热，试以室内空气为系统计算熵变、流、熵产和作功能力损失。(14 分)

提示及答案 (1) 为维持房子内温度，需使散热与热泵供热平衡，所以 Φ_1 = P ε' = 20 kW，P = Φ_1 / ε' = 5.56 kW；(2) 以热源供热，室内气体维持压力温度不变，故 Δ\dot{S} = 0。气体从热源吸热，向环境大气散热，故 \dot{S}_f = Φ_1 / T_r + Φ_2 / T_0 = Φ(1 / T_r - 1 / T_0) = -0.020 26 kJ/(K·s)，Δ\dot{S} = \dot{S}_f + \dot{S}_g = 0，\dot{S}_g = 0.020 26 kJ/(K·s)，\dot{I} = T_0 \dot{S}_g = 5.43 kJ/s_0

本题主要错误及简析 (1) “q_2' = (20 + 5) × 0.8 kW = 20 kW” —— 热泵从低温热源(环境大气)中吸收能量输入高温物体如室内空气，所以 q_1 = 20 kW；(2) “以空气为系统，Δs = s_f + s_g，s_f = 0，Δs = s_g = Φ_1 / T_1 - Φ_2 = ...” —— 以室内空气为系统，空气温度、压力维持不变，故 Δs = 0，空气吸收热源提供的热量，向环境大气放出热量，虽两者热量相同，但因与其换热的系统温度不同，故 s_f ≠ 0，s_f = q / T_{r2} - q / T_{r2} = ...，s_g = -s_{f0}。
