### 十、水蒸气的基本过程

水蒸气的热力过程中最常见的过程是定压过程和绝热过程，水在锅炉内加热过程、从汽轮机排出的乏汽在冷凝器的凝结过程、制冷剂在蒸发器内汽化等过程都可近似为定压过程，而水在水泵内升压、蒸汽在汽轮机内膨胀、制冷剂在压缩机内的压缩过程都可当作绝热过程。

据 $q = \Delta h + w_1$，定压过程的技术功等于零，故定压过程的热量 $q = h_2 - h_1$。前已述及，未饱和水定压加热为过热蒸汽经历预热、汽化和过热三个过程（图4-5），这三个过程的加热量分别为

$q_1 = h_2 - h_1 = \gamma = h_3 - h_2 = q_{\text{sup}} = h_4 - h_3$

所以，总加热量为

$q = q_1 + \gamma + q_{\text{sup}} = h_4 - h_1$

根据热力学第一定律，不论过程是否可逆，水和水蒸气绝热膨胀（或压缩）过程的技术功为 $w_1 = -\Delta h$，以膨胀为例，若过程可逆，则 $w_1 = h_1 - h_2$，若不可逆，则 $w_1 = h_1 - h_2'$，如图 4-6 所示。由于不可逆绝热过程的熵产，使由初态 1 膨胀到相同的终压力 $p_2$，蒸汽的技术功减少了 $h_2' - h_2$，作功能力损失 $I = T_0 s_g$（详见第五章）。

工程上也将水蒸气的可逆绝热过程中压力和比体积的关系表示成 $pv^\kappa = $ 常数，但这里的绝热指数 $\kappa$ 不是比热容比而是经验常数。通常，过热蒸汽的 $\kappa$ 可用 1.3；干饱和蒸汽的 $\kappa$ 可用 1.135；湿饱和蒸汽的 $\kappa$ 可用 1.035 + 0.1x（x 为干度）。需要指出的是，由于动力工程中应用的水蒸气通常不符合理想气体假设的条件，所以不能由 $pv^\kappa = $ 常数进一步导出 $Tv^{\kappa-1} = $ 常数等关系式。
