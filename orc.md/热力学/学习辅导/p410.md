率和汽轮机内过程的焨损失。已知由 $175\,\mathrm{℃}$，查饱和水蒸气表 $h_{1}=2773.23$ $\mathrm{kJ/kg}$，$s_{1}=6.6253\,\mathrm{kJ/(kg·K)}$，$p_{1}=891.8\,\mathrm{kPa}$。由 $7.5\,\mathrm{kPa}$，查饱和水蒸气表，$h^{\prime}=$ $168.65\,\mathrm{kJ/kg}$，$h^{\prime\prime}=2573.85\,\mathrm{kJ/kg}$，$s^{\prime}=0.576\,\mathrm{kJ/(kg·K)}$，$s^{\prime\prime}=8.2493\,\mathrm{kJ/(kg·K)}$； $v^{\prime}=0.00101\,\mathrm{m}^{3}/\mathrm{kg}$；$T_{0}=293\,\mathrm{K}$。（20分）

提示及答案 （1）据 $s_{1}=s_{2}$，$s^{\prime}<s_{2}<s^{\prime\prime}$，状态 2 为湿蒸汽状态 $x_{2}=\frac{s_{2}-s^{\prime}}{s^{\prime\prime}-s^{\prime}}=$ $0.788$，$h_{2}=h^{\prime}+x_{2}\left(h^{\prime\prime}-h^{\prime}\right)=2063.95\,\mathrm{kJ/kg}$，$h_{4}\approx h_{3}+v_{3}\left(p_{4}-p_{3}\right)=169.54\,\mathrm{kJ/kg}$。汽轮机输出功 $w_{\mathrm{T}}=h_{1}-h_{2}=709.28\,\mathrm{kJ/kg}$，水泵耗功 $w_{3}=h_{4}-h_{3}=0.89\,\mathrm{kJ/kg}$，可忽略不计。从集热器吸热量 $q_{1}=h_{1}-h_{4}=2603.69\,\mathrm{kJ/kg}$，冷凝器中放热量 $q_{2}=h_{2}-$ $h_{3}=1895.3\,\mathrm{kJ/kg}$。循环热效率 $\eta_{1}=\frac{w_{\mathrm{T}}-w_{\mathrm{P}}}{q_{1}}=0.272$。（2）由汽轮机相对内效率 $h_{2 \text { act }}=h_{1}-\eta_{\mathrm{T}}\left(h_{1}-h_{2}\right)=2120.69\,\mathrm{kJ/kg}$，$x_{2}=\frac{h_{2 \text { act }}-h^{\prime}}{h^{\prime \prime}-h^{\prime}}=0.812$，$s_{2 \text { act }}=s^{\prime}+x_{2 \text { act }}\left(s^{\prime \prime}-s^{\prime}\right)=$ $6.8067\,\mathrm{kJ/(kg·K)}$，绝热，熵流为零，故 $s_{\mathrm{g}}=s_{2 \text { act }}-s_{1}=0.1814\,\mathrm{kJ/(kg·K)}$，过程焨损失 $i=T_{0} s_{\mathrm{g}}=53.15\,\mathrm{kJ/kg}$。水泵损失不计，故 $\eta_{\mathrm{i}}=\eta_{\mathrm{T}} \eta_{\mathrm{i}}=0.250$ 。

本题主要错误及简析 （1）“ $I=T_{0} \Delta s=T_{s}\left(s_{1}-s_{3}\right)=\cdots$ ”—— $T_{s}\left(s_{1}-s_{3}\right)$ 是蒸汽在汽轮机内等熵膨胀的条件下乏汽在冷凝器内的放热量，并非焨损， $I=T_{0} s_{\mathrm{g}}=T_{0}$ $\left(s_{2 \text { act }}-s_{3}\right)=\cdots$；（2）“ $\Delta s=s_{\mathrm{i}}+s_{\mathrm{g}}$，因等熵膨胀，故 $s_{\mathrm{i}}=0, s_{\mathrm{g}}=0$”——蒸汽在汽轮机内膨胀近似绝热， $\eta_{\mathrm{T}}<1$ 指膨胀过程不可逆， $s_{\mathrm{g}}>0$；（3）“ $s_{2 \text {,act }}=s_{1}+\frac{\gamma}{T_{\mathrm{s}}}=s_{1}+\frac{h^{\prime \prime}-h^{\prime}}{T_{\mathrm{s}}}=$ $6.6253+\frac{2405.2}{175+273}=11.99$”——干饱和蒸汽在汽轮机内绝热膨胀，降压降温成为湿蒸汽，并非干饱和蒸汽状态。终态 $2_{\text {act }}$ 熵值小于相同压力下饱和蒸汽的熵值，而 $s_{1}+\frac{\gamma}{T_{\mathrm{s}}}=s_{1}+\left(s^{\prime \prime}-s^{\prime}\right)=s^{\prime \prime} \neq s_{2 \text {,act }}$ 且 $7.5\,\mathrm{kPa}$ 时的饱和温度远小于 $175\,\mathrm{℃}$； （4）“ $I=h_{2 \text {,act }}-h_{2}=\cdots$ ”—— $h_{2 \text {,act }}-h_{2}$ 是由于不可逆膨胀而少作的功，但由于 $h_{2 \text {,act }}$
