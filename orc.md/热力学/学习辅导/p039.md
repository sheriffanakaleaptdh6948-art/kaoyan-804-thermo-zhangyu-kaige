解 方法 1: 取换热器为控制体积, 进入换热器的状态为 1 , 离开状态为 2 ,列能量方程, 因流进及流出的质量流量相同, 所以

$\begin{aligned}& q_{m 1} h_{1}=q_{m 1} h_{2}+q_{Q, \text { cool }} \\& q_{Q, \text { cool }}=q_{m 1}\left(h_{1}-h_{2}\right)=q_{m 1} c_{p}\left(T_{1}-T_{2}\right) \\& T_{2}=T_{1}-\frac{q_{Q, \text { cool }}}{q_{m 1} c_{p}}=35^{\circ} \mathrm{C}-\frac{15.1 \mathrm{kW}}{0.5 \mathrm{~kg} / \mathrm{s} \times 1.005 \mathrm{kJ} /(\mathrm{kg} \cdot \mathrm{K})}=5^{\circ} \mathrm{C}\end{aligned}$

取混合器为控制体积, 能量方程及质量方程为

$\begin{aligned}& q_{m 4} h_{4}=q_{m 2} h_{2}+q_{m 3} h_{3} \\& q_{m 4}=q_{m 2}+q_{m 3} \\& h_{4}=\frac{q_{m 2} h_{2}+q_{m 3} h_{3}}{q_{m 4}}=\frac{q_{m 2} h_{2}+q_{m 3} h_{3}}{q_{m 2}+q_{m 3}}\end{aligned}$

$T_{4}=\frac{q_{m 2} T_{2}+q_{m 3} T_{3}}{q_{m 2}+q_{m 3}}=\frac{0.5 \mathrm{~kg} / \mathrm{s} \times 278.15 \mathrm{~K}+0.25 \mathrm{~kg} / \mathrm{s} \times 293.15 \mathrm{~K}}{0.5 \mathrm{~kg} / \mathrm{s}+0.25 \mathrm{~kg} / \mathrm{s}}=283.15 \mathrm{~K}=10^{\circ} \mathrm{C}$

方法 2: 取冷却器和混合器一起为控制体积

$\begin{aligned}& q_{m 1} h_{1}+q_{m 3} h_{3}-q_{m 4} h_{4}-q_{Q, \text { cool }}=0 \\& q_{m 4}=q_{m 1}+q_{m 3} \\& q_{m 1} h_{1}+q_{m 3} h_{3}-\left(q_{m 1}+q_{m 3}\right) h_{4}-q_{Q, \text { cool }}=0 \\& h_{4}=\frac{q_{m 1} h_{1}+q_{m 3} h_{3}-q_{Q, \text { cool }}}{q_{m 1}+q_{m 3}} \\& T_{4}=\frac{q_{m 1} T_{1}+q_{m 3} T_{3}-q_{Q, \text { cool }} / c_{p}}{q_{m 1}+q_{m 3}} \\& \quad \frac{0.5 \mathrm{~kg} / \mathrm{s} \times 308.15 \mathrm{~K}+0.25 \mathrm{~kg} / \mathrm{s} \times 293.15 \mathrm{~K}}{0.25 \mathrm{~kg} / \mathrm{s}+0.5 \mathrm{~kg} / \mathrm{s}}=\frac{15.1 \mathrm{~kJ} / \mathrm{s}}{1.005 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K})} \\& =283.11 \mathrm{~K}\end{aligned}$

点评 流动混合的问题除了系统应满足热力学第一定律, 能量守恒, 还应满足质量守恒; 选取不同的系统, 可列出不同的能量方程, 得到相同的最终结果。
