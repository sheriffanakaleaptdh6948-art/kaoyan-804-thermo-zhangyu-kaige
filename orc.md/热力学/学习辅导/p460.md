2. 在分析同为温度 t、压力的 p 的两种处在理想气体状态的气体 A 和 B 在刚性绝热容器内等压流动混合过程气体熵变时，有人从气体的温度、压力均无改变，据 Δs = ∫₁^₂ c_p \frac{\mathrm{d}T}{T} - R_g \ln \frac{p_2}{p_1} 得出熵变为零，是否正确，为什么？

答题要点 据热力学第一定律可得，两种同温理想气体在刚性绝热容器内等压混合，形成的混合气体温度不变，过程中虽与外界无热量交换而热熵流为零，但两种气体混合过程是不可逆过程，故有熵产，从而使熵增加。计算两种气体各自熵变时，应利用各自混合前后的分压力，即 Δs_i = ∫₁^₂ c_p \frac{\mathrm{d}T}{T} - R_g \ln \frac{p_{i2}}{p_{i1}}，而非如给出的用总压力。

本题主要错误及简析 （1）“不正确，两股气流等压流动混合过程气体的总体积减小，外界对气体作功，q = 0，所以温度升高，故 ΔS > 0”——两种处在理想气体状态的气体在刚性绝热容器内等压流动混合过程总体积并不减小，与外界无可逆体积功交换，流动功则在进、出口气体的焓中得到体现，混合后温度未必升高，熵增大的原因是不可逆熵产 （2）“不正确，气体混合过程为不可逆过程，所有不可逆过程熵变必大于零，题中公式建立在可逆的基础上。”——不可逆过程存在熵产，但并非所有不可逆过程都使系统的熵增加，如闭口系不可逆放热，当放热的熵流大于不可逆的熵产时系统的熵减少；稳定流动的体系中进行不可逆过程时，系统的熵保持不变。Δs = ∫₁^₂ c_p \frac{\mathrm{d}T}{T} - R_g \ln \frac{p_2}{p_1} 虽由可逆过程推出，但由于熵是状态参数，所以也可以用于初终态是平衡状态的不可逆过程，因为状态参数的变化与经历的过程性质无关，只与初终态有关。（3）“不同气体混合后各种组分的熵变必定大于零。”——不同气体混合后各种组分的熵变还与混合的条件有关，如各 1 mol 理想气体状态的 O₂ 和 N₂ 等温、等体积混合，因此时 O₂ 和 N₂ 的分压力分别与混合前相等，虽混合过程不可逆，但过程必须放热，故混合过程的熵变等于零。（4）“混合过程 m_A h_A + m_B h_B = (m_A + m_B) h，即使流量相等，c_p 也不相等，所以混合后温度不相等。”——组分气体的比定压热容，与混合气体的比定压热容一般不相等，但两种温度相等的气体混合，若与外界没有热量传递，同时没有进行功交换，满足能量方程 m_A h_A + m_B h_B = (m_A + m_B) h，即 m_A (h_A - h) + m_B (h_B - h) = 0，而理想气体的焓仅是温度的函数，即得 T = T_A = T_B，当然混合气体的折合比热容与组分气体的不同，c_p = \frac{m_A c_{pA} + m_B c_{pB}}{m_A + m_B}。
