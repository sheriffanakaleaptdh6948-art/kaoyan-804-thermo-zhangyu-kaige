3. 有人声称设计了一台热机, 从温度为 $600 \mathrm{~K}$ 的高温热源 $T_{1}$ 吸取 $25 \mathrm{~kJ} / \mathrm{s}$ 热量, 向 $300 \mathrm{~K}$ 的低温热源 $T_{2}$ 放出 $12 \mathrm{~kJ} / \mathrm{s}$ 热量, 并向外界提供了 $15 \mathrm{~kW}$ 功, 判断此设计是否能实现? (5 分)

提示及答案 该设计循环理论功率 $P^{\prime}=q_{01}^{\prime}-q_{02}^{\prime}=25 \mathrm{~kJ} / \mathrm{s}-12 \mathrm{~kJ} / \mathrm{s}=13 \mathrm{~kJ} / \mathrm{s}<$ $15 \mathrm{~kJ} / \mathrm{s}$, 故违反热力学第一定律。据卡诺定理在两个恒温热源之间最高热效率为 $\eta_{\mathrm{c}}=1-\frac{T_{2}}{T_{1}}=0.5$, 该设计循环的热效率 $\eta_{1}=\frac{P}{q_{01}}=0.6>\eta_{\mathrm{c}}$, 违反热力学第二定律。此设计既违反热力学第一定律又违反热力学第二定律, 故不可能实现。

本题主要错误及简析 (1) $\because q=\Delta u+w=(12-25) \mathrm{k} J / \mathrm{s}+15 \mathrm{~kJ} / \mathrm{s}=2 \mathrm{~kJ} / \mathrm{s}$, $\Delta s=\frac{q}{T}>0$, 所以设计能实现”——工质经循环后 $\Delta u=0 、 \Delta s=0$, 与 $q_{1} 、 q_{2}$ 无关; $\Delta s_{\text {iso }}$ $>0$ 才是热源、热机和冷源组成的系统内热机循环的判据。(2) “$\frac{\delta q_{1}}{T_{1}}+\frac{\delta q_{1}}{T_{2}}=$ $\frac{25 \mathrm{~kJ} / \mathrm{s}}{600 \mathrm{~K}}+\frac{-12 \mathrm{~kJ} / \mathrm{s}}{300 \mathrm{~K}}>\mathrm{O}$, 所以可以实现。”——克劳修斯积分不等式 $\oint \frac{\delta q}{T_{\mathrm{r}}} < 0 !$
