由有关数据表查得相关物质的标准生成焓为

$$\Delta H_{\mathrm{f}, \mathrm{CO}_{2}}^{0}=-393.522 \mathrm{~J} / \mathrm{mol}, \Delta H_{\mathrm{f}, \mathrm{H}_{2} \mathrm{O}(\mathrm{g})}^{0}=-241826 \mathrm{~J} / \mathrm{mol}$$

$$\Delta H_{\mathrm{f}, \mathrm{C}_{2} \mathrm{H}_{5} \mathrm{OH}(\mathrm{g})}^{0}=-235000 \mathrm{~J} / \mathrm{mol}$$

代入上式, 得

$$Q_{p}^{0}=2 \times(-393522 \mathrm{~J} / \mathrm{mol})+3 \times(-241826 \mathrm{~J} / \mathrm{mol})-(-235000 \mathrm{~J} / \mathrm{mol}+0)$$

$$=-1277522 \mathrm{~J} / \mathrm{mol}(=-27730.6 \mathrm{~kJ} / \mathrm{kg})$$

所以, 燃烧产物中 $\mathrm{H}_{2} \mathrm{O}$ 为气态时 $\mathrm{C}_{2} \mathrm{H}_{5} \mathrm{OH}(\mathrm{g})$ 的标准燃烧焓 $\Delta H_{\mathrm{c}, \mathrm{C}_{2} \mathrm{H}_{5} \mathrm{OH}(\mathrm{g})}$为 $-27730.6 \mathrm{~kJ} / \mathrm{kg}$ 。

点评 据能量方程, 定压过程的热量等于焓差, 在标准状态的燃烧反应也遵守这规律, 所以可用标准生成焓的数据计算标准燃烧焓。氧为稳定单质, 故其标准生成焓是零。本例燃烧产物中 $\mathrm{H}_{2} \mathrm{O}$ 为气态, 因此计算所得应为低热值。

【例 13-4】试计算丙烷在 $600 \mathrm{~K}$ 和 $101325 \mathrm{~Pa}$ 时的燃烧热。假设燃烧产物中的水是气相。

解 丙烷燃烧反应方程式为

$$\mathrm{C}_{3} \mathrm{H}_{8(\mathrm{~g})}+5 \mathrm{O}_{2} \rightarrow 3 \mathrm{CO}_{2}+4 \mathrm{H}_{2} \mathrm{O}(\mathrm{g})$$

$$Q_{T}=\Delta H^{0}+3\left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{CO}_{2}+4\left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{H}_{2} \mathrm{O}(\mathrm{g})$$

$$\left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{C}_{3} \mathrm{H}_{8}-5\left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{O}_{2}$$

查表得, 丙烷气体 $25{ }^{\circ} \mathrm{C}$ 时的燃烧焓 $\left(\mathrm{H}_{2} \mathrm{O}\right.$ 在燃烧产物中为气体)

$$\Delta H_{\mathrm{c}}^{0}=-46352 \mathrm{~kJ} / \mathrm{kg}=-2043845.1 \mathrm{~J} / \mathrm{mol}$$

丙烷等的热焓差

$\begin{aligned} & \left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{CO}_{2}=22271.3 \mathrm{~J} / \mathrm{mol}-9364.0 \mathrm{~J} / \mathrm{mol}=12907.3 \mathrm{~J} / \mathrm{mol} \\ & \left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{H}_{2} \mathrm{O}=20405.9 \mathrm{~J} / \mathrm{mol}-9904.0 \mathrm{~J} / \mathrm{mol}=10501.9 \mathrm{~J} / \mathrm{mol} \\ & \left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{C}_{3} \mathrm{H}_{8}=1334.7 \mathrm{~kJ} / \mathrm{kg}-630.8 \mathrm{~kJ} / \mathrm{kg}=703.9 \mathrm{~kJ} / \mathrm{kg}=310377.7 \mathrm{~J} / \mathrm{mol} \\ & \left(H_{\mathrm{m}, 600 \mathrm{~K}}-H_{\mathrm{m}}^{0}\right) \mathrm{O}_{2}=17926.1 \mathrm{~J} / \mathrm{mol}-8683.0 \mathrm{~J} / \mathrm{mol}=9243.1 \mathrm{~J} / \mathrm{mol} \end{aligned}$
