4. 某压缩蒸气制汽冷装置采用氨 ($\mathrm{NH}_3$) 为制冷剂，从蒸发器中出来的氨气的状态是 $t_1 = -15^\circ \mathrm{C}$，$x_1 = 0.95$。进入压气机升温压后进入冷凝器。在冷凝器中冷凝成饱和氨液，温度为 $t_4 = 25^\circ \mathrm{C}$。从点 4 经节流阀，降温降压成干度较小的湿蒸气状态，再进入蒸发器汽化吸热（参见附录 II 图 25）。求：(1) $q_c$、$w_{\text{net}}$ 和制冷系数 $\varepsilon$；(2) 设该装置的制冷量 $q_{Q_c} = 4.2 \times 10^4$ kJ/h，氨的流量 $q_m$；(3) 该装置的冷量焮。已知：$h_1' = 111.66$ kJ/kg，$h_1'' = 1424.6$ kJ/kg，$s_1' = 0.4538$ kJ/(kg·K)，$s_1'' = 5.539$ kJ/(kg·K)；$h_2 = 1542.9$ kJ/kg；$h_4 = 298.25$ kJ/kg。（15 分）

提示及答案 (1) $h_1 = x h_1 + (1 - x) h_1' = 1358.95$ kJ/kg，$s_1 = s_1' + x (s_1'' - s_1') = 5.2854$ kJ/(kg·K)，$q_c = h_1 - h_4 = 1060.7$ kJ/kg，$w_{\text{net}} = h_2 - h_1 = 184.0$ kJ/kg，$\varepsilon = \frac{q_c}{w_{\text{net}}} = 5.77$；(2) $q_m = \frac{q_{Q_c}}{q_c} = 0.11$ kg/s，(3) 冷量焮 $e_{x,Q} = \left(\frac{T_0}{T_c} - 1\right) q_c = 164.35$ kJ/kg。

本题主要错误及简析 $e_{x,Q} = h_1 - h_4' = \cdots$ 冷量焮 $E_{x,Q} = \left(\frac{T_0}{T_c} - 1\right) q_{Q,c}, h_1 - h_1'$ 仅是点 1 的焓与点 1 压力下饱和液的焓之差，在这里并无明显物理意义。

5. 就题“喷气发动机前端是起扩压器作用的扩压段，其后为压缩段。若空气流以 900 km/h 的速度流入扩压段，流入时温度为 -5°C，压力为 50 kPa。空气流离开扩压段进入压缩段时速度为 80 m/s，扩压段出口流通截面积为入口截面积的 80%，试确定扩压段出口截面气流的压力和温度。”给出 A 两种 B 不同的解，你认为哪一个解答案是错误的，为什么？(10 分)

(A) 扩压段出口的温度

$T_2 = T_1 + \frac{c_{\text{f1}}^2 - c_{\text{f2}}^2}{2 c_p} = (273.15 - 5) \text{K} + \frac{\left(\frac{900000}{3600} \text{m/s}\right)^2 - (80 \text{m/s})^2}{2 \times 1005 \text{J/(kg·K)}} = 296.06 \text{K}$

由质量守恒，$q_m = \frac{A_1 c_{\text{f1}}}{v_1} = \frac{A_2 c_{\text{f2}}}{v_2} = \frac{0.8 A_1 c_{\text{f2}}}{v_2}$，得 $v_2 = 0.8 v_1 \frac{c_{\text{f2}}}{c_{\text{f1}}}$，所以

$v_2 = \frac{R_g T_2}{p_2} = 0.8 \frac{R_g T_1}{p_1} \frac{c_{\text{f2}}}{c_{\text{f1}}}$

$p_2 = \frac{1}{0.8} p_1 \frac{T_2}{T_1} \frac{c_{\text{f1}}}{c_{\text{f2}}} = \frac{50 \text{kPa} \times 296.06 \text{K} \times 250 \text{m/s}}{0.8 \times 268.15 \text{K} \times 80 \text{m/s}} = 215.6 \text{kPa}$
