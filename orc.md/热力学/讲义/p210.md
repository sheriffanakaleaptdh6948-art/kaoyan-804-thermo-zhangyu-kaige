**例 10-11 计算题：**一燃气轮机装置由一台压气机 C 产生压缩空气，然后分两路进入两个燃烧室 A 和 B 中进行等压燃烧，燃气分别进入两台燃气轮机，其中燃气轮机 I 发出的功率全部供应压气机，燃气轮机 II 发出功率 $P = 2000\text{kW}$，压气机进口状态为 $p_1 = 0.1\text{MPa}$，环境温度 $t_1 = 27^{\circ}\text{C}$；压气机增压比 $\pi = 10$；两台燃气轮机进口处的燃气温度均为 $t_3 = 1180^{\circ}\text{C}$，出口处的燃气温度均为 $t_4$。燃气可近似为空气，且 $c_p = 1.004\text{kJ}/(\text{kg}\cdot\text{K})$，$\kappa = 1.4$。假设全部是可逆过程，且燃气轮机出口压力与压气机进口压力相等；试求：

(1) 每 $\text{kg}$ 燃气在燃气轮机中所作的功 $w_{\text{T}}$；
(2) 燃气轮机 II 的质量流量 $q_{\text{m,B}}$；
(3) 压气机每压缩 $\text{kg}$ 空气所消耗的功 $w_{\text{C}}$；
(4) 燃气轮机 I 的质量流量 $q_{\text{m,A}}$；
(5) 每秒钟气体工质分别从两燃烧室吸收的热量 $Q_{\text{A}}$ 和 $Q_{\text{B}}$；
(6) 整个装置的热效率 $\eta_{\text{t}}$。
（南航 2010 年考研试题）

【系统流程图】

**解：**1. 物理模型：该燃气轮机循环中每一过程、参数均已确定，因此该循环确定，可按照分析循环的方法求解。

2. 数学模型及求解：

(1) 燃气轮机涡轮功 $w_{\text{T I}} = w_{\text{T II}} = c_p (T_3 - T_4)$

2. 数学模型及求解：

燃气轮机出口温度

$$T_4 = T_3 ( )^{\frac{\kappa-1}{\kappa}} = 1453 \times 0.1^{\frac{1.4-1}{1.4}}$$

$$= 752.58\text{K} = 479.58^{\circ}\text{C}$$

则 $w_{\text{T I}} = w_{\text{T II}} = c_p (t_3 - t_4) = 1.004 \times (1180 - 479.58) = 703.22\text{kJ}/\text{kg}$
