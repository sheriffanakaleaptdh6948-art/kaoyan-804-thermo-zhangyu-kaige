**例 8-17** 理想气体从初态$(p_1, T_1)$经过不同的热力过程到达相同的终压$p_2$，一过程为经过喷管的可逆绝热膨胀过程，一过程为经过喷管的不可逆绝热膨胀过程，一过程为经过节流阀的绝热节流过程。若环境参数为$(p_0, T_0)$，且$p_1 > p_0, T_1 > T_0$，试比较三过程不可逆损失的大小。

**解：** 1. 物理模型 如图所示为$T-s$图，可逆绝热膨胀过程、不可逆绝热膨胀过程和绝热节流过程三个过程都是绝热过程。根据孤立体系熵增原理，熵增大的不可逆损失较大。

2. 数学模型及求解 由于不可逆造成的做功能力损失为
$$W_l = T_0 \Delta S_{\text{iso}} = T_0 \Delta S_g$$

【图 T-s 图】

可逆绝热膨胀过程功损为 $W_{l12} = T_0 \Delta S_{12} = 0$
不可逆绝热膨胀过程功损为 $W_{l12'} = T_0 \Delta S_{12'} = T_0(S_{2'} - S_1) = \text{面积 } aceda$
绝热节流过程功损为 $W_{l13} = T_0 \Delta S_{13} = T_0(S_3 - S_1) = \text{面积 } abfda$

3. 讨论及结论：
1) $p_1, p_2$ 确定以后，在所有由 $p_1$ 降至 $p_2$ 的绝能流动中，绝热节流过程的熵增是最大的，因而其不可逆损失也是最大的。
2) 可逆绝热膨胀过程焓降最大，对外做功最大，没有损失；不可逆绝热膨胀过程降次之，对外做功次之，损失也次之；而绝热节流过程焓降为零，对外不做功，损失最大。

绝热节流过程只降压、不做功的特性决定了其必然损失最大。因此，不可逆性是绝热节流的最主要的特性，节流过程就是典型的不可逆过程。

绝热节流是工程上常见的现象。除了可用它来研究物性外，还利用流来进行测量和调节。具有反应速度快、结构简单、价格便宜等优点。如汽车的刹车，水龙头的流量调节，制冷设备中制冷量的调节等。

当然，在测量和调节中应想办法尽量减少不可逆性，如利用电机转速调节水泵供水压力来调节水流量，利用汽车刹车把一部分动能转化为电能储存起来，都可以减少不可逆损耗。
