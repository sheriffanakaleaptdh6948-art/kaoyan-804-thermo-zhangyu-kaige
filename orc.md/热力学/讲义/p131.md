沈维道《工程热力学》考点精讲及复习思路

(南航 2005 年考研试题)
**考点六：维里(Virial)方程**

1901 年，卡·昂尼斯(K. Onnes)提出拉丁文“力”
$$Z = f(T, p) \quad Z = f(T, v) \quad Z = f(T, \rho)$$
上述形式的状态方程，主要思想是借用无量纲参数 $Z$ 来考虑分子间作用力。

一切气体 $p \to 0 \quad Z = 1$

一般实际气体 $Z = \frac{pv}{R_{\text{g}}T} = 1 + B'p + C'p^2 + D'p^3 + \cdots\cdots$

或 $Z = 1 + B\rho + C\rho^2 + D\rho^3 + \cdots\cdots = 1 + \frac{B}{v} + \frac{C}{v^2} + \frac{D}{v^3} + \cdots\cdots$

$B = B'R_{\text{g}}T \quad C = B'BR_{\text{g}}T + C'R_{\text{g}}^2T^2$
维里系数都是温度的函数。

维里系数的物理意义
理论上维里方程适合于任何工质，级数越多，精度越高，系数由实验数据拟合。

【图 维里系数物理意义示意图：$Z=1+\frac{B}{v}+\frac{C}{v^2}+\frac{D}{v^3}+\cdots\cdots$ 对应 分子间无作用力、两个分子间作用力、三个分子间作用力、四个分子间作用力，作用递减，需要多少精度，就从某处截断。】

截断型维里方程
一般情况

当 $\rho < \frac{1}{2}\rho_c \begin{cases} Z = 1 + B'p \\ Z = 1 + \frac{B}{v} \end{cases}$

当 $\frac{1}{2}\rho_c < \rho < \rho_c \begin{cases} Z = 1 + B'p + C'p^2 \\ Z = 1 + \frac{B}{v} + \frac{C}{v^2} \end{cases}$

维里方程的优点：(1)物理意义明确，(2)实验曲线拟合容易。
