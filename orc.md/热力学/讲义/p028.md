2) 开口系一般瞬态能量方程
能量守恒：energy conservation
进入系统的能量 - 离开系统的能量 = 系统储存能量的变化

【图 开口系能量平衡示意图】

进入 CV 的能量
$$= Q + E_{\text{in}}$$
$$= Q + m_{\text{in}}(e + pv)_{\text{in}}$$
$$= Q + m_{\text{in}}(u + pv + c_{\text{f}}^2/2 + gz)_{\text{in}}$$

离开 CV 的能量
$$= W_{\text{CV}} + E_{\text{out}}$$
$$= W_{\text{net}} + m_{\text{out}}(e + pv)_{\text{out}}$$
$$= W_{\text{net}} + m_{\text{out}}(u + pv + c_{\text{f}}^2/2 + gz)_{\text{out}}$$

开口系 CV 储存能量的变化 $= \Delta E_{\text{CV}} = E_2 - E_1$

流动时，总在一起出现
$$Q + m_{\text{in}}(u + pv + c_{\text{f}}^2/2 + gz)_{\text{in}} - m_{\text{out}}(u + pv + c_{\text{f}}^2/2 + gz)_{\text{out}} - W_{\text{net}} = \Delta E_{\text{cv}}$$

开口系从外界吸收的热量，一部分用来使开口系自身能量增加，一部分用来对外做功，最后一部分用来支付由于工质进出开口系带出和带入能量的差，包括热力学能、流动功、宏观动能和宏观位能。
$$Q = \Delta E_{\text{cv}} + m_{\text{out}}(h + c_{\text{f}}^2/2 + gz)_{\text{out}} - m_{\text{in}}(h + c_{\text{f}}^2/2 + gz)_{\text{in}} + W_{\text{net}}$$

$$\delta Q = \mathrm{d}E_{\text{CV}} + \delta m_{\text{out}} \left( h + \frac{c_{\text{f}}^2}{2} + gz \right)_{\text{out}} - \delta m_{\text{in}} \left( h + \frac{c_{\text{f}}^2}{2} + gz \right)_{\text{in}} + \delta W_{\text{net}}$$

$$\dot{Q} = \mathrm{d}E_{\text{cv}}/\delta \tau + (h + c_{\text{f}}^2/2 + gz)_{\text{out}} q_{m,\text{out}} - (h + c_{\text{f}}^2/2 + gz)_{\text{in}} q_{m,\text{in}} + \dot{W}_{\text{net}}$$

常用流率 $\dot{Q} = \lim_{\delta \tau \to 0} \left( \frac{\delta Q}{\delta \tau} \right)$， $q_m = \lim_{\delta \tau \to 0} \left( \frac{\delta m}{\delta \tau} \right)$， $\dot{W}_{\text{net}} = \lim_{\delta \tau \to 0} \left( \frac{\delta W_{\text{net}}}{\delta \tau} \right)$
