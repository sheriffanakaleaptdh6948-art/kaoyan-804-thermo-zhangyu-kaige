【图：波前波后气体参数及 $c_f, p$ 分布示意图】

对这个开口系列连续方程，有 $\rho_1 c A = \rho_2 (c-a) A$ (1)
列伯努利方程式 $-(p_2 - p_1) = \rho_1 c [(c-a) - c] = -\rho_1 c a$ (2)
数学模型的求解：(1)、(2)联立，消去活塞运动速度 $a$ 得
$$c = \sqrt{\frac{\rho_2}{\rho_1} \frac{p_2 - p_1}{\rho_2 - \rho_1}}$$
声速的求解（讨论及结论）
若扰动很微弱，即 $\rho_2 - \rho_1 \to \mathrm{d}\rho \quad p_2 - p_1 \to \mathrm{d}p$
则有声速 $c = \sqrt{\frac{\partial p}{\partial \rho}} \quad \rho_1 \to \rho_2$
声波传播过程是一个什么过程？
在气体介质中，压力波的传播，实质上就是在气体中交替发生的膨胀和压缩过程。过程进行得很快，来不及发生热交换，故可视为绝热过程。
压力波是微弱扰动波，内摩擦忽略，视为可逆绝热，即定熵过程。
则声速公式的一般形式为 $c = \sqrt{\left(\frac{\partial p}{\partial \rho}\right)_s}$
可进一步推导为 $c = \sqrt{\left(\frac{\partial p}{\partial \rho}\right)_s} = \sqrt{\frac{1}{(\partial \rho / \partial p)_s}} = \sqrt{\frac{-v^2}{(\partial v / \partial p)_s}}$
声速在固体中的最大，气体中最小。
$c_{\text{钢铁}} = 5200 \text{m/s} \quad c_{\text{海水}} = 1531 \text{m/s} \quad c_{\text{空气}} = 343.2 \text{m/s}$
声速是其传播介质（工质）状态的函数，因而也是一个状态参数，会随介质状态的变化而变化。
场内某一点的声速称为当地声速。
当地声速大小与当地工质的状态密切相关。
对于理想气体 $\frac{\mathrm{d}p}{p} + \kappa \frac{\mathrm{d}v}{v} = 0 \to \left(\frac{\partial v}{\partial p}\right)_s = -\frac{v}{\kappa p}$
则 $c = \sqrt{\kappa p v} = \sqrt{\kappa R_g T}$
理想气体中声速不仅是气体的状态参数，而且还仅仅是温度的单值函数。
$T \uparrow \quad c \uparrow$ ；分子量 $\downarrow R_g \uparrow \quad c \uparrow$
