理论压气功(可逆过程)为 $w_c = \frac{nR_g T_1}{n-1} [1 - (\frac{p_2}{p_1})^{\frac{n-1}{n}}]$

$$w_c = - \frac{nR_g T_1}{n-1} (\pi^{\frac{n-1}{n}} - 1)$$

$\pi$:压力比或增压比 $\pi = \frac{p_2}{p_1}$

【图 p-v 图 可能的压缩过程】

可能的压缩过程
(1)特别快,来不及换热。$n = k$
(2)特别慢,热全散走。$n = 1$
(3)实际压缩过程是 $1 < n < k$

【图 三种压缩过程的 p-v 图和 T-s 图】

三种压缩过程的参数关系

$$|w_{tT}| < |w_{tn}| < |w_{ts}| \quad |q_T| > |q_n| > |q_s| = 0$$

$$v_{2T} < v_{2n} < v_{2s} \quad T_1 = T_{2T} < T_{2n} < T_{2s}$$

【图 三种压缩过程的 p-v 图和 T-s 图】

三种压缩过程功的计算

$$w_{tn} = \frac{n}{n-1}R_g T_1 [1 - (\quad)^{\frac{n-1}{n}}] \quad w_{tT} = R_g T_1 \ln \frac{p_1}{p_2}$$

$$w_{ts} = \frac{\kappa}{\kappa-1}R_g T_1 [1 - (\quad)^{\frac{\kappa-1}{\kappa}}]$$
