$$c_p = \left(\frac{\partial h}{\partial T}\right)_p = \left(\frac{\partial h}{\partial s}\right)_p \left(\frac{\partial s}{\partial T}\right)_p = T \left(\frac{\partial s}{\partial T}\right)_p$$

**例 6-4** 试证明：比热比 $\gamma = \frac{c_p}{c_v} = \frac{\kappa_T}{\kappa_S}$

**证明：**

$$
\begin{aligned}
\gamma &= \frac{c_p}{c_v} = \frac{T \left(\frac{\partial s}{\partial T}\right)_p}{T \left(\frac{\partial s}{\partial T}\right)_v} = \frac{\left(\frac{\partial s}{\partial T}\right)_p}{\left(\frac{\partial s}{\partial T}\right)_v} = \frac{-\left(\frac{\partial p}{\partial T}\right)_s \left(\frac{\partial s}{\partial p}\right)_T}{-\left(\frac{\partial v}{\partial T}\right)_s \left(\frac{\partial s}{\partial v}\right)_T} = () () \\
&= \frac{-\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_T}{-\frac{1}{v} \left(\frac{\partial v}{\partial p}\right)_s} = \frac{\kappa_T}{\kappa_S}
\end{aligned}
$$

**二、$\left(\frac{\partial c_p}{\partial p}\right)_T$ 及 $\left(\frac{\partial c_v}{\partial v}\right)_T$ 与 $p, v, T$ 之间的关系**

上面得到的是 $c_p$ 与 $c_v$ 与 $u, h, s$ 之间的关系，由于 $u, h, s$ 都不可测量，所以希望得到随可测量参数 $p, v, T$ 之间的关系。

$$(\quad) = \frac{\partial}{\partial v} [ \quad ]_T = T \frac{\partial}{\partial T} [ \quad ] = T \frac{\partial}{\partial T} [ \quad ] = T (\quad)$$

$$(\quad) = \frac{\partial}{\partial p} [ \quad ]_T = T \frac{\partial}{\partial T} [ \quad ] = T \frac{\partial}{\partial T} [ \quad ] = -T (\quad)$$

上式说明 $c_p$ 与 $c_v$ 的一阶导数与状态方程的二阶导数相关。$c_p$ 与 $c_v$ 也是热系数。

**比热容关系式的用途**

1. 已知状态方程 $f(p, v, T) = 0$，$\left(\frac{\partial c_p}{\partial p}\right)_T = -T \left(\frac{\partial^2 v}{\partial T^2}\right)_p$

对状态方程微分两次，再对压力积分

$$c_p - c_{p0}(T) = - \left[ \int_{p \to 0}^p T \left(\frac{\partial^2 v}{\partial T^2}\right)_p \mathrm{d}p \right]_T$$

理想气体 $c_{p0}(T)$ + 状态方程 $\to$ 实际气体 $c_p$

状态方程对温度的二阶偏导数要足够精确。

同时也说明用比热容描述工质物性更加精确。

3. 若有实验测得的比热容数据，可以由比热容确定状态方程。通常用 $c_p$ 二次积分求状态方程。

$$\left(\frac{\partial v}{\partial T}\right)_p = \int_0^T \left(\frac{\partial^2 v}{\partial T^2}\right)_p \mathrm{d}T + \varphi(p) = - \int_0^T \frac{1}{T} \left(\frac{\partial c_p}{\partial p}\right)_T \mathrm{d}T + \varphi(p)$$

$$v = \int_0^T \left(\frac{\partial v}{\partial T}\right)_p \mathrm{d}T + f(p) = - \iint \frac{1}{T} \left(\frac{\partial c_p}{\partial p}\right)_T \mathrm{d}T \mathrm{d}T + T\varphi(p) + f(p)$$
