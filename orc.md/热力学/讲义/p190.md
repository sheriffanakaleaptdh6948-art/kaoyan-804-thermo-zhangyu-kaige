例 10-4 计算题：某种理想气体完成了一个由下述过程构成的可逆循环，(1) 从状态 1（压力$p_1$等，温度为$T_1$）经等温膨胀到压力为$\alpha p_1$的状态 2；(2) 等压压缩到温度为$\beta T_1$的状态 3；(3) 经过一个等熵过程 回到系统的初始状态。(a) 分别在$p-v$ 图和$T-s$ 图上画出这个循环；(b) 证明循环效率为$\eta = 1 - \kappa (\beta - 1) / [ (\kappa - 1) \ln \alpha ]$，其中$\kappa$ 为定指数。（北京科技大学 2008 年考研试题）

**解：** 1. 物理模型：该理想气体循环已是一可逆理想循环，循环中每一过程及其始、终态均确定，因此该循环确定，可按照本章分析循环的方法求解。

(b) 证明循环效率为$\eta = 1 - \kappa (\beta - 1) / [ (\kappa - 1) \ln \alpha ]$。

2. 数学模型：
1-2 定温吸热 $q_1 = T_2(s_2 - s_1)$ ①
理想气体 $s_2 - s_1 = -R_g \ln \alpha$ ②
$c_p = \kappa R_g / (\kappa - 1)$ ③
2-3 定压放热 $q_2 = c_p(T_2 - T_3) = c_p(T_1 - \beta T_1)$ ④

热效率 $\eta = 1 - q_2/q_1$ ⑤

3. 数学模型求解：①～④代入⑤得 热效率
$$ \eta = 1 - q_2/q_1 = 1 - c_p(T_1 - \beta T_1) / [T_2(s_2 - s_1)] = 1 - \kappa R_g / (\kappa - 1) (1 - \beta) T_1 / \{ T_1 [-R_g \ln \alpha] \} $$
$$ = 1 - \kappa (\beta - 1) / [ (\kappa - 1) \ln \alpha ] $$

4. 讨论及结论：
可以采用同样的方法计算分析任一循环的热效率和循环功。决不能靠记公式来求解循环。
