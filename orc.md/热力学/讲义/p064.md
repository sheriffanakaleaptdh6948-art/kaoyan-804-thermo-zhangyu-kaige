$$ \pi_1 = \frac{p_{\mathrm{a}}}{p_1} \quad \pi_2 = \frac{p_2}{p_{\mathrm{a}}} $$

$$ w_c = \frac{n}{n-1} R_{\mathrm{g}} T_1 [ 2 - ( \pi_1^{\frac{n-1}{n}} + \pi_2^{\frac{n-1}{n}} ) ] $$

在 $\pi_1 \pi_2 = \frac{p_{\mathrm{a}}}{p_1} \frac{p_2}{p_{\mathrm{a}}} = \frac{p_2}{p_1} = \pi_{\mathrm{tot}} = \text{常数}$ 的前提条件下，只有当 $\pi_1 = \pi_2 = \sqrt{\pi_{\mathrm{tot}}} = \sqrt{\frac{p_2}{p_1}}$ 时，$\pi_1^{\frac{n-1}{n}} + \pi_2^{\frac{n-1}{n}}$ 达到最小

其最小耗功为 $w_{c, \min} = - \frac{2n R_{\mathrm{g}} T_1}{n-1} ( \pi_{\mathrm{tot}}^{\frac{n-1}{2n}} - 1 )$

此时，两级压气机出口气温相等，
即 $T_{\mathrm{a}} = T_2 = T_1 \pi_{\mathrm{tot}}^{\frac{n-1}{2n}}$

【p-v图 两级压气机省功示意图】

此时中间冷却器散热量最小，为 $q_{c, \min} = h_{\mathrm{a}}' - h_{\mathrm{a}} = c_p ( T_{\mathrm{a}}' - T_{\mathrm{a}} ) = - \frac{n R_{\mathrm{g}} T_1}{n-1} ( \pi_{\mathrm{tot}}^{\frac{n-1}{2n}} - 1 )$

对 $L$ 级压气机，当各级增压比相等或者说按照几何平均均匀分配总增压比时，压气机耗功最小，

即 $\pi_{\mathrm{opt}} = \pi_1 = \pi_2 = \cdots = \sqrt[L]{\pi_{\mathrm{tot}}} = \sqrt[L]{\frac{p_2}{p_1}}$

最小耗功为 $w_{c, \min} = - \frac{L n R_{\mathrm{g}} T_1}{n-1} ( \pi_{\mathrm{tot}}^{\frac{n-1}{Ln}} - 1 )$

【p-v图 L级压气机省功示意图】

此时 $L-1$ 级中间冷却器总散热量为

$$ q_{c, \min} = (L-1) ( h_{\mathrm{a}}' - h_{\mathrm{a}} ) = - \frac{(L-1) n R_{\mathrm{g}} T_1}{n-1} ( \pi_{\mathrm{tot}}^{\frac{n-1}{2n}} - 1 ) $$

要让最终出口气体温度降至初温，需增加后冷器，则 $L$ 级冷却器的总散热量为

$$ q_{c, \min} = - \frac{L n R_{\mathrm{g}} T_1}{n-1} ( \pi_{\mathrm{tot}}^{\frac{n-1}{Ln}} - 1 ) $$

此时散热量与耗功完全相等，实际上仍然是把外界做功全部散出，只是压力增大，气体密度增加。
