沈维道《工程热力学》考点精讲及复习思路

system surroundings
以系统与外界关系划分：
*   是否质量交换 mass：
    *   有：Control Volume 开口系（控制体积）open system
    *   无：Control Mass 闭口系（控制质量）closed system
*   是否热量交换 heat：
    *   非绝热系
    *   绝热系 adiabatic system
*   是否功量交换 work：
    *   非绝功系
    *   绝功系 adiabatic system
*   是否热、功、质量交换：
    *   非孤立系 nonisolated system
    *   孤立系 isolated system
