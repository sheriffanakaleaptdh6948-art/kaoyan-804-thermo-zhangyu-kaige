沈维道《工程热力学》考点精讲及复习思路

一维稳定流动沿流动方向各截面面积、速度和密度的相对变化率之和为零。
一维稳定流动沿流动方向各截面面积与速度的相对变化率之和等于比体积的相对变化率。
应用：
1) 对于不可压流体($\mathrm{d}v = 0$)，如液体等，流体速度的改变取决于截面的改变，截面积 A 与流速 $c_f$ 成反比；
河道窄处湍急，河道宽处和缓。
2) 对于气体等可压缩流，流速的变化取决于截面和比体积的综合变化。
气体高速流动流道设计变化复杂。

2. 能量守恒——一维稳定流动能量方程式
对微元过程 $\delta q = \mathrm{d}h + \mathrm{d}\frac{c_f^2}{2} + g\mathrm{d}z + \delta w_{\mathrm{s}}$
对积分过程 $q = \Delta h + \frac{1}{2}\Delta c_f^2 + g\Delta z + w_{\mathrm{s}}$
一维稳定流动能量方程式
对微元过程 $\delta q = \mathrm{d}h + \delta w_{\mathrm{t}}$
对积分过程 $q = \Delta h + w_{\mathrm{t}}$
热力学第一定律第二表达式

3. 机械能守恒——伯努利方程式
若过程可逆，则 $-v\mathrm{d}p = \mathrm{d}\frac{c_f^2}{2} + g\mathrm{d}z + \delta w_{\mathrm{s}}$ 能量形式
$-\mathrm{d}p - \rho g\mathrm{d}z - \rho \delta w_{\mathrm{s}} = \rho c_f \mathrm{d}c_f$ 动量方程和牛顿第二定律的形式
注意：能量、热力学第一定律和伯努利等 3 个方程中只有 2 个是独立的。

4. 热力学第二定律——熵方程
热力学第二定律通用形式 $\mathrm{d}S_{\mathrm{iso}} \geqslant 0$
开口系熵方程 $\mathrm{d}s = \frac{\delta q}{T} + \mathrm{d}s_{\mathrm{g}}$

5. 物性方程 对理想气体
状态方程 $pv = R_{\mathrm{g}}T$
热力学能的表达式 $\mathrm{d}u = c_v \mathrm{d}T$
焓的表达式 $\mathrm{d}h = c_p \mathrm{d}T$
熵的表达式 $\mathrm{d}s = c_v \frac{\mathrm{d}T}{T} + R_{\mathrm{g}} \frac{\mathrm{d}v}{v}$
$\mathrm{d}s = c_p \frac{\mathrm{d}T}{T} - R_{\mathrm{g}} \frac{\mathrm{d}p}{p} \quad \mathrm{d}s = c_v \frac{\mathrm{d}p}{p} + c_p \frac{\mathrm{d}v}{v}$
若比热容为常数，则其表达式为 $c_p = \frac{\kappa}{\kappa - 1}R_{\mathrm{g}}, c_v = \frac{1}{\kappa - 1}R_{\mathrm{g}}$
若不是理想气体，则用相对应的方程（或图、表）替代即可。

6. 过程方程 即反映具体流动过程特征的方程。
