**二、循环关系和倒数关系**

令 $\mathrm{d}z = \left(\frac{\partial z}{\partial x}\right)_y \mathrm{d}x + \left(\frac{\partial z}{\partial y}\right)_x \mathrm{d}y = 0 (1)$

整理可得 $\left(\frac{\partial y}{\partial x}\right)_z = - \frac{\left(\frac{\partial z}{\partial x}\right)_y}{\left(\frac{\partial z}{\partial y}\right)_x} \quad \left(\frac{\partial x}{\partial y}\right)_z = - \frac{\left(\frac{\partial z}{\partial y}\right)_x}{\left(\frac{\partial z}{\partial x}\right)_y}$

则 $\left(\frac{\partial x}{\partial y}\right)_z \left(\frac{\partial y}{\partial x}\right)_z = 1$

$\left(\frac{\partial x}{\partial y}\right)_z = \frac{1}{\left(\frac{\partial y}{\partial x}\right)_z}$ 倒数关系

将倒数关系代入(1)得

$\left(\frac{\partial x}{\partial y}\right)_z \left(\frac{\partial y}{\partial z}\right)_x \left(\frac{\partial z}{\partial x}\right)_y = -1$ 循环关系

**三、链式关系和不同下标关系**

考虑任意四个状态参数 $x, y, z, w$ 间的关系，对函数 $x=x(y,w)$ 有 $\mathrm{d}x = \left(\frac{\partial x}{\partial y}\right)_w \mathrm{d}y + \left(\frac{\partial x}{\partial w}\right)_y \mathrm{d}w (2)$

对函数 $y=y(z,w)$ 有 $\mathrm{d}y = \left(\frac{\partial y}{\partial z}\right)_w \mathrm{d}z + \left(\frac{\partial y}{\partial w}\right)_z \mathrm{d}w (3)$

式(3)代入式(2)并整理得

$\mathrm{d}x = \left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial z}\right)_w \mathrm{d}z + \left[ \left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial w}\right)_z + \left(\frac{\partial x}{\partial w}\right)_y \right] \mathrm{d}w (4)$

又对函数 $x=x(z,w)$ 可写成 $\mathrm{d}x = \left(\frac{\partial x}{\partial z}\right)_w \mathrm{d}z + \left(\frac{\partial x}{\partial w}\right)_z \mathrm{d}w (5)$

比较式(4)和式(5)得 $\left(\frac{\partial x}{\partial z}\right)_w = \left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial z}\right)_w$

利用倒数关系整理得 $\left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial z}\right)_w \left(\frac{\partial z}{\partial x}\right)_w = 1$ 链式关系

不同下标关系 $\left(\frac{\partial x}{\partial w}\right)_z = \left(\frac{\partial x}{\partial w}\right)_y + \left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial w}\right)_z$

链式关系可以扩充到多个参数 $\left(\frac{\partial x}{\partial y}\right)_w \left(\frac{\partial y}{\partial z}\right)_w \left(\frac{\partial z}{\partial u}\right)_w \left(\frac{\partial u}{\partial v}\right)_w = 1$

**例 6-2** 求证：$\left(\frac{\partial T}{\partial v}\right)_u = \left(\frac{\partial T}{\partial v}\right)_s + \frac{p}{c_v}$

**证明：** 由不同下标关系得 $\left(\frac{\partial T}{\partial v}\right)_u = \left(\frac{\partial T}{\partial v}\right)_s + \left(\frac{\partial T}{\partial s}\right)_v \left(\frac{\partial s}{\partial v}\right)_u$

由热力学第一定律解析式得 $\mathrm{d}u = T\mathrm{d}s - p\mathrm{d}v = 0$

则 $\left(\frac{\partial s}{\partial v}\right)_u = \frac{p}{T}$
