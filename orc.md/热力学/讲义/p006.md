system 热力系其它分类方式
*   物理化学性质
    *   均匀系 uniform system
    *   非均匀系 nonuniform system
*   working fluid 工质种类
    *   单元系 single-component system
    *   多元系 multicomponent system
*   相态
    *   单相系 single-phase system
    *   多相系 multi-phase system
*   compressibility 可压缩性
    *   可压缩系 compressible system
    *   不可压缩系 incompressible system

选择不同的热力系，就选择了不同的方法来处理。
拉格朗日法 $\Longrightarrow$ 闭口系 $\Longrightarrow$ 控制质量 (C.M.)
欧拉法 $\Longrightarrow$ 开口系 $\Longrightarrow$ 控制体积 (C.V.)

本质：不同的热力系，就是不同的研究方法。
在研究方法这个层次上，所有的概念都变得容易理解了。
一个特殊的热力系——简单可压缩热力系的由来：
理想化方法$\rightarrow$使热力系尽量简单，突出热能与机械能的转换$\rightarrow$只有两种能量传递方式：热量和体积功

**考点 2：热力系的描述——状态与状态参数 (property)**
状态：某一瞬间热力系所呈现的宏观物理状况。
状态参数：描述热力系状态的宏观物理量。
并不是所有的状态都有状态参数。只有当热力系内部参数处处相等时，其内部状态才能用状态参数来表征。即
$$p_1=p_2=p$$
