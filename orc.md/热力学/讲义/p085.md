实际上这种分析方法就是把热力过程的内部视为完全可逆的，称为内部可逆；而把所有的不可逆性都归结到外部温差中去，称为外部不可逆。对分析热力过程来说，通常内部可逆的假设就足够了，已经可以保证用可逆的方法去分析可逆的热力过程了。因此，分析中所说的可逆实际上大多数都指的是内部可逆。

实际过程中根本不存在内部和外部均可逆的所谓完全可逆的过程，因此通常就将不可逆性归结到外部。这是“可逆”概念在工程实际中得以贯彻实施的重要方法。

在多热源循环 ABCD 中，工质吸热量 和放热量分别为 $Q_1 = \text{c} + \text{d} + \text{e} + \text{f}$，$Q_2 = \text{c} + \text{d} + \text{f}$

而在相同的温度极限范围内的卡诺循环，工质吸热量 和放热量分别为 $Q_{1\text{c}} = \text{a} + \text{b} + \text{c} + \text{d} + \text{e} + \text{f}$，$Q_{2\text{c}} = \text{f}$

显然，有 $Q_{1\text{c}} > Q_1, Q_{2\text{c}} < Q_2, \eta_t = 1 - \frac{Q_2}{Q_1} < 1 - \frac{Q_{2\text{c}}}{Q_{1\text{c}}} = \eta_{t\text{c}} = 1 - \frac{T_2}{T_1}$

**结论：**在相同的温度极限范围内多热源循环热效率一定小于卡诺循环热效率。

**四、卡诺效率对热机的指导意义**

1. 使热机经历循环尽可能接近卡诺循环。
如图，多热源循环对其外切的卡诺循环充满度越大，就越接近卡诺循环，热效率就越高；

【图 T-s图】

2. 尽量减少循环的不可逆性，包括内不可逆性和外不可逆性。不可逆性越小，热效率越高。
实际上前述使循环尽可能接近卡诺循环也可以理解为尽量减少外不可逆性，此外还应尽量减少过程的内不可逆性，如减少摩擦、泄露、掺混等。

3. 尽量扩大循环的极限温度范围，即提高最高温度 $T_{\max}$，降低最低温度 $T_{\min}$。
一般来说，$T_{\max}$ 受材料高温性能的限制，而 $T_{\min}$ 受环境如大气及江河湖海温度的限制。因此，提高热机热效率应该从改善材料的性能和改进对自然界环境的放热过程两方面着手；

4. 卡诺循环热效率使我们看到了影响热效率的本质因素是温差，而不是吸热量和放热量。
