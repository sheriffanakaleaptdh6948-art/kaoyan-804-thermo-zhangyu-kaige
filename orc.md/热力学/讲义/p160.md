3. 数学模型求解：当 $p_1 = 3.5\text{MPa}$ 时，

$\because p_2/p_1 = 0.7/3.5 = 0.2 < \nu_{\text{cr}} = 0.528$

$\therefore$ 喷管处于超临界状态，缩放喷管

代入②得 $T_2 = T_1 \left(\frac{p_2}{p_1}\right)^{\frac{\kappa-1}{\kappa}} = 773 \times \left(\frac{0.7}{3.5}\right)^{\frac{1.4-1}{1.4}} = 488.06\text{ K}$

代入①得 $c_{f2} = \sqrt{2 \times 1005 \times (773 - 488.06)} = 756.8\text{ m/s}$

令 $Ma=1$，代入得 $\frac{T_1}{T_{\text{cr}}} = 1 + \frac{(\kappa-1)}{2} = \frac{\kappa+1}{2}$

则 $T_{\text{cr}} = \frac{2T_1}{\kappa+1} = \frac{2 \times 773}{1.4+1} = 644.17\text{ K}$

临界速度 $c_{\text{cr}} = a_{\text{cr}} = \sqrt{\kappa R_g T_{\text{cr}}} = \sqrt{1.4 \times 287 \times 644.17} = 508.75\text{ m/s}$

由⑤得 $\rho_{\text{cr}} = \frac{p_{\text{cr}}}{R_g T_{\text{cr}}} = \frac{0.528 \times 3.5 \times 10^6}{287 \times 644.17} = 9.99585\text{ kg/m}^3$

代入③得 $A_{\text{cr}} = \frac{q_m}{\rho_{\text{cr}} c_{f\text{cr}}} = \frac{1.3}{9.99585 \times 508.75} = 2.556 \cdot \text{cm}^2$

由⑥得 $\rho_2 = \frac{p_2}{R_g T_2} = \frac{0.7 \times 10^6}{287 \times 488.06} = 4.99739 \cdot \text{kg/m}^3$

代入④得 $A_2 = \frac{q_m}{\rho_2 c_{f2}} = \frac{1.3}{4.99739 \times 756.8} = 3.43 \cdot \text{cm}^2$

由⑦得 $Ma = \sqrt{\frac{2(\frac{T_1}{T_2}-1)}{\kappa-1}} = \sqrt{\frac{2(\frac{773}{488.06}-1)}{1.4-1}} = 1.709$

或由定义得 $Ma = \frac{c_{f2}}{a_2} = \frac{c_{f2}}{\sqrt{\kappa R_g T_2}} = \frac{756.8}{\sqrt{1.4 \times 287 \times 488.06}} = 1.709$

所得参数均合理可信。最后一步马赫数采用不同方法求解一是尽量会用各种方法求解，二也可以对前面的数据进行检验和验证。

**考点六：绝热节流**

$\blacktriangleright$ **定义**：流体在管道中流动，遇到管道突然收缩（如工程上的阀门、孔板、多孔堵塞物等等），由于旋涡、绕流等引起局部阻力使流体压力降低的现象称为节流。如果节流过程中流体与外界没有热量交换，就称为绝热节流，也简称节流（throttling）。
