**例 8-13 计算题**：某理想气体 $c_p = 1\text{kJ}/(\text{kg} \cdot \text{K}), \kappa = 1.4$，可逆绝热地流过渐缩喷管出口时，恰好处于临界工况，若测得喷管中间某截面速度 $c_{\text{f1}} = 165\text{m/s}, p_1 = 0.7\text{MPa}, t_1 = 300^{\circ}\text{C}$，求喷管出口截面空气流速、压力及温度。若上述气体不可逆绝热地流过喷管，试将不可逆过程的作功能力损失定性地表示在 $T-s$ 图上。（南航 2008 年考研试题）

**解：1. 物理模型**：该题给出了管道大致形状和进口（某截面）参数，进出口间过程完全确定，出口截面积和压力未知。但已知出口为临界工况，则出口参数也可以完全确定。

2. 数学模型及求解：根据能量方程
$$q = \Delta h + \frac{1}{2}\Delta c_{\text{f}}^2 + g\Delta z + w_{\text{s}}$$
绝能定熵流动，并忽略空气重力势能 $h^* = h_1 + \frac{c_{\text{f1}}^2}{2}$
对定比热容理想气体 $c_p T^* = c_p T_1 + \frac{c_{\text{f1}}^2}{2}$
则 $T^* = T_1 + \frac{c_{\text{f1}}^2}{2c_p} = 573.15 + \frac{165^2}{2 \times 1000} = 586.76\text{K}$
对定比热容理想气体 $R_{\text{g}} = \frac{\kappa-1}{\kappa}c_p = \frac{1.40-1}{1.40} \times 1 = 0.2857\text{kJ}/(\text{kg} \cdot \text{K})$
对定熵过程，有 $\frac{T_2}{T^*} = \left(\frac{p_2}{p^*}\right)^{\frac{\kappa-1}{\kappa}} = \left(\frac{p_{\text{cr}}}{p^*}\right)^{\frac{\kappa-1}{\kappa}} = 0.528^{\frac{1.40-1}{1.40}} = 0.8332$
则 $T_2 = T_{\text{cr}} = 0.8332T^* = 0.8332 \times 586.76 = 488.89\text{K}$
$$p_2 = p_1 \left(\frac{T_2}{T_1}\right)^{\frac{\kappa}{\kappa-1}} = 0.7 \times \left(\frac{488.89}{573.15}\right)^{\frac{1.4}{1.4-1}} = 0.40\text{MPa}$$
$$c_{\text{f2}} = c_{\text{cr}} = \sqrt{\kappa R_{\text{g}} T_{\text{cr}}} = \sqrt{1.4 \times 285.7 \times 488.89} = 442.22\text{ m/s}$$
