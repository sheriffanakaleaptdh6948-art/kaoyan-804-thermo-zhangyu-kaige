临界压力
$$p_{cr} = v_{cr}p_0 = 0.528 \times 0.16\text{MPa} = 0.0845\text{MPa} > 0.05\text{MPa} = p_b,$$
由于是渐缩喷管。出口压力
$$p_2 = p_{cr} = 0.0845\text{MPa}$$
$$T_2 = T_1\left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}} = 290.15\text{K} \times \left(\frac{0.0845\text{MPa}}{0.16\text{MPa}}\right)^{\frac{1.4-1}{1.4}} = 241.771\text{K}$$
出口截面上的流速
$$c_{f2} = \sqrt{2(h_0 - h_2)} = \sqrt{2c_p(T_0 - T_2)}$$
$$c_{f2} = \sqrt{2 \times 1004.5\text{J}/(\text{kg}\cdot\text{K}) \times (290.15\text{K} - 241.771\text{K})} = 311.759\text{m/s}$$

（图：第4题循环的 T-s 图）

解：循环的 $T-s$ 图如图所示 $T_1 = T_0 = 310.15\text{K}$， $T = 770.15\text{K}$， $\pi = \frac{p_2}{p_1} = 12$
（1）压缩过程绝热，所以
$$T_2 = T_1\left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}} = T_1\pi^{\frac{k-1}{k}} = 310.15\text{K} \times 12^{\frac{1.4-1}{1.4}} = 630.8\text{K}$$
压缩 1kg 空气压气机耗功
$$w_C = h_2 - h_1 = c_p(T_2 - T_1) = 1.005\text{kJ}/(\text{kg}\cdot\text{K})(630.8\text{K} - 310.15\text{K}) = 322.25\text{kJ}/\text{kg}$$
（2）过程 3-4 是可逆绝热过程，所以
$$T_3 = T_4\left(\frac{p_3}{p_4}\right)^{\frac{k-1}{k}} = T_4\left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}} = T_4\pi^{\frac{k-1}{k}} = 770.15\text{K} \times 12^{\frac{1.4-1}{1.4}} = 1556.4\text{K}$$
1kg 空气流经燃气轮机作的功：
$$w_T = h_3 - h_4 = c_p(T_3 - T_4) = 1.005\text{kJ}/(\text{kg}\cdot\text{K})(1566.4\text{K} - 770.15\text{K}) = 800.2\text{kJ}/\text{kg}$$
（3）燃烧过程的换热量：
$$q_1 = h_3 - h_2 = c_p(T_3 - T_2) = 1.005\text{kJ}/(\text{kg}\cdot\text{K}) \times (1566.4 - 630.8)\text{K} = 940.3\text{kJ}/\text{kg}$$
排气过程的换热量：
$$q_2 = h_4 - h_1 = c_p(T_4 - T_1) = 1.005\text{kJ}/(\text{kg}\cdot\text{K}) \times (770.15 - 310.15)\text{K} = 462.3\text{kJ}/\text{kg}$$
（5）循环的热效率
$$\eta_t = 1 - \frac{q_2}{q_1} = 1 - \frac{462.3\text{kJ}/\text{kg}}{940.3\text{kJ}/\text{kg}} = 0.508$$
