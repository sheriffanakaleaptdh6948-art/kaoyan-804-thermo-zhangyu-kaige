# 2007年硕士学位研究生入学考试试题—参考答案

**一、名词解释**

**热力学温度**
答：热力学温度是热力学温标所表示的温度，单位为开尔文（K）。它是基于热力学第二定律定义的温度，与工作物质的性质无关。热力学温度 $T$ 与摄氏温度 $t$ 的关系为：
$$T = t + 273.15$$
热力学温度是国际单位制中的基本物理量之一。

**热力学第一定律**
答：热力学第一定律是能量守恒与转换定律在热力学中的应用，表明能量既不能创生也不能消灭，只能从一种形式转化为另一种形式，总量保持不变。
数学表达式：
闭口系统：$Q = \Delta U + W$
开口系统稳定流动：$Q = \Delta H + W_{\text{t}}$

**卡诺定理**
答：卡诺定理包括两个定理：
（1）在相同的高温热源和低温热源之间工作的一切可逆热机，其热效率都相等，与工作物质无关。
（2）在相同的高温热源和低温热源之间工作的一切不可逆热机，其热效率都小于可逆热机的热效率。
卡诺定理指出：$\eta_{\text{t}} \le 1 - \frac{T_2}{T_1}$
等号对应可逆循环，不等号对应不可逆循环。

**道尔顿分压定律**
答：道尔顿分压定律指出：混合气体的总压力等于各组成气体的分压力之和。
$$p = p_1 + p_2 + \cdots + p_n = \sum p_i$$
其中分压力是指各组成气体单独占据混合气体的容积时所具有的压力。

**相对湿度**
答：相对湿度是湿空气中水蒸气的分压力与同温度下饱和水蒸气分压力之比：
$$\varphi = \frac{p_{\text{v}}}{p_{\text{s}}}$$
