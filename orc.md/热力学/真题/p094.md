定压比热容
$$c_p = \frac{k}{k-1}R_g = \frac{1.35}{1.35-1} \times 0.4\text{kJ}/(\text{kg}\cdot\text{K}) = 1.543\text{kJ}/(\text{kg}\cdot\text{K})$$
热力学能变化量
$$\Delta U = mc_v(T_2 - T_1) = 2.5\text{kg} \times 1.143\text{kJ}/(\text{kg}\cdot\text{K}) \times (T_2 - 470\text{K}) = 295.4\text{kJ}$$
那么 $T_2 = 573.377\text{K}$
过程功
$$W = m\frac{R_g}{n-1}(T_1 - T_2) = 2.5\text{kg} \times \frac{0.4\text{kJ}/(\text{kg}\cdot\text{K})}{0.4-1} \times (470\text{K} - 573.377\text{K}) = 172.295\text{kJ}$$
过程热量 $Q = m\frac{n-k}{n-1}C_v(T_2 - T_1)$
$$Q = 2.5\text{kg} \times \frac{0.4-1.35}{0.4-1} \times 1.143\text{kJ}/(\text{kg}\cdot\text{K}) \times (573.377\text{K} - 470\text{K}) = 467.716\text{kJ}$$
压缩后的终压
$$p_2 = p_1\left(\frac{T_2}{T_1}\right)^{\frac{k}{k-1}} = 0.1\text{MPa} \times \left(\frac{573.377\text{K}}{470\text{K}}\right)^{\frac{0.4}{0.4-1}} = 0.0876\text{MPa}$$
熵的变化量
$$\Delta S = m\left(c_p\ln\frac{T_2}{T_1} - R_g\ln\frac{p_2}{p_1}\right)$$
$$\Delta S = 2.5\text{kg} \times \left[1.543\text{kJ}/(\text{kg}\cdot\text{K}) \times \ln\frac{573.377\text{K}}{470\text{K}} - 0.4\text{kJ}/(\text{kg}\cdot\text{K}) \times \ln\frac{0.0876\text{MPa}}{0.1\text{MPa}}\right]$$
$$= 0.899\text{kJ}/\text{K}$$

（1）由于初速度忽略不计，滞止参数：
$$T_0 = T_1 = 290.15\text{K}, p_0 = p_1 = 0.16\text{MPa}$$
临界压力
$$p_{cr} = v_{cr}p_0 = 0.528 \times 0.16\text{MPa} = 0.0845\text{MPa} < 0.1\text{MPa} = p_b,$$
由于是渐缩喷管。出口压力
$$p_2 = p_b = 0.1\text{MPa}$$
$$T_2 = T_1\left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}} = 290.15\text{K} \times \left(\frac{0.1\text{MPa}}{0.16\text{MPa}}\right)^{\frac{1.4-1}{1.4}} = 253.69\text{K},$$
定压比热容
$$c_p = \frac{k}{k-1}R_g = \frac{1.4}{1.4-1} \times 0.287\text{kJ}/(\text{kg}\cdot\text{K}) = 1.0045\text{kJ}/(\text{kg}\cdot\text{K})$$
出口截面上的流速
$$c_{f2} = \sqrt{2(h_0 - h_2)} = \sqrt{2c_p(T_0 - T_2)}$$
$$c_{f2} = \sqrt{2 \times 1004.5\text{J}/(\text{kg}\cdot\text{K}) \times (290.15\text{K} - 253.69\text{K})} = 270.644\text{m/s}$$

（2）由于初速度忽略不计，滞止参数：
$$T_0 = T_1 = 290.15\text{K}, p_0 = p_1 > 0.16\text{MPa}$$
