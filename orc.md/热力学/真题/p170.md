已知：
$$t_1 = 45^\circ\text{C}, T_1 = 318\text{ K}$$
$$p = p_b + p_g = 0.1 + 0.01 = 0.11\text{ MPa}$$
$$V_1 = 0.3\text{ m}^3$$

氧气参数：
$$R_g = 0.260\text{ kJ/(kg}\cdot\text{K)}$$
$$c_p = 0.918\text{ kJ/(kg}\cdot\text{K)}$$
$$c_v = 0.658\text{ kJ/(kg}\cdot\text{K)}$$

气体质量：
$$m = \frac{pV_1}{R_g T_1} = 0.11 \times 10^6 \times \frac{0.3}{260 \times 318} = 0.40\text{ kg}$$

过程 1-2：定压加热
由定压过程：
$$Q = mc_p(T_2 - T_1)$$
$$T_2 = T_1 + \frac{Q}{mc_p} = 318 + \frac{40}{0.40 \times 0.918} = 427\text{ K}$$

焓变：
$$\Delta H = Q = 40\text{ kJ}$$

膨胀功：
$$W = mR_g(T_2 - T_1) = 0.40 \times 0.260 \times (427 - 318) = 11.3\text{ kJ}$$

过程 2-3：多变膨胀到初温
已知：
$$T_3 = T_1 = 318\text{ K}, \quad p_3 = 18\text{ kPa} = 0.018\text{ MPa}$$
由多变过程：
$$\frac{T_2}{T_3} = \left(\frac{p_2}{p_3}\right)^{\frac{n-1}{n}}$$
$$\frac{427}{318} = \left(\frac{0.11}{0.018}\right)^{\frac{n-1}{n}}$$
$$1.343 = 6.111^{\frac{n-1}{n}}$$
$$\frac{n-1}{n} = \frac{\ln(1.343)}{\ln(6.111)} = 0.162$$
$$n = 1.194$$

膨胀功：
$$W = mR_g\frac{T_2 - T_3}{n - 1} = 0.40 \times 0.260 \times \frac{427 - 318}{1.194 - 1}$$
$$= 57.7\text{ kJ}$$
