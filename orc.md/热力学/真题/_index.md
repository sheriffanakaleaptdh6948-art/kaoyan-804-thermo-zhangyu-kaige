## 页码口径（重要）

`pXXX.md` 的 XXX **就是书上印的页码**（与教材 OCR 不同 —— 教材那套是 PDF 页码，差 13）。
每个文件的页头记录了：来源照片、算出的书页码、**模型读到的印页码**、题型。

### 两个使用口

1. **「书上印的页码」这个校验在本套扫描件上基本失效。** Adobe 合订时把**很多页的页脚裁掉了**
   （实测 p37/p46 整页底部无页码），模型只能报 `?`。**改用「年份封面标题的落点」做对齐校验** ——
   就是上表那个 38/38，比读小字号页码硬得多。
2. **71 页（37%）提到图**（T-s 图 / p-v 图 / 循环图 / 示意图），但**图本身没有转录**，只留了图名。
   **带图的题必须回到原书 PDF 看。**
3. **单位大小写会被降级**：实测见到 `420.83\text{k}`（应为 K）、`11\text{kJ/k}`（应为 kJ/K）。
   做题时单位自己核。

## 扫描/转录命令

```powershell
cd 视频爬取
python ocr_zhenti.py --dir "<真题目录>\2025"      --start 6   --tag "2025 试题" --workers 8
python ocr_zhenti.py --dir "<真题目录>\答案\2026"  --start 72  --tag "2026 答案" --workers 8
```

`--start N` = 该文件夹第 1 张照片对应的**书页码**，第 i 张即第 (N+i−1) 页。
`--dir` 可以给**文件夹**（手机照片），也可以直接给**一个 PDF**（Adobe Scan 输出）。

## 两种输入源的取舍（2026-09-25 实测）

| | 手机拍照 JPG | **Adobe Scan PDF** |
|---|---|---|
| 图质量 | 2592×4608，有透视/阴影/弯曲 | 内嵌图 3680×2400，**拉平增强过** |
| 文字化结果 | 好 | **更好**（少了 `\_\_\_\_\_\_` 这类占位残留，考生须知正确分行） |
| 旋转 | 无害（实测相似度 0.95+） | 无关（已拉平） |
| 建议 | 可用 | **首选** |

**关键坑：不要用 Adobe Scan 自带的文本层。** 它确实有文字层，但实测同一页对比：
- 阅读顺序全乱（选项 A/B/C/D 与题干分离、跨题交错）
- 公式垮掉：`dssur -` / `B. dSsur To` / `C. dSeu, =0`
- 错别字密集：选**抨**题 / **咎**案 / **式**题纸 / 草**秘**纸 / 可逆定**焙**压缩 / **符台** / **嫡**变
- 水印混进正文，且微信号都认错（870703756，实际 870705756）

**它的价值在「图被拉平增强过」，不在「它认得字」。** 所以 PDF 也只取图，OCR 仍走 qwen3.7-plus。
（`ocr_zhenti.py` 已支持 PDF 直读，无需先转图片。）

## 这套资料的已知问题（背诵前必读）

1. **是「回忆版」，且部分题目经过改编**
   书里明写两类批注，转录时**原样保留**：
   - p001 题1「【回忆版按"不可逆过程同样绝热"还原】」
   - p003 题8「【根据回忆版真题改编，缺失条件已按合理假设补充】」
   - p002 题6「**改编版题目：**」
   → **回忆版 ≠ 官方原卷**。题干准确性、题目完整性、答案唯一性都受此影响。

2. **科目编号印的是 803，但招生专业目录写的是 804**
   p001 封面裁图放大核实：**确实印「803」**。而 `海大\2026招生专业目录.md` 里
   「工程热力学（**804**）」，且 **803 在目录里对应「遥感原理与应用」**。
   **未下结论** —— 需翻其他年份看是否都印 803。

3. **2026 的选择题只到第 4 题就进简答题**，与记录的「选择 10×2 + 简答 6×10」对不上。
   可能是回忆版不全，也可能题型有变。**未下结论**，待其他年份印证。

4. **拍照时右下角页码容易被切掉** —— 2020 第 2 页的印页码只拍到一半（读出"3"，
   实为 33，由目录与前后页 32/34 夹出）。**后续拍照留点右边距**。

5. **页边界会切断题干** —— 属正常，按页码顺序读即可接上
   （例：p002 末尾「经绝热节流降至 $p_2=2$」→ p003 开头「1.00 MPa。求：…」）。
