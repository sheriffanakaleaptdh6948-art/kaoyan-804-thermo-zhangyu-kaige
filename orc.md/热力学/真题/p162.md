奥托循环为：1→2 等熵压缩，2→3 定容加热，3→4 等熵膨胀，4→1 定容放热。
单位质量循环净功为
$$w_{\text{net}} = c_v[(T_3 - T_2) - (T_4 - T_1)].$$
由等熵关系
$$T_2 = T_1 \varepsilon^{\kappa-1},$$
$$T_4 = \frac{T_3}{\varepsilon^{\kappa-1}}.$$
令
$$x = \varepsilon^{\kappa-1},$$
则
$$w_{\text{net}} = c_v \left( T_3 - T_1 x - \frac{T_3}{x} + T_1 \right).$$
对 $x$ 求导并令其为零：
$$\frac{\mathrm{d}w_{\text{net}}}{\mathrm{d}x} = c_v \left( -T_1 + \frac{T_3}{x^2} \right) = 0.$$
因此
$$x = \sqrt{\frac{T_3}{T_1}}.$$
于是
$$T_2 = T_4 = \sqrt{T_1 T_3}.$$
最佳压缩比为
$$\varepsilon_{\text{opt}} = \left( \frac{T_3}{T_1} \right)^{\frac{1}{2(\kappa-1)}}.$$
奥托循环热效率为
$$\eta_{\text{th}} = 1 - \frac{T_4 - T_1}{T_3 - T_2}.$$
代入最优条件 $T_2 = T_4 = \sqrt{T_1 T_3}$，得
在净功最大条件下，热效率为
$$\eta_{\text{th}} = 1 - \sqrt{\frac{T_1}{T_3}}.$$
