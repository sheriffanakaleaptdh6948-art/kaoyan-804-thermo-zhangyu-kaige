将上述条件代入一般方程，两边除以 $\dot{m}$，得到单位质量工质的能量方程：
$$q = (h_2 - h_1) + \frac{c_2^2 - c_1^2}{2} + g(z_2 - z_1) + w_s$$
$$q = \Delta h + \Delta \left( \frac{c^2}{2} \right) + g \Delta z + w_s$$

（3）各项物理意义：
$q$ 单位质量工质吸收的热量，J/kg；
$\Delta h = h_2 - h_1$ 焓差，代表工质焓的变化，J/kg；
$\Delta \left( \frac{c^2}{2} \right) = \frac{c_2^2 - c_1^2}{2}$ 动能变化，J/kg；
$g \Delta z = g(z_2 - z_1)$ 重力位能变化，J/kg；
$w_s$ 轴功，单位质量工质通过叶轮等机械装置对外输出的功，J/kg。

本题是工程热力学核心公式推导题。关键要点：
① 开口系统能量方程中，流动工质携带的能量用焓 $h$ 而非热力学能 $u$，因为 $h$ 中已包含推动功 $pv$；
② 稳定流动的三个条件必须写全；
③ 推导过程中注意从一般式到稳定流动的化简逻辑；
 若采用“工质对外输出功为正”的约定，则稳定流动中技术功可写为 $w_t = w_s + \Delta \left( \frac{c^2}{2} \right) + g \Delta z$；作答时应先说明功的正负号约定。

（1）焓的定义：是人为定义的一个组合状态参数，用符号 $H$ 表示，单位为 J（或 kJ）。比焓用 $h$ 表示，单位为 J/kg。定义式为：$H = U + pV$ 或 $h = u + pv$。其中 $U$ 为热力学能，$p$ 为压力，$V$ 为体积；$u$ 为比热力学能，$v$ 为比体积。
（2）焓的物理意义：
① 对于流动工质（开口系统），焓代表流动工质携带的总能量中取决于热力状态的那部分能量。具体来说，工质流进（或流出）控制体积时，不仅携带热力学能 $u$，还因推动功 $pv$ 而伴随能量传递，二者之和即为 $h = u + pv$。因此，在开口系统能量方程中，流动工质的能量传递用焓来计算。
② 对于闭口系统，焓没有直接的物理意义，仅是一个方便计算的组合状态参数。在定压过程且只做体积功时，焓的变化等于过程热量：$\Delta h = q_p$（定压比热相关）。
③ 焓是状态参数，只取决于系统所处的状态，与达到该状态的路径无关。

（1）㶲（Exergy）的定义：
在给定环境条件下，系统从给定状态可逆地变化到与环境达到平衡时，理论上能够获得的最大有用功称为㶲。能量中不能转化为有用功的部分可称为无效能（anergy）。
