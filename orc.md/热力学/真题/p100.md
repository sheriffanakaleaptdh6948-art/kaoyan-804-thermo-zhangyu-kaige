得 $T = \frac{71}{0.72} = 420.83\text{k}$
$$m = \frac{P_2 V}{R_g T_2} = \frac{4 \times 10^6}{287 \times 420.83}$$
得 $m = 33.2\text{kg}$
$$S = m \Delta S = m C_P \ln \frac{T_2}{T_1}$$
$$= 33.2 \times 0.3308 = 11\text{kJ/k}$$
$$I = T_0 S = 303 \times 11 = 3333\text{kJ}$$

对于函数 $f = (T, v)$，那么 $-p = \left(\frac{\partial f}{\partial v}\right)_T$， $-s = \left(\frac{\partial f}{\partial T}\right)_v$， $u = f + Ts = f - T\left(\frac{\partial f}{\partial T}\right)_v$
$$h = u + pv = f - T\left(\frac{\partial f}{\partial T}\right)_v - v\left(\frac{\partial f}{\partial v}\right)_T, \quad g = h - Ts$$
$$= f - T\left(\frac{\partial f}{\partial T}\right)_v - v\left(\frac{\partial f}{\partial v}\right)_T + T\left(\frac{\partial f}{\partial T}\right)_v = f - v\left(\frac{\partial f}{\partial v}\right)_T.$$
故已知状态参数 $f = (T, v)$，其他的状态参数都可以确定，满足特性函数的定义，因此 $f = (T, v)$ 是特性函数。

$$T_1 = 900.15\text{K}, \quad c_p = \frac{k}{k-1}R_g = \frac{1.4}{1.4-1} \times 256\text{J/(kg}\cdot\text{K)} = 896\text{J/(kg}\cdot\text{K)}$$
滞止参数： $T_0 = T_1 + \frac{c_{f1}^2}{2c_p} = 900.15\text{K} + \frac{(100\text{m/s})^2}{2 \times 896\text{J/(kg}\cdot\text{K)}} = 905.73\text{K}$
$$p_0 = p_1 \left(\frac{T_0}{T_1}\right)^{\frac{k}{k-1}} = 0.6\text{MPa} \times \left(\frac{905.73\text{K}}{900.15\text{K}}\right)^{\frac{1.4}{1.4-1}} = 0.6131\text{MPa}$$
临界压力 $p_{cr} = \nu_{cr} p_0 = 0.528 \times 0.6131\text{MPa} = 0.3237\text{MPa}$
当出口的压力等于临界的压力时， $p_2 = p_{cr} = 0.3237\text{MPa}$，喷管的流量达到最大。
喷管出口的温度 $T_2 = T_1 \left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}} = 900.15\text{K} \times \left(\frac{0.3237\text{MPa}}{0.6\text{MPa}}\right)^{\frac{1.4-1}{1.4}} = 754.64\text{K}$，
出口的速度
$$c_{f2} = \sqrt{2(h_0 - h_2)} = \sqrt{2c_p(T_0 - T_2)} = \sqrt{2 \times 896\text{J/(kg}\cdot\text{K)} \times (900.15\text{K} - 754.64\text{K})}$$
$$= 520.31\text{m/s}$$
出口的比体积 $v_2 = \frac{R_g T_2}{p_2} = \frac{256\text{J/(kg}\cdot\text{K)} \times 754.64\text{K}}{0.3237 \times 10^6\text{Pa}} = 0.597\text{m}^3/\text{kg}$
喷管质量流量 $q_m = \frac{A_2 c_{f2}}{v_2} = \frac{1.5 \times 10^{-3}\text{m}^2 \times 520.31\text{m/s}}{0.597\text{m}^3/\text{kg}} = 1.307\text{kg/s}$
