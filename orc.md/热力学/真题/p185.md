初始为真空$U_1=0$ 充入质量$m_{\text{in}}=m_2$，故：$Q = m_2 u_2 + W - h_{\text{in}} m_2 = m_2(u_2 - h_{\text{in}}) + W$
终态质量：$V_2 = AL = 6.45 \times 10^{-3} \times 0.6 = 3.87 \times 10^{-3} m^3$
终态比热力学能与入口比焓为：$u_2 = c_v T_2 = 0.718 \times 303 = 217.6 \text{ kJ kg}^{-1}$；$h_{\text{in}} = c_p T_{\text{in}} = 1.005 \times 363 = 364.8 \text{ kJ kg}^{-1}$。
$$w_t = GL = 100 \times 0.6 = 60\text{J} = 0.06\text{kJ}$$
$$Q = 0.00520 \times (217.6 - 364.8) + 0.452 = -0.765 + 0.452 = -0.313\text{kJ}$$
负号表示系统对外放热 0.313 kJ（即吸热量为-0.313 kJ）。

(1) 过程热量 Q
由闭口系统能量方程$Q = \Delta U + W$：
$$\Delta U = m c_v (T_2 - T_1) = 0.25 \times 0.747 \times (298 - 393) = -17.74\text{kJ}$$
$$Q = -17.74 + 8.0 = -9.74\text{kJ}$$
负号表示系统放热 9.74 kJ。
(2) 判断过程是否可逆
用孤立系统熵增原理判断。系统熵变：
$$\Delta S_{\text{sys}} = m [C_v \ln\left(\frac{T_2}{T_1}\right) + R_g \ln\left(\frac{v_2}{v_1}\right)]$$
由理想气体状态方程，$\frac{v_2}{v_1} = \frac{p_1 T_2}{p_2 T_1} = 1.517$。
$$\Delta S_{\text{sys}} = 0.25 \times [0.747 \times \ln\left(\frac{298}{393}\right) + 0.297 \times \ln(1.517)] = 0.25 \times (-0.206 + 0.124)$$
$$= -0.0206\text{kJ/K}$$
外界（环境）熵变：
$$\Delta S_{\text{sur}} = \frac{|Q|}{T_0} = 9.74/298 = 0.0327\text{kJ/K}$$
$$\Delta S_{\text{iso}} = \Delta S_{\text{sys}} + \Delta S_{\text{sur}} = -0.0206 + 0.0327 = 0.0121\text{kJ/K} > 0$$
孤立系统熵增大于零，故该过程不可逆。

(1) 低压缸出口压力$p_2$
两级压缩、级间冷却到初温、耗功最少时，中间压力为：
$$p_2 = \sqrt{(p_1 p_3)} = \sqrt{(0.1 \times 1.6)} = \sqrt{0.16} = 0.4\text{MPa}$$
每级压比$\pi = \frac{p_2}{p_1} = \frac{p_3}{p_2} = 4$。
(2) 压气机所耗总功率
多变压缩技术功（每级，两级进气温度相同均为$T_1$）：
$$W_t = \frac{n}{n-1} R_g T_1 [\pi^{\frac{n-1}{n}} - 1]$$
