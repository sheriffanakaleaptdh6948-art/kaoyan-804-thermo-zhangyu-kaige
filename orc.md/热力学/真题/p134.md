已知：$p_1=0.75\text{ MPa}$，$T_1=750^\circ\text{C}=1023\text{ K}$，$p_2=0.1\text{ MPa}$，$T_2=320^\circ\text{C}=593\text{ K}$，$p_0=0.1\text{ MPa}$，$T_0=298\text{ K}$，$R_g=0.287\text{ kJ/(kg}\cdot\text{K)}$，$c_p=1.004\text{ kJ/(kg}\cdot\text{K)}$

$$k = \frac{c_p}{c_p - R_g} = \frac{1.004}{1.004 - 0.287} = 1.4$$

(1) 实际过程输出的内部功 $W_i$：
绝热过程，$q=0$ 由稳定流动能量方程：
$$W_i = h_1 - h_2 = c_p(T_1 - T_2)$$
$$W_i = 1.004 \times (1023 - 593) = 1.004 \times 430 = 431.72\text{ kJ/kg}$$
判断是否可逆：
计算变：
$$\Delta s = c_p \ln\left(\frac{T_2}{T_1}\right) - R_g \ln\left(\frac{p_2}{p_1}\right)$$
$$\Delta s = 1.004 \times \ln\left(\frac{593}{1023}\right) - 0.287 \times \ln\left(\frac{0.1}{0.75}\right)$$
$$\Delta s = 1.004 \times (-0.548) - 0.287 \times (-2.015) = -0.550 + 0.578 = 0.028\text{ kJ/(kg}\cdot\text{K)}$$
$\Delta s > 0$，过程不可逆。

(2) 最大有用功 $W_{\text{max}}$：
$$W_{\text{max}} = (h_1 - h_2) - T_0(s_1 - s_2)$$
$$W_{\text{max}} = 431.72 - 298 \times (-0.028) = 431.72 + 8.34 = 440.06\text{ kJ/kg}$$

(3) 损失 $I$：
$$I = T_0 \cdot \Delta s_{\text{iso}}$$
$$\Delta s_{\text{iso}} = \Delta s = 0.028\text{ kJ/(kg}\cdot\text{K)}$$
$$I = 298 \times 0.028 = 8.34\text{ kJ/kg}$$

(4) 可逆绝热膨胀的理论内部功 $W_{i,\text{rev}}$：
可逆绝热过程（等熵过程）：
$$T_{2s} = T_1 \times \left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}}$$
$$T_{2s} = 1023 \times \left(\frac{0.1}{0.75}\right)^{\frac{0.4}{1.4}} = 1023 \times 0.553 = 575.3\text{ K}$$
$$W_{i,\text{rev}} = c_p(T_1 - T_{2s}) = 1.004 \times (1023 - 565.7) = 1.004 \times 457.3 = 449.5\text{ kJ/kg}$$
讨论 $I$ 与 $(W_{i,\text{rev}} - W_i)$ 的关系：
$$W_{i,\text{rev}} - W_i = 17.78\text{ kJ/kg}$$
$I = 8.34\text{ kJ/kg}$，而 $W_{i,\text{rev}} - W_i = 17.78\text{ kJ/kg}$，两者不相同。
