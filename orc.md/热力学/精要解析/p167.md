由于工程实际情况不同，有时需要对湿空气吸入一定的水分，即所谓加湿过程，这种加湿过程可采用如下一些方法：

(1) 干球温度不变的定干球温度加湿方法；

(2) 相对湿度不变的定相对湿度加湿方法；

(3) 绝热条件下的绝热加湿方法。

分别按各种调湿过程将湿空气调节为要求的湿空气。已知：$t_{1}=12\ \mathrm{^{\circ}C}$，$p_{1}=100\ \mathrm{kPa}$，$\varphi_{1}=25\%$，$d_{2}=5 \times 10^{-3}\ \mathrm{kg/kg}$（干空气），湿空气进入房间的体积流量 $V_{V}=60\ \mathrm{m}^{3}/\mathrm{min}$，加湿水温为 $12\ \mathrm{^{\circ}C}$。试确定：

(1) 加湿后的相对湿度 $\varphi_{2}$；

(2) 加湿后的空气温度 $t_{2}$；

(3) 热流量 $\dot{Q}$。

解 1. 按定干球温度加湿过程

参见图 7-11，由已知的 $t_{1}=12\ \mathrm{^{\circ}C}$，$\varphi_{1}=25\%$ 在图上可以定出调湿前湿空气的状态点 1。由 $t_{2}$ $=t_{1}$ 和 $d_{2}=5 \times 10^{-3}\ \mathrm{kg/kg}$（干空气）可确定调湿后

的湿空气状态点 2，则 $1-2$ 为定干球温度的调湿过程。查得 $\varphi_{2}=55\%$。

当水喷入湿空气后，湿空气的含湿量增加，干球温度要下降，为保持干球温度不变，则必须同时加入热量。

据稳定流动能量方程

$\dot{Q}=q_{m,\text { a }}\left(h_{2}-h_{1}\right)-q_{m,\text { w }} h^{\prime}$

其中，$q_{m,\text { a }}$ 由下式求得

$q_{m}=q_{m,\text { a }}+q_{m,\text { a }} d_{1}=q_{m,\text { a }}\left(1+d_{1}\right)=\frac{q_{V}}{v_{1}}$

则

$q_{m,\text { a }}=\frac{q_{V} / v_{1}}{1+d_{1}}$

由 $h-d$ 图上读得

$\begin{aligned} & v_{1}=0.821 \mathrm{~m}^{3} / \mathrm{kg} \text { (干空气) }, \quad d_{1}=0.0023 \mathrm{~kg} / \mathrm{kg} \text { (干空气) } \\ & h_{1}=17.7 \mathrm{~kJ} / \mathrm{kg} \text { (干空气) }, \quad h_{2}=25.0 \mathrm{~kJ} / \mathrm{kg} \text { (干空气) } \end{aligned}$

另外按 $12\ \mathrm{^{\circ}C}$ 查饱和水蒸气表，饱和水的焓 $h^{\prime}=50.37\ \mathrm{kJ/kg}$

于是

$q_{m,\text { a }}=\frac{60 \mathrm{~m}^{3} / \mathrm{min}}{0.821 \mathrm{~m}^{3} / \mathrm{kg} \text { (干空气) }} \times \frac{1}{1+0.0023 \mathrm{~kg} / \mathrm{kg} \text { (干空气) }}=72.91 \mathrm{~kg} / \mathrm{min}$

根据质量守恒，加湿后加入的水

$\begin{aligned} q_{m, \mathrm{w}} & =q_{m, \mathrm{a}}\left(d_{2}-d_{1}\right) \\ & =72.91 \mathrm{~kg} / \mathrm{min}\left(5 \times 10^{-3}-0.0023\right) \mathrm{kg} / \mathrm{kg} \text { (干空气) } \\ & =0.1969 \mathrm{~kg} / \mathrm{min} \end{aligned}$
