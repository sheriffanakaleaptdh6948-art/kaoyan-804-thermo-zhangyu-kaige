讨论

本例题加了一些第二定律的讨论，可看到压缩机、燃气轮机和放热过程引起的可用能损失占输入可用能的百分数分别为 $\frac{i_{\mathrm{C}}}{e_{\mathrm{x}, q}} = 7.36 \%$，$\frac{i_{\mathrm{T}}}{e_{\mathrm{x}, q}} = 8.35 \%$，$\frac{i_{4^{\prime}-1}}{e_{\mathrm{x}, q}} = 46.6 \%$。显然，放热过程的损失最大且几乎占了一半。实际上，简单燃气轮机的排气温度还较高，可利用之来加热压气机出口的气体，以达到降低排气余热浪费和节约热能的目的，这就是燃气轮机装置的回热循环。

例题 10-13 燃气轮机装置循环的 T-S 图如图 10-35 所示。若工质视为空气，空气进入压气机的温度为 $17^{\circ} \mathrm{C}$，压力为 $100 \mathrm{kPa}$，循环增压比 $\pi = 5$，燃气轮机进口温度为 $810^{\circ} \mathrm{C}$，且压气机绝热效率 $\eta_{\mathrm{c}, \mathrm{s}} = 0.85$，燃气轮机相对内效率 $\eta_{\mathrm{T}} = 0.88$，空气的质量流量为 $4.5 \mathrm{~kg} / \mathrm{s}$。试计算：在理想极限回热时，及由于回热器有温差传热、回热度 $\sigma = 0.65$ 时，实际循环输出的净功率和循环热效率各为多少？

解 (1) 先确定各状态点的温度

点 1: $T_{1} = 290 \mathrm{~K}$

点 2: $T_{2} = T_{1}\left(\frac{p_{2}}{p_{1}}\right)^{(\kappa-1) / \kappa} = T_{1} \pi^{(\kappa-1) / \kappa} = 290 \mathrm{~K} \times 5^{0.4 / 1.4} = 459.3 \mathrm{~K}$

点 $2^{\prime}$: $T_{2^{\prime}} = \frac{T_{2} - T_{1}}{\eta_{\mathrm{c}, \mathrm{s}}} + T_{1}$

$$= \frac{459.3 \mathrm{~K} - 290 \mathrm{~K}}{0.85} + 290 \mathrm{~K} = 489.2 \mathrm{~K}$$

点 3: $T_{3} = 1083 \mathrm{~K}$

点 4: $T_{4} = T_{3} \frac{1}{\pi^{(\kappa-1) / \kappa}} = 1083 \mathrm{~K} \times \frac{1}{5^{0.4 / 1.4}} = 683.8 \mathrm{~K}$

点 $4^{\prime}$: $T_{4^{\prime}} = T_{3} - \eta_{\mathrm{T}}\left(T_{3} - T_{4}\right)$

$$= 1083 \mathrm{~K} - 0.88(1083 \mathrm{~K} - 683.8 \mathrm{~K}) = 731.7 \mathrm{~K}$$

点 5: $T_{5} = T_{4^{\prime}} = 731.7 \mathrm{~K}$

点 $5^{\prime}$: 由 $\sigma = \frac{T_{5^{\prime}} - T_{2^{\prime}}}{T_{5} - T_{2^{\prime}}}$ 得

$$T_{5^{\prime}} = T_{2^{\prime}} + \sigma\left(T_{5} - T_{2^{\prime}}\right) = 489.2 \mathrm{~K} + 0.65(731.7 \mathrm{~K} - 489.2 \mathrm{~K}) = 646.8 \mathrm{~K}$$

点 6: $T_{6} = T_{2^{\prime}} = 489.2 \mathrm{~K}$

点 $6^{\prime}$: 由 $\sigma = \frac{T_{4^{\prime}} - T_{6^{\prime}}}{T_{4^{\prime}} - T_{6}}$ 得

$$T_{6^{\prime}} = T_{4^{\prime}} - \sigma\left(T_{4^{\prime}} - T_{6}\right) = 731.7 \mathrm{~K} - 0.65(731.7 \mathrm{~K} - 489.2 \mathrm{~K}) = 574.1 \mathrm{~K}$$
