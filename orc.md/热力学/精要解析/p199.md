2. 不同压缩过程的比较

压缩过程可能出现 3 种情况：第 1 种是过程中对气体未采取冷却措施，过程可视为绝热压缩；第 2 种是气体被充分冷却，过程接近定温压缩；第 3 种是压气机的实际压缩过程，虽采用了一定的冷却措施，但气体又未能充分冷却，所以压缩过程为定温与绝热之间的多变过程。不同压缩过程的热力分析和比较如下。

(2) 排气温度的计算与比较

定熵过程 $ T_{2s}=T_{1}\left(\frac{p_{2}}{p_{1}}\right)^{(n-1)/\kappa} $

多变过程 $ T_{2n}=T_{1}\left(\frac{p_{2}}{p_{1}}\right)^{(n-1)/n} $

定温压缩 $ T_{2T}=T_{1} $

(3) 压气机耗功的计算与比较

定熵压缩

$\begin{aligned}&w_{t,s}=\frac{\kappa}{\kappa-1} R_{g} T_{1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{(n-1)/\kappa}\right] \\&=p-v \text { 图上面积 } 1-2_{s}-b-a-1 \\&=T-s \text { 图上 } 1-2_{s}-2_{T}-c-e-1\end{aligned}$

多变压缩

$\begin{aligned}&w_{1,n}=\frac{n}{n-1} R_{g} T_{1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{(n-1)/n}\right] \\&=p-v \text { 图上面积 } 1-2_{n}-b-a-1 \\&=T-s \text { 图上面积 } 1-2_{n}-2_{T}-c-e-1\end{aligned}$

$ w_{\mathrm{i}, T}=R_{\mathrm{g}} T_{1} \ln \frac{v_{2}}{v_{1}}=-R_{\mathrm{g}} T_{1} \ln \frac{p_{2}}{p_{1}} $
