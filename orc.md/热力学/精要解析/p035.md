2.2.7 一般开口系的能量方程

一般开口系是指控制体积可膨胀的、空间各点参数随时间而变的非稳定流动系统。一般开口系是最普遍的热力系。闭口系和稳定流动系是它的特殊情况, 工程上的充气、抽气、容器泄漏以及热机启动和停机阶段, 都是一般开口系。

一般开口系经过微元过程, 其能量方程为

$\mathrm{d} Q=\mathrm{d} E_{\mathrm{cv}}+\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {out }} \delta m_{\text {out }}-\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {in }} \delta m_{\text {in }}+\delta W_{\text {net }}$

式中: $W_{\text {net }}$ 为开口系与外界交换的净功, 应包括通过转轴而传送的轴功, 以及系统除进、出口边界推动功外, 在开口系其他运动边界上完成的功。

用传热率、功率等形式表示的开口系能量方程为

$\dot{Q}=\frac{\mathrm{d} E_{\mathrm{cv}}}{\mathrm{d} \tau}+q_{m, \text { out }}\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {out }}-q_{m, \text { in }}\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {in }}+\dot{W}_{\text {net }}$

如果进、出开口系统的工质有若干股, 则上式可写成

$\dot{Q}=\frac{\mathrm{d} E_{\mathrm{cv}}}{\mathrm{d} \tau}+\sum q_{m, \text { out }}\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {out }}-\sum q_{m, \text { in }}\left(h+\frac{1}{2} c_{\mathrm{f}}^{2}+g z\right)_{\text {in }}+\dot{W}_{\text {net }}$

式 $(2-13 \mathrm{a}) \sim(2-13 \mathrm{c})$ 是开口系能量方程的一般形式, 结合具体情况常可简化成各种不同的形式。
