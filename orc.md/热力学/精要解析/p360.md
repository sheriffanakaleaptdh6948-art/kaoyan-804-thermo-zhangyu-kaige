(1) 热力学第二定律实质描述自发过程的不可逆性，或能量转换的方向性，或能量的品质性。

热力学第二定律得数学表达式：

$\begin{aligned}& \eta_{i} \leqslant \eta_{\mathrm{i}, \mathrm{c}}=1-\frac{T_{2}}{T_{1}} \\& \mathrm{ds} \geqslant \frac{\delta q}{T} \text { 或 } \oint \frac{\delta q}{T} \leqslant 0\end{aligned}$

或者孤立系: ds is o ≥ 0

双热源热机: ηi ≤ ηi,c = 1 - T2/T1;

过程: ds ≥ δq/T；循环：∮δq/Tr ≤ 0；

孤立系: dsiso ≥ 0

(2) 系统是处于热力学平衡状态，因为该体系仍然处于热平衡和力平衡状态，这是判断热力学平衡的充要条件。

(3) 稳定流动的系统能量方程为:

$q=\Delta h+\frac{1}{2} c_{p}+g \Delta z+w_{s}$

其应用于换热器: q = Δh; 应用于绝热节流装置: Δh = 0

(4) 不能通过敞开冰箱大门的方式来降低室内温度。因为取房间空气为一闭口系的话，则

$Q=\Delta U+W$

此时，Q > 0，W = 0

所以，ΔU > 0，

房间内的空气是理想气体，则 ΔU > 0，就说明房间空气的温度不但不能降低，反而会升高。

(5) 因为相同含湿量 d 情况下，温度 t 越高，相对湿度 φ 越小，湿空气吸收水分的能力就越强。

(6) pv = ZRgT，Z 表示相同温度、压力下实际气体的比体积与理想气体的比体积之比。

(7) 熵流是指热力系统由于质量或者热量变化而引起的熵变; 熵产是指热力系统由于不可逆因素而引起的熵变。

$\mathrm{dS}=\mathrm{dS}_{\mathrm{t}}+\mathrm{dS}_{\mathrm{g}}$，其中熵流 dSf 可正，可负，也可为零; 熵产只能 dSg ≥ 0

(8) 卡诺热机效率: ηc = 1 - T2/T1 = 1 - 283/300 = 0.057;

该热机效率: ηt = 100/1421 = 0.07 > ηc = 0.057，

所以该热机不可行，且违背热力学第二定律。

本题也可以通过判断是否满足 dsiso ≥ 0，来判断该热机是否可以实现。
