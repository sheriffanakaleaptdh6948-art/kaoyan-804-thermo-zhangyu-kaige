2. 工程上除了采用以分压表示的 $K_{p}$ 外, 还有用摩尔分数 $x_{i}$ 或浓度 $C_{i}$ 表示的平衡常数 $K_{x}$ 或 $K_{r}$ 。由于混合气体中各组元分压力 $p_{i}=x_{i} p$, 代入式 $(11-15 \mathrm{a})$ 可得

$K_{x}=\frac{x_{c}^{\gamma_{c}} x_{d}^{\gamma_{d}}}{x_{a}^{\gamma_{a}} x_{b}^{\gamma_{b}}}=K_{p}\left(\frac{p}{p_{0}}\right)^{\left(\gamma_{c}+\gamma_{d}-\gamma_{4}-\gamma_{b}\right)}=K_{p}\left(\frac{p}{p_{1}}\right)^{-\gamma_{4}}$

又因 $C_{i}=\frac{\gamma_{i}}{V}, p_{i}=\frac{\gamma_{i} R T}{V}=C_{i} R T$ 代入式 $(11-15 \mathrm{a})$ 得

$\begin{aligned} K_{C} & =\frac{C_{c}^{\gamma_{c}} C_{\mathrm{d}}^{\gamma_{\mathrm{d}}}}{C_{\mathrm{a}}^{\gamma_{\mathrm{a}}} C_{\mathrm{b}}^{\gamma_{\mathrm{b}}}}=K_{p}(R T)^{-\left(\gamma_{c}+\gamma_{d}-\gamma_{4}-\gamma_{b}\right)} \\ & =K_{p}(R T)^{-\Sigma \gamma_{i}} \end{aligned}$

式中: $K_{x} 、 K_{C}$ 分别是以摩尔分数和浓度表示的理想气体平衡常数。$K_{x}$ 一般与反应温度 $T$ 和反应总压力 $p$ 有关, 只有当反应前后的化学计量系数代数和为零时, $K_{x}$ 才只与反应温度有关, 而且在此情况下, $K_{x}=K_{p}=K_{C}$ 。$K_{C}$ 和 $K_{p}$ 一样只是温度的函数, 因此总压改变时对 $K_{p}$, $K_{C}$ 不产生影响, 但对 $K_{x}$ 产生影响。

3. 某些复杂的化学反应的平衡常数, 可利用已知的简单化学反应的平衡常数来计算。例如 $\mathrm{CO}+\mathrm{H}_{2} \mathrm{O} \rightleftharpoons \mathrm{CO}_{2}+\mathrm{H}_{2}$ 的平衡常数 $K_{\mathrm{p}, 1}$ 可利用 $\mathrm{CO}+\frac{1}{2} \mathrm{O}_{2} \rightleftharpoons \mathrm{CO}_{2}$ 的平衡常数 $K_{p, 2}$ 与 $\mathrm{H}_{2}+\frac{1}{2} \mathrm{O}_{2} \rightleftharpoons \mathrm{H}_{2} \mathrm{O}$ 的平衡常数 $K_{p, 3}$ 来确定。这 3 个平衡常数之间应符合 $K_{p, 1}=\frac{K_{p, 2}}{K_{p, 3}}$ 的关系。

4. 平衡常数的值与反应式的书写形式 (计量系数的取值) 和方向有关。如

$\mathrm{CO}+\frac{1}{2} \mathrm{O}_{2} \rightleftharpoons \mathrm{CO}_{2} \text { 及 } 2 \mathrm{CO}+\mathrm{O}_{2} \rightleftharpoons 2 \mathrm{CO}_{2}$

则

$K_{p, 1}=\left(K_{p, 2}\right)^{1 / 2}$

又

$K_{p, \text { 正向 }}=\frac{1}{K_{p, \text { 逆向 }}}$

5. 平衡常数的用途很多, 具体参见例题 $11-10$ 和 $11-11$ 。
