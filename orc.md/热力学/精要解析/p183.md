理想气体：

$\begin{aligned}& T_{0}=T_{1}+\frac{c_{\mathrm{fl}}^{2}}{2 c_{p}} \\& p_{0}=p_{1}\left(\frac{T_{0}}{T_{1}}\right)^{\kappa /(\kappa-1)} \\& v_{0}=v_{1}\left(\frac{T_{1}}{T_{0}}\right)^{1 /(\kappa-1)} \quad \text { 或 } \quad v_{0}=\frac{R_{\mathrm{g}} T_{0}}{p_{0}}\end{aligned}$

水蒸气：

$h_{0}=h_{1}+\frac{1}{2} c_{\mathrm{fl}}^{2}$

据 $h_{0}$ 及 $s_{0}=s_{1}$ 查图或表得到 $p_{0}$, 参见图 8-3。

(2) 选型

计算出 $\frac{p_{\mathrm{b}}}{p_{0}}$, 与 $\nu_{\mathrm{cr}}\left(=\frac{p_{\mathrm{cr}}}{p_{0}}\right)$ 比较:

若 $\frac{p_{\mathrm{b}}}{p_{0}} \geqslant \nu_{\mathrm{cr}}$, 选渐缩喷管

若 $\frac{p_{\mathrm{b}}}{p_{0}}<\nu_{\mathrm{cr}}$, 选缩放喷管

可见, 临界压力比 $\nu_{\mathrm{cr}}$ 非常重要, 它提供了选择喷管的依据。所以, 常见工质的 $\nu_{\mathrm{cr}}$ 应记住。

双原子理想气体: $\nu_{\mathrm{cr}}=0.528$

多原子理想气体: $\nu_{\mathrm{cr}}=0.546$

(3) 求临界截面和出口截面上气体的状态参数

$p_{\mathrm{cr}}=\nu_{\mathrm{cr}} p_{0} ; \quad p_{2}=p_{\mathrm{b}}$

理想气体:

$\begin{gathered}T_{\mathrm{cr}}=T_{0} \nu_{\mathrm{cr}}^{(\kappa-1) / \kappa} ; \quad T_{2}=T_{0}\left(\frac{p_{2}}{p_{0}}\right)^{(\kappa-1) / \kappa} ; \\v_{\mathrm{cr}}=\frac{R_{\mathrm{g}} T_{\mathrm{cr}}}{p_{\mathrm{cr}}} ; \quad v_{2}=\frac{R_{\mathrm{g}} T_{2}}{p_{2}}\end{gathered}$
