(2) 为求解循环各过程的热量、膨胀功和技术功，需先确定各状态点的有关状态参数。各状态点的已知参数：$t_1 = 20^\circ \mathrm{C}$, $p_1 = 0.4 \mathrm{MPa}$；

$t_2 = 200^\circ \mathrm{C}$, $p_2 = 0.4 \mathrm{MPa}$；

$t_3 = 100^\circ \mathrm{C}$, $t_4 = 20^\circ \mathrm{C}$

于是，各状态点的其他状态参数为

$v_2 = \frac{R_g T_2}{p_2} = \frac{0.287 \times (200 + 273)}{0.4 \times 10^3} = 0.3394 \, \mathrm{m}^3/\mathrm{kg}$

$v_4 = v_3 = v_2 \left( \frac{T_2}{T_3} \right)^{\frac{1}{2-1}} = 0.3394 \times \left( \frac{473}{373} \right)^{\frac{1}{2-1}} = 6146 \, \mathrm{m}^3/\mathrm{kg}$

$p_4 = \frac{R_g T_4}{v_4} = \frac{0.287 \times 10^3 \times 293}{0.6146} = 0.1368 \times 10^6 \, \mathrm{Pa} = 0.1368 \, \mathrm{MPa}$

则循环各过程的热量、膨胀功和技术功分别为：

1-2 定压过程：

$q_{12} = c_p (t_2 - t_1) = 1.004 \times (200 - 20) = 180.7 \, \mathrm{kJ/kg}$

$w_{12} = p_1 (v_2 - v_1) = R_g (T_2 - T_1) = 0.287 \times 180 = 51.6 \, \mathrm{kJ/kg}$

$w_{1,12} = 0$

2-3 可逆绝热过程：

$q_{23} = 0$

$w_{23} = \frac{R_g}{\kappa - 1} (T_2 - T_3) = \frac{0.287}{0.4} \times (200 - 100) = 71.75 \, \mathrm{kJ/kg}$

$w_{1,23} = \kappa w_{23} = 1.4 \times 71.75 = 100.45 \, \mathrm{kJ/kg}$

3-4 定容过程：

$q_{34} = c_V (T_4 - T_3) = \frac{c_p}{\kappa} (T_4 - T_3) = \frac{1.004}{1.4} \times (20 - 100) = -57.37 \, \mathrm{kJ/kg}$

$w_{34} = 0$

$w_{1,34} = -v_3 (p_4 - p_3) = -R_g (T_4 - T_3) = -0.287 \times (20 - 100) = 22.96 \, \mathrm{kJ/kg}$
