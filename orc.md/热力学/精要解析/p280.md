$Q_{p}$ 与 $Q_{V}$ 之间的关系

$\begin{aligned}Q_{p}-Q_{V} & =R T\left(n_{\mathrm{P}}-n_{\mathrm{R}}\right) \\& =R T \sum \gamma_{i, g}\end{aligned}$

是反应物和生成物中的气态物质可按理想气体处理，且是同温度下的 $Q_{p}$ 与 $Q_{V}$ 的关系。

$\sum \gamma_{i, g}$ 是指生成物与反应物中气态物质化学计量系数的代数和，而其中的液态物质或固态物质的化学计量系数可忽略不计。

绝热燃烧热平衡式

$\begin{aligned}-Q_{p}^{0} & =-\Delta H^{0}=\left.\sum_{\mathrm{P}} n \mathrm{C}_{\mathrm{m}}\right|_{T} ^{T}\left(T_{\mathrm{P}}-T\right)- \\& \left.\sum_{\mathrm{R}} n \mathrm{C}_{\mathrm{m}}\right|_{T / T_{0}}^{T}\left(T_{\mathrm{R}}-T\right)\end{aligned}$

若已知反应物的温度 $T_{\mathrm{R}}$，用试凑法可求得绝热燃烧温度 $T_{\mathrm{ad}}$。

孤立系统的熵判据

$\begin{array}{ll}>\quad \text { 自发 } \\\mathrm{dS}_{\mathrm{iso}}=0 & \text { 可逆过程 } \\\underbrace{()}_{<} & \text { 非自发 }\end{array}$

$\mathrm{d} S_{\mathrm{iso}}=0, \quad \mathrm{~d}^{2} S_{\mathrm{iso}}<0$ 化学平衡

定温定容反应系统的亥姆霍兹函数判据

$\begin{array}{ll}

\begin{aligned}

& <\quad \text { 自发 } \\

& \mathrm{d} F_{T, v}=0 \quad \text { 可逆过程 } \\

& >\quad \text { 非自发 }

\end{aligned}$$

$\mathrm{d} F_{T, v}=0, \quad \mathrm{~d}^{2} F_{T, v}>0$, 化学平衡

定温定压反应系统的吉布斯函数判据

$\begin{array}{ll}

\begin{aligned}

& <\quad \text { 自发 } \\

& \mathrm{d} G_{T, p}=0 \quad \text { 可逆过程 } \\

& >\quad \text { 非自发 }

\end{aligned}$$

$\mathrm{d} G_{T, p}=0, \quad \mathrm{~d}^{2} G_{T, p}>0$, 化学平衡
