(4) 抽汽系数的计算

取混合式加热器为热力系, 由能量平衡可得

$\alpha_{1}=\frac{h_{01}^{\prime}-h_{5}}{h_{01}-h_{5}}=\frac{(633-375) \mathrm{kJ} / \mathrm{kg}}{(2804-375) \mathrm{kJ} / \mathrm{kg}}=0.106$

又如图 10-44 所示, 取表面式加热器为热力系, 并进行能量和质量平衡计算, 则

$\begin{aligned}& \alpha_{2}\left(h_{02}-h_{02}^{\prime}\right)=\left(1-\alpha_{1}\right)\left(h_{5}-h_{4}\right) \\& \alpha_{2}=\left(1-\alpha_{1}\right) \frac{h_{5}-h_{4}}{h_{02}-h_{02}^{\prime}} \\& =(1-0.106) \frac{(375-121) \mathrm{kJ} / \mathrm{kg}}{(2488-375) \mathrm{kJ} / \mathrm{kg}}=0.107\end{aligned}$

(5) 循环功率计算

$\begin{aligned}w_{\text {net }} &\approx w_{\mathrm{T}}=h_{1}-\alpha_{1} h_{01}-\alpha_{2} h_{02}-\left(1-\alpha_{1}-\alpha_{2}\right) h_{2} \\& =3306 \mathrm{~kJ} / \mathrm{kg}-0.106 \times 2804 \mathrm{~kJ} / \mathrm{kg}-0.107 \times 2488 \mathrm{~kJ} / \mathrm{kg} \\& -(1-0.106-0.107) \times 2090 \mathrm{~kJ} / \mathrm{kg} \\& =1097.7 \mathrm{~kJ} / \mathrm{kg}\end{aligned}$

(6) 循环热效率和汽耗率

循环吸热量

$q_{1}=h_{1}-h_{7}=(3306-633) \mathrm{kJ} / \mathrm{kg}=2673 \mathrm{~kJ} / \mathrm{kg}$

循环热效率

$\eta=\frac{w_{\text {net }}}{q_{1}}=\frac{1097.7 \mathrm{~kJ} / \mathrm{kg}}{2673 \mathrm{~kJ} / \mathrm{kg}}=0.410$

循环汽耗率

$d=\frac{3600}{w_{\text {net }}}=\frac{3600}{1097.7}=3.279 \mathrm{~kg} /(\mathrm{kW} \cdot \mathrm{h})$

(7) 与同参数朗肯循环的比较

同参数朗肯循环的热效率为

$\eta_{\mathrm{R}}=\frac{h_{1}-h_{2}}{h_{1}-h_{4}}=\frac{(3306-2090) \mathrm{kJ} / \mathrm{kg}}{(3306-121) \mathrm{kJ} / \mathrm{kg}}=0.381$

回热使循环效率提高

$0.410-0.381=0.029$

相对值为

$\frac{0.029}{0.381}=7.6 \%$
