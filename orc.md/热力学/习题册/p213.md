(1) 定压吸热，满足 \( q_{\mathrm{p}} = h_{\mathrm{x}} - h^{\prime} = 628 \, \mathrm{kJ/kg} \)，即： \( x h^{\prime} + (1 - x) h^{\prime} - h^{\prime} = 628 \, \mathrm{kJ/kg} \)。

整理得: \( x ( h^{\prime} - h^{\prime} ) = 628 \, \mathrm{kJ/kg} \)。

所以 \( x r = 628 \, \mathrm{kJ/kg} \)，可得:

$$ x = 628 / 1294 = 0.4583 $$

(2) \( q_{\mathrm{p}} = \Delta u + w = \Delta u + p \Delta v \)。

\[ \Delta v = ( q_{\mathrm{p}} - \Delta u ) / p = ( 628 - 418.7 ) / ( 0.3 \times 10^{6} ) = 0.6997 ( \mathrm{~m}^{3} / \mathrm{kg} ) \]

(3) 由题意可知, \( \Delta s = s_{\mathrm{x}} - s^{\prime} = x s^{\prime} + (1 - x) s^{\prime} - s^{\prime} = x ( s^{\prime} - s^{\prime} ) \)，\( s^{\prime} - s^{\prime} = \frac{r}{T} \)，所以:

\[ \Delta s = x \frac{r}{T} = 0.4583 \times \frac{1294}{263.15} = 2.3864 ( \mathrm{kJ/(kg \cdot K)} ) \]
