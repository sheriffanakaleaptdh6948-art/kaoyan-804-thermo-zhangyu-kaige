$\begin{aligned} & \text { 【2-41】(中国科学院一中国科学技术大学 2006 年考研试题)某燃气轮机装置中燃烧室的 } \\ & \text { 温度为 } 1700^{\circ} \mathrm{C} \text {, 来自压气机的压缩空气的温度为 } 210^{\circ} \mathrm{C} \text { 。根据燃气轮机叶片强度的要求, 进入 } \\ & \text { 燃气轮机的气体温度不得超过 } 850^{\circ} \mathrm{C} \text { 。试确定来自燃烧室的燃气与自来压气机的压缩空气的混合 } \\ & \text { 比例。设燃烧室燃气的比热 } c_{\mathrm{P} 1}=1.170 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}) \text {, 压缩空气的比热 } c_{\mathrm{P} 2}=1.00 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}) \text { 。 } \\ & \text { 解: 设 } 1 \mathrm{kg 燃气需 } m \mathrm{kg} \text { 的空气与之混合, 则由理想气体混合物比热容公式得混合气体的比 } \\ & \text { 热容为: } \\ & c_{\mathrm{P} 3}=\frac{1}{1+m} c_{\mathrm{P} 1}+\frac{m}{1+m} c_{\mathrm{P} 2} \end{aligned}$

又可知, 开口系稳定流动方程为: $Q=\Delta H+W_{\mathrm{t}}$ 。

因混合过程绝热且不做功, 故有: $Q=0, W_{\mathrm{t}}=0$ 。

所以, 混合前后 $\Delta H=0$, 即:

$$c_{\mathrm{P} 1} T_{1}+m c_{\mathrm{P} 2} T_{2}=\left(1+m\right) c_{\mathrm{P} 3} T_{3}$$

将所得的 $c_{\mathrm{P} 3}$ 式代入, 有:

$$c_{\mathrm{P} 1} T_{1}+m c_{\mathrm{P} 2} T_{2}=\left(c_{\mathrm{P} 1}+m c_{\mathrm{P} 2}\right) T_{3}$$

所以有:

$$m=\frac{c_{\mathrm{P} 1}\left(T_{1}-T_{3}\right)}{c_{\mathrm{P} 2}\left(T_{3}-T_{2}\right)}=\frac{1.170 \times(1700-850)}{1.004 \times(850-210)}=1.55(\mathrm{~kg})$$

故燃气与空气混合比为 $1: 1.55$ 。
