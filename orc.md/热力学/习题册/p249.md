$\begin{aligned}& \text { 【10-51】(南京航空航天大学 2008 年考研试题)判断题: 喷管内稳定流动气体在各 } \\& \text { 的流速不同, 但各截面上的流量相同。 } \\& \text { 答案: 对 } \\& \text { 【10-52】(南京航空航天大学 2008 年考研试题) 判断题: 若缩放喷管进口截面上工质的参数不变, 背压提高 (仍小于临界压力), 则流经喷管的流量下降。 } \\& \text { 答案: 错 } \\& \text { 解析: 只要背压小于临界压力, 流经喷管的流量就保持不变。 } \\& \text { 【10-53】(南京航空航天大学 2008 年考研试题) 喷管中作可逆绝热流动时, 进口的定熵滞止参数与出口的定熵滞止参数是否相同? 作不可逆绝热流动时又如何? } \\& \text { 解: 喷管中作可逆绝热流动时, 进口的定熵滞上参数与出口的定熵滞止参数是相同的。作不可逆绝热流动时, 总焓、总温是相同的, 但总压是下降的。 } \\& \text { 【10-54】(南京航空航天大学 2008 年考研试题) 某理想气体 } c_{p}=1 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}), \kappa=1.4, \text { 可 } \\& \text { 逆绝热地流过渐缩喷管出口时, 恰好处于临界工况, 若测得喷管中间某截面的空气流速 } \\& \text { 为 } 165 \mathrm{~m} / \mathrm{s}, p=0.7 \mathrm{MPa}, t=300^{\circ} \mathrm{C}, \text { 求喷管出口截面空气流速、压力及温度。若上述气体不可 } \\& \text { 逆绝热地流过喷管时, 试将不可逆过程的作功能力损失定性地表示在 } T-s \text { 图上。 } \\& \text { 解: 依题意可知, } \kappa=\frac{c_{p}}{c_{v}}, R_{g}=0.286 \mathrm{~kJ} / \mathrm{kg} \cdot \mathrm{K} \text { 。因为喷管出口为临界, 所以恰好有: } \\& c_{f 2}=c_{2} \\& \text { 可求得入口处的温度为: } \\& T_{0}=T+\frac{c_{p}^{2}}{2 c_{p}}=573+\frac{165^{2}}{2 \times 1000}=586.6(\mathrm{~K}) \\& \text { 又由 } T_{0}=T_{2}+\frac{c_{f 2}^{2}}{2 c_{p}}=T_{2}+\frac{c_{2}^{2}}{2 c_{p}}=T_{2}+\frac{\kappa R_{g} T_{2}}{2 c_{p}} \text {, 可求得出口处的温度为: } \\& T_{2}=\frac{T_{0}}{1+\frac{\kappa R_{g}}{2 c_{p}}}=\frac{586.6}{1+\frac{1.4 \times 0.286}{2 \times 1}}=488.8(\mathrm{~K})\end{aligned}$

出口截面的温度为当地音速, 即:

$c_{f 2}=c_{2}=\sqrt{\kappa R_{g} T_{2}}=\sqrt{1.4 \times 286 \times 488.8}=442.4(\mathrm{~m} / \mathrm{s})$

出口截面的压力可求得为:

$p_{2}=p \times\left(\frac{T_{2}}{T}\right)^{\frac{\kappa}{\kappa-1}}=0.7 \times\left(\frac{488.8}{573}\right)^{\frac{1.4}{1.4-1}}=0.4(\mathrm{MPa})$
