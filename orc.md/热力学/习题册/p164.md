【5-48】 (清华大学 2004—2005 学年第 1 学期期中考试试题) 某正循环可逆热机,在温度为 $30^{\circ} \mathrm{C}$ 的环境和 4000kg 的 $0^{\circ} \mathrm{C}$ 的冰间工作,最后 $0^{\circ} \mathrm{C}$ 的冰变为 $30^{\circ} \mathrm{C}$ 的水,试求可逆热机对外作的净功为多少? 已知冰的溶解热为 $333 \mathrm{~kJ} / \mathrm{kg}$ (冰在溶解过程中温度不变),水的比热容 $c=4.1868 \mathrm{~kJ} / \mathrm{kg} . \mathrm{K}$ 。

解:可逆机工作过程如图 5-18 所示。

解法一:系统可逆时:

$\Delta S_{\text {iso }}=0, W=W_{\text {max }}$

$\Delta S_{\text {iso }}=\Delta S_{\mathrm{T}_{0}}+\Delta S_{\text {ice }}=\frac{Q_{0}}{T_{0}}+\frac{m \gamma}{T_{i}}+m c_{\mathrm{w}} \ln \frac{T_{0}}{T_{i}}=0$

$Q_{2}=m \gamma+m c_{\mathrm{w}} \Delta T=\left\{\begin{array}{l} 1.834 \times 10^{6} \mathrm{kJ} \text { (冰 } 4000 \mathrm{~kg}) \\ 9.172 \times 10^{5} \mathrm{kJ} \text { (冰 } 2000 \mathrm{~kg}) \end{array}\right.$

$Q_{0}=\left\{\begin{array}{l} -2.007 \times 10^{6} \mathrm{kJ} \text { (冰 } 4000 \mathrm{~kg}) \\ -1.004 \times 10^{6} \mathrm{kJ} \text { (冰 } 2000 \mathrm{~kg}) \end{array}\right.$

$W_{\text {max }}=\left|Q_{0}\right|-Q_{2}=\left\{\begin{array}{l} 1.715 \times 10^{5} \mathrm{kJ} \text { (冰 } 4000 \mathrm{~kg}) \\ 8.651 \times 10^{4} \mathrm{kJ} \text { (冰 } 2000 \mathrm{~kg}) \end{array}\right.$

解法二:用冷量 Exergy 求解。可逆过程中:

$W=W_{\max }=E_{x, Q_{2}}$

$E_{x, Q_{2}}=\left(\frac{T_{0}}{T_{i}}-1\right) m \gamma+\int_{T_{i}}^{T_{0}}\left(\frac{T_{0}}{T}-1\right) \delta Q_{2}=\left(\frac{T_{0}}{T_{i}}-1\right) m \gamma+T_{0} \Delta S_{2, \text { water }}-Q_{2}, \text { water }$
