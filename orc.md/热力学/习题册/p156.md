(1) 换热过程熵产及做功能力损失。

(2) 若在烟气和空气间设置一可逆机利用热机排热加热空气, 求空气终温和热机效率。

解:

(1) 由能量守恒定律得:

$$\dot{m}_{\text {烟 }} c_{\mathrm{p}} \text { 烟 }\left(T_{1 \text { 烟 }}-T_{2 \text { 烟 }}\right)=\dot{m}_{\text {空 }} c_{\mathrm{p}} \text { 空 }\left(T_{2 \text { 空 }}-T_{1 \text { 空 }}\right)$$

可求的状态 2 下空气的温度为:

$$T_{2 \text { 空 }}=\frac{\dot{m}_{\text {烟 }}}{\dot{m}_{\text {空 }}} c_{\mathrm{p}} \text { 烟 }\left(T_{1 \text { 烟 }}-T_{2 \text { 烟 }}\right)+T_{1 \text { 空 }}=\frac{50000 \times 1.088(315-205)}{46500 \times 1.004}+273+37=438(\mathrm{~K})$$

系统熵增为:

$$\begin{aligned} \Delta S & =\dot{m}_{\text {烟 }} \Delta S_{\text {烟 }}+\dot{m}_{\text {空 }} \Delta S_{\text {空 }}=50000 \int_{315+273}^{205+273} \frac{c_{\mathrm{p}}}{T} \mathrm{~d} T+46500 \int_{273+37}^{438} \frac{c_{\mathrm{p}}}{T} \mathrm{~d} T \\ & =50000 \times 1.088 \ln \frac{205+273}{315+273}+46500 \times 1.004 \ln \frac{438}{273+37} \\ & =4869.7 \mathrm{~kJ} /(\mathrm{K} \cdot \mathrm{h}) \end{aligned}$$

做功能能力损失为:

$$I=T_{0} \Delta S=(273+37) \times 4869.7=1.51 \times 10^{6}(\mathrm{~kJ/h})$$

(2) 由孤立系熵增原理有: $\Delta S_{\text {iso }}=\Delta S_{\text {烟 }}+\Delta S_{\text {空 }}=0$ 。即:

$$\dot{m}_{\text {烟 }} \int_{588}^{478} \frac{c_{\mathrm{p}}}{T} \mathrm{~d} T+\dot{m}_{\text {空 }} \int_{310}^{T_{2}} \frac{c_{\mathrm{p}}}{T} \mathrm{~d} T=0$$

计算得空气的终温为: $T_{2}=394.5 \mathrm{~K}$ 。

故烟气放出的热量为:

$$Q_{1}=\dot{m}_{\text {烟 }} c_{\mathrm{p}}\left(T_{1 \text { 烟 }}-T_{2 \text { 烟 }}\right)=50000 \times 1.088 \times(315-105)=5.984 \times 10^{6}(\mathrm{~kJ/h})$$

空气吸收的热量为:

$$Q_{2}=\dot{m}_{\mathrm{c}} c_{\mathrm{p}}\left(T_{2 \text { 空 }}-T_{1 \text { 空 }}\right)=46500 \times 1.004 \times(394.5-273-37)=3.945 \times 10^{6}(\mathrm{~kJ/h})$$

则热机效率为:

$$\eta=1-\frac{Q_{2}}{Q_{1}}=1-\frac{3.945 \times 10^{6}}{5.984 \times 10^{6}}=34 \%$$

【5-16】 (同济大学 2006 年考研试题) 1000kg 温度为 $0^{\circ} \mathrm{C}$ 的冰, 在 $0^{\circ} \mathrm{C}$ 的大气环境中融化成 $0^{\circ} \mathrm{C}$ 的水, 这时热量的做功能力损失了。若在大气和这块冰之间放一可逆机, 求冰块完全融化时可逆机能做出的功 (冰的融化潜热为 $335 \mathrm{~kJ / kg}$ )。

解: 如图 5-10 所示, 将冰及周围大气作为研究对象, 放在孤立系统中分析, $0$ 度的冰融化成 $0$ 度的水所需要的热量为:

$$Q=m r=3.35 \times 10^{5} \mathrm{~kJ}$$

由孤立系熵增原理可知:

$$\Delta S_{\text {iso }}=\Delta S_{1}+\Delta S_{2}+\Delta S_{3}=\frac{3.35 \times 10^{5}}{273}-\frac{3.35 \times 10^{5}+\mathrm{W}}{273}=0$$

可得冰块完全融化时可逆机能做出的功为:

$W=0$
