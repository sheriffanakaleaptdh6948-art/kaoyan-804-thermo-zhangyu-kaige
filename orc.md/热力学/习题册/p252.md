解：

(1) 可逆膨胀时，熵不变，$\Delta s = 0, s_1 = s_2$，所以：$s_1 = x_2 s'' + (1 - x_2) s'$。

可以求到干度为：$x_2 = (s_1 - s')/(s'' - s') = 0.8345$。

又根据干度可以求得：$h_{2s} = x_2 h'' + (1 - x_2) h' = 2160.1 kJ/kg$。

所以汽轮机产生的功率为：

$$P = \dot{m} w_s = \dot{m} (h - h_{2s}) = \frac{30 \times 10^3}{3600} \times (3344.4 - 2160.1) = 9869 (\text{kW})$$

(2) 因为汽轮机的效率为 85%，故实际功率为：

$$P' = 0.85 P = 0.85 \times 9869 = 8389 (\text{kW})$$

可以根据汽轮机的效率求得：$h_2 = h_1 - 0.85 (h_1 - h_{2s}) = 2337.75 kJ/kg$。

又 $h_2 = x_2 h'' + (1 - x_2) h'$，所以求到这时的干度为：$x_2 = (h_2 - h'_2)/(h''_2 - h'_2) = 0.9078$。

所以熵为：

$$s_2 = x_2 s'' + (1 - x_2) s' = 7.665 kJ/(kg·K)$$

故熵变为：

$$\Delta s' = s_2 - s_1 = 7.665 - 7.0847 = 0.5803 kJ/(kg·K)$$
