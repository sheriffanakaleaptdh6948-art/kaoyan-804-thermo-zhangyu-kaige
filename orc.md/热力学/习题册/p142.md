【4-155】 (西安交通大学 2004 年考研试题) 采用两级活塞式压缩机将压力为 $0.1 \mathrm{MPa}$ 的空气压缩至 $2.5 \mathrm{MPa}$, 中间压力为多少时耗功最小?

解: 当两级的增压比相等时, 耗功达到最小值。最小值为:

$$p_{\text {opt }}=\sqrt{0.1 \times 2.5}=0.5 \mathrm{MPa}$$

【4-156】 (北京理工大学 2006 年考研试题) 一压气机, 要求将温度为 $295 \mathrm{~K}$ 的空气从 $0.1 \mathrm{MPa}$ 压缩到 $0.6 \mathrm{MPa}$ 。则此压气机的压比为多少? 如果采用单级压缩, 压缩过程为可逆绝热, 问压缩每 $\mathrm{kg}$ 空气需要耗功多少? 如果采用两级压缩, 级间最大程度冷却时, 最有利的中间压力为多少? 压缩功又为多少?

解: 此压气机压比为 $0.6 / 0.1=6$ 。

绝热指数为:

$$\kappa=\left(c_{\mathrm{V}}+R_{\mathrm{g}}\right) / c_{\mathrm{V}}=\left(0.717+0.287\right) / 0.717=1.4$$

采用单级压缩, 因可逆绝热过程, 可求得压缩终了气体的温度为:

$$T_{2}=T_{1}\left(p_{2} / p_{1}\right)^{(\kappa-1) / \kappa}=295 \times(6)^{(1.4-1) / 1.4}=492.2(\mathrm{~K})$$

消耗的功为:

$$W_{\mathrm{i}}=c_{\mathrm{p}}\left(T_{2}-T_{1}\right)=1.004 \times(492.2-295)=198(\mathrm{~kJ} / \mathrm{kg})$$

采用中间冷却, 最大可冷却到 $295 \mathrm{~K}$ 。最有利的中间压力为:

$$p_{2}=\sqrt{p_{3} p_{1}}=\sqrt{0.6 \times 0.1}=0.245(\mathrm{MPa})$$

该点冷却前温度为:

$$T_{2}=T_{1}\left(p_{2} / p_{1}\right)^{(\kappa-1) / \kappa}=295 \times(2.45)^{(1.4-1) / 1.4}=381.1(\mathrm{~K})$$

则耗功:

$$W_{\mathrm{i}}=2 c_{\mathrm{p}}\left(T_{2}-T_{1}\right)=2 \times 1.004 \times(381.1-295)=172.9(\mathrm{~kJ} / \mathrm{kg})$$
