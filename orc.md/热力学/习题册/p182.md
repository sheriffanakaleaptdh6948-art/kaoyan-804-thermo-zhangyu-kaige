$$\dot{m}_{1 \text { ,air }}=\omega_{1 \text { ,air }} \dot{m}_{1}=1.23 \times 0.993=1.2214(\mathrm{~kg} / \mathrm{s})$$

$$\dot{m}_{1 \mathrm{~V}}=\omega_{1 \mathrm{~V}} \dot{m}_{1}=1.23 \times 0.007=0.0086(\mathrm{~kg} / \mathrm{s})$$

同样可求得第二股湿空气流的参数为：

$$m_{2, \text { air }}=0.986, \omega_{2, \mathrm{~V}}=0.014, R_{\mathrm{R} 2}=0.289 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K})$$

$$\dot{m}_{2}=0.761 \mathrm{~kg} / \mathrm{s}, \dot{m}_{2 \text { ,air }}=0.7503 \mathrm{~kg} / \mathrm{s}, \omega_{2, \mathrm{~V}}=0.0107 \mathrm{~kg} / \mathrm{s}$$

由湿空气的焓的计算公式 $h=1.005 t+d(2501+1.86 t) \mathrm{k} \mathrm{J} / \mathrm{kg}(\mathrm{a})$, 可得第一股和第二股湿空气每秒流过的焓分别为:

$$H_{1}=m_{1, \mathrm{~A}} h_{1}=1.2214\left[1.005 \times 10+\frac{7}{1000}(2501+1.86 \times 10)\right]=33.82(\mathrm{~kJ})$$

$$H_{2}=m_{2, \mathrm{~A}} h_{2}=0.7503\left[1.005 \times 30+\frac{14}{1000}(2501+1.86 \times 30)\right]=49.48(\mathrm{~kJ})$$

两股湿空气合流后形成的第三股湿空气的质量流量为:

$$\dot{m}_{3}=\dot{m}_{1}+\dot{m}_{2}=1.23+0.761=1.991(\mathrm{~kg} / \mathrm{s})$$

$$\dot{m}_{3, \text { air }}=\dot{m}_{1, \text { air }}+\dot{m}_{2, \text { air }}=1.2214+0.7503=1.9717(\mathrm{~kg} / \mathrm{s})$$

$$\dot{m}_{3, \mathrm{~V}}=\dot{m}_{1, \mathrm{~V}}+\dot{m}_{2, \mathrm{~V}}=0.0086+0.01107=0.0193(\mathrm{~kg} / \mathrm{s})$$

含湿量为:

$$d_{3}=\frac{\dot{m}_{3, \mathrm{~V}}}{\dot{m}_{3, \mathrm{~air}}}=\frac{0.0193}{1.9717}=0.0098[1 / \mathrm{kg}(\mathrm{a})]$$

每秒流过的焓为:

$$H_{3}=H_{1}+H_{2}=33.82+49.48=83.8(\mathrm{~kJ})$$

$$h_{3}=\frac{H_{3}}{m_{3, \text { air }}}=\frac{83.8}{1.9717}=42.25[k] / k g(a)]$$

又由湿空气焓 $h_{3}=1.005 t_{3}+\omega_{3}\left(2501+1.86 t_{3}\right)$ 可得:

$$t_{3}=\frac{h_{3}-\omega_{3} \times 2501}{1.005+\omega_{3} \times 1.86}=\frac{42.25-0.0098 \times 2501}{1.005+0.0098 \times 1.86}=17.3(\mathrm{~K})$$

解法二: 用解法一求得 $\dot{m}_{1, \text { air }}$ 和 $\dot{m}_{2, \text { air }}$ 后, 由质量守恒及湿空气中水蒸气守恒可得:

$$\dot{m}_{1, \text { air }}+\dot{m}_{2, \text { air }}=\dot{m}_{3, \text { air }}$$

$$\dot{m}_{1, \text { air }} d_{1}+\dot{m}_{2, \text { air }} d_{2}=\dot{m}_{3, \text { air }} d_{3}$$

又由能量守恒可知:

$$\dot{m}_{1, \text { air }} h_{1}+\dot{m}_{2, \text { air }} h_{2}=\dot{m}_{3, \text { air }} h_{3}$$

另外湿空气焓计算式:

$$h=1.005 t+d(2501+1.86 t)$$

联立上述两式, 解得含湿量为:

$$d_{3}=9.8 \mathrm{~kg} / \mathrm{a}, h_{3}=42.25 \mathrm{~kJ} / \mathrm{kg}(\mathrm{a}), t_{3}=17.3^{\circ} \mathrm{C}$$

【6-40】(中国科学院——中国科学技术大学 2007 年考研试题)名词解释:绝对湿度与相对湿度。

解:湿空气的绝对湿度是指单位体积湿空气中包含的水蒸气的质量, 也即水蒸气的密度 $\mathrm{g} / \mathrm{m}^{3}$ 。
