### 核心规则

1. 正文公式 — 必须LaTeX
   - 行内公式用`$$...$$`，行间公式用 `$$\begin{aligned} & \text { T } \\ & \text { t }_{1} \\ & \text { t }_{\mathrm{n}} \\ & \text { b } \\ & \text { c } \\ & \text { 3 } \\ & \text { 2 } \end{aligned}$$`

2. 图 — 只留名字，不描述内容（重要）
   - 遇到插图/示意图/曲线图（如 T-s图、p-v图、h-s图、装置图等），**不要识别、不要描述图形内部**，只在图出现的正文位置，输出一行标记：
     - `【图X-X 图名】`

3. 表 — 识别文字内容
   - 表名输出为一行标记：`【表X-X 表名】`
   - 表内若为文字/数据，用Markdown表格识别；若为纯图形/曲线（无文字），只输出表名标记，不硬编

4. 结构保留
   - 保留标题层级：`## 第X章`、`### X.X 节名`、`**例X-X**`、`**解：**` 等
   - 编号、列表保持原文结构

5. 忽略水印/广告 — 绝对不要输出（重要）

### 6. 输出格式
- 纯Markdown，不要用代码块包裹
- 不要加"本页包含""如下图所示"等元评论
- 不要加页码数字
