【4-121】(中国科学院一中国科学技术大学 2009 年考研试题)有人欲发明一种绝热的稳定流动设备,其可将能量分离以输出冷、热流体。假定出口流量 $\dot{m}_{\text {冷 }}=\dot{m}_{\text {热 }}$, 试判断图 4-42 所示的状态参数能否实现?

空气

$\left(\begin{array}{l} 3.1 \times 10^{5} \mathrm{~Pa} \\ 21^{\circ} \mathrm{C} \end{array}\right)$

能量分离器

热空气

$\left(\begin{array}{l} 2.75 \times 10^{5} \mathrm{~Pa} \\ 59^{\circ} \mathrm{C} \end{array}\right)$

冷空气

$\left(\begin{array}{l} 2.75 \times 10^{5} \mathrm{~Pa} \\ 0^{\circ} \mathrm{C} \end{array}\right)$

图 4-42

解:因能量分离装置绝热,因而可将进出口空气流与分离装置一起作为一孤立系统。装置的状态在工作前后不变,其熵变为 0 ,故该孤立系的熵增即等于空气流出口相对于进口的熵变,依据熵的计算式,可得:

$\begin{aligned} \Delta S_{\text {iso }} & =\Delta S_{\text {空气 }}+\Delta S_{\text {装置 }}=\Delta S_{\text {空气 }}=\frac{m}{2}\left(c_{p} \ln \frac{T_{2 \text { 热 }}}{T_{1}}-R_{g} \ln \frac{p_{2 \text { 热 }}}{p_{1}}\right)+\frac{m}{2}\left(c_{p} \ln \frac{T_{2 \text { 冷 }}}{T_{1}}-R_{g} \ln \frac{p_{2 \text { 冷 }}}{p_{1}}\right) \\ & =\frac{m}{2}\left(c_{p} \ln \frac{T_{2 \text { 热 }} T_{2 \text { 冷 }}}{T_{1}^{2}}-R_{g} \ln \frac{p_{2 \text { 热 }} p_{2 \text { 冷 }}}{p_{1}^{2}}\right)=\frac{m}{2}\left(c_{p} \ln \frac{332 \times 273}{294^{2}}-R_{g} \ln \frac{2.75^{2}}{3.1^{2}}\right) \\ & =\frac{m}{2}\left(0.047 c_{p}+0.240 R_{g}\right)>0 \end{aligned}$

故能实现。

【4-122】(中国科学院一中国科学技术大学 2008 年考研试题)分别写出闭口系和开口系的熵方程,并指明其各项的含义。

解:闭口系的熵方程为:

$d S=\delta S_{t}+\delta S_{g}$

即系统的熵变等于熵流加熵产。其中熵流 $\delta S_{t}=\frac{\delta Q}{T}$ 为热流引起的熵变,熵产 $\delta S_{g}$ 为不可逆因素导致的熵变。

开口系的熵方程为:

$d S_{\mathrm{C}, \mathrm{V}}=\delta S_{\mathrm{t}}+\delta m_{\mathrm{in}} s_{\mathrm{in}}-\delta n t_{\mathrm{out}} s_{\mathrm{out}}+\delta S_{\mathrm{g}}$

即系统的熵变等于热流和质量流引起的净熵流加熵产。与闭口系相比,开口系多了质量熵流项 $\delta m_{\text {in }} s_{\text {in }}-\delta m_{\text {out }} s_{\text {out }}$ 。
