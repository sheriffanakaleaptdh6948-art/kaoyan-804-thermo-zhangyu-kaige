【3-42】（西安交通大学 2002 年考研试题）如图 3-16 所示，试在 T-s 图上把理想气体任意状态间的热力学能及焓的变化表示出来。

解:根据理想气体的内能与焓的计算表达式 \(\Delta u = \int_1^2 c_v \, dT\)，\(\Delta h = \int_1^2 c_p \, dT\)，对于定容过程来说，

\[
\frac{dT}{ds} = \frac{T}{c_v}, \text{故：}
\]

\[
\Delta u = \int_1^2 T \, ds
\]

对于定压过程来说，\(\frac{dT}{ds} = \frac{T}{c_p}\)，故：

\[
\Delta h = \int_1^2 T \, ds
\]

所以，内能与焓的变化可以分别利用定容 T-s 曲线和定压 T-s 曲线表示出来如图 3-17 所示。

【3-43】（西安交通大学 2002 年考研试题）已知理想气体的定容比热容 \(c_v = a + bT\)，其中 \(a, b\) 为常数，试导出其热力学能、焓和熵的计算式。

解:因为 \(c_v = a + bT\)，所以有 \(c_p = a + bT + R_g\)。代入 \(\Delta u\)、\(\Delta h\)、\(\Delta s\) 的计算式，可得：

\[
\Delta u = \int_{T_1}^{T_2} c_v \, dT = \int_{T_1}^{T_2} (a + bT) \, dT = a \left( T_2 - T_1 \right) + \frac{b}{2} \left( T_2^2 - T_1^2 \right)
\]

\[
\Delta h = \int_{T_1}^{T_2} c_p \, dT = \int_{T_1}^{T_2} (a + bT + R_g) \, dT = (a + R_g) \left( T_2 - T_1 \right) + \frac{b}{2} \left( T_2^2 - T_1^2 \right)
\]
