【8-16】(哈尔滨工业大学 2002 年考研试题)如图 8-13 所示, 某蒸汽压缩制冷循环, 其蒸发温度为 $-20^{\circ} \mathrm{C}$, 冷凝温度为 $30^{\circ} \mathrm{C}$, 原先制冷剂为氟利昂 12 (CFC12), 现为保护臭氧层改为 HFC134a 作为制冷剂, 查得循环中各点的焓值为: $\mathrm{CFC} 12: h_{1}=564 \mathrm{~kJ} / \mathrm{kg}, h_{2}=592.9 \mathrm{~kJ} / \mathrm{kg}, h_{3}=448 \mathrm{~kJ} / \mathrm{kg}$; $\mathrm{HFC} 134 \mathrm{a}: h_{1}=387 \mathrm{~kJ} / \mathrm{kg}, h_{2}=423 \mathrm{~kJ} / \mathrm{kg}, h_{3}=243 \mathrm{~kJ} / \mathrm{kg}$ 。试计算两种制冷剂为工质时, 制冷量 $q_{2}$ 和制冷系数 $\varepsilon$ 。

解:

(1)若以 $\mathrm{CFC} 12$ 为制冷剂, 则冷凝器中制冷剂与外界的热交换为:

$$q_{1}=h_{3}-h_{2}=-144.9 \mathrm{~kJ} / \mathrm{kg}$$

蒸发器中制冷剂与外界的热交换为:

$$q_{2}=h_{1}-h_{4}=h_{1}-h_{3}=116 \mathrm{~kJ} / \mathrm{kg}$$

则得制冷系数为:

$\varepsilon=\frac{q_{2}}{\left|w_{0}\right|}=\frac{q_{2}}{\left|q_{1}+q_{2}\right|}=\frac{116}{\left|-144.9+116\right|}=4.01$

(2)若以 HFC134a 为制冷剂, 则冷凝器中制冷剂与外界的热交换为:

$$q_{1}=h_{3}-h_{2}=-180 \mathrm{~kJ} / \mathrm{kg}$$

蒸发器中制冷剂与外界的热交换为:

$$q_{2}=h_{1}-h_{4}=h_{1}-h_{3}=144 \mathrm{~kJ} / \mathrm{kg}$$

则得制冷系数为:

$\varepsilon=\frac{q_{2}}{\left|w_{0}\right|}=\frac{q_{2}}{\left|q_{1}+q_{2}\right|}=\frac{144}{\left|-180+144\right|}=4$
