【4-189】(中国石油大学<华东>2005-2006学年第1学期期末考试)有两个任意过程 ab 与 ac , b 及 c 点在同一条可逆热线上,如图 4-61 所示。设工质为理想气体,其比热容为定值。试问 Δuab 与 Δuac 哪个大?为什么?

$$\text { 解: } b \text { 及 } c \text { 点在同一条可逆热线上, } \frac{T_{\mathrm{b}}}{T_{\mathrm{c}}}=\left(\frac{p_{\mathrm{b}}}{p_{\mathrm{c}}}\right)^{\frac{\kappa-1}{\kappa}}, \kappa>1,$$

$$p_{\mathrm{b}}>p_{\mathrm{c}} \text {, 所以: } T_{\mathrm{b}}>T_{\mathrm{c}} \text { 。 }$$

又因为 Δuab = cv(Tb - Ta), Δuac = cv(Tc - Tb), 所以: Δuab > Δuac 。

【4-190】(南京工业大学 2004-2005 学年第 1 学期期末考试)空气由初态压力为 0.1MPa, 温度 20°C, 经 2 级压缩机压缩后, 压力提高到 2MPa。若空气进入各级气缸的温度相同,且各级压缩过程的多变指数均为 1.2, 求最佳的中间压力为多少? 并求生产 1kg 质量的压缩空气所消耗的理论功? 求各级气缸的排气温度为多少?

$$\text { 解: 由题意可知, 最佳中间压力: } p_{2}=\sqrt{p_{1} p_{3}}=\sqrt{0.1 \times 2}=0.447(\mathrm{MPa}) \text { 。 }$$

理论比功:

$$\begin{aligned} w_{\mathrm{c}} & =\frac{n}{n-1} R_{\mathrm{g}} T_{1}\left[\left(\frac{p_{2}}{p_{1}}\right)^{\frac{n-1}{n}}+\left(\frac{p_{3}}{p_{2}}\right)^{\frac{n-1}{n}}-2\right] \\ & =\frac{1.2}{1.2-1} \times 287.06 \times 10^{-3} \times(273.15+20) \times\left[2 \times\left(\frac{0.447}{0.1}\right)^{\frac{1.2-1}{1.2}}-2\right] \\ & =286.2(\mathrm{kJ}) \end{aligned}$$

多变过程: T3/T2′=T2′=p2′/p1′=p2′/p1′。

因为吸气温度 T1=T2′, 所以两级排气温度为:

$$T_{3}=T_{2}=T_{1}\left(\frac{p_{2}}{p_{1}}\right)^{\frac{n-1}{n}}=293.15 \times\left(\frac{0.447}{0.1}\right)^{\frac{1.2-1}{1.2}}=376.25(\mathrm{~K})$$
