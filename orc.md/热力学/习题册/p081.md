【3-174】(吉林大学 2007-2008 学年第 1 学期期末考试题)一个门窗敞开的房间,若室内空气的压力不变而温度升高了,问室内空气的总热力学能怎样变化?比热力学能又怎样变化?

解:室内空气的总热力学能不变,比热力学能增加。

【3-175】(吉林大学 2006-2007 学年第 1 学期期末考试题)两容积相同的刚性容器 A、B 通过阀门相连接,如图 3-52 所示,其中 A 为绝热容器,B 为透热容器。初态时,A 中装有空气,且 \(T_{\text{A1}} = 305 \text{K}, P_{\text{A1}} = 400 \text{kPa}, m_{\text{A1}} = 2 \text{kg}\); 而 B 中为真空。现将阀门打开,使用空气由 A 流入 B,直至 \(P_{\text{A2}} = 300 \text{kPa}\) 时才关闭阀门。周围环境 \(T_0 = 298 \text{K}, P_0 = 100 \text{kPa}\)。求:

(1)两容器的容积;

(2)终态时 B 中空气的温度 \(T_{\text{B2}}\)、质量 \(m_{\text{B2}}\) 及压力 \(P_{\text{B2}}\)。

(3)容器 B 在充气过程中所交换的热量 \(Q\),过程中的 \(S_{\text{ptor}}\) 及 \(I_{\text{tot}}\)。

解:

(1)两容器的容积:

$$V_{\text{A}} = V_{\text{B}} = \frac{m_{\text{A1}} RT_{\text{A1}}}{p_{\text{A1}}} = \frac{2 \times 0.287 \times 305}{400} = 0.438 \, (\text{m}^3)$$

(2)因为刚性容器绝热放气过程中,容器内剩余气体经历定熵过程。则:

$$\frac{T_{\text{A2}}}{T_{\text{A1}}} = \left( \frac{p_{\text{A2}}}{p_{\text{A1}}} \right)^{\frac{k-1}{k}} = \left( \frac{300}{400} \right)^{\frac{0.4}{1.4}} = 0.9211$$

可得:

$$T_{\text{A2}} = 0.9211 T_{\text{A1}} = 0.9211 \times 305 = 281 \, (\text{K})$$

又 \(V_{\text{A}} = \frac{m_{\text{A1}} RT_{\text{A1}}}{p_{\text{A1}}} = \frac{m_{\text{A2}} RT_{\text{A2}}}{p_{\text{A2}}}\),则:

$$m_{\text{A2}} = \frac{T_{\text{A1}}}{T_{\text{A2}}} \times \frac{p_{\text{A2}}}{p_{\text{A1}}} \times m_{\text{A1}} = 0.8142 \times 2 = 1.628 \, (\text{kg})$$

$$m_{\text{B2}} = m_{\text{A1}} - m_{\text{A2}} = 2 - 1.628 = 0.372 \, (\text{kg})$$

由于 B 为透热容器,故有:

$$T_{\text{B2}} = T_0 = 298 \, \text{K}$$

$$p_{\text{B2}} = \frac{m_{\text{B2}} RT_{\text{B2}}}{V_{\text{B}}} = \frac{0.372 \times 0.287 \times 298}{0.438} = 72.7 \, (\text{kPa})$$

(3)以 \(A + B\) 为系统,则: \(\Delta E = (\Delta E)_Q + (\Delta E)_W + (\Delta E)_M\)。
