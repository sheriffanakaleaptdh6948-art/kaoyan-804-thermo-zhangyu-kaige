表 4-1 理想气体可逆过程计算公式 (定值比热容)

|  | 定容过程 |  | 定压过程 |  | 定温过程 |  | 定熵过程 |  | 多变过程 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  | $n=\infty$ |  | $n=0$ |  | $n=1$ |  | $n=\kappa$ |  | $n$ |
| 过程特征 | $v=$ 定值 | $p=$ 定值 | $T=$ 定值 |  |  |  | $s=$ 定值 |  |  |
| $T_{\mathrm{p}} p_{\mathrm{p}} v$ 之间 | $\frac{T_{1}}{P_{1}}=\frac{T_{2}}{P_{2}}$ | $\frac{T_{1}}{v_{1}}=\frac{T_{2}}{v_{2}}$ | $p_{1} v_{1}=p_{2} v_{2}$ | $\begin{aligned} & p_{1} v_{1}^{\kappa}=p_{2} v_{2}^{\kappa} \\ & T_{1} v_{1}^{\kappa-1}=T_{2} v_{2}^{\kappa-1} \\ & T_{1} p_{1}^{\frac{\kappa-1}{\kappa}}=T_{2} p_{2}^{\frac{\kappa-1}{\kappa}} \end{aligned}$ | $\begin{aligned} & p_{1} v_{1}^{n}=p_{2} v_{2}^{n} \\ & T_{1} v_{1}^{n-1}=T_{2} v_{2}^{n-1} \\ & T_{1} p_{1}^{\frac{n-1}{n}}=T_{2} p_{2}^{\frac{n-1}{n}} \end{aligned}$ |  |  |  |  |

| $\Delta u$ | $c_{v}\left(T_{2}-T_{1}\right)$ | $c_{v}\left(T_{2}-T_{1}\right)$ | 0 | $c_{v}\left(T_{2}-T_{1}\right)$ | $c_{v}\left(T_{2}-T_{1}\right)$ |
| --- | --- | --- | --- | --- | --- |
| $\Delta h$ | $c_{p}\left(T_{2}-T_{1}\right)$ | $c_{p}\left(T_{2}-T_{1}\right)$ | 0 | $c_{p}\left(T_{2}-T_{1}\right)$ | $c_{p}\left(T_{2}-T_{1}\right)$ |

| $\Delta s$ | $c_{v} \ln \frac{T_{2}}{T_{1}}$ | $c_{p} \ln \frac{T_{2}}{T_{1}}$ | $\frac{q}{T}$ | $R_{k} \ln \frac{v_{2}}{v_{1}}$ | 0 | $c_{v} \ln \frac{T_{2}}{T_{1}}+R_{\mathrm{g}} \ln \frac{v_{2}}{v_{1}}$ | $c_{p} \ln \frac{T_{2}}{T_{1}}-R_{\mathrm{g}} \ln \frac{p_{2}}{p_{1}}$ | $c_{v} \ln \frac{p_{2}}{p_{1}}+c_{p} \ln \frac{v_{2}}{v_{1}}$ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 比热容 $c$ | $c_{v}=\frac{R_{k}}{\kappa-1}$ | $c_{p}=\frac{\kappa R_{k}}{\kappa-1}$ | $\infty$ | 0 | $\frac{n-\kappa}{n-1} c_{v}$ |  |  |  |

| 过程功 | 0 | $p\left(v_{2}-v_{1}\right)$ | $R_{\mathrm{g}} T \ln \frac{v_{2}}{v_{1}}$ | $\frac{R_{\mathrm{g}}}{\kappa-1}\left(T_{1}-T_{2}\right)$ | $\frac{R_{\mathrm{g}}}{n-1}\left(T_{1}-T_{2}\right)$ |
| --- | --- | --- | --- | --- | --- |
| $w=\int_{1}^{2} p \mathrm{~d} v$ | $R_{\mathrm{g}}\left(T_{2}-T_{1}\right)$ | $R_{\mathrm{g}} T \ln \frac{p_{1}}{p_{2}}$ | $\frac{R_{\mathrm{g}} T_{1}}{\kappa-1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{\frac{\kappa-1}{\kappa}}\right]$ | $\frac{R_{\mathrm{g}} T_{1}}{n-1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{\frac{n-1}{n}}\right]$ |  |

| 技术功 | $v\left(p_{1}-p_{2}\right)$ | 0 | $w_{1}=w$ | $-\Delta h$ | $\frac{n R_{\mathrm{g}}}{n-1}\left(T_{1}-T_{2}\right)$ |
| --- | --- | --- | --- | --- | --- |
| $w_{1}=-\int_{1}^{2} v \mathrm{~d} p$ |  |  |  | $\frac{\kappa R_{\mathrm{g}}}{\kappa-1}\left(T_{1}-T_{2}\right)$ | $\frac{n R_{\mathrm{g}} T_{1}}{n-1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{\frac{n-1}{n}}\right]$ |
|  |  |  |  | $\frac{\kappa R_{\mathrm{g}} T_{1}}{\kappa-1}\left[1-\left(\frac{p_{2}}{p_{1}}\right)^{\frac{\kappa-1}{\kappa}}\right]$ | $w_{1}=n w$ |

| 过程热量 $q$ | $\Delta u$ | $\Delta h$ | $T\left(s_{2}-s_{1}\right)$ |  |  | $\frac{n-\kappa}{n-1} c_{v}\left(T_{2}-T_{1}\right)$ |
