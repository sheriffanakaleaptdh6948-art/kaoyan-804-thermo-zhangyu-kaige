例 10-5 按例 10-3 各参数，若采用二级抽汽回热，抽汽压力分别为 4 MPa 和 0.4 MPa，试求：(1) 抽汽量 α1 和 α2；(2) 汽轮机作功 WT,act 和水泵耗功 Wp 及循环净功 Wnet,act；(3) 循环内部热效率 η1 和实际耗汽率 di；(4) 各过程及循环的不可逆损失。

解 本题装置示意图如图 10-15 所示，T-s 图如图 10-16 所示。

(1) 分别对回热器 R1 及 R2 列热平衡方程式，得

$$\begin{aligned}&(1-\alpha_{1})\left(h_{01}-h_{02}\right)=\alpha_{1}\left(h_{01}-h_{01}^{\prime}\right) \\&\left(1-\alpha_{1}-\alpha_{2}\right)\left(h_{02}-h_{2}^{\prime}\right)=\alpha_{2}\left(h_{02}-h_{02}^{\prime}\right)\end{aligned}$$

所以

$$\alpha_{1}=\frac{h_{01}-h_{02}}{h_{01}-h_{02}^{\prime}}, \quad \alpha_{2}=\frac{\left(1-\alpha_{1}\right)\left(h_{02}-h_{2}^{\prime}\right)}{h_{02}-h_{2}^{\prime}}$$

由状态 1 及 p01 = 4 MPa、p02 = 0.4 MPa，在 h-s 图上查得：ha = 3 010 kJ/kg，hb = 2 552 kJ/kg。由式 (10-6)

$$\begin{aligned}h_{01} & = h_{a} + (1-\eta_{\mathrm{T}})\left(h_{1}-h_{a}\right) \\& = 3010 \mathrm{~kJ} / \mathrm{kg}+(1-0.9) \times(3426 \mathrm{~kJ} / \mathrm{kg}-3010 \mathrm{~kJ} / \mathrm{kg}) \\& = 3051.6 \mathrm{~kJ} / \mathrm{kg}\end{aligned}$$

查饱和水和饱和水蒸气表，得：ho1 = 1 087.2 kJ/kg，ho2 = 604.87 kJ/kg，h2' = 137.72 kJ/kg。所以

$$\begin{gathered}\alpha_{1}=\frac{h_{01}-h_{02}}{h_{01}-h_{02}}=\frac{1087.2 \mathrm{~kJ} / \mathrm{kg}-604.87 \mathrm{~kJ} / \mathrm{kg}}{3051.6 \mathrm{~kJ} / \mathrm{kg}-604.87 \mathrm{~kJ} / \mathrm{kg}}=0.1971 \\\alpha_{2}=\frac{\left(1-\alpha_{1}\right)\left(h_{02}-h_{2}^{\prime}\right)}{h_{02}-h_{2}^{\prime}}=\frac{(1-0.1971) \times(604.87 \mathrm{~kJ} / \mathrm{kg}-137.72 \mathrm{~kJ} / \mathrm{kg})}{2639.4 \mathrm{~kJ} / \mathrm{kg}-137.72 \mathrm{~kJ} / \mathrm{kg}}=0.1499\end{gathered}$$
