8-1 某单级活塞式压气机每小时吸入的空气量 V1 = 140 m3，吸入空气的状态参数是 p1 = 0.1 MPa、t1 = 27 °C，输出空气的压力 p2 = 0.6 MPa。试按下列三种情况计算压气机所需要的理想功率（以 kW 表示）：(1) 定温压缩；(2) 绝热压缩（设 κ = 1.4）；(3) 多变压缩（设 n = 1.2）。

8-2 某单级活塞式压气机吸入空气参数为 p1 = 0.1 MPa、t1 = 50 °C、V1 = 0.032 m3，经多变压缩 p2 = 0.32 MPa、V2 = 0.012 m3。求：(1) 压缩过程的多变指数；(2) 压缩终了空气温度；(3) 所需压缩功；(4) 压缩过程中传出的热量。

8-3 压气机中气体压缩后的温度不宜过高，若取极限值为 150 °C。某单缸压气机吸入空气的压力和温度为 p1 = 0.1 MPa、t1 = 20 °C，吸气量为 250 m3/h，若压气机中缸套流过冷却水 465 kg/h，温升为 14 °C。求：(1) 空气可能达到的最高压力；(2) 压气机必需的功率。
