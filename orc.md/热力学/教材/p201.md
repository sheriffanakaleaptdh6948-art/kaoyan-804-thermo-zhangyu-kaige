$I_{2}=e_{x, Q_{1}, T_{1}}-w_{\text {net }}-e_{x, Q_{2}, T_{2}}=52 \mathrm{~kJ} / \mathrm{kg}-40 \mathrm{~kJ} / \mathrm{kg}-2.4 \mathrm{~kJ} / \mathrm{kg}=9.6 \mathrm{~kJ} / \mathrm{kg}$

(3) 由 \(T_{2} \rightarrow T_{0}\)，不可逆传热的㶲损失为

$I_{3}=e_{x, Q_{2}, T_{2}}-e_{x, Q_{2}, T_{0}}=2.4 \mathrm{~kJ} / \mathrm{kg}-0=2.4 \mathrm{~kJ} / \mathrm{kg}$

整个系统的㶲损失为

$I=I_{1}+I_{2}+I_{3}=25.8 \mathrm{~kJ} / \mathrm{kg}+9.6 \mathrm{~kJ} / \mathrm{kg}+2.4 \mathrm{~kJ} / \mathrm{kg}=37.8 \mathrm{~kJ} / \mathrm{kg}$

讨论：(1) 对照例 5-9，㶲分析法得到的结果和熵分析法相同。(2) 实际循环比可逆循环少作功 \(w_{\mathrm{c}}-w_{\text {net }}=(50-40) \mathrm{kJ} / \mathrm{kg}=10 \mathrm{~kJ} / \mathrm{kg}\)，而㶲损失 \(I_{3}=\) \(9.6 \mathrm{~kJ} / \mathrm{kg}\)，即 \(w_{\mathrm{c}}-w_{\text {net }} \neq I_{3}\) 。这是因为可逆机放热量为 \(50 \mathrm{~kJ} / \mathrm{kg}\)，其中热量㶲为

$\left(1-\frac{T_{0}}{T_{2}}\right) q_{2, r}=\left(1-\frac{288 \mathrm{~K}}{300 \mathrm{~K}}\right) \times 50 \mathrm{~kJ} / \mathrm{kg}=2.0 \mathrm{~kJ} / \mathrm{kg}$

而不可逆机放热量为 \(60 \mathrm{~kJ} / \mathrm{kg}\)，其中热量㶲为 \(20.4 \mathrm{~kJ} / \mathrm{kg}\)，不可逆机多放出的 \(10 \mathrm{~kJ} / \mathrm{kg}\) 热量中尚有热量㶲 \(0.4 \mathrm{~kJ} / \mathrm{kg}\)，故㶲损失要比少作的功小 \(0.4 \mathrm{~kJ} / \mathrm{kg}\) 。
