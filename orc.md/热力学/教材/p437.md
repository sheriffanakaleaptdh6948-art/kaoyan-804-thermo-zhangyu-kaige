bB + dD ⇌ gG + rR

当反应达到平衡时, $w_{1} = w_{2}$, 所以若令 $K_{c} = \frac{k_{1}}{k_{2}}$, 称为平衡常数, 则

$K_{c} = \frac{k_{1}}{k_{2}} = \frac{c_{\mathrm{G}}^{g} c_{\mathrm{R}}^{r}}{c_{\mathrm{B}}^{b} c_{\mathrm{D}}^{d}}$

如果, $k_{1} \gg k_{2}$, 即 $K_{c}$ 很大, 则自左向右的反应可以进行得接近完全, 达到平衡时只留下很少量的 B 和 D; 反之, 当 $k_{1} \ll k_{2}$, 即 $K_{c}$ 很小时, 则自右向左的反应可以接近完全。对于一定的反应, 如果参加反应的物质都为理想气体或很接近理想气体, 则平衡常数 $K_{c}$ 的数值只随反应时物系的温度 $T$ 而定。

对于理想气体反应物系, 把理想气体状态方程式 $p_{i} V = n_{i} RT$ 代入浓度定义式, 有

$c_{i} = \frac{n_{i}}{V} = \frac{p_{i}}{RT}$

即气体的浓度 $c_{i}$ 与气体的分压力 $p_{i}$ 成正比。将之代入式 (13-15), 可得

$K_{c} = \frac{c_{\mathrm{G}}^{g} c_{\mathrm{R}}^{r}}{c_{\mathrm{B}}^{b} c_{\mathrm{D}}^{d}} = \frac{p_{\mathrm{G}}^{g} p_{\mathrm{R}}^{r}}{p_{\mathrm{B}}^{b} p_{\mathrm{D}}^{d}} (RT)^{g+(r-b-d)} = K_{p} (RT)^{-\Delta n}$

式中

$K_{p} = \frac{p_{\mathrm{G}}^{g} p_{\mathrm{R}}^{r}}{p_{\mathrm{B}}^{b} p_{\mathrm{D}}^{d}}$

是用气体分压力表示的平衡常数, 和 $K_{c}$ 一样, $K_{p}$ 的数值也只随反应物系的温度而定; $\Delta n = g + r - b - d$, 是反应前后物系物质的量的变化值。从式 (13-16) 可以看出, 在 $\Delta n = 0$ 时, $K_{c} = K_{p}$ 。

把各种气体的分压力与反应物系的总压力的关系 $p_{i} = x_{i} p = \frac{n_{i}}{n} p$ (其中 $n$ 为化学平衡时反应物系的总物质的量; $n_{i}$ 为第 $i$ 种物质的量; $x_{i}$ 是第 $i$ 种气体的摩尔分数) 代入式 (13-17) 得

$K_{p} = \frac{n_{\mathrm{G}}^{g} n_{\mathrm{R}}^{r}}{n_{\mathrm{B}}^{b} n_{\mathrm{D}}^{d}} \left( \frac{p}{n} \right)^{g + r - b - d}$

这是化学平衡计算的重要公式。当反应物系中有惰性气体存在时, 例如燃烧物系中有氮气存在时, 总物质的量 $n$ 中应包括惰性气体的物质的量。

式 (13-15) 和式 (13-17) 都只适用于反应物系中的物质为理想气体的单相化学反应。若反应中有固体和液体, 例如

$\mathrm{C} + \mathrm{CO}_{2} \rightleftharpoons 2 \mathrm{CO}$

这时认为是由于固体 (或液体) 的升华 (或蒸发) 产生了气态物质与参与反应的
