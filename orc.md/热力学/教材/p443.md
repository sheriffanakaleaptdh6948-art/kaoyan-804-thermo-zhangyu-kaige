# 一、定温定容反应和定温定压反应方向判据和平衡条件

孤立系统熵增原理 dS is $\geqslant$ 0 指出，孤立系的熵只能增大而不会减少，在未达平衡前系统必定向着熵增加的方向变化，当熵为最大值时系统的状态不再改变而达到平衡态，所以孤立系统熵增原理指出了孤立系统自发变化的方向 (dS is > 0) 和实现平衡的条件 (dS is = 0)。孤立系统熵增原理具有极大的概括性，在热力学中占有重要的地位。但孤立系统的熵增原理需把所有发生变化的有关物体取成孤立系，有时实际应用不方便。尤其是大量化学反应常常在定温定压或定温定容下进行，需要导出定温定压和定温定容下的平衡判据。下面从孤立系统熵增原理导出定温定容过程的平衡判据。

热力学第二定律的数学表达式为

$\mathrm{dS} \geqslant \frac{\delta Q}{T}$

式中，dS 是系统的微元熵变，T 是与系统进行热量交换的外界热源温度，δQ 是微元过程中系统和外界交换的热量。据热力学第一定律，物系在反应中的能量方程式为 δQ = dU + δWtot，代入上式可得

$\mathrm{dS} \geqslant \frac{\mathrm{dU}+\delta W_{\text {tot }}}{T}$

考虑到过程中温度 T 为常数，且平衡时系统与外热源达到热平衡，二者温度相等，所以 T = Tr = 常数。此时

$\mathrm{dS} \geqslant \frac{\mathrm{dU}+\delta W_{\text {tot }}}{T}$

上式整理移项并注意到温度为定值，则

$\mathrm{dU}-\mathrm{TdS}=\mathrm{dU}-\mathrm{d}(\mathrm{TS})=\mathrm{d}(\mathrm{U}-\mathrm{TS}) \leqslant-\delta W_{\text {tot }}$

把亥姆霍兹函数函数 (即自由能，亦称定容位) F = U - TS 代入上式，有

$\begin{gathered}-\mathrm{d} F_{\mathrm{T}} \geqslant \delta W_{\text {tot }} \\F_{1}-F_{2} \geqslant W_{\text {tot }}\end{gathered}$

$F_{1}-F_{2} \geqslant W_{\mathrm{u}, \mathrm{v}}$
