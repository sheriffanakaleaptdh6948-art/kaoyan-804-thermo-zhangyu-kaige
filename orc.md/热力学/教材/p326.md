状态 3:

$p_{3}=1400 \mathrm{kPa} 、 T_{3}=1600 \mathrm{~K}$

状态 $4^{\prime}$ :

$p_{4}=100 \mathrm{kPa}$

$T_{4}=T_{3}\left(\frac{p_{4}}{p_{3}}\right)^{\frac{\kappa-1}{\kappa}}=T_{3}\left(\frac{1}{\pi}\right)^{\frac{\kappa-1}{\kappa}}=1600 \mathrm{~K} \times\left(\frac{1}{14}\right)^{\frac{1.4-1}{1.4}}=752.8 \mathrm{~K}$

$T_{4^{\prime}}=T_{3}-\eta_{\mathrm{T}}\left(T_{3}-T_{4}\right)=1600 \mathrm{~K}-0.88 \times(1600 \mathrm{~K}-752.8 \mathrm{~K})=854.5 \mathrm{~K}$

循环中 $1 \mathrm{~kg}$ 工质的吸热量、压气机内耗功、燃气轮机输出功及循环净功

$w_{\mathrm{C}}=h_{2^{\prime}}-h_{1}=c_{p}\left(T_{2^{\prime}}-T_{1}\right)=1.005 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}) \times(697.2 \mathrm{~K}-300 \mathrm{~K})=399.2 \mathrm{~kJ} / \mathrm{kg}$

$w_{\mathrm{T}}=h_{3}-h_{4^{\prime}}=c_{p}\left(T_{3}-T_{4^{\prime}}\right)=1.005 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}) \times(1600 \mathrm{~K}-854.5 \mathrm{~K})=749.2 \mathrm{~kJ} / \mathrm{kg}$

$w_{\text {net }}=w_{\mathrm{T}}-w_{\mathrm{C}}=749.2 \mathrm{~kJ} / \mathrm{kg}-399.2 \mathrm{~kJ} / \mathrm{kg}=350.0 \mathrm{~kJ} / \mathrm{kg}$

$q_{1}=h_{3}-h_{2^{\prime}}=c_{p}\left(T_{3}-T_{2^{\prime}}\right)=1.005 \mathrm{~kJ} /(\mathrm{kg} \cdot \mathrm{K}) \times(1600-697.2) \mathrm{K}=907.3 \mathrm{~kJ} / \mathrm{kg}$

循环工质流量

$q_{m}=\frac{P}{w_{\text {net }}}=\frac{100000 \mathrm{kW}}{350.0 \mathrm{~kJ} / \mathrm{kg}}=285.7 \mathrm{~kg} / \mathrm{s}$

压气机功率

$P_{\mathrm{C}}=q_{m} w_{\mathrm{C}}=285.7 \mathrm{~kg} / \mathrm{s} \times 399.2 \mathrm{~kJ} / \mathrm{kg}=114051.4 \mathrm{kW}$

燃气轮机功率

$P_{\mathrm{T}}=q_{m} w_{\mathrm{T}}=285.7 \mathrm{~kg} / \mathrm{s} \times 749.2 \mathrm{~kJ} / \mathrm{kg}=214046.4 \mathrm{kW}$

热流量

$q_{Q 1}=q_{m} q_{1}=285.7 \mathrm{~kg} / \mathrm{s} \times 907.3 \mathrm{~kJ} / \mathrm{kg}=259219.6 \mathrm{kW}$

循环热效率

$\eta_{1}=\frac{P_{\mathrm{T}}-P_{\mathrm{C}}}{q_{Q 1}}=\frac{214046.4 \mathrm{kW}-114051.4 \mathrm{kW}}{259219.6 \mathrm{kW}}=0.386$
