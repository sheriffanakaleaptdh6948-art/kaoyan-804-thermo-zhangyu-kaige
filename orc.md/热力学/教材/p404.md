$p_{\mathrm{a}}=p-p_{\mathrm{v}}=101300 \mathrm{~Pa}-2544.6 \mathrm{~Pa}=98755.4 \mathrm{~Pa}$

干空气质量

$m_{\mathrm{a}}=\frac{p_{\mathrm{a}} V}{R_{\mathrm{g}, \mathrm{a}} T}=\frac{98755.4 \mathrm{~Pa} \times 50 \mathrm{~m}^{3}}{287 \mathrm{~J} /(\mathrm{kg} \cdot \mathrm{K}) \times(30+273) \mathrm{K}}=56.78 \mathrm{~kg}$

水蒸气质量

$m_{\mathrm{v}}=d m_{\mathrm{a}}=0.0160 \mathrm{~kg}(\text { 水蒸气 }) / \mathrm{kg}(\text { 干空气 }) \times 56.78 \mathrm{~kg}(\text { 干空气 })=0.91 \mathrm{~kg}$

将 $t=30{ }^{\circ} \mathrm{C}$ 代入式 $(12-34)$, 得湿空气的比焓

$h=71.06 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })$

湿空气的总焓

$H=m_{\mathrm{a}} h=56.78 \mathrm{~kg}(\text { 干空气 }) \times 71.06 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })=4034.8 \mathrm{~kJ}$

讨论：(1) 与湿空气的分压力对应的饱和温度即为露点，因此含湿量相等 (总压力相同) 的湿空气的露点相同。(2) 水蒸气比焓的确定有三种方法：(1) 由 $t=30{ }^{\circ} \mathrm{C} 、 p_{\mathrm{v}}=2544.6 \mathrm{~Pa}$, 过热蒸汽表中查得 $h_{\mathrm{v}}=2556.8 \mathrm{~kJ} / \mathrm{kg}$; (2) 取 $h_{\mathrm{v}}$ 近似等 $t=30{ }^{\circ} \mathrm{C}$ 的饱和水蒸气焓, 在饱和水蒸气表中查得 $h_{\mathrm{v}}=2556.4 \mathrm{~kJ} / \mathrm{kg}$; (3) 由经验公式 $h_{\mathrm{v}}=2501+1.86 t$, 代入 $t=30{ }^{\circ} \mathrm{C}$, 得 $h_{\mathrm{v}}=2556.8 \mathrm{~kJ} / \mathrm{kg}$ 。温度较低时, 三种方法的结果基本一致。

例 12-4 若上例中湿空气定压冷却到 $10{ }^{\circ} \mathrm{C}$, 求凝水量 $\Delta m_{\mathrm{v}}$ 和放热量。

解 终态温度 $t_{2}=10{ }^{\circ} \mathrm{C}$ 低于露点, 故终态为饱和湿空气。湿空气冷却到 $t_{\mathrm{d}}=21.36{ }^{\circ} \mathrm{C}$ 达到饱和, 再继续冷却就会有凝水析出。凝水量等于初、终态湿空气中含有水蒸气量的差值。

由 $t_{2}=10{ }^{\circ} \mathrm{C}$, 在饱和水蒸气表中查出 $p_{\mathrm{s}}=1227.9 \mathrm{~Pa}, p_{\mathrm{v}, 2}=p_{\mathrm{s}}=1227.9 \mathrm{~Pa}$ 。终态含湿量

$\begin{aligned} d_{2} & =0.622 \frac{p_{\mathrm{v}}}{p-p_{\mathrm{v}}}=0.622 \times \frac{1227.9 \mathrm{~Pa}}{101300 \mathrm{~Pa}-1227.9 \mathrm{~Pa}} \\ & =0.00763 \mathrm{~kg}(\text { 水蒸气 }) / \mathrm{kg}(\text { 干空气 }) \end{aligned}$

凝水量

$\begin{aligned} \Delta m_{\mathrm{v}} & =m_{\mathrm{a}}\left(d_{2}-d_{1}\right) \\ & =56.78 \mathrm{~kg}(\text { 干空气 }) \times(0.0160-0.00763) \mathrm{kg}(\text { 水蒸气 }) / \mathrm{kg}(\text { 干空气 }) \\ & =0.475 \mathrm{~kg} \end{aligned}$

$t=10{ }^{\circ} \mathrm{C}$ 代入式 $(12-34)$ 计算得终态湿空气比焓

$h_{2}=29.27 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })$

定压冷却过程湿空气的放热量 $Q=m_{\mathrm{a}}\left(h_{1}-h_{2}\right)$, 上题已得出 $h_{1}=71.06 \mathrm{~kJ} / \mathrm{kg}$ (干空气), $m_{\mathrm{a}}=56.78 \mathrm{~kg}$ 。因此

$Q=56.78 \mathrm{~kg}(\text { 干空气 }) \times[71.06 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })-29.27 \mathrm{~kJ} / \mathrm{kg}(\text { 干空气 })]$
