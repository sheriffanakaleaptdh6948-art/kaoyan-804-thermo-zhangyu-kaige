水蒸气的比焓也有足够精确的经验公式

$\left\{h_{v}\right\}_{\mathrm{kJ} / \mathrm{kg}}\left(\text { 水蒸气 }\right)=2501+1.86\left\{t\right\}_{\mathrm{C}}$

式中, 2501 kJ/(kg·K) 是 0 °C 时饱和水蒸气的焓值, 而常温低压下水蒸气的平均质量定压热容可取 1.86 kJ/(kg·K)。将 \(h_{\mathrm{a}}\) 和 \(h_{\mathrm{v}}\) 的计算式代入式 (12-33), 得

$h=1.005 t+d(2501+1.86 t) \quad \mathrm{kJ} / \mathrm{kg}(\text { 干空气 })$

式中: \(t\) 单位为 °C; \(d\) 单位为 kg(水蒸气)/kg(干空气)。

水蒸气比焓 \(h_{\mathrm{v}}\) 的精确值, 可由水蒸气图表中查得。为了简便, 通常以温度为 \(t\) 的饱和水蒸气焓 \(h^{\prime \prime}\) 代替, 即取 \(h_{\mathrm{v}} \approx h^{\prime \prime}(t)\) 。温度不太高时误差极微 (\(t=100^{\circ} \mathrm{C}\) 时, 误差不超过 0.3%) , 因此湿空气的比焓也近似可由下式确定

$h=1.005 t+d h^{\prime \prime} \quad \mathrm{kJ} / \mathrm{kg}(\text { 干空气 })$

四、湿空气的比体积

1 kg 干空气和 \(d \mathrm{~kg}\) 水蒸气组成的湿空气的体积, 称为湿空气的比体积, 用 \(v\left(\mathrm{~m}^{3} / \mathrm{kg}\right.\) 干空气) 表示:

$v=\frac{R_{\mathrm{g}} T}{d}=\frac{R_{\mathrm{g}}}{d}(1+d)^{d}$

式中, \(R_{\mathrm{g}}\) 为湿空气的气体常数

$R_{\mathrm{g}}=\sum w_{i} R_{\mathrm{g}, i}=\frac{1}{1+d} R_{\mathrm{g}, \mathrm{a}}+\frac{d}{1+d} R_{\mathrm{g}, \mathrm{v}}=\frac{R_{\mathrm{g}, \mathrm{a}}+R_{\mathrm{g}, \mathrm{v}}}{1+d}$

例 12-3 房间的容积为 \(50 \mathrm{~m}^{3}\), 室内空气温度 \(30^{\circ} \mathrm{C}\), 相对湿度为 \(60 \%\), 大气压力 \(p_{\mathrm{b}}=0.1013 \mathrm{MPa}\), 求湿空气的露点温度 \(t_{\mathrm{d}}\) 、含湿量 \(d\) 、干空气质量 \(m_{\mathrm{a}}\) 、水蒸气质量 \(m_{\mathrm{v}}\) 及湿空气的焓值 \(H\) 。

解 由饱和水蒸气表或附表 14 查得 \(t=30^{\circ} \mathrm{C}\) 时 \(p_{\mathrm{s}}=4241 \mathrm{~Pa}\), 所以

$p_{\mathrm{v}}=\varphi p_{\mathrm{s}}=0.6 \times 4241 \mathrm{~Pa}=2544.6 \mathrm{~Pa}$

与此分压力对应的饱和温度即为湿空气的露点温度, 从上述表中可查得 \(t_{\mathrm{d}}=21.36^{\circ} \mathrm{C}\) 。
