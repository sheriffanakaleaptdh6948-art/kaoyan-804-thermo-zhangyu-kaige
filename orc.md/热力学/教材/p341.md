与燃气轮机相仿，汽轮机内蒸汽实际作功 $w_{\mathrm{T}, \text { act }}$ 与理论功 $w_{\mathrm{T}}$ 的比值称为汽轮机的相对内效率，简称汽(轮)机效率，以 $\eta_{\mathrm{T}}$ 表示，则

$\eta_{\mathrm{T}}=\frac{w_{\mathrm{T}, \text { act }}}{w_{\mathrm{T}}}=\frac{h_{1}-h_{2}, \text { act }}{h_{1}-h_{2}}$

这样

$h_{2, \text { act }}=h_{2}+\left(1-\eta_{\mathrm{T}}\right)\left(h_{1}-h_{2}\right)=h_{2}+\left(1-\eta_{\mathrm{T}}\right) \Delta h_{0}$

式中，$\Delta h_{0}=h_{1}-h_{2}$ 称为理想绝热焓降。汽轮机相对内效率 $\eta_{\mathrm{T}}$ 由生产厂据大量试验结果提供，近代大功率汽轮机的 $\eta_{\mathrm{T}}$ 在 $0.85 \sim 0.92$ 之间。

1 kg 蒸汽在实际工作循环中作出的循环净功称为实际循环内部功，用 $w_{\mathrm{net}, \text { act }}$ 表示，$w_{\mathrm{net}, \text { act }}=w_{\mathrm{T}, \text { act }}-w_{\mathrm{P}, \text { act }}$。如忽略水泵功，

$w_{\mathrm{net}, \text { act }} \approx w_{\mathrm{T}, \text { act }}=h_{1}-h_{2, \text { act }}$

则循环内部热效率 $\eta_{i}$ ——蒸汽在实际循环中所作的循环净功与循环中热源所供给的热量的比值，为

$\eta_{i}=\frac{w_{\mathrm{net}, \text { act }}}{q_{1}}=\frac{h_{1}-h_{2, \text { act }}}{h_{1}-h_{2}^{\prime}}=\frac{h_{1}-h_{2, \text { act }}}{h_{1}-h_{2}}=\frac{h_{1}-h_{2}}{h_{1}-h_{2}^{\prime}}=\eta_{\mathrm{T}} \eta_{1}$

若进一步再考虑轴承等处的机械损失，则汽轮机输出的有效功，即轴功为

$w_{s}=\eta_{\mathrm{m}} w_{\mathrm{T}, \text { act }}$

其中，$\eta_{\mathrm{m}}$ 为机械效率。将式 $(10-5)$ 代入，得

$w_{\mathrm{s}}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} w_{\mathrm{T}}$

或用轴功率表示：

$P_{\mathrm{s}}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} P_{0}=\eta_{\mathrm{m}} \eta_{\mathrm{T}} \frac{D\left(h_{1}-h_{2}\right)}{3600}$

上式是忽略水泵功时循环输出净功率表达式。式中：$P_{0}=D\left(h_{1}-h_{2}\right) / 3600$ 是汽轮机理想输出功率，W；$D$ 为蒸汽消耗量，$\mathrm{kg} / \mathrm{h}$。

以实际内部功率 $P_{\mathrm{i}}$ 为基准时的耗汽率，称内部功耗汽率，用 $d_{\mathrm{i}}$ 表示：

$d_{\mathrm{i}}=\frac{D}{P_{\mathrm{i}}}=\frac{1}{h_{1}-h_{2, \text { act }}}=\frac{1}{\eta_{\mathrm{T}}\left(h_{1}-h_{2}\right)}=\frac{d_{0}}{\eta_{\mathrm{T}}}$

若考虑有效功，则有效功耗汽率

$d_{\mathrm{e}}=\frac{D}{P_{\mathrm{s}}}=\frac{1}{P_{0} \eta_{\mathrm{T}} \eta_{\mathrm{m}}}=\frac{d_{0}}{\eta_{\mathrm{T}} \eta_{\mathrm{m}}}$
