其他各点焱值可通过类似计算或查有关水和水蒸气图表, 如焓焩图获得, 同列于参数表内。

焓分析的基本依据是焓平衡方程: 进入系统的焓减去离开系统的焓减去系统焓损失等于系统焓增量。对于稳定流动系统, 可简化成: 焓损失 $=$ 进入系统的焓-离开系统的焓。其中焓损失是工质在设备内部经历不可逆过程的内部焓损失和由于泄漏、散热等造成的外部焓损失的总和。

同时, 以焓效率 $\eta_{e x}$ 来评定设备的热力学完善程度。本例中对于汽轮机进行绝热过程时, 定义其焓效率

$\eta_{e_{x}, \mathrm{r}}=\frac{\text { 实际输出的轴功率 }}{\text { 设备进出口工质的焓值差 }}=\frac{w_{\mathrm{T}}}{e_{x, \mathrm{in}}-e_{x, \mathrm{out}}}$

对于无功量输入或输出的设备, 如锅炉、冷凝器等, 定义

$\eta_{e_{x}}=\frac{\text { 流出设备的工质焓 }}{\text { 流入设备的工质焓 + 热量焓 }}=\frac{e_{x, \text { out }}}{e_{x, \mathrm{in}}+e_{x, q}}$

(1) 锅炉

进入锅炉的焓有给水带入的焓值 $e_{x, 4}$ 和烟气供给水和水蒸气的热量 $Q_{1}$ 中的热量焓 $E_{x, q}$; 离开设备的工质是状态 1 的过热蒸汽, 它带走焓值为 $e_{x, 1}$ 。据焓平衡方程, 产生 $1 \mathrm{~kg}$ 蒸汽, 锅炉内过程的焓损失为:

$I_{\mathrm{B}}=E_{x, 4}+E_{x, q}-E_{x, 1}$

$=1 \mathrm{~kg} \times 17.22 \mathrm{~kJ} / \mathrm{kg}+2331.75 \mathrm{~kJ}-1 \mathrm{~kg} \times 1510.60 \mathrm{~kJ} / \mathrm{kg}=838.37 \mathrm{~kJ}$

焓损占烟气焓值的百分率为

$\frac{I_{\mathrm{B}}}{E_{x, q}}=\frac{838.37 \mathrm{~kJ} / \mathrm{kg}}{2331.75 \mathrm{~kJ} / \mathrm{kg}}=35.95 \%$

锅炉的焓效率

$\eta_{e_{x}, B}=\frac{E_{x, 1}}{E_{x, 4}+E_{x, q}}=\frac{1 \mathrm{~kg} \times 1510.60 \mathrm{~kJ} / \mathrm{kg}}{1 \mathrm{~kg} \times 17.22 \mathrm{~kJ} / \mathrm{kg}+2331.75 \mathrm{~kJ}}=64.30 \%$
